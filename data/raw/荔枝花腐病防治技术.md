# 荔枝花腐病防治技术

## 摘要

荔枝花腐病是花期重要的病害之一，主要由炭疽菌、灰霉菌及立枯丝核菌等引起，导致花穗腐烂、花朵败育，严重影响坐果率。该病在花期遇阴雨天气时暴发性强，是荔枝丰产的关键限制因素。本文系统阐述花腐病的病原、发病规律、诊断和防治技术。

## 1. 病原生物学

荔枝花腐病为多病原复合病害，不同病原菌引起不同的花腐类型：

| 病原菌 | 花腐类型 | 症状特点 |
|-------|---------|---------|
| *Colletotrichum* spp. | 炭疽型花腐 | 花穗褐色腐烂，有黑色小点 |
| *Botrytis cinerea* | 灰霉型花腐 | 花穗表面灰色霉层 |
| *Rhizoctonia solani* | 立枯丝核菌型 | 花穗缢缩腐烂 |
| *Pestalotiopsis* spp. | 黑盘孢型 | 花穗有黑色小点 |

## 2. 发病规律

花腐病在荔枝花期（3-5 月）发生，病菌以菌丝体和分生孢子在病残花穗上越冬。翌年春季，在温暖多雨的条件下，孢子借风雨传播，侵染花穗。

### 2.1 症状特征

| 症状类型 | 描述 |
|---------|------|
| 花穗腐烂 | 花穗基部褐色腐烂，逐渐向上蔓延 |
| 花朵褐变 | 花朵呈褐色，干枯脱落 |
| 霉层出现 | 潮湿条件下，病部产生霉层 |
| 整穗枯死 | 严重时整穗枯死，无花无果 |

### 2.2 发病与环境条件

| 条件 | 影响 | 阈值 |
|-----|------|------|
| 花期阴雨 | 重发 | 连续降雨 >3 天 |
| 湿度 >85% | 孢子萌发 | 饱和湿度最利 |
| 温度 20-28 ℃ | 病菌繁殖 | 花期温度范围 |
| 花穗过密 | 加重 | 通风不良 |
| 偏施氮肥 | 加重 | 花穗柔嫩 |

## 3. 诊断技术

### 3.1 田间诊断要点

- 花穗基部最先受害，逐渐向上扩展。
- 潮湿条件下病部产生霉层（灰色或黑色）。
- 病花穗呈褐色，花蕾不开放即枯死。
- 干燥后病穗干枯挂在树上。

### 3.2 与生理性落花区分

| 项目 | 花腐病 | 生理性落花 |
|-----|--------|-----------|
| 病部霉层 | 有 | 无 |
| 发病部位 | 花穗基部开始 | 随机 |
| 天气关系 | 阴雨后暴发 | 高温干旱 |
| 病部气味 | 腐臭 | 无 |

## 4. 防治技术

### 4.1 农业防治

- **清园**：冬季清除病残花穗和落叶，减少菌源。
- **修剪**：疏除过密花穗，改善通风。
- **控梢**：花期前避免促梢，减少养分竞争。
- **施肥**：花期增施磷钾肥，提高抗病力。
- **排水**：花期避免积水。

### 4.2 花期化学防治

| 时期 | 药剂 | 稀释倍数 | 用途 |
|-----|------|---------|------|
| 花穗露白期 | 嘧霉胺 50% | 1500-2000 倍 | 保护花穗 |
| 开花初期 | 苯醚甲环唑 10% | 2000-3000 倍 | 保护花朵 |
| 花期阴雨前 | 代森锰锌 80% | 600-800 倍 | 雨前保护 |
| 开花盛期 | 嘧菌酯 25% | 2000-3000 倍 | 补充保护 |
| 花期结束后 | 苯醚甲环唑 | 2000-3000 倍 | 幼果保护 |

### 4.3 物理防治

- **套袋**：花穗期套袋隔离风雨，减少侵染。
- **避雨栽培**：花期搭避雨棚，降低湿度。

### 4.4 综合防治技术路线

```
清园 → 花穗露白期保护 → 开花期重点保护 → 雨前应急 → 花期结束幼果保护
```

### 4.5 注意事项

- 花期喷药宜在上午露水干后或下午进行。
- 避免在花朵开放最盛时大量喷施，减少对授粉昆虫的影响。
- 药剂应选用对蜜蜂低毒的种类。
- 雨前 3-4 h 喷施保护性杀菌剂效果最好。
