# 荔枝施肥量计算方法

## 摘要

科学计算施肥量是实现荔枝精准施肥的核心环节。本文系统阐述荔枝施肥量的计算原理、公式及方法，包括基于目标产量的施肥量计算、基于土壤养分离缺的施肥量计算、基于叶片诊断的施肥量计算以及氮磷钾比例配伍方法，为荔枝园科学施肥提供量化计算依据。

## 1. 施肥量计算原理

### 1.1 基本原理

| 原理 | 说明 |
|------|------|
| 养分平衡法 | 需肥量=作物吸收量-土壤供肥量+损失量 |
| 目标产量法 | 以目标产量推算总需肥量 |
| 土壤供肥力法 | 根据土壤养分含量计算土壤供给量 |
| 肥料利用率法 | 考虑肥料利用率折减实际施用量 |
| 养分比例法 | 根据作物养分比例配伍NPK |

### 1.2 基本公式

| 公式名称 | 公式 |
|----------|------|
| 作物需肥量 | 作物需肥量(kg)=目标产量(kg)×经济系数⁻¹×养分含量(%) |
| 土壤供肥量 | 土壤供肥量(kg)=土壤养分含量(mg/kg)×土层体积(m³)×利用率(%) |
| 施肥量 | 施肥量(kg)=需肥量(kg)÷肥料养分含量(%)÷肥料利用率(%) |
| 折纯施肥量 | 折纯施肥量(kg)=施肥量(kg)×肥料养分含量(%) |

## 2. 基于目标产量的施肥量计算

### 2.1 荔枝养分吸收参数

| 品种 | 经济系数 | 产量(kg/667m²) | 吸收N(kg) | 吸收P₂O₅(kg) | 吸收K₂O(kg) |
|------|----------|----------------|-----------|---------------|-------------|
| 妃子笑 | 0.40 | 800-1200 | 16-24 | 6-9 | 12-18 |
| 桂味 | 0.35 | 600-1000 | 14-21 | 5-7 | 10-16 |
| 糯米糍 | 0.45 | 800-1200 | 14-21 | 5-7 | 10-16 |
| 白糖罂 | 0.40 | 700-1000 | 12-17 | 4-6 | 8-13 |
| 怀枝 | 0.38 | 600-900 | 11-17 | 4-6 | 8-12 |

### 2.2 养分吸收比例

| 指标 | 数值 | 说明 |
|------|------|------|
| N:P₂O₅:K₂O | 2:1:1.5 | 荔枝典型养分比例 |
| 氮素利用效率 | 25-35% | 实际吸收率 |
| 磷素利用效率 | 15-25% | 实际吸收率 |
| 钾素利用效率 | 30-40% | 实际吸收率 |
| 有机肥氮释放率 | 20-30% | 当年释放比例 |

### 2.3 计算步骤示例(以妃子笑为例)

| 步骤 | 计算内容 | 计算过程 | 结果 |
|------|----------|----------|------|
| 1.确定目标产量 | 1000 kg/667m² | - | 1000 kg |
| 2.计算需氮量 | 1000×0.40⁻¹×1.6% | =64 kg | 64 kg(N) |
| 3.计算需磷量 | 1000×0.40⁻¹×0.6% | =24 kg | 24 kg(P₂O₅) |
| 4.计算需钾量 | 1000×0.40⁻¹×1.2% | =48 kg | 48 kg(K₂O) |
| 5.考虑土壤供肥 | N供25%、P供30%、K供40% | - | 剩余需肥 |
| 6.计算实际施氮 | (64×75%)÷30% | =160 kg(N) | 240 kg(N)折合 |
| 7.计算实际施磷 | (24×70%)÷20% | =84 kg(P₂O₅) | - |
| 8.计算实际施钾 | (48×60%)÷35% | =82 kg(K₂O) | - |

## 3. 基于土壤养分离缺的施肥量计算

### 3.1 土壤供肥力计算

| 步骤 | 公式 | 示例 |
|------|------|------|
| 1.测定土壤养分 | 碱解氮、速效磷、速效钾 | 碱解氮120 mg/kg |
| 2.计算土壤含养分量 | 含量×土层体积×容重 | 120×0.2×1.2=28.8 kg |
| 3.计算土壤供肥量 | 含养分量×土壤养分利用率 | 28.8×30%=8.6 kg(N) |

### 3.2 土壤肥力等级与施肥调整

| 土壤养分等级 | 土壤供肥比例 | 施肥量调整 |
|--------------|--------------|------------|
| 高肥力 | N供30%、P供40%、K供50% | 减量15-20% |
| 中肥力 | N供25%、P供30%、K供40% | 标准用量 |
| 低肥力 | N供15%、P供20%、K供30% | 增量20-30% |
| 缺素 | 针对性补施 | 重点补施缺素 |

## 4. 基于叶片诊断的施肥量计算

### 4.1 矫正施肥量计算

| 缺乏元素 | 叶片含量(mg/kg或%) | 矫正施肥量(kg/667m²) | 施用方法 |
|----------|--------------------|----------------------|----------|
| 氮 | <1.8% | 增施尿素10-15 kg | 土壤+叶面 |
| 磷 | <0.15% | 增施过磷酸钙15-20 kg | 土壤 |
| 钾 | <1.8% | 增施硫酸钾8-12 kg | 土壤+叶面 |
| 钙 | <0.8% | 增施硝酸钙5-10 kg | 土壤+叶面 |
| 镁 | <0.40% | 增施硫酸镁8-12 kg | 土壤+叶面 |
| 铁 | <40 mg/kg | 螯合铁喷施500-800倍 | 叶面 |
| 锌 | <20 mg/kg | 硫酸锌喷施0.2% | 叶面 |
| 硼 | <20 mg/kg | 硼砂喷施0.2% | 叶面/花穗 |
| 锰 | <40 mg/kg | 硫酸锰喷施0.2% | 叶面 |

### 4.2 过量元素的减量计算

| 过量元素 | 叶片含量 | 减量幅度 | 措施 |
|----------|----------|----------|------|
| 氮 | >3.5% | 减量30-50% | 控氮促花 |
| 磷 | >0.50% | 减量20-30% | 减少磷肥 |
| 钾 | >4.0% | 减量20-30% | 减少钾肥 |

## 5. 氮磷钾配伍计算方法

### 5.1 NPK比例设计

| 生育时期 | N:P₂O₅:K₂O | 目的 |
|----------|-------------|------|
| 春梢肥 | 4:2:3 | 促进春梢生长 |
| 花前肥 | 1:2:3 | 控氮促花 |
| 壮果肥 | 3:2:4 | 促进果实膨大 |
| 采后肥 | 4:1:3 | 恢复树势 |
| 秋梢肥 | 3:2:2 | 培育秋梢 |

### 5.2 复合肥用量计算

| 目标养分 | 施肥量计算 |
|----------|----------|
| 复合肥N含量% | 需施N量÷复合肥N含量%=复合肥用量 |
| 复合肥P含量% | 需施P量÷复合肥P含量%=复合肥用量 |
| 复合肥K含量% | 需施K量÷复合肥K含量%=复合肥用量 |
| 取最小值 | 按三种元素算出的最小用量为实际用量 |
