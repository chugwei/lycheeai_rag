# 荔枝有机肥施用技术规程

## 摘要

有机肥是荔枝营养管理的基础肥料，能够改善土壤结构、提高土壤有机质含量、促进土壤微生物活动、增强荔枝树体抗逆性，并为荔枝提供全面而持久的营养供应。本文系统阐述荔枝有机肥的种类、质量标准、施用时期、施用量、施用方法及腐熟技术，为荔枝园科学施用有机肥提供规范化技术指导。荔枝园有机肥年施用量应不低于2000 kg/亩，是构建健康土壤、实现荔枝优质高产的关键措施。

## 1. 有机肥的定义与分类

有机肥是指以动植物残体、废弃物等有机物质为原料，经堆肥发酵腐熟后制成的肥料，含有丰富的有机质、多种营养元素和有益微生物。在荔枝栽培中，有机肥是改良土壤、培肥地力、提高果品质量的不可替代的基础肥料。

### 1.1 有机肥的分类

| 分类依据 | 种类 | 主要来源 | 有机质含量 | 养分特点 |
|----------|------|----------|------------|----------|
| 来源 | 畜禽粪肥 | 鸡粪、牛粪、猪粪、羊粪 | 25-50% | 氮磷钾含量高 |
| 来源 | 植物源有机肥 | 秸秆、落叶、绿肥、果渣 | 30-60% | 碳氮比高、分解慢 |
| 来源 | 粪肥类 | 家禽粪便堆肥 | 30-45% | 速效养分多 |
| 来源 | 饼肥类 | 豆饼、花生饼、菜籽饼 | 40-60% | 含N高、养分全 |
| 功能 | 商品有机肥 | 工业化发酵产品 | 45%以上 | 质量稳定 |
| 功能 | 生物有机肥 | 添加功能微生物 | 45%以上 | 含有益菌群 |

## 2. 有机肥质量标准

### 2.1 商品有机肥国家标准(NY 525-2021)

| 指标 | 合格标准 | 备注 |
|------|----------|------|
| 有机质(干基) | ≥45% | 核心指标 |
| 总养分(N+P₂O₅+K₂O) | ≥5.0% | 辅助指标 |
| pH值 | 5.5-8.5 | 适宜范围 |
| 水分 | ≤30% | 便于储运 |
| 堆肥温度 | 累计高温天数≥15天 | 腐熟保证 |
| 蛔虫卵死亡率 | ≥95% | 卫生安全 |
| 大肠杆菌值 | ≤100个/g | 卫生安全 |
| 重金属(铅) | ≤100 mg/kg | 安全限量 |
| 重金属(镉) | ≤10 mg/kg | 安全限量 |
| 重金属(汞) | ≤2 mg/kg | 安全限量 |
| 重金属(铬) | ≤150 mg/kg | 安全限量 |
| 重金属(砷) | ≤25 mg/kg | 安全限量 |
| 种子发芽指数 | ≥70% | 毒害评价 |

### 2.2 生物有机肥标准(NY 884-2021)

| 指标 | 合格标准 | 备注 |
|------|----------|------|
| 有机质(干基) | ≥40% | - |
| 活菌数 | ≥2.0×10⁷ CFU/g | 核心指标 |
| 有效活菌数 | ≥1.0×10⁷ CFU/g | 使用期保证 |
| pH值 | 5.5-8.5 | - |
| 重金属 | 同NY 525标准 | - |

## 3. 荔枝有机肥施用时期

### 3.1 全年施用计划

荔枝有机肥的施用应与树体营养需求和土壤改良相结合，全年分次施用。

| 施用时期 | 时间(广东) | 施用目的 | 施用类型 | 施用量(占全年%) |
|----------|------------|----------|----------|-----------------|
| 秋施基肥 | 9-11月 | 补充树体养分、促花芽分化、改良土壤 | 有机肥+复合肥 | 50-60% |
| 春施萌芽肥 | 2-3月 | 促梢壮叶 | 有机肥+速效肥 | 20-25% |
| 采后恢复肥 | 6-7月 | 树体恢复、促秋梢 | 有机肥 | 15-20% |
| 全年总用量 | - | - | - | 100% |

### 3.2 不同树龄有机肥施用量

| 树龄 | 年施用量(kg/株) | 折合约亩施量(kg/亩) | 备注 |
|------|-----------------|---------------------|------|
| 1-2年生(幼树) | 5-10 | 500-1000 | 少量多次 |
| 3-5年生(初产树) | 20-50 | 1000-2000 | 逐步增加 |
| 6-10年生(壮树) | 50-100 | 2000-4000 | 足量施用 |
| 10年以上(成年树) | 100-200 | 3000-6000 | 维持稳定 |
| 老树(20年以上) | 100-300 | 3000-6000 | 配合改良 |

## 4. 有机肥施用方法

### 4.1 沟施法（环状沟/条沟）

沟施是荔枝园最常用的有机肥施用方法，适用于不同树龄。

| 步骤 | 操作方法 | 技术要求 |
|------|----------|----------|
| 开沟位置 | 树冠滴水线附近 | 根系集中分布区 |
| 开沟深度 | 30-40 cm | 触及主要根系层 |
| 开沟宽度 | 20-30 cm | 根据肥料量确定 |
| 施肥操作 | 肥料均匀撒入沟内 | 与表土充分混合 |
| 覆土 | 填入原土并压实 | 防止水分蒸发 |
| 浇水 | 施后充分浇水 | 促进肥料分解 |

### 4.2 穴施法

穴施适用于幼树或局部缺肥的成年树。

| 操作要点 | 具体要求 |
|----------|----------|
| 开穴位置 | 树冠投影范围内，均匀分布4-6个穴 |
| 开穴深度 | 20-30 cm |
| 开穴直径 | 30-50 cm |
| 每穴施入量 | 3-5 kg有机肥 |
| 覆土压实 | 施后立即覆土压实 |

### 4.3 撒施法

撒施适用于覆盖作物或果园绿肥还田，配合翻耕使用。

| 操作要点 | 具体要求 |
|----------|----------|
| 撒施范围 | 全园或行间全幅 |
| 撒施均匀度 | 均匀撒布、无遗漏 |
| 配合措施 | 撒后翻耕20-30 cm |
| 浇水 | 翻耕后充分浇水 |

## 5. 有机肥腐熟技术

生粪直接使用易烧根、带病菌虫卵，必须充分腐熟后方可施用。

### 5.1 堆肥腐熟方法

| 方法 | 操作步骤 | 腐熟周期 | 优点 | 缺点 |
|------|----------|----------|------|------|
| 自然堆肥 | 分层堆置、定期翻堆 | 3-6个月 | 成本低、简单 | 周期长 |
| 高温堆肥 | 调控碳氮比、保持温度 | 2-4个月 | 速度快、杀虫好 | 需管理 |
| 发酵箱堆肥 | 密闭发酵、保温保湿 | 1-2个月 | 环境可控 | 设备投入 |
| 好氧发酵 | 强制通风、控温控湿 | 20-45天 | 高效 | 设备复杂 |

### 5.2 腐熟判断标准

| 判断指标 | 腐熟标准 | 检测方法 |
|----------|----------|----------|
| 外观 | 颜色深褐、无臭味 | 目测 |
| 温度 | 温度降至常温 | 温度计 |
| 气味 | 无臭味、有土腥味 | 嗅觉 |
| 质地 | 疏松、易碎 | 手捏 |
| 种子发芽指数 | >70% | 实验室测定 |
| C/N比 | <20 | 实验室测定 |
| 堆肥温度 | 累计高温>55℃天数≥7天 | 温度记录 |

### 5.3 加速腐熟的方法

| 措施 | 具体方法 | 加速效果 |
|------|----------|----------|
| 调节碳氮比 | C/N控制在25-30:1 | 显著加速 |
| 保持水分 | 含水量50-60% | 有利微生物活动 |
| 通气 | 定期翻堆或强制通风 | 促进好氧分解 |
| 接种菌种 | 添加EM菌或堆肥菌剂 | 缩短周期50% |
| 控制温度 | 维持55-65℃ | 杀菌灭虫 |

## 6. 有机肥与化肥配施

有机肥应与化肥配合施用，发挥各自优势，实现养分互补。

| 配施方案 | 有机肥比例 | 化肥比例 | 适用时期 | 效果 |
|----------|------------|----------|----------|------|
| 基肥型 | 70% | 30% | 秋施 | 改良土壤为主 |
| 平衡型 | 50% | 50% | 全年 | 养分均衡 |
| 追肥型 | 30% | 70% | 生长期 | 速效养分补充 |

### 6.1 配施原则

- 有机肥以基肥为主，化肥以追肥为主。
- 有机肥侧重改良土壤，化肥侧重快速供肥。
- 有机肥与化肥配施时，可减少化肥用量20-30%。
- 酸性土壤应配合施用石灰或碱性有机肥调节pH。

## 7. 注意事项

### 7.1 施用禁忌

- 严禁施用未腐熟的畜禽粪便，防止烧根和传播病菌虫卵。
- 重金属超标地区应选用优质商品有机肥，避免重金属累积。
- 果园周边有工业污染源的粪便应检测后方可使用。
- 有机肥不宜与强碱性物质混合施用。

### 7.2 施用安全

| 安全措施 | 具体要求 |
|----------|----------|
| 个人防护 | 戴手套、口罩，防止病菌感染 |
| 施用后洗手 | 施用有机肥后及时清洁 |
| 儿童禁入 | 施用期果园禁止儿童进入 |
| 记录档案 | 建立施肥档案，记录种类、用量、时间 |
