# 增城挂绿荔枝质量标准

> 本标准规定了地理标志产品增城挂绿荔枝的术语和定义、保护范围、质量等级、品质特征、检验方法及标志包装运输要求。增城挂绿荔枝是广东省广州市增城区特有的荔枝品种，以其独特的品质和历史文化价值享誉中外。

---

### 适用范围
本标准适用于国家地理标志产品增城挂绿荔枝的生产、流通和销售。

## 二、地理标志产品保护范围

### 保护区域
增城挂绿荔枝地理标志产品保护范围限于广东省广州市增城区行政区域内，包括荔城街道、增江街道、朱村街道、中新镇、石滩镇、新塘镇、小楼镇、派潭镇、正果镇等管辖区域。

### 产地环境条件
| 环境因子 | 适宜条件 | 特征说明 |
|---------|---------|---------|
| 年均气温(°C) | 21.5-22.5 | 温暖湿润 |
| 年降雨量(mm) | 1800-2100 | 雨量充沛 |
| 无霜期(天) | 360-365 | 极少霜冻 |
| 土壤类型 | 赤红壤、水稻土 | 土层深厚，pH 5.5-6.5 |
| 地貌 | 丘陵台地、河谷平原 | 海拔50-200m |

## 四、质量等级

### 等级划分
增城挂绿荔枝按质量分为特级、一级和二级三个等级。

| 项目 | 特级 | 一级 | 二级 |
|-----|------|-----|------|
| 单果重(g) | ≥22 | ≥18 | ≥15 |
| 果形 | 近圆形，果肩耸起，形态典型 | 近圆形，果形较典型 | 基本近圆形 |
| 果皮颜色 | 暗红带绿，缝合线绿色明显 | 暗红带绿，缝合线可见绿色 | 暗红，缝合线绿色不明显 |
| 果面 | 洁净光滑，无褐变 | 洁净，褐变≤5% | 基本洁净，褐变≤10% |
| 可溶性固形物(%) | ≥20 | ≥18 | ≥16 |
| 可食率(%) | ≥80 | ≥78 | ≥75 |
| 风味 | 清甜爽脆，典型挂绿风味 | 清甜爽口 | 较清甜 |
| 核 | 焦核(核重<1g) | 小核或焦核 | 小核 |
| 病虫害 | 无 | 无 | 无 |
| 机械伤 | 无 | 无 | 轻微 |

## 五、检验方法

### 感官检验
| 检验项目 | 检验方法 |
|---------|---------|
| 果形 | 目视，参照增城挂绿标准果形图 |
| 果皮颜色 | 在自然光下目视，对比标准比色卡 |
| 缝合线绿色特征 | 目视，观察缝合线是否呈现绿色 |
| 褐变 | 目视估算百分比 |
| 病虫害 | 目视+剖检 |

### 理化检验
| 项目 | 方法 | 仪器 |
|-----|------|------|
| 单果重 | 称重 | 电子天平(0.1g) |
| 可溶性固形物 | 折光法 | 阿贝折射仪 |
| 可食率 | 称重计算 | 电子天平 |
| 总酸度 | 酸碱滴定 | 滴定装置 |
| 维生素C | 2,6-二氯靛酚法 | 滴定装置 |
| 核重 | 称重 | 电子天平(0.01g) |

### 真实性鉴定
| 鉴定方法 | 原理 | 应用 |
|---------|-----|------|
| 形态学鉴定 | 果形、缝合线颜色等外观特征 | 常规鉴定 |
| DNA指纹鉴定 | SSR分子标记 | 争议时使用 |
| 矿物元素分析 | 特征元素含量分布 | 产地溯源 |

## 七、历史与文化价值

增城挂绿荔枝原产于增城荔城街道，已有400多年栽培历史。清代屈大均《广东新语》中已有记载。现挂绿广场母树所结果实曾拍出单颗55.5万元的天价。挂绿荔枝以果皮暗红、缝合线翠绿、清甜爽脆、微香可口而闻名，是荔枝中的极品。
