# 荔枝品种抗逆性鉴定技术

## 摘要

抗逆性（抗寒、抗旱、抗病、抗风等）是荔枝品种适栽区划和区域化推广的重要评价指标。本文系统介绍了荔枝品种抗逆性鉴定的技术方法，涵盖低温胁迫鉴定、干旱胁迫鉴定、病害抗性鉴定和抗风性评价等内容，为品种选育和区域化推广提供标准化的抗逆性评价技术参考。

## 1 抗逆性鉴定概述

荔枝原产于亚热带地区，对低温、干旱、台风和病害具有一定的敏感性。随着栽培区域北扩和气候变化加剧，抗逆性评价在品种选育中的重要性日益突出。科学的抗逆性鉴定技术有助于识别抗逆品种，为扩大适栽区和指导种植提供依据。

## 2 抗寒性鉴定

### 2.1 自然鉴定法

在自然条件下记录品种低温反应：

| 记录项目 | 方法 |
| --- | --- |
| 低温记录 | 最冷月均温、极端低温（连续记录） |
| 受害时间 | 首次低温受害日期 |
| 受害部位 | 叶尖、嫩梢、枝条、树干 |
| 受害等级 | 目测分级（1-5级） |

### 2.2 人工低温胁迫法

| 项目 | 技术要求 |
| --- | --- |
| 胁迫条件 | -2℃、-4℃、-6℃梯度 |
| 胁迫时长 | 4h、12h、24h |
| 样本数量 | 每个品种≥20株 |
| 评价指标 | 叶片褐变率、芽萌发率、恢复率 |

### 2.3 抗寒性分级标准

| 等级 | 标准 | 代表品种 |
| --- | --- | --- |
| 抗寒（强） | -4℃下叶片褐变率<10% | 部分四川荔枝 |
| 较抗寒 | -4℃下叶片褐变率10%-30% | 桂味、糯米糍 |
| 中等 | -4℃下叶片褐变率30%-60% | 妃子笑、怀枝 |
| 不耐寒 | -4℃下叶片褐变率>60% | 三月红、部分海南品种 |

## 3 抗旱性鉴定

| 方法 | 描述 |
| --- | --- |
| 田间自然干旱鉴定 | 在自然干旱条件下记录品种存活率 |
| 控水胁迫法 | 温室或盆栽控水处理，记录萎蔫恢复率 |
| 生理指标测定 | 叶片相对含水量、脯氨酸含量、SOD活性 |

## 4 抗病性鉴定

### 4.1 主要病害抗性鉴定

| 病害 | 鉴定方法 | 评价标准 |
| --- | --- | --- |
| 霜疫霉病 | 人工接种+田间发病率统计 | 病情指数<10%为抗病 |
| 炭疽病 | 人工接种，叶片病斑统计 | 病斑直径<5mm为抗病 |
| 煤烟病 | 田间自然发病率 | 发病率<5%为抗病 |

### 4.2 抗病性评价方法

- **自然鉴定**：在多发病害区域观察发病率
- **人工接种**：在受控条件下接种病原菌，定量评价
- **分子标记辅助鉴定**：利用与抗病基因连锁的分子标记

## 5 抗风性鉴定

| 鉴定指标 | 评价方法 |
| --- | --- |
| 树干强度 | 树干基部直径、木材密度 |
| 枝条韧性 | 枝条弯曲恢复能力 |
| 台风后表现 | 台风后倒伏率、断枝率、落叶率 |

## 6 抗逆性综合评价

| 性状 | 权重 | 评分方式 |
| --- | --- | --- |
| 抗寒性 | 30% | 1-5级 |
| 抗旱性 | 20% | 1-5级 |
| 抗病性 | 30% | 病情指数 |
| 抗风性 | 20% | 1-5级 |
| 综合抗逆指数 | 100% | 加权平均 |
