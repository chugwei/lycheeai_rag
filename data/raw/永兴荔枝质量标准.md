# 永兴荔枝质量标准

> 本标准规定了地理标志产品永兴荔枝的术语和定义、保护范围、品种特征、质量等级、品质要求、检验方法及标志包装运输要求。永兴荔枝产自海南省海口市永兴镇，是海南独特的火山岩台地荔枝产区，以其独特的火山岩土壤孕育的优质荔枝闻名。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于国家地理标志产品永兴荔枝的生产、流通和销售。

| SB/T 10059 | 荔枝 |

## 二、地理标志产品保护范围

### 保护区域
永兴荔枝地理标志产品保护范围限于海南省海口市秀英区永兴镇行政区域内，包括永兴墟、美安墟、雷虎墟、建中、建群、美东、美梅、博强等自然村所辖区域。

### 独特产地环境
| 环境因子 | 特征 | 对荔枝品质的影响 |
|---------|------|----------------|
| 地质 | 火山岩台地，玄武岩风化土壤 | 矿物质丰富，赋予独特风味 |
| 土壤 | 火山岩砖红壤，富含钾、钙、镁、硒 | 果实味甜，风味浓郁 |
| 年均气温(°C) | 24.0-25.0 | 成花好，成熟早 |
| 年降雨量(mm) | 1400-1700 | 干湿季分明 |
| 海拔(m) | 50-200 | 排水良好 |
| 昼夜温差(°C) | 8-12(冬春季) | 糖分积累多 |

## 六、检验方法

### 常规检验
| 检验项目 | 检验方法 | 检验标准 |
|---------|---------|---------|
| 感官 | 目视、品尝 | 本标准第四章 |
| 单果重 | 称重法 | GB/T 5009 |
| 果形 | 目视+卡尺测量 | 本标准 |
| 可溶性固形物 | 手持折射仪 | GB/T 5009 |
| 可食率 | 称重计算 | 本标准 |
| 总酸度 | 酸碱滴定 | GB/T 5009 |
| 维生素C | 2,6-二氯靛酚法 | GB/T 5009 |

### 产地特征鉴定
| 鉴定方法 | 检测内容 | 永兴荔枝特征 |
|---------|---------|------------|
| 矿物元素分析 | 钾、钙、镁、硒含量 | 硒含量≥0.01mg/kg（火山岩土壤特征） |
| 稳定同位素分析 | δ13C、δ15N值 | 特征指纹图谱 |
| 稀土元素分析 | 稀土元素配分模式 | 火山岩产地特征 |

### 运输贮藏要求
- 永兴荔枝成熟期早（5月），气温较高
- 采后必须在2小时内完成预冷
- 全程冷链运输，温度2-4°C
- 航空运输适用于高端市场（北京、上海等远距离）
- 从采收到消费端不超过72小时
