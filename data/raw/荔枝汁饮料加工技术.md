# 荔枝汁饮料加工技术

> 荔枝汁饮料是以新鲜荔枝为原料，经取汁、澄清、调配、杀菌等工序制成的果汁类饮品。荔枝汁富含糖分、维生素C和多种矿物质，风味独特，市场前景广阔。

---

## 二、荔枝汁加工工艺

### 清汁加工工艺

```
原料验收 → 清洗 → 去壳去核 → 破碎 → 榨汁 → 
粗滤 → 酶解澄清 → 精滤 → 调配 → 脱气 → 
均质 → 杀菌 → 灌装 → 封口 → 冷却 → 成品检验
```

### 各工序参数

| 工序 | 设备 | 工艺参数 | 操作要点 |
|------|------|---------|---------|
| **破碎** | 锤式破碎机 | 破碎粒度5-8mm | 破碎适度，避免过度破坏种子 |
| **榨汁** | 螺旋榨汁机 | 转速300-500rpm, 筛网0.5mm | 出汁率60-75% |
| **粗滤** | 振动筛 | 筛网40-60目 | 去除果肉粗纤维 |
| **酶解** | 酶解罐 | 果胶酶0.02-0.05%, 45-50°C, 1-2h | 降低粘度，提高清亮度 |
| **精滤** | 板框过滤机 | 硅藻土助滤，精度0.5-1μm | 获得澄清透明果汁 |
| **调配** | 调配罐 | 调整糖度至标准值（一般12-14°Brix） | 如需加糖，使用白砂糖 |
| **脱气** | 真空脱气罐 | 真空度0.08-0.09MPa, 40°C | 脱除溶解氧，防止氧化 |
| **均质** | 高压均质机 | 20-30MPa, 60-70°C | 浑浊汁需均质处理 |
| **杀菌** | 管式/板式UHT | 135°C, 5-10s | 瞬间高温杀菌 |
| **灌装** | 无菌灌装机 | 灌装温度25-30°C | 无菌环境操作 |

### 浑浊汁加工工艺

浑浊汁与清汁的区别在于不进行酶解澄清和精滤，而是通过均质使果肉微粒均匀悬浮。

```
原料 → 清洗 → 去壳去核 → 破碎 → 榨汁 → 
粗滤 → 调配 → 脱气 → 均质 → 杀菌 → 灌装
```

### 出汁率影响因素

| 因素 | 影响 | 优化措施 |
|------|------|---------|
| 品种 | 糯米糍>妃子笑>黑叶 | 选择高出汁率品种 |
| 成熟度 | 充分成熟出汁率高 | 成熟度SSC≥16°Brix |
| 破碎程度 | 破碎过细堵塞筛网，过粗出汁率低 | 破碎粒度5-8mm |
| 榨汁压力 | 压力适当提高出汁率 | 调整螺旋间隙 |
| 酶处理 | 果胶酶提高出汁率5-10% | 0.02-0.05%果胶酶 |

## 三、荔枝浓缩汁加工

### 浓缩工艺

| 浓缩方法 | 原理 | 浓缩倍数 | 品质 | 成本 | 适用 |
|---------|------|---------|------|------|------|
| **真空浓缩** | 减压蒸发 | 5-8倍 | 良 | 中 | 工业化 |
| **冷冻浓缩** | 冰晶分离 | 4-6倍 | 优 | 高 | 高端 |
| **膜浓缩** | 反渗透(RO) | 2-4倍 | 优 | 中 | 预浓缩 |
| **膜蒸馏** | 蒸汽通过膜 | 4-6倍 | 优 | 高 | 中试阶段 |

### 真空浓缩工艺参数

| 阶段 | 温度(°C) | 真空度(MPa) | 时间(min) | 固形物(°Brix) |
|------|---------|-----------|---------|------------|
| 进料 | 30-40 | 常压 | — | 12-14 |
| 初浓缩 | 50-55 | -0.08~-0.085 | 30-40 | 20-30 |
| 中浓缩 | 45-50 | -0.085~-0.09 | 40-60 | 30-50 |
| 终浓缩 | 40-45 | -0.09~-0.095 | 20-30 | 60-72 |
| 冷却 | 20-25 | 常压 | 10-15 | 60-72 |

## 六、品质控制与常见问题

### 常见质量问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| **褐变** | 酶促褐变/非酶褐变 | 加VC护色，脱气处理，低温贮藏 |
| **分层沉淀** | 果胶未充分酶解 | 优化酶解工艺，加稳定剂 |
| **风味劣变** | 加热过度/氧化 | 改进杀菌工艺，加强脱气 |
| **微生物超标** | 杀菌不足/二次污染 | 校准杀菌参数，无菌灌装 |
| **酸败** | 酸度失衡/微生物发酵 | 调整配方，严格杀菌 |
| **后浑浊** | 蛋白质/多酚复合 | 充分酶解+明胶澄清 |

### 品质检测指标

| 检测项目 | 荔枝原汁 | 荔枝浓缩汁 | 荔枝饮料 |
|---------|---------|----------|---------|
| 可溶性固形物(°Brix) | 12-16 | 60-72 | 10-14 |
| 总酸(以柠檬酸计,%) | 0.2-0.4 | 1.5-2.5 | 0.2-0.5 |
| pH | 4.5-5.0 | 3.5-4.0 | 3.5-4.5 |
| VC含量(mg/100g) | ≥15 | ≥80 | ≥5 |
| 透光率(T%, 660nm) | ≥90(清汁) | — | — |
| 菌落总数(CFU/mL) | <100 | <100 | <100 |
| 大肠菌群(MPN/100mL) | ≤3 | ≤3 | ≤3 |
| 霉菌(CFU/mL) | <10 | <10 | <10 |
| 酵母菌(CFU/mL) | <10 | <10 | <10 |
