# 荔枝绿色食品生产技术规程

> 本规程依据NY/T 391-2013《绿色食品 产地环境质量》、NY/T 393-2013《绿色食品 农药使用准则》和NY/T 394-2013《绿色食品 肥料使用准则》制定，规定了A级和AA级绿色食品荔枝的生产技术要求。

---

## 一、范围与术语定义

### 适用范围
本规程适用于申请绿色食品认证的荔枝生产基地，涵盖A级绿色食品和AA级绿色食品(有机食品)两个等级的生产技术管理。

### 等级区别
| 项目 | A级绿色食品 | AA级绿色食品 |
|-----|------------|-------------|
| 化学农药 | 限量使用 | 禁止使用 |
| 化学肥料 | 限量使用 | 禁止使用 |
| 认证标准 | NY/T 393-2013 | GB/T 19630 |
| 标识颜色 | 绿底白字 | 白底绿字 |
| 生产难度 | 中等 | 较高 |

---

## 二、产地环境要求

### 2.1 空气质量
| 污染物 | 浓度限值(mg/m³) |
|-------|----------------|
| 总悬浮颗粒物(TSP) | ≤0.30(日平均) |
| 二氧化硫(SO₂) | ≤0.15(日平均) |
| 二氧化氮(NO₂) | ≤0.08(日平均) |
| 氟化物(F) | ≤7μg/m³(日平均) |

### 2.2 灌溉水质
| 污染物 | 浓度限值(mg/L) |
|-------|----------------|
| pH | 5.5-8.5 |
| 总汞 | ≤0.001 |
| 总镉 | ≤0.005 |
| 总砷 | ≤0.05 |
| 总铅 | ≤0.1 |
| 六价铬 | ≤0.1 |
| 氟化物 | ≤2.0 |

### 2.3 土壤质量
| 项目 | pH<6.5 | pH6.5-7.5 | pH>7.5 |
|-----|--------|----------|--------|
| 镉(mg/kg) | ≤0.30 | ≤0.30 | ≤0.40 |
| 汞(mg/kg) | ≤0.25 | ≤0.30 | ≤0.35 |
| 砷(mg/kg) | ≤25 | ≤20 | ≤20 |
| 铅(mg/kg) | ≤50 | ≤50 | ≤50 |
| 铬(mg/kg) | ≤120 | ≤120 | ≤120 |

## 三、品种选择

### 3.1 适宜绿色食品生产的荔枝品种
| 品种 | 绿色食品等级 | 主要优势 | 注意事项 |
|-----|-------------|---------|---------|
| 妃子笑 | A级/AA级 | 抗病性强、丰产性好 | 注意肥水管理 |
| 黑叶 | A级/AA级 | 适应性广、抗病 | 品质中等 |
| 白糖罂 | A级 | 早熟、品质优 | 需加强病虫害防控 |
| 鸡嘴荔 | A级/AA级 | 抗逆性强 | 果实偏小 |
| 水东 | A级/AA级 | 早熟、管理粗放 | 果实中等 |

### 3.2 品种配置要求
- 主栽品种占70-80%，配栽品种占20-30%
- 选择花期相近的品种相互授粉
- 同一园区品种不超过3-4个，便于管理

## 四、施肥技术(AA级标准)

### 4.1 允许使用的肥料
| 肥料类别 | 肥料名称 | 施用方法 |
|---------|---------|---------|
| 有机肥 | 腐熟厩肥 | 沟施或穴施，15-20kg/株 |
| 有机肥 | 堆肥 | 与土壤混合后施用 |
| 有机肥 | 绿肥 | 翻压入土 |
| 饼肥 | 花生麸、菜籽麸 | 沤制后淋施 |
| 生物肥料 | 固氮菌肥 | 拌种或灌根 |
| 生物肥料 | 解磷菌肥 | 与有机肥混合施用 |
| 矿物肥料 | 磷矿粉 | 与有机肥混合堆沤 |
| 矿物肥料 | 钾矿粉 | 沟施 |
| 微量元素 | 硫酸锌、硫酸镁 | 叶面喷施 |

### 4.2 AA级禁止使用的肥料
- 化学合成肥料(尿素、复合肥等)
- 未经腐熟的人畜粪便
- 城市垃圾和污泥
- 含有重金属的肥料

### 4.3 A级绿色食品肥料使用要求
| 肥料类型 | 使用限制 |
|---------|---------|
| 化学氮肥 | 总氮量的50%以内 |
| 化学磷肥 | 限量使用 |
| 化学钾肥 | 限量使用 |
| 有机氮与无机氮比 | 有机氮>无机氮 |

## 五、病虫害绿色防控技术

### 5.1 AA级绿色食品病虫害防治策略
| 防治方法 | 具体措施 | 防治对象 |
|---------|---------|---------|
| 农业防治 | 选用抗病品种、合理修剪、清园 | 各种病虫害 |
| 物理防治 | 灯光诱杀、色板诱杀、套袋 | 蒂蛀虫、蝽象、蓟马 |
| 生物防治 | 释放天敌、使用生物农药 | 蝽象、卷叶蛾 |
| 植物源农药 | 印楝素、苦参碱、除虫菊素 | 多种害虫 |
| 矿物源农药 | 石硫合剂、波尔多液、矿物油 | 病害、介壳虫 |

### 5.2 AA级允许使用的农药清单
| 农药名称 | 主要成分 | 防治对象 | 使用浓度 |
|---------|---------|---------|---------|
| 印楝素 | 0.3%乳油 | 蚜虫、蓟马、螨类 | 800倍液 |
| 苦参碱 | 0.5%水剂 | 蚜虫、红蜘蛛 | 600倍液 |
| 除虫菊素 | 5%乳油 | 多种害虫 | 1000倍液 |
| 苏云金杆菌 | 8000IU/mg WP | 鳞翅目幼虫 | 500倍液 |
| 多抗霉素 | 1.5% WP | 霜疫霉病 | 400倍液 |
| 枯草芽孢杆菌 | 1000亿/g WP | 多种病害 | 500倍液 |
| 石硫合剂 | 29% AS | 病害、螨类 | 3-5波美度(冬季) |
| 矿物油 | 95% EC | 介壳虫、螨类 | 150倍液 |
| 波尔多液 | 硫酸铜+石灰 | 多种病害 | 0.5:1:100倍液 |

### 5.3 A级绿色食品补充农药清单
| 农药名称 | 防治对象 | 安全间隔期(天) | 每季最多使用次数 |
|---------|---------|--------------|----------------|
| 吡虫啉10%WP | 蚜虫、蓟马 | 7 | 2 |
| 阿维菌素1.8%EC | 瘿螨、红蜘蛛 | 14 | 2 |
| 敌百虫90%SP | 荔枝蝽象 | 7 | 2 |
| 氯虫苯甲酰胺200g/LSC | 蒂蛀虫 | 7 | 2 |
| 咪鲜胺45%EC | 炭疽病 | 7 | 2 |

## 六、绿色食品质量要求

### 6.1 感官品质
| 项目 | A级绿色食品 | AA级绿色食品 |
|-----|------------|-------------|
| 外观 | 果实均匀，色泽一致 | 果实均匀，允许轻微瑕疵 |
| 病虫害 | 无病虫害症状 | 允许轻微虫伤 |
| 机械伤 | 无 | 允许轻微机械伤 |
| 洁净度 | 洁净 | 基本洁净 |

### 6.2 农药残留限量
| 农药 | A级绿色食品(mg/kg) | AA级绿色食品(mg/kg) |
|-----|-------------------|-------------------|
| 多菌灵 | ≤0.5 | 不得检出 |
| 敌百虫 | ≤0.1 | 不得检出 |
| 阿维菌素 | ≤0.01 | 不得检出 |
| 吡虫啉 | ≤0.5 | 不得检出 |
| 高效氯氟氰菊酯 | ≤0.2 | 不得检出 |

## 七、生产管理与认证

### 7.1 生产档案管理
| 记录项目 | 内容 | 保存期限 |
|---------|------|---------|
| 农事记录 | 施肥、修剪、灌溉等操作 | 3年以上 |
| 投入品记录 | 农药、肥料使用的详细记录 | 3年以上 |
| 采收记录 | 采收日期、产量、批次号 | 3年以上 |
| 检测记录 | 产品质量检测报告 | 3年以上 |

### 7.2 认证管理
- 基地需获得绿色食品产地环境认定
- 每年进行产品抽检
- 建立内部质量控制体系
- 接受认证机构的年度检查
