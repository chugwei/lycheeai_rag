# 荔枝枝组培养技术标准

## 摘要

荔枝枝组是树冠上相对独立的枝条单元，是结果和营养生长的重要载体。枝组培养直接影响产量和树体结构。本文制定荔枝枝组培养技术标准，涵盖枝组分类、枝组配置、培养方法、修剪管理和枝组更新，为荔枝精细化管理提供枝组培育技术指南。

## 1. 枝组培养概述

荔枝枝组是由2-5个枝条组成的相对独立的枝条单元，是树冠的基本功能单元。优良枝组应具备：枝条健壮、分布合理、结构紧凑、通风透光。枝组培养从第3年开始，是树体结构精细化的关键。

## 2. 枝组分类

### 2.1 枝组类型

| 枝组类型 | 特点 | 功能 |
|---------|------|------|
| 结果枝组 | 以结果为主的枝组 | 结果 |
| 营养枝组 | 以营养生长为主的枝组 | 扩大树冠 |
| 混合枝组 | 兼具结果和营养功能 | 综合功能 |
| 更新枝组 | 以更新换枝为主的枝组 | 枝组更新 |

### 2.2 枝组分级

| 枝组级别 | 位置 | 大小 | 功能 |
|---------|------|------|------|
| 一级枝组 | 主枝上 | 大枝组（3-5枝） | 主要结果 |
| 二级枝组 | 侧枝上 | 中枝组（2-3枝） | 结果和营养 |
| 三级枝组 | 枝组上 | 小枝组（1-2枝） | 精细结果 |

## 3. 枝组配置标准

### 3.1 枝组数量配置

| 栽培模式 | 一级枝组数 | 二级枝组数 | 总枝组数 |
|---------|----------|----------|---------|
| 常规栽培 | 8-12个 | 15-25个 | 30-50个 |
| 矮化密植 | 6-10个 | 10-20个 | 20-40个 |
| 超高密度 | 4-6个 | 8-15个 | 15-30个 |

### 3.2 枝组分布配置

| 配置要素 | 标准 |
|---------|------|
| 水平分布 | 在主枝上均匀分布 |
| 垂直分布 | 不同层次均匀分布 |
| 枝组间距 | 15-25cm |
| 枝组密度 | 不重叠，通风透光 |

## 4. 枝组培养技术

### 4.1 枝组培养方法

| 培养方法 | 操作要点 | 适用时期 |
|---------|---------|---------|
| 短截培养 | 短截枝条培养新枝 | 冬季 |
| 拉枝培养 | 拉枝培养侧枝 | 夏季 |
| 摘心培养 | 摘心培养分枝 | 夏季 |
| 环割培养 | 环割促枝 | 夏季 |

### 4.2 枝组培养步骤

| 步骤 | 操作内容 | 时期 |
|------|---------|------|
| 1.选留枝组位置 | 在主枝上选留合适位置 | 第3年 |
| 2.培养枝组骨架 | 短截培养2-3个骨干枝 | 第3-4年 |
| 3.培养枝组枝梢 | 在骨干枝上培养结果枝 | 第4-5年 |
| 4.枝组成型 | 枝组骨架和枝梢定型 | 第5-6年 |
| 5.枝组维护 | 维持枝组结构和功能 | 第6年起 |

## 5. 结果枝组培养

### 5.1 结果枝组培养标准

| 培养要素 | 标准 |
|---------|------|
| 枝组大小 | 3-5个枝条组成 |
| 枝组结构 | 有骨干枝和结果枝 |
| 枝组健壮度 | 枝条健壮，芽眼饱满 |
| 枝组角度 | 主枝上的枝组开张60°-80° |

### 5.2 结果枝组修剪

| 修剪类型 | 操作内容 | 时期 |
|---------|---------|------|
| 更新修剪 | 回缩衰老枝组，培养新枝组 | 冬季 |
| 疏枝修剪 | 疏除过密枝组 | 冬季和夏季 |
| 短截修剪 | 短截枝组上的徒长枝 | 夏季 |

## 6. 枝组更新技术

### 6.1 枝组更新周期

| 枝组类型 | 更新周期 | 更新方法 |
|---------|---------|---------|
| 一级枝组 | 5-8年 | 回缩更新 |
| 二级枝组 | 3-5年 | 短截更新 |
| 三级枝组 | 2-3年 | 自然更新 |

### 6.2 枝组更新方法

| 方法 | 操作要点 | 时期 |
|------|---------|------|
| 回缩更新 | 回缩至健壮部位，培养新枝 | 冬季 |
| 短截更新 | 短截枝组，促发新枝 | 冬季 |
| 疏除更新 | 疏除衰老枝组，培养新枝组 | 冬季 |

## 7. 枝组管理

### 7.1 枝组日常管理

| 管理内容 | 操作要点 | 频率 |
|---------|---------|------|
| 枝组修剪 | 疏枝、短截、回缩 | 每年1-2次 |
| 枝组拉枝 | 调整枝组角度 | 每年1次 |
| 枝组施肥 | 枝组营养管理 | 按物候期 |
| 枝组防病 | 枝组病虫害防治 | 按需 |

### 7.2 枝组养护

| 养护内容 | 操作要点 |
|---------|---------|
| 枝组支撑 | 枝组过重时设立支撑 |
| 枝组保护 | 防止机械损伤和日灼 |
| 枝组伤口处理 | 修剪后涂保护剂 |

## 8. 枝组效果评价

| 评价指标 | 优良标准 |
|---------|---------|
| 枝组数量 | 符合配置标准 |
| 枝组分布 | 均匀分布，不重叠 |
| 枝组健壮度 | 枝条健壮，芽眼饱满 |
| 结果能力 | 枝组结果正常 |
| 通风透光 | 枝组间通风透光好 |

## 9. 注意事项

枝组培养需循序渐进，不宜一次性培养过多枝组。枝组更新应及时，避免枝组衰老影响产量。枝组修剪应在晴天进行。
