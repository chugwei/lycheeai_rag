# 荔枝选种育种技术规程

## 摘要

选种育种是荔枝品种改良的基础工作，包括从自然实生后代、芽变群体或杂交后代中筛选优良单株的过程。本文系统规定了荔枝选种育种的操作技术规程，涵盖实生选种、芽变选种、杂交选种三种主要途径的操作要点、筛选标准和技术要求。

## 1 适用范围

本规程适用于荔枝品种选种育种工作，包括实生后代选种、芽变选种、杂交后代选种三种选种途径。

## 2 实生选种技术规程

### 2.1 实生选种原理

利用荔枝种子繁殖后代自然分离的特性，在实生后代群体中筛选出表现优于母本的优良单株。实生选种是发现新品种的传统有效途径。

### 2.2 操作流程

| 阶段 | 操作要点 | 技术要求 |
| --- | --- | --- |
| 种子来源 | 优良母株采种 | 选择丰产、优质、健康的母树 |
| 播种育苗 | 规模化播种 | 单组合≥100株 |
| 幼苗期筛选 | 苗势观察 | 选择树势强、分枝多、生长快 |
| 初果期筛选 | 品质评价 | 初果品质不低于母株水平 |
| 盛果期筛选 | 综合评价 | 产量、品质、抗性、丰产稳定性 |

### 2.3 筛选标准

| 评价维度 | 优良单株标准 |
| --- | --- |
| 果实品质 | 可溶性固形物>母株，果形端正，可食率高 |
| 产量 | 单株产量>母株或群体均值 |
| 抗逆性 | 抗寒、抗旱、抗病能力不劣于母株 |
| 丰产稳定性 | 大小年差异<30% |

## 3 芽变选种技术规程

### 3.1 芽变选种原理

荔枝品种在长期栽培中可能产生自然芽变（枝变），表现为果实性状（果色、果形、焦核率等）发生变化。芽变选种是利用有性生殖方式无法获得的变异资源。

### 3.2 芽变类型识别

| 芽变类型 | 表现特征 | 典型品种 |
| --- | --- | --- |
| 果色变异 | 果皮颜色改变 | 妃子笑红肩变异 |
| 焦核变异 | 种子从大核变为退化核 | 桂味焦核芽变 |
| 早熟变异 | 成熟期提前 | 早妃 |
| 品质变异 | 糖度或风味改变 | — |

### 3.3 芽变选种流程

1. 发现与记录芽变枝的表现
2. 连续观察3年以上，确认性状稳定遗传
3. 采穗嫁接繁殖，建立鉴定圃
4. 进行品质、产量全面评价
5. 确认稳定后进行品种审定

## 4 杂交选种技术规程

杂交选种是在杂交育种基础上进行的，核心是在F1实生后代群体中进行系统性筛选。

| 筛选阶段 | 目标 | 保留比例 |
| --- | --- | --- |
| 苗期初筛 | 淘汰弱势苗、杂性苗 | 保留70% |
| 初果期复筛 | 品质性状初评 | 保留30% |
| 盛果期决选 | 综合性能评价 | 保留1%-2% |
| 品系鉴定 | DUS测试与区试 | 保留0.1%-0.5% |

## 5 选种技术通用要求

| 通用要求 | 说明 |
| --- | --- |
| 样本规模 | 选种群体越大，发现优良单株的概率越高 |
| 多代观察 | 至少连续观察3年，排除环境影响 |
| 标准参照 | 每批选种应设母株或标准品种对照 |
| 记录档案 | 全程记录选种过程和数据 |

## 6 注意事项

- 选种工作应结合品种资源普查和种质评价开展
- 注意区分环境影响与遗传变异，避免误选
- 芽变选种需连续3年以上观察确认稳定性
- 选种群体管理应标准化，排除管理差异干扰
