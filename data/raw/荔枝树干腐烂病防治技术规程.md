# 荔枝树干腐烂病防治技术规程

> 本规程规定了荔枝树干腐烂病的症状识别、病原鉴定、发病规律和综合防治技术，适用于荔枝产区树干腐烂病的防治管理。

---

## 一、病害概述

荔枝树干腐烂病（Lychee Trunk Rot），又称荔枝溃疡病，由多种弱寄生真菌（*Fusarium* spp.、*Phytophthora* spp.、*Armillaria* spp.等）侵染引起。该病危害荔枝主干和主枝的树皮及木质部，造成树皮腐烂、木质部变色，严重时导致整株死亡。该病在管理粗放、树势衰弱的老龄荔枝园中尤为常见。

---

## 二、症状识别

### 2.1 症状特征
| 发病阶段 | 症状描述 | 识别要点 |
|---------|---------|---------|
| 初期 | 树皮表面出现水渍状暗褐色斑块，微隆起 | 病部树皮颜色变深 |
| 扩展期 | 病斑扩大，树皮腐烂呈湿腐状，有酒糟味 | 树皮松软，有异味 |
| 显症期 | 树皮纵向开裂，流出褐色汁液，皮层与木质部分离 | 树皮剥落，木质部裸露 |
| 后期 | 病部树皮脱落，木质部变褐色，表面产生白色菌丝或子实体 | 木质部腐烂，树势衰弱 |
| 终期 | 病斑环绕枝干一周，上部枝叶枯死 | 整枝或整株枯死 |

### 2.2 不同病原引起的症状差异
| 病原 | 树干症状特征 | 菌丝特征 |
|------|-------------|---------|
| *Fusarium* spp. | 树皮湿腐，红褐色，有酒糟味 | 白色至粉红色菌丝 |
| *Phytophthora* spp. | 树皮暗褐色水渍状，病健交界明显 | 白色棉絮状菌丝 |
| *Armillaria* spp. | 根颈部腐烂，树皮与木质部之间有白色菌膜 | 白色菌丝束，有黑色菌索 |
| *Botryosphaeria* spp. | 树皮溃疡状，木质部变褐色 | 初无色后褐色菌丝 |

### 2.3 与其他树干病害的区别
| 病害 | 关键区别 |
|------|---------|
| 树干腐烂病 | 树皮腐烂湿腐，有酒糟味，皮层与木质部分离 |
| 流胶病 | 树干流胶，胶状物明显，不腐烂 |
| 膏药病 | 枝干有膏药状菌膜，不腐烂 |
| 日灼病 | 树皮龟裂，干燥，不腐烂 |

## 三、病原与发病规律

### 3.1 病原特征
| 病原 | 分类 | 越冬方式 | 侵染特点 |
|------|------|---------|---------|
| *Fusarium solani* | 半知菌亚门镰刀菌属 | 厚垣孢子、菌丝体 | 从伤口侵入 |
| *Fusarium oxysporum* | 半知菌亚门镰刀菌属 | 厚垣孢子、菌丝体 | 土壤传播，从根部侵入 |
| *Phytophthora palmivora* | 卵菌门疫霉属 | 卵孢子、菌丝体 | 游动孢子传播 |
| *Armillaria mellea* | 担子菌亚门蜜环菌属 | 菌索、菌丝体 | 根状菌索侵入 |

### 3.2 发病规律
| 因素 | 规律描述 |
|------|---------|
| 越冬 | 以菌丝体、厚垣孢子或菌索在病树残体及土壤中越冬 |
| 传播 | 主要随雨水、灌溉水、土壤和农事操作传播 |
| 侵染途径 | 从根部伤口、树干机械伤、冻伤、虫伤等伤口侵入 |
| 温度 | 25-30°C最适宜发病 |
| 湿度 | 多雨季节或土壤积水时发病加重 |
| 树龄 | 老龄树(20年以上)发病重 |
| 树势 | 树势衰弱、管理粗放的果园发病重 |
| 土壤 | 排水不良、土壤板结的重粘土果园发病重 |
| 地形 | 低洼积水处发病重，坡地发病轻 |

### 3.3 高发病期
| 季节 | 发病特点 | 防治关键期 |
|------|---------|-----------|
| 春季(3-4月) | 气温回升，病菌开始活动 | 定期检查树干 |
| 夏季(5-7月) | 高温多雨，发病高峰期 | 及时处理病株 |
| 秋季(8-10月) | 台风暴雨后易发 | 台风后及时检查 |
| 冬季(11-2月) | 病菌越冬，病害发展缓慢 | 清园减少菌源 |

## 四、防治技术

### 4.1 农业防治
| 防治措施 | 技术要求 | 实施时间 |
|---------|---------|---------|
| 增强树势 | 增施有机肥15-20kg/株，合理灌溉，提高抗病力 | 全年 |
| 改良土壤 | 深翻改土，增施石灰调节pH至6.0-6.5 | 建园时或冬季 |
| 排水防涝 | 低洼果园开沟排水，垄高20-30cm | 建园时、雨季 |
| 树干保护 | 树干涂白(生石灰:硫磺:食盐:水=10:1:0.2:40) | 每年11-12月 |
| 减少伤口 | 修剪时大伤口涂抹保护剂，避免树干损伤 | 修剪时 |
| 及时挖除病株 | 重病株挖除后土壤消毒 | 发现即处理 |

### 4.2 物理防治
| 措施 | 操作方法 | 适用范围 |
|------|---------|---------|
| 刮除病皮 | 刮除病部树皮至健康组织，边缘超出病部2-3cm | 病斑面积<1/3枝干周长 |
| 火焰消毒 | 用喷灯火焰灼烧病部及周围树皮 | 病斑局限时使用 |
| 桥接 | 用健康枝条桥接，帮助养分运输 | 病斑环绕枝干时 |
| 晒根 | 挖开根颈部晾晒，降低土壤湿度 | 根颈部腐烂 |

### 4.3 化学防治
#### 伤口处理
| 药剂名称 | 浓度 | 使用方法 | 处理时间 |
|---------|------|---------|---------|
| 石硫合剂原液 | 29%AS | 涂抹伤口 | 刮除病皮后立即处理 |
| 波尔多浆 | 硫酸铜:石灰:水=1:1:10 | 涂抹伤口 | 刮除病皮后 |
| 甲基硫菌灵 | 70%WP 100倍液(糊剂) | 涂抹伤口 | 刮除病皮后 |
| 多菌灵 | 50%WP 100倍液(糊剂) | 涂抹伤口 | 刮除病皮后 |
| 腐植酸铜 | 原液 | 涂抹伤口 | 消毒+愈合 |

#### 全树喷施和灌根
| 药剂名称 | 浓度 | 使用方法 | 安全间隔期(天) |
|---------|------|---------|--------------|
| 甲霜灵·锰锌 | 58%WP 500倍液 | 树干和根颈部喷洒 | 14 |
| 甲基硫菌灵 | 70%WP 800倍液 | 全树喷洒 | 14 |
| 多菌灵 | 50%WP 500倍液 | 全树喷洒 | 10 |
| 恶霉灵 | 70%WP 3000倍液 | 灌根 | 30 |
| 枯草芽孢杆菌 | 1000亿/g WP 500倍液 | 灌根 | 3 |

### 4.4 生物防治
| 生物制剂 | 使用方法 | 防治对象 | 效果 |
|---------|---------|---------|------|
| 枯草芽孢杆菌 | 500倍液灌根 | 镰刀菌、疫霉菌 | 中等 |
| 木霉菌制剂 | 300倍液涂抹或灌根 | 多种土传病菌 | 60-70% |
| 链霉菌制剂 | 500倍液灌根 | 多种土传病菌 | 50-60% |

## 五、治疗方案

### 5.1 不同严重程度的治疗方案
| 严重程度 | 治疗方案 | 预期效果 |
|---------|---------|---------|
| 轻度(病斑面积<枝干周长1/4) | 刮除病皮→消毒→涂药保护 | 可治愈 |
| 中度(病斑面积占枝干周长1/4-1/2) | 刮除病皮→消毒→涂药+桥接 | 控制病情，恢复树势 |
| 重度(病斑面积>枝干周长1/2) | 挖除病株+土壤消毒 | 防止传播 |

### 5.2 治疗操作流程
| 步骤 | 操作 | 详细要求 |
|------|------|---------|
| 第1步 | 挖开根颈部 | 露出根颈部及主根上部 |
| 第2步 | 刮除病皮 | 用锋利的刮刀彻底刮除腐烂树皮和变色木质部 |
| 第3步 | 清洗消毒 | 用75%酒精或0.1%高锰酸钾液清洗 |
| 第4步 | 涂药 | 涂抹甲基硫菌灵糊剂或波尔多浆 |
| 第5步 | 晾干 | 晾晒2-3天 |
| 第6步 | 覆土 | 回填消毒过的土壤或新土 |
| 第7步 | 树势恢复 | 追施有机肥+叶面喷肥 |

## 六、防治效果评价

### 6.1 评价指标
| 指标 | 调查方法 | 优秀标准 |
|------|---------|---------|
| 治愈率 | 处理后6个月检查 | >85% |
| 复发率 | 处理后1年内检查 | <10% |
| 树势恢复 | 新梢生长量、叶片颜色 | 恢复正常生长 |
| 发病率 | 果园总发病率 | <5% |
