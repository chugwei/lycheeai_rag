# 荔枝叶枯病防治技术

## 摘要

荔枝叶枯病是由多种真菌（包括炭疽菌、叶点霉、尾孢菌等）引起的叶片病害，以叶片出现不规则枯斑、叶片早落为主要特征。该病在华南荔枝产区普遍发生，尤其在雨季和高温高湿条件下危害严重。本文系统介绍叶枯病的病原、发病规律、诊断和防治技术。

## 1. 病原生物学

荔枝叶枯病为多病原复合病害，主要病原菌包括：

| 病原菌 | 病害类型 | 分生孢子特征 |
|-------|---------|------------|
| *Colletotrichum* spp. | 炭疽型叶枯 | 椭圆形，单胞，无色 |
| *Phyllosticta* spp. | 叶点霉型 | 卵形，单胞，无色 |
| *Cercospora* spp. | 尾孢型 | 长圆柱形，多隔 |
| *Pestalotiopsis* spp. | 黑盘孢型 | 五隔，两端有附属丝 |

## 2. 发病规律

病菌以菌丝体和分生孢子器在病叶及落叶上越冬。翌年春末夏初，分生孢子释放，通过风雨传播。病害全年均可发生，但以 5-9 月高温高湿期为高峰。

### 2.1 症状特征

| 病原类型 | 症状 |
|---------|------|
| 炭疽型 | 圆形或椭圆形枯斑，有同心轮纹，中央灰白色 |
| 叶点霉型 | 近圆形小斑点，中央灰白色，边缘褐色 |
| 尾孢型 | 长椭圆形枯斑，沿叶脉扩展 |
| 黑盘孢型 | 不规则枯斑，潮湿时有黑色小点 |

### 2.2 发病过程

| 阶段 | 时间 | 症状 |
|-----|------|------|
| 侵染期 | 1-3 天 | 叶片出现水浸状小斑点 |
| 扩展期 | 4-7 天 | 斑点扩大为枯斑 |
| 成熟期 | 8-15 天 | 枯斑成熟，中央组织脱落 |
| 落叶期 | 15 天后 | 大量叶片脱落 |

### 2.3 发病与环境

| 条件 | 影响 |
|-----|------|
| 高温高湿（28-35 ℃，湿度 >85%） | 最利发病 |
| 连续阴雨 | 孢子大量传播 |
| 通风不良 | 树冠内湿度高，病害重 |
| 偏施氮肥 | 新叶柔嫩，抗性弱 |
| 树势衰弱 | 抗病力下降 |

## 3. 诊断技术

### 3.1 田间诊断

- 叶片上出现褐色或黄褐色枯斑，斑点大小不一。
- 斑点形状规则（圆形）或不规则，边缘多为褐色。
- 斑点中央灰白色，有时可见黑色小点（分生孢子器）。
- 严重时叶片大面积枯黄脱落。

### 3.2 镜检诊断

| 病原 | 镜检特征 |
|-----|---------|
| 炭疽菌 | 分生孢子盘，新月形孢子 |
| 叶点霉 | 分生孢子器，卵形孢子 |
| 尾孢菌 | 长圆柱形多隔孢子 |
| 黑盘孢菌 | 五隔孢子，两端有附属丝 |

## 4. 防治技术

### 4.1 农业防治

- **清园**：清除落叶和病叶，集中烧毁。
- **修剪**：改善通风透光，降低树冠湿度。
- **平衡施肥**：增施磷钾肥，控制氮肥。
- **排水**：雨季及时排水。

### 4.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 备注 |
|-----|------|---------|------|
| 萌芽前 | 石硫合剂 | 3-5 波美度 | 清园 |
| 新梢期 | 苯醚甲环唑 10% | 2000-3000 倍 | 保护 |
| 雨季 | 代森锰锌 80% | 600-800 倍 | 保护 |
| 发病初期 | 戊唑醇 25% | 3000-4000 倍 | 治疗 |
| 发病期 | 咪鲜胺 70% | 1500-2000 倍 | 治疗 |

### 4.3 防治关键节点

| 节点 | 措施 |
|-----|------|
| 春梢萌发前 | 石硫合剂清园 |
| 春梢期 | 苯醚甲环唑保护 |
| 雨季来临前 | 代森锰锌预防 |
| 高温高湿期 | 戊唑醇 + 咪鲜胺轮换 |
