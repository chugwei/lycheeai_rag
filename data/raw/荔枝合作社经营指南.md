# 荔枝合作社经营指南

## 摘要

农民专业合作社是连接小农户与大市场的重要纽带，在荔枝产业发展中发挥着组织化、规模化和专业化的重要作用。本文系统介绍荔枝合作社的设立登记、经营管理、利益分配、规范发展和政策支持等内容，为荔枝种植户组建和经营合作社提供实务指导。

## 一、合作社概述

### 1.1 合作社定义

农民专业合作社是成员以农村集体经济组织、农民为主体，按照互助合作原则，自愿联合、民主管理的互助性经济组织。

### 1.2 合作社价值

| 价值维度 | 具体内容 |
|---------|---------|
| 组织化 | 提高农民组织化程度 |
| 规模化 | 实现规模生产、降低成本 |
| 专业化 | 提高专业化水平 |
| 市场化 | 增强市场谈判能力 |
| 风险分散 | 分散经营风险 |

## 二、合作社设立登记

### 2.1 设立条件

| 条件 | 要求 |
|------|------|
| 成员数量 | 5 名以上 |
| 农民比例 | 成员中农民至少占 80% |
| 注册资本 | 不少于 50 万元 |
| 章程 | 制定合作社章程 |
| 组织机构 | 设立理事会、监事会 |

### 2.2 登记流程

```
筹备（制定章程、召开成立大会） → 向市场监管部门申请登记 → 领取营业执照 → 刻章、开立账户 → 开展业务
```

### 2.3 登记材料

| 材料 | 说明 |
|------|------|
| 登记申请书 | 市场监管部门提供 |
| 章程 | 经全体成员表决通过 |
| 成员名册 | 成员身份信息 |
| 出资证明 | 成员出资证明 |
| 办公场所证明 | 办公地址证明 |

## 三、经营管理

### 3.1 组织架构

| 机构 | 职责 | 构成 |
|------|------|------|
| 成员大会 | 最高权力机构 | 全体成员 |
| 理事会 | 执行机构 | 3-5 人 |
| 监事会 | 监督机构 | 1-2 人 |
| 总经理 | 日常经营 | 1 人 |

### 3.2 业务范围

| 业务类型 | 具体内容 |
|---------|---------|
| 生产服务 | 农资采购、技术培训 |
| 销售服务 | 统一销售、品牌营销 |
| 加工服务 | 初加工、深加工 |
| 物流服务 | 仓储、冷链配送 |
| 金融服务 | 互助资金、保险 |

### 3.3 财务管理

| 财务环节 | 管理要求 |
|---------|---------|
| 资金管理 | 规范收支、定期公示 |
| 会计核算 | 建立会计账簿 |
| 财务公开 | 定期向成员公开 |
| 审计监督 | 年度审计 |

## 四、利益分配

### 4.1 分配原则

| 原则 | 内容 |
|------|------|
| 按交易额返还 | 返还总额不少于可分配盈余的 60% |
| 按股份分红 | 剩余部分按股分红 |
| 公积金提取 | 提取一定比例公积金 |
| 风险基金 | 提取风险基金 |

### 4.2 分配方案

| 分配项目 | 比例 | 说明 |
|---------|------|------|
| 公积金 | 10% | 发展基金 |
| 风险金 | 5% | 风险准备金 |
| 按交易额返还 | 60% | 成员交易返还 |
| 按股分红 | 25% | 股东分红 |

## 五、规范发展

### 5.1 规范化要求

| 要求 | 内容 |
|------|------|
| 制度健全 | 建立各项管理制度 |
| 民主管理 | 成员参与决策 |
| 财务规范 | 财务公开透明 |
| 业务规范 | 按章程经营 |
| 档案管理 | 建立档案 |

### 5.2 示范社创建

| 标准 | 要求 |
|------|------|
| 成员规模 | 成员不少于 100 人 |
| 经济实力 | 年交易额不少于 500 万元 |
| 规范程度 | 制度健全、财务规范 |
| 示范带动 | 带动农户 200 户以上 |

## 六、政策支持

| 政策类型 | 内容 | 申请渠道 |
|---------|------|---------|
| 财政扶持 | 专项资金 | 农业农村部门 |

| 金融支持 | 低息贷款 | 银行 |
| 用地支持 | 用地指标 | 自然资源部门 |
