# 荔枝蚜虫防治技术

## 摘要

荔枝蚜虫（*Toxoptera* spp. 及相关种类）是荔枝上的重要刺吸式害虫，主要危害嫩梢、叶片和花穗，吸食汁液导致叶片卷曲、嫩梢枯死，并分泌蜜露诱发煤烟病。本文系统介绍蚜虫的生物学特性、发生规律和综合防治技术。

## 1. 生物学特性

### 1.1 常见种类

| 种类 | 学名 | 主要寄主 |
|-----|------|---------|
| 荔枝二叉蚜 | *Toxoptera citricida* | 荔枝、柑桔等芸香科、无患子科 |
| 桃蚜 | *Myzus persicae* | 多种果树 |
| 棉蚜 | *Aphis gossypii* | 多种植物 |

### 1.2 生活史

| 虫态 | 发育期（天） | 形态特征 |
|-----|-----------|---------|
| 卵 | 5-10 | 椭圆形，黑色，越冬 |
| 若虫（1-3 龄） | 3-5/龄 | 黄绿色至黑褐色 |
| 无翅成蚜 | 繁殖期 | 黄绿色，体长 2-3 mm |
| 有翅成蚜 | 迁飞期 | 有翅，体色较深 |

蚜虫繁殖力强，一个世代仅 7-10 天，一年可繁殖 20-30 代。

## 2. 发生规律

| 时期 | 发生程度 | 原因 |
|-----|---------|------|
| 春梢期（3-5 月） | 重发 | 新梢嫩叶是主要取食部位 |
| 花期（3-4 月） | 重发 | 花穗受害 |
| 秋梢期（9-11 月） | 中等 | 秋梢嫩叶取食 |
| 冬季 | 轻发 | 低温抑制 |

## 3. 危害症状

| 部位 | 症状 |
|-----|------|
| 嫩梢 | 嫩梢卷曲、畸形、枯死 |
| 叶片 | 叶片卷曲、黄化、早落 |
| 花穗 | 花穗受害，坐果率下降 |
| 分泌物 | 蜜露诱发煤烟病 |

## 4. 监测技术

| 方法 | 操作 |
|-----|------|
| 目测检查 | 检查嫩梢和叶背蚜虫密度 |
| 黄板诱测 | 悬挂黄色粘虫板 |
| 糖醋液诱测 | 糖醋酒液诱杀有翅蚜 |

## 5. 防治技术

### 5.1 农业防治

- 及时抹除被害嫩梢。
- 清除杂草，减少中间寄主。
- 合理施肥，增强树势。

### 5.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 备注 |
|-----|------|---------|------|
| 若虫期 | 吡虫啉 10% | 2000-3000 倍 | 内吸性 |
| 若虫期 | 啶虫脒 20% | 2000-3000 倍 | 触杀 |
| 成虫期 | 烯啶虫胺 10% | 3000-4000 倍 | 长残效 |
| 综合防治 | 溴氰虫酰胺 10% | 3000-4000 倍 | 新型杀虫剂 |
| 环保型 | 苦参碱 0.5% | 800-1000 倍 | 植物源 |

### 5.3 生物防治

| 天敌 | 作用 |
|-----|------|
| 瓢虫（*Coccinella* spp.） | 捕食蚜虫成虫和若虫 |
| 草蛉（*Chrysopa* spp.） | 捕食卵和若虫 |
| 食蚜蝇幼虫 | 捕食蚜虫 |
| 蚜茧蜂（*Aphidius* spp.） | 寄生蚜虫 |

### 5.4 注意事项

- 蚜虫易产生抗药性，需轮换使用不同作用机制的药剂。
- 喷药时应重点喷施嫩梢和叶背。
- 与天敌释放配合使用，提高防治效果。
