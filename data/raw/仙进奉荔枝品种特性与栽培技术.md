# 仙进奉荔枝品种特性与栽培技术

## 摘要

仙进奉（Litchi chinensis Sonn. cv. 'Xianjinfeng'）是广东省农业科学院果树研究所等单位从增城荔枝实生后代中选育出的优质荔枝新品种，兼具早结、丰产、优质、耐贮运等优良特性。本文详细介绍了仙进奉的选育背景、品种特征特性、果实品质指标、物候期及配套栽培技术，为仙进奉的推广应用和标准化生产提供技术参考。

## 一、品种来源与选育背景

仙进奉荔枝是广东省农业科学院果树研究所与增城区农业技术推广中心合作，从增城荔枝实生群体中选育出的优良新品种。2000年初发现优良单株，经过连续多年的无性繁殖、品比试验和区域化试验，于2010年通过广东省农作物品种审定委员会审定。仙进奉名称中的"仙"指其品质超凡，"进奉"寓意曾为进贡佳品。该品种在岭南地区推广表现优异，目前在广东、广西、海南、福建等地已推广种植约5000公顷。

## 二、品种特征特性

### 2.1 树体特征

树势中等偏强，树冠半圆头形，树姿半开张。主干灰褐色，表皮较光滑。枝条分布均匀，枝梢密度中等，分枝角度45-60度。叶片为偶数羽状复叶，小叶2-4对，叶片长椭圆形或披针形，叶色浓绿，叶面光滑有光泽，叶缘平整。叶片长12-17厘米，宽3.5-5.0厘米。叶脉两面均明显。

### 2.2 花器特征

花序为多分枝的圆锥形聚伞花序，长25-40厘米。每花序有花400-1000朵，雄花占75%-85%，雌花占15%-25%。雌花比例较高，有利于丰产稳产。雄花直径6-8毫米，雌花稍大。花期较集中，单株花期约15-20天。

### 2.3 果实品质特征

| 性状 | 描述 |
|------|------|
| 果形 | 近心形或椭圆形，果肩微耸 |
| 单果重 | 20-30克，平均25-28克 |
| 果皮 | 鲜红色至深红色，有光泽 |
| 龟裂片 | 中等大，隆起较平，排列整齐 |
| 果皮厚度 | 1.0-1.4毫米 |
| 果肉 | 乳白色，半透明，爽脆，汁多，浓甜微香 |
| 可食率 | 78%-85% |
| 可溶性固形物 | 18%-23% |
| 总糖含量 | 15%-19% |
| 总酸含量 | 0.12%-0.20% |
| 维生素C | 35-55 mg/100g |
| 种子 | 中等大，焦核率40%-60% |
| 耐贮性 | 常温贮藏3-5天，冷藏10-15天 |

仙进奉最大的特点是焦核率高、品质极优且耐贮运，是鲜食和高端市场的理想品种。

## 三、物候期

仙进奉在广州地区的物候期表现：

| 物候期 | 时间（月/旬） |
|--------|-------------|
| 萌芽期 | 2月中旬-3月上旬 |
| 春梢抽生期 | 3月上旬-4月上旬 |
| 现蕾期 | 3月中旬-4月上旬 |
| 开花期 | 4月上旬-5月上旬 |
| 幼果发育期 | 4月中旬-5月下旬 |
| 果实膨大期 | 5月中旬-6月下旬 |
| 果实成熟期 | 7月上旬-7月中旬 |
| 秋梢抽生期 | 7月下旬-9月下旬 |
| 花芽分化期 | 11月-次年1月 |

仙进奉属于中晚熟品种，成熟期比妃子笑晚15-20天，比桂味晚5-7天，可延长荔枝鲜果供应期。

## 四、适应性

### 4.1 气候适应性

仙进奉对温度适应性较强，可耐短期-1℃低温。花期适温20-26℃，果实发育期需25-32℃。年降雨量1400-2000mm条件下生长良好。较耐干旱，但不耐涝。果实成熟期遇雨不易裂果，是该品种的重要优势。

### 4.2 土壤适应性

对土壤适应性广，在红壤、砖红壤、赤红壤上均可种植。以pH5.5-6.5、有机质含量1.5%以上的沙壤土为佳。对土壤钙、镁需求较高，缺钙易导致果肉软化和裂果。

## 五、栽培技术要点

### 5.1 定植技术

| 项目 | 技术参数 |
|------|---------|
| 株行距 | 5米×6米或6米×7米 |
| 密度 | 240-330株/公顷 |
| 定植穴 | 0.8m×0.8m×0.8m |
| 基肥 | 有机肥20-30kg/穴+钙镁磷肥1.5kg/穴 |
| 定植时间 | 春植3-4月或秋植9-10月 |
| 定植要求 | 嫁接口高出地面5-10cm |

### 5.2 土壤管理

**幼树期管理：** 定植后1-3年逐年向外扩穴深翻，结合施肥改良土壤。树盘覆盖稻草或地膜，保水控草。行间间作花生、大豆、蔬菜等矮秆作物。

**成年期管理：** 每2年深翻一次，深度20-30厘米。每年采果后结合施肥进行培土，厚度3-5厘米。每3年施一次石灰调节pH，用量50-75公斤/亩。

### 5.3 营养管理

仙进奉盛果树年施肥量推荐（每株/年）：

| 肥料种类 | 用量(kg) | 施用时期 |
|---------|---------|---------|
| 尿素 | 0.8-1.2 | 分次施用 |
| 过磷酸钙 | 0.6-0.8 | 基肥和花前肥 |
| 氯化钾 | 0.8-1.2 | 分次施用 |
| 硫酸镁 | 0.2-0.3 | 花前和壮果期 |
| 有机肥 | 40-50 | 采果后 |

施肥分配方案：
- 采果肥（7月）：占全年35%，以有机肥为主，配合速效氮肥
- 秋梢肥（9月）：占全年15%，以氮钾肥为主
- 促花肥（1-2月）：占全年20%，以磷钾肥为主，配合硼、镁
- 壮果肥（4月）：占全年30%，以钾肥为主，配合氮肥和钙肥

### 5.4 水分管理

仙进奉对水分反应敏感，需根据物候期精准调控：

| 物候期 | 土壤含水量(%) | 管理要点 |
|--------|-------------|---------|
| 花芽分化期(11-1月) | 55-65 | 适度控水，促进分化 |
| 现蕾开花期(3-4月) | 70-80 | 保持湿润，忌干旱积水 |
| 幼果发育期(4-5月) | 75-85 | 保证充足水分 |
| 果实膨大期(5-6月) | 75-85 | 水分均衡供给 |
| 成熟期(6-7月) | 60-70 | 适当控水，提高品质 |
| 秋梢生长期(7-9月) | 70-80 | 及时灌溉促梢 |

### 5.5 整形修剪

**树形选择：** 采用自然圆头形或开心形，干高50-70厘米，主枝3-4条。

**幼树修剪：** 以轻剪为主，培养树形骨架。选留主枝后适时摘心，促发侧枝，加速树冠成形。

**结果树修剪：** 采果后立即修剪，剪除过密枝、交叉枝、病虫枝、枯死枝和弱枝。保留健壮秋梢作为结果母枝，结果母枝以长度15-25厘米、粗度0.4-0.6厘米为佳。修剪量占总枝叶量的20%左右。

### 5.6 花果管理

**控梢促花：**
- 秋梢老熟后喷施多效唑300-500mg/L或烯效唑100-150mg/L
- 11月对旺盛树进行环割或环剥
- 控制冬梢，确保花芽分化顺利进行

**保花保果：**
- 花期放蜂，每公顷10-15箱
- 盛花期喷施0.1%硼砂+0.2%磷酸二氢钾+0.1%尿素
- 谢花后喷施赤霉素(GA3)10-15mg/L+芸苔素内酯0.01mg/L
- 第一次生理落果后喷施0.2%尿素+0.2%磷酸二氢钾
- 第二次生理落果后定果，每穗保留15-20个果

**提高焦核率：**
- 谢花后7天内喷施GA3 20-30mg/L
- 增施钾肥，控制氮肥
- 钙肥补充，促进种皮发育

### 5.7 病虫害防治

仙进奉主要病虫害防治技术：

| 病虫害 | 防治药剂 | 防治时期 | 注意事项 |
|--------|---------|---------|---------|
| 霜疫霉病 | 烯酰吗啉、甲霜灵 | 花前、花后、幼果期 | 重点防治病害 |
| 炭疽病 | 咪鲜胺、苯醚甲环唑 | 抽梢期、果实生长期 | 雨后及时防治 |
| 蒂蛀虫 | 高效氯氟氰菊酯 | 果实发育期 | 注意卵孵盛期 |
| 荔枝蝽象 | 啶虫脒、高效氯氟氰菊酯 | 花期、幼果期 | 越冬期捕杀成虫 |
| 瘿螨 | 阿维菌素、炔螨特 | 春梢抽生期 | 叶背喷雾均匀 |
| 红蜘蛛 | 哒螨灵、噻螨酮 | 春梢期 | 交替用药防抗性 |

## 六、采收与贮运

### 6.1 采收

仙进奉在7月上旬至中旬成熟，采收标准为果皮全面转红，可溶性固形物达18%以上。采收时间宜在早晨或傍晚，采后果实避免日晒。采用"一果两剪"法，保留果梗1-2厘米。

### 6.2 分级包装

| 等级 | 单果重(g) | 外观要求 | 可溶性固形物(%) |
|------|----------|---------|-----------------|
| 特级 | ≥28 | 果形端正，色泽鲜红，无瑕疵 | ≥20 |
| 一级 | 24-28 | 果形端正，色泽鲜红，轻微瑕疵 | 18-20 |
| 二级 | 20-24 | 果形较端正，色泽较好 | 16-18 |

### 6.3 贮运保鲜

仙进奉耐贮性好，采后立即预冷至5-8℃，采用二氧化氯熏蒸或咪鲜胺浸泡杀菌处理。包装采用泡沫箱+冰袋方式，冷藏运输温度3-5℃。冷藏条件下保鲜期10-15天，货架期2-3天。

## 七、经济效益

仙进奉盛产期株产30-60公斤，每公顷产量9000-18000公斤。市场售价50-120元/公斤，每公顷产值45-216万元，生产成本约30-50万元/公顷，纯收益15-166万元/公顷。该品种由于品质优、耐贮运，经济效益显著高于普通荔枝品种。
