# 荔枝酸腐病防治技术规程

> 本规程规定了荔枝酸腐病的症状识别、病原鉴定、发病规律和综合防治技术，涵盖采前预防和采后处理两个关键环节，适用于荔枝产区酸腐病的防治管理。

---

## 一、病害概述

荔枝酸腐病（Lychee Sour Rot）是荔枝成熟果实和采后果实的重要病害，由酵母菌（*Geotrichum candidum*）和多种细菌（*Erwinia* spp.、*Pseudomonas* spp.等）复合侵染引起。该病在果实成熟期和采后贮运过程中发生，可导致果实严重腐烂，造成重大经济损失。该病最典型的特征是病果产生强烈的酸臭味。

---

## 二、症状识别

### 2.1 症状特征
| 发病阶段 | 症状描述 | 典型特征 |
|---------|---------|---------|
| 初期 | 果皮出现水渍状褐色斑块，病健交界不明显 | 果皮颜色变暗 |
| 中期 | 病斑迅速扩大，整个果实变褐软化 | 果皮变软，稍有酸味 |
| 后期 | 果实内部浆液化，流出酸臭汁液，果皮皱缩 | 强烈的酸臭味，汁液流出 |
| 末期 | 果实完全腐烂，仅剩果皮和果核 | 全果腐烂，无法食用 |

### 2.2 与其他果实病害的区别
| 病害 | 关键区别特征 |
|------|-------------|
| 酸腐病 | 强烈酸臭味，无霉层，果实浆液化 |
| 霜疫霉病 | 白色霉层，水渍状，有霉味 |
| 炭疽病 | 凹陷病斑，粉红色孢子团，无酸臭味 |
| 蒂蛀虫危害 | 虫孔、虫粪，果肉不腐烂 |

### 2.3 病情分级标准
| 级别 | 症状描述 |
|------|---------|
| 0级 | 果实正常，无病斑 |
| 1级 | 果皮出现<5%面积水渍状斑块 |
| 3级 | 病斑面积5-20%，果肉开始变色 |
| 5级 | 病斑面积20-50%，有轻微酸臭味 |
| 7级 | 病斑面积>50%，严重酸臭味，汁液外流 |
| 9级 | 全果腐烂，不堪食用 |

## 三、病原与发病规律

### 3.1 病原特征
| 病原 | 分类 | 特征 |
|------|------|------|
| *Geotrichum candidum* | 半知菌亚门地霉属 | 酵母样真菌，菌丝有横隔，节孢子 |
| *Erwinia* spp. | 肠杆菌科欧文氏菌属 | 革兰氏阴性杆菌，兼性厌氧 |
| *Pseudomonas* spp. | 假单胞菌科假单胞菌属 | 革兰氏阴性杆菌，好氧 |
| *Acetobacter* spp. | 醋酸菌科 | 产酸细菌，增加酸味 |

### 3.2 发病规律
| 因素 | 规律描述 |
|------|---------|
| 侵染途径 | 通过果皮伤口（机械损伤、虫伤、裂果）侵入 |
| 温度 | 最适发病温度25-30°C，>35°C或<10°C受抑制 |
| 湿度 | 高湿度(>90%)利于发病 |
| 传播方式 | 接触传播，病果与健康果直接接触即可传染 |
| 高发条件 | 果实采收后堆放、运输过程中高温高湿+机械损伤 |
| 品种差异 | 果皮薄、易裂果的品种发病重（如桂味、糯米糍） |
| 虫害关联 | 蒂蛀虫危害增加伤口，显著提高发病风险 |

### 3.3 发病速度
| 温度条件 | 果实状态 | 发病时间 |
|---------|---------|---------|
| 30°C+高湿 | 有伤口 | 12-24小时 |
| 25°C+高湿 | 有伤口 | 24-48小时 |
| 20°C+高湿 | 有伤口 | 48-72小时 |
| 2-4°C冷藏 | 有伤口 | 7-10天 |

## 四、防治技术

### 4.1 采前预防
| 防治措施 | 技术要求 | 实施时间 | 预期效果 |
|---------|---------|---------|---------|
| 减少裂果 | 稳控水分，增施钙肥(硝酸钙0.1-0.2kg/株) | 果实发育期 | 减少裂果率50%以上 |
| 防治蒂蛀虫 | 高效氯氟氰菊酯3000倍液或氯虫苯甲酰胺3000倍液 | 幼果期-膨大期 | 减少虫伤 |
| 杀菌剂保护 | 咪鲜胺1000倍液或嘧菌酯1500倍液 | 采前7-10天 | 降低果面菌量 |
| 避免雨天采收 | 晴天或阴天采收，雨后3天内不采收 | 采收期 | 减少果实含水量 |
| 卫生采收 | 采收时轻拿轻放，减少机械损伤 | 采收期 | 减少伤口 |

### 4.2 采后处理（关键环节）
#### 4.2.1 预冷处理
| 项目 | 技术要求 |
|------|---------|
| 预冷时间 | 采收后2小时内 |
| 预冷温度 | 2-4°C |
| 预冷方式 | 强制风冷或冷水预冷 |
| 果心温度 | 降至8°C以下 |

#### 4.2.2 分级挑拣
| 项目 | 要求 |
|------|------|
| 剔除标准 | 裂果、虫果、机械损伤果、病果 |
| 检验比例 | 逐果检查 |
| 不合格果处理 | 单独存放，及时处理 |
| 分级标准 | 按大小、色泽、完整度分级 |

#### 4.2.3 药剂浸泡处理
| 药剂名称 | 浓度 | 浸泡时间 | 安全间隔期 |
|---------|------|---------|-----------|
| 咪鲜胺 | 45%EC 1000倍液 | 2分钟 | 7天 |
| 噻菌灵 | 50%SC 500倍液 | 2分钟 | 14天 |
| 异菌脲 | 50%SC 500倍液 | 2分钟 | 7天 |
| 双胍三辛烷基苯磺酸盐 | 40%WP 1000倍液 | 2分钟 | 7天 |
| 二氧化氯 | 100mg/L溶液 | 1分钟 | 无需间隔 |

#### 4.2.4 包装要求
| 包装项目 | 要求 |
|---------|------|
| 包装材料 | 打孔保鲜袋，孔径0.5-1cm |
| 包装量 | 每袋不超过5kg |
| 堆放厚度 | 不超过30cm |
| 包装方式 | 单层摆放或分层摆放 |

#### 4.2.5 冷链运输
| 环节 | 温度要求 | 相对湿度 |
|------|---------|---------|
| 运输前冷藏 | 2-4°C | 90-95% |
| 运输途中 | 2-4°C | 90-95% |
| 销售冷柜 | 4-8°C | 85-90% |
| 家庭冷藏 | 4-8°C | 不宜超过3天 |

---

## 五、采后处理流程图

```
采收 → 2小时内预冷(2-4°C) → 剔除病果虫果裂果 
→ 药剂浸泡处理(2分钟) → 沥干水分 → 打孔包装 
→ 冷链运输(2-4°C) → 销售
```

## 六、防治效果评价

### 6.1 效果指标
| 指标 | 评价方法 | 优秀标准 |
|------|---------|---------|
| 采后48小时发病率 | 抽查100个果实 | <3% |
| 采后72小时发病率 | 抽查100个果实 | <5% |
| 货架期(常温) | 维持商品性时间 | >48小时 |
| 商品果率 | 符合销售标准的果实比例 | >95% |

### 6.2 采后处理效果对比
| 处理方式 | 常温(25°C)下保存时间 | 冷藏(4°C)下保存时间 |
|---------|-------------------|-------------------|
| 未经处理 | 24-36小时 | 3-5天 |
| 拣果+预冷 | 36-48小时 | 5-7天 |
| 药剂浸泡+预冷 | 48-72小时 | 7-10天 |
| 全程冷链 | 72-96小时 | 10-14天 |
