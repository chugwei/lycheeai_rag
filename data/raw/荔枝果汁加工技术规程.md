# 荔枝果汁加工技术规程

## 摘要

荔枝果汁加工是将荔枝果肉经破碎、榨汁、澄清、浓缩、杀菌等工序制成饮料原料的工业化过程。荔枝果汁富含维生素 C、多酚和花青素等活性成分，具有独特的风味。本规程规定了荔枝果汁加工的全流程工艺参数、设备选型及质量控制标准，适用于荔枝原汁、荔枝浓缩汁等产品的规模化生产。

## 1. 引言

荔枝果汁加工是荔枝产业化利用的重要方向，可有效解决鲜果销售周期短、储运损耗大的问题。荔枝果汁产品包括鲜榨果汁、NFC（非浓缩还原）果汁、浓缩果汁及果汁饮料等品类。

## 2. 原料要求与预处理

### 2.1 加工用原料标准

| 指标 | 要求 | 备注 |
|------|------|------|
| 品种 | 妃子笑、白糖罂、糯米糍 | 妃子笑汁率高 |
| 成熟度 | 8~9 成熟 | 糖酸比最优 |
| 可溶性固形物 | ≥14°Brix | 保证出汁品质 |
| 可滴定酸 | 0.20%~0.40% | 风味平衡 |
| 腐烂率 | ≤2% | 剔除标准 |
| 褐变率 | ≤5% | 保证色泽 |

### 2.2 预处理流程

| 步骤 | 操作 | 参数 | 目的 |
|------|------|------|------|
| 1 | 原料验收 | 检测糖度、酸度 | 品质把关 |
| 2 | 清洗 | 流动水 + 毛刷清洗 | 去除表面污物 |
| 3 | 预冷 | 5~8°C | 降低酶活性 |
| 4 | 剥壳 | 手工/机械剥壳 | 去壳取果肉 |
| 5 | 去核 | 人工去核 | 提高果肉纯度 |
| 6 | 护色 | 0.05%~0.1% 抗坏血酸浸泡 | 防止褐变 |
| 7 | 破碎 | 滚筒式破碎机 | 破碎果肉 |

## 3. 榨汁工艺

### 3.1 榨汁方式

| 榨汁方式 | 出汁率 | 汁液品质 | 适用产品 |
|---------|-------|---------|---------|
| 挤压榨汁 | 55%~65% | 含果渣较多 | 全汁型产品 |
| 压榨榨汁 | 60%~70% | 清澈度高 | 澄清汁 |
| 酶解辅助榨汁 | 70%~80% | 出汁率高 | 高效加工 |
| 离心榨汁 | 65%~75% | 快速、汁液清 | 大规模生产 |

### 3.2 酶解处理参数

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 果胶酶用量 | 0.05%~0.1%（占果肉重） | 提高出汁率 |
| 处理温度 | 45~50°C | 酶活性最适 |
| 处理时间 | 30~60 min | 充分酶解 |
| pH 调节 | 3.5~4.0 | 酶活性最适 |

### 3.3 榨汁后处理

| 步骤 | 操作 | 目的 |
|------|------|------|
| 粗滤 | 100~150 目筛网 | 去除大颗粒果渣 |
| 精滤 | 300~400 目筛网或袋滤 | 去除细颗粒 |
| 脱气 | 真空脱气（50~70 kPa） | 去除氧气，防止氧化 |
| 预热 | 60~65°C | 灭酶、杀菌 |

## 4. 澄清与浓缩

### 4.1 澄清方法

| 方法 | 原理 | 澄清度 | 适用性 |
|------|------|-------|-------|
| 自然沉降 | 重力分离 | 中等 | 小规模 |
| 离心澄清 | 高速离心 | 高 | 大规模 |
| 酶澄清 | 果胶酶+淀粉酶 | 高 | 全汁型 |
| 膜过滤 | 超滤/微滤 | 极高 | 高端产品 |
| 膨润土澄清 | 吸附絮凝 | 高 | 传统方法 |

### 4.2 澄清工艺参数

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 果胶酶用量 | 0.03%~0.08% | 水解果胶 |
| 处理温度 | 45~55°C | 酶活性温度 |
| 处理时间 | 30~90 min | 充分反应 |
| 静置时间 | 4~8 h | 自然沉降 |
| 离心转速 | 3000~5000 r/min | 离心分离 |

### 4.3 浓缩工艺

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 浓缩方式 | 真空蒸发（降膜/刮板式） | 低温浓缩 |
| 浓缩温度 | 40~55°C | 避免高温破坏风味 |
| 真空度 | 30~50 kPa | 降低沸点 |
| 浓缩倍数 | 3~6 倍 | 至可溶性固形物 35%~45°Brix |
| 保留风味物质 | 香气回收冷凝器 | 保持荔枝风味 |

## 5. 杀菌工艺

### 5.1 杀菌方式

| 杀菌方式 | 温度（°C） | 时间 | 效果 | 适用产品 |
|---------|----------|------|------|---------|
| 巴氏杀菌 | 75~85 | 15~30 s | 商业无菌 | 鲜榨汁、NFC 果汁 |
| 高温瞬时杀菌 | 90~95 | 5~10 s | 商业无菌 | 浓缩汁 |
| 超高压杀菌 | 常温 | 200~400 MPa | 非热杀菌 | 高端 NFC |
| UV 杀菌 | 常温 | 30~60 s | 表面杀菌 | 辅助杀菌 |
| 膜过滤 | 常温 | 即时 | 除菌 | 冷杀菌果汁 |

### 5.2 杀菌 F₀ 值计算

| 杀菌条件 | F₀ 值（min） | 产品 |
|---------|------------|------|
| 85°C/15 s | 0.5~1.0 | 鲜榨汁 |
| 90°C/5 s | 1.0~2.0 | 浓缩汁 |
| 95°C/10 s | 2.0~3.0 | 高酸果汁 |

## 6. 产品规格

### 6.1 荔枝鲜榨果汁

| 指标 | 要求 |
|------|------|
| 可溶性固形物 | 10°~14°Brix |
| 可滴定酸 | 0.3%~0.6%（以柠檬酸计） |
| 蛋白质 | ≥0.3% |
| 微生物 | 符合 GB 2760 标准 |
| 包装 | 200 mL~1 L PET 瓶或玻璃瓶 |

### 6.2 荔枝浓缩汁

| 指标 | 要求 |
|------|------|
| 可溶性固形物 | 35°~45°Brix |
| 还原后风味 | 与原果汁一致 |
| 蛋白质 | ≥1.5% |
| 微生物 | 符合出口标准 |
| 包装 | 25 kg 塑料桶或 300 L 不锈钢桶 |

## 7. 质量控制

| 控制点 | 指标 | 频率 |
|-------|------|------|
| 原料糖度 | ≥14°Brix | 每批次 |
| 出汁率 | ≥60% | 每班 |
| 汁液澄清度 | 透光率 ≥90% | 每批次 |
| 杀菌温度 | 75~95°C | 连续监控 |
| 微生物检测 | 符合国标 | 每批次 |

## 8. 结论

荔枝果汁加工的关键在于原料品质控制、高效榨汁和低温杀菌。通过酶解辅助榨汁可将出汁率提高至 75% 以上，真空浓缩结合香气回收可保持荔枝独特风味。
