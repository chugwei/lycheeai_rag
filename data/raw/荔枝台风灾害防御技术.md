# 荔枝台风灾害防御技术

## 摘要

本文件规定了荔枝园台风灾害的防御技术，涵盖台风预警监测、防台准备、抗风栽培、应急加固、灾后恢复等技术内容。台风是华南荔枝产区最主要的自然灾害之一，每年5-11月均有台风影响，强台风可造成荔枝园80%以上的产量损失。本文件为荔枝主产区台风灾害防御提供系统技术指导，通过科学的综合防御措施，可将台风损失降低40%-60%。

## 1 总则

### 1.1 适用范围

适用于广东、广西、海南、福建等荔枝台风频发产区的台风灾害防御。

### 1.2 台风等级

| 台风等级 | 风力 | 风速(m/s) | 荔枝园危害 |
|---------|------|----------|-----------|
| 热带低压 | 6-7级 | 10.8-17.1 | 轻度摇晃 |
| 热带风暴 | 8-9级 | 17.2-24.4 | 落叶、落果 |
| 强热带风暴 | 10-11级 | 24.5-32.6 | 折枝、倒伏 |
| 台风 | 12级 | 32.7-41.4 | 倒伏、断干 |
| 强台风 | 13-14级 | 41.5-50.9 | 大量倒伏 |
| 超强台风 | ≥15级 | >51.0 | 毁灭性破坏 |

### 1.3 台风影响周期

| 阶段 | 时间 | 特征 | 应对重点 |
|------|------|------|---------|
| 预兆期 | 台风登陆前72小时 | 风力增强，降雨增多 | 加固准备 |
| 影响期 | 台风登陆前后12小时 | 狂风暴雨 | 应急防护 |
| 余波期 | 台风登陆后24小时 | 持续降雨 | 排水防涝 |
| 恢复期 | 台风过后 | 灾害评估 | 恢复生产 |

## 3 防台准备

### 3.1 果园加固

| 加固对象 | 加固方法 | 材料 |
|---------|---------|------|
| 成年树 | 支柱支撑主枝 | 竹竿/木桩 |
| 幼树 | 立支柱绑扎 | 竹竿 |
| 行道树 | 修剪弱枝 | - |
| 设施 | 拆除或加固大棚 | - |
| 排水沟 | 清理堵塞 | - |

### 3.2 支柱加固

| 参数 | 技术要求 |
|------|---------|
| 支柱材质 | 竹竿或木桩，直径≥8cm |
| 支柱长度 | 比树高多出0.5-1.0m |
| 支柱数量 | 每株3-4根(三角形支撑) |
| 绑扎材料 | 塑料带或麻绳 |
| 绑扎高度 | 主枝分叉处 |
| 倾斜角度 | 支柱向外倾斜30° |

### 3.3 修剪防台

| 修剪对象 | 修剪量 | 目的 |
|---------|--------|------|
| 徒长枝 | 全剪 | 减少受风面 |
| 弱枝 | 全剪 | 减少折损 |
| 过密枝 | 疏剪30% | 增加通透性 |
| 下垂枝 | 短截 | 防断裂 |
| 注意 | 台风前7-10天完成 | 避免新梢生长 |

## 4 抗风栽培技术

### 4.1 品种选择

| 品种 | 抗风性 | 特点 |
|------|--------|------|
| 挂绿 | 较强 | 主干粗壮，分枝角度大 |
| 怀枝 | 中 | 冠幅适中 |
| 白糖罂 | 中 | 树势中等 |
| 妃子笑 | 弱 | 树冠松散，易折 |
| 糯米糍 | 弱 | 枝条柔韧，易倒 |
| 桂味 | 中 | 树冠紧凑 |

### 4.2 整形修剪

| 修剪方式 | 操作 | 抗风效果 |
|---------|------|---------|
| 矮化修剪 | 控制树高3-4m | 降低重心，减少受风 |
| 开心形 | 主干2-3m开张 | 减少风阻 |
| 自然圆头形 | 保留主枝3-4个 | 均衡受风 |
| 疏枝 | 疏除内膛密枝 | 增加通透性 |

### 4.3 密度控制

| 密度(株/亩) | 抗风性 | 适用 |
|-----------|--------|------|
| 30-40 | 好 | 高抗风区域 |
| 40-50 | 中 | 一般区域 |
| 50-60 | 差 | 需支柱加固 |
| >60 | 差 | 易相互倒伏 |

## 5 应急防护

### 5.1 抢收措施

| 条件 | 措施 | 时间窗口 |
|------|------|---------|
| 台风前果实已成熟 | 提前采收上市 | 台风前3-5天 |
| 果实半成熟 | 适当提前采收 | 台风前1-2天 |
| 幼果期 | 无法抢收 | 重点加固 |
| 花期 | 无法抢收 | 重点加固 |

### 5.2 人员安全

| 措施 | 要求 |
|------|------|
| 人员撤离 | 台风红色预警时全员撤离 |
| 值守人员 | 仅留应急值班人员 |
| 通讯设备 | 保持手机、对讲机畅通 |
| 应急物资 | 准备食物、水、药品 |

## 6 灾后恢复

### 6.1 灾害评估

| 灾害类型 | 等级 | 损失率 | 恢复周期 |
|---------|------|--------|---------|
| 落叶落果 | 轻 | <10% | 1个月 |
| 枝条折断 | 中 | 10%-30% | 3-6个月 |
| 树干断裂 | 重 | 30%-60% | 6-12个月 |
| 整株倒伏 | 严重 | >60% | 需重建 |

### 6.2 恢复措施

| 阶段 | 时间 | 措施 |
|------|------|------|
| 清理 | 灾后1-3天 | 清理倒伏、折断树 |
| 排水 | 灾后当天 | 疏通排水沟 |
| 修剪 | 灾后3-7天 | 剪除折枝、枯枝 |
| 扶正 | 灾后3-5天 | 扶正倒伏树，支柱 |
| 伤口处理 | 修剪后 | 涂伤口愈合剂 |
| 施肥 | 灾后10-15天 | 施恢复肥 |
| 病虫害防治 | 灾后7-10天 | 防治伤口感染 |

### 6.3 倒伏树处理

| 倒伏程度 | 处理方法 | 预期恢复 |
|---------|---------|---------|
| 轻度倾斜 | 扶正+支柱 | 可恢复 |
| 重度倾斜 | 截干+扶正+支柱 | 部分恢复 |
| 主干断裂 | 保留下部截干重植 | 可恢复 |
| 完全倒伏 | 砍除重建 | 需重栽 |
