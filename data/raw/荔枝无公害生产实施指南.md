# 荔枝无公害生产实施指南

## 摘要

荔枝无公害生产是指在生产过程中，将农药、化肥、生长调节剂等农业投入品对环境和人体的危害控制在安全标准范围内的生产方式。本指南系统阐述了荔枝无公害生产的技术标准、实施方法和质量控制要求，为荔枝产区推广无公害生产提供技术指导。

## 1. 引言

无公害农产品是我国农产品质量安全认证体系的重要组成部分，与绿色食品、有机食品构成三级认证体系。无公害农产品认证侧重于"安全"，即农产品的有毒有害物质限量符合国家标准。截至2023年，全国无公害农产品认证总量超过50万个，是覆盖面最广的农产品质量认证。荔枝无公害生产是实现"绿色革命"和食品安全的重要基础。

## 2. 无公害生产标准体系

### 2.1 标准框架

| 标准类型 | 标准名称 | 主要内容 |
|----------|----------|----------|
| 产地环境 | 无公害农产品产地环境要求 | 土壤、水、气标准 |
| 生产技术 | 荔枝无公害生产技术规程 | 种植管理 |
| 产品标准 | 荔枝无公害产品标准 | 质量安全指标 |
| 投入品 | 允许和限制使用投入品 | 农药化肥清单 |
| 包装标识 | 包装与标识规定 | 标签规范 |

### 2.2 无公害农产品认证等级

| 等级 | 特点 | 要求 |
|------|------|------|
| 无公害 | 基本安全 | 农药残留≤GB 2763 |
| 绿色A级 | 安全优质 | 限量使用化学投入品 |
| 绿色AA级(有机) | 最安全 | 禁用化学合成投入品 |

## 3. 产地环境要求

### 3.1 大气环境质量

| 项目 | 日均值限值 | 年均值限值 |
|------|------------|------------|
| 二氧化硫 | ≤0.15mg/m³ | ≤0.06mg/m³ |
| 氮氧化物 | ≤0.12mg/m³ | ≤0.08mg/m³ |
| 氟化物 | ≤0.02mg/m³ | ≤0.01mg/m³ |

### 3.2 土壤环境质量

| 项目 | 水田标准(mg/kg) | 旱地标准(mg/kg) |
|------|-----------------|-----------------|
| pH | 5.5-8.5 | 5.5-8.5 |
| 镉 | ≤0.30 | ≤0.30 |
| 汞 | ≤0.15 | ≤0.50 |
| 砷 | ≤25 | ≤40 |
| 铅 | ≤120 | ≤200 |
| 铬 | ≤150 | ≤250 |

### 3.3 灌溉水质

| 项目 | 限值 |
|------|------|
| pH | 5.5-8.5 |
| 化学需氧量 | ≤120mg/L |
| 石油类 | ≤10mg/L |
| 总氮 | ≤120mg/L |
| 总磷 | ≤20mg/L |
| 大肠菌群 | ≤10000个/L |

## 4. 生产技术规程

### 4.1 产地选择与布局

| 要求 | 内容 |
|------|------|
| 远离污染源 | 工业区≥500m,交通干线≥50m |
| 环境质量 | 符合产地环境标准 |
| 种植历史 | 非重度污染地块 |
| 隔离条件 | 与常规种植区有隔离带 |

### 4.2 品种选择

| 要求 | 内容 |
|------|------|
| 抗病虫害 | 优先选择抗虫抗病品种 |
| 品质优良 | 口感好、外观佳 |
| 适应性 | 适应当地气候条件 |
| 品种来源 | 经检疫合格 |

### 4.3 土壤管理

| 措施 | 内容 | 频次 |
|------|------|------|
| 土壤检测 | 检测pH、养分、重金属 | 每年1次 |
| 增施有机肥 | 施用腐熟有机肥 | 每年2-3次 |
| 绿肥种植 | 种植豆科绿肥 | 每年1-2次 |
| 秸秆还田 | 修剪物粉碎还田 | 每年 |

### 4.4 科学施肥

| 原则 | 内容 |
|------|------|
| 测土配方 | 根据土壤检测确定施肥量 |
| 有机肥为主 | 有机肥与化肥配施 |
| 控氮增磷钾 | 控制氮肥用量，增施磷钾肥 |
| 精准施肥 | 分次施用，提高利用率 |

### 4.5 病虫无害化防治

| 技术 | 内容 | 要求 |
|------|------|------|
| 物理防治 | 粘虫板、诱杀灯、果袋 | 优先使用 |
| 生物防治 | 天敌、生物农药 | 优先使用 |
| 农业防治 | 清洁果园、合理修剪 | 基础措施 |
| 化学防治 | 高效低毒农药 | 最后手段 |
| 安全间隔期 | 严格执行 | 确保采收前停药 |

**允许使用的低毒低残留农药**：

| 农药名称 | 防治对象 | 剂量(g/a.i./亩) | 安全间隔期(天) |
|----------|----------|-----------------|---------------|
| 吡虫啉 | 荔枝蝽、介壳虫 | 15-25 | 14 |
| 噻虫嗪 | 粉虱、蚜虫 | 10-15 | 10 |
| 甲维盐 | 蒂蛀虫 | 5-10 | 7 |
| 嘧菌酯 | 炭疽病、霜疫霉病 | 30-50 | 14 |
| 吡唑醚菌酯 | 炭疽病、白粉病 | 20-30 | 10 |

### 4.6 采收与采后处理

| 环节 | 要求 |
|------|------|
| 采收时期 | 达到商品成熟度 |
| 安全间隔 | 满足最后一次施药的安全间隔期 |
| 采收工具 | 消毒剪刀 |
| 采后处理 | 去除病果、虫果 |
| 包装 | 使用洁净包装材料 |
| 标识 | 贴无公害农产品标识 |

## 5. 质量控制

### 5.1 产品安全指标

| 指标 | 限值 | 检测方法 |
|------|------|----------|
| 农药残留 | 符合GB 2763 | GC-MS/LC-MS |
| 铅 | ≤0.2mg/kg | AFS |
| 镉 | ≤0.05mg/kg | AFS |
| 汞 | ≤0.01mg/kg | AFS |
| 六六六 | ≤0.05mg/kg | GC |
| 滴滴涕 | ≤0.05mg/kg | GC |
| 二氧化硫 | ≤50mg/kg | 离子色谱 |

### 5.2 感官品质

| 指标 | 要求 |
|------|------|
| 形状 | 端正，品种特征明显 |
| 色泽 | 鲜红或紫红，有光泽 |
| 香味 | 具有品种特有香气 |
| 肉质 | 饱满，化渣 |
| 滋味 | 甜酸适中 |

## 6. 认证流程

| 步骤 | 时间 | 内容 |
|------|------|------|
| 产地环境评价 | 1个月 | 环境检测 |
| 提交申请 | 1周 | 申请材料 |
| 材料审核 | 2周 | 文件审核 |
| 现场检查 | 1-2天 | 实地核查 |
| 产品检测 | 2周 | 实验室检测 |
| 认证决定 | 1周 | 评审决定 |
| 颁发证书 | 1周 | 发放证书 |
