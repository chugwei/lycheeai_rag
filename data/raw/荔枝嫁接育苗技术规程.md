# 荔枝嫁接育苗技术规程

> 本标准规定了荔枝嫁接育苗的术语和定义、砧木培育、接穗采集与处理、嫁接技术、嫁接后管理及苗木出圃等环节的技术要求。适用于荔枝各品种的嫁接育苗生产。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝各品种（包括妃子笑、桂味、糯米糍、黑叶、白糖罂等）的嫁接育苗，包括小苗嫁接和苗木嫁接。

## 二、嫁接原理与成活条件

### 嫁接成活原理
荔枝嫁接成活的关键在于砧木和接穗的形成层紧密结合，形成愈伤组织并分化出新的输导组织，使上下两部分连通成为一体。

### 影响嫁接成活的因素
| 因素 | 影响程度 | 最佳条件 |
|-----|---------|---------|
| 砧穗亲和力 | 最关键 | 同种或同属不同种 |
| 温度 | 重要 | 20-30°C |
| 湿度 | 重要 | 相对湿度80-90% |
| 砧木生长状态 | 重要 | 生长旺盛，形成层活跃 |
| 接穗质量 | 重要 | 芽饱满，枝条充实 |
| 嫁接技术 | 关键 | 切面平整，形成层对齐 |

## 三、砧木培育

### 砧木选择
| 砧木种类 | 亲和性 | 根系特性 | 适用品种 | 备注 |
|---------|-------|---------|---------|------|
| 怀枝 | 优良 | 根系发达，主根深 | 所有品种 | 最常用砧木 |
| 山枝 | 优良 | 耐瘠薄，抗旱 | 所有品种 | 山地果园适用 |
| 酸荔枝 | 良好 | 耐湿，适应性强 | 糯米糍等 | 低洼地适用 |
| 黑叶 | 良好 | 生长快，根系发达 | 妃子笑等 | 早产早丰 |
| 三月红 | 一般 | 生长强壮 | 早熟品种 | 部分品种不亲和 |

### 砧木苗培育标准
| 砧木年龄 | 茎粗要求(cm) | 苗高要求(cm) | 嫁接适宜期 |
|---------|------------|------------|---------|
| 1年生 | 0.6-1.0 | 40-60 | 春、秋季 |
| 2年生 | 1.0-1.5 | 60-100 | 春、秋季 |

## 四、接穗采集与处理

### 接穗质量标准
| 项目 | 一级接穗 | 二级接穗 |
|-----|---------|---------|
| 母树树龄 | 5-15年盛产期 | 3年以上结果树 |
| 枝条年龄 | 1年生 | 1年生 |
| 枝条粗度 | 0.6-1.0cm | 0.4-0.8cm |
| 芽眼 | 饱满，3-5个饱满芽 | 饱满，2-3个饱满芽 |
| 枝条状态 | 木质化良好，充实 | 半木质化以上 |
| 病虫害 | 无 | 无 |

### 接穗采集方法
| 操作步骤 | 技术要求 |
|---------|---------|
| 采穗时间 | 清晨(6:00-9:00)或阴天，避免高温时段 |
| 采穗部位 | 树冠外围中上部，向阳面枝条 |
| 采穗工具 | 锋利修枝剪，消毒处理 |
| 采后处理 | 剪除叶片（保留叶柄），立即保湿 |
| 标签 | 注明品种、采集日期、母树编号 |

### 接穗保存运输
| 保存方式 | 保存时间 | 操作方法 |
|---------|---------|---------|
| 短期保存(1-3天) | 3天 | 湿毛巾包裹，放阴凉处 |
| 中期保存(3-15天) | 15天 | 湿沙层积，温度10-15°C |
| 长期保存(15-60天) | 60天 | 塑料袋密封，2-4°C冷藏 |
| 运输 | - | 保湿包装，避免挤压 |

## 五、嫁接技术

### 嫁接时期
| 季节 | 嫁接时间 | 成活率(%) | 管理要点 |
|-----|---------|----------|---------|
| 春接 | 2月下旬-4月中旬 | 85-95 | 气温回升后，树液开始流动 |
| 夏接 | 5月中旬-6月中旬 | 70-80 | 需遮荫，注意保湿 |
| 秋接 | 9月上旬-10月中旬 | 80-90 | 气温适宜，成活率高 |
| 冬接 | 12月-1月 | 50-60 | 低温期不宜大规模嫁接 |

### 嫁接方法

#### 切接法（最常用）
| 操作步骤 | 技术要点 |
|---------|---------|
| 1.削砧木 | 离地面10-15cm剪断砧木，选平滑面斜切2-3cm长切口 |
| 2.削接穗 | 接穗下端削成2-3cm楔形面，保留2个芽 |
| 3.插入 | 接穗楔形面插入砧木切口，一侧形成层对齐 |
| 4.绑扎 | 用嫁接膜从下往上包扎，仅露芽眼 |
| 5.封顶 | 接穗上端剪口用蜡或嫁接膜封口 |

#### 劈接法
| 操作步骤 | 技术要点 |
|---------|---------|
| 1.削砧木 | 砧木离地10-15cm剪断，从中心劈开2-3cm |
| 2.削接穗 | 接穗下端削成楔形，两面对称 |
| 3.插入 | 将接穗插入劈口，形成层对齐 |
| 4.绑扎 | 嫁接膜严密包扎 |

#### 腹接法
| 操作步骤 | 技术要点 |
|---------|---------|
| 1.切砧木 | 砧木不剪断，在光滑处切T形或盾形口 |
| 2.削接穗 | 接穗削成盾形芽片 |
| 3.插入 | 将芽片插入砧木切口 |
| 4.绑扎 | 露出芽眼，其余包扎严密 |

## 六、嫁接后管理

### 各项管理措施
| 管理项目 | 操作时间 | 技术要求 |
|---------|---------|---------|
| 抹芽 | 嫁接后7天开始 | 每7-10天抹除砧木萌芽1次，连续3-5次 |
| 遮荫 | 嫁接后立即 | 搭设遮荫棚，遮光率50-60%，7-10天后逐步去除 |
| 浇水 | 根据土壤湿度 | 保持土壤湿润，避免过干过湿 |
| 施肥 | 新梢老熟后 | 薄施稀粪水或0.2%尿素 |
| 解绑 | 新梢木质化后 | 用小刀划断嫁接膜，勿伤及苗木 |
| 立支柱 | 新梢长30cm时 | 竹竿绑缚，防止风折 |
| 病虫害防治 | 新梢期 | 重点防治炭疽病、蚜虫、瘿螨 |
| 整形 | 苗高40-50cm | 摘心定干，促发分枝 |

### 成活率调查
| 调查时间 | 调查内容 | 判定标准 |
|---------|---------|---------|
| 嫁接后15-20天 | 愈伤组织形成情况 | 形成愈伤组织为成活 |
| 嫁接后30-40天 | 萌芽抽梢情况 | 接穗芽萌发为新梢为成活 |
| 嫁接后60天 | 新梢生长情况 | 新梢长度≥10cm为成活 |

## 七、苗木出圃

### 出圃标准
| 苗木等级 | 苗龄(月) | 苗高(cm) | 茎粗(cm) | 分枝(条) | 根系 |
|---------|---------|---------|---------|---------|------|
| 一级 | 12-18 | 50-80 | ≥1.0 | 2-3 | 发达，主根≥25cm |
| 二级 | 12-18 | 40-60 | 0.8-1.0 | 1-2 | 较发达，主根≥20cm |

### 苗木检疫
- 出圃前必须进行产地检疫
- 检疫合格后签发《植物检疫证书》
- 检疫对象：荔枝溃疡病、根结线虫等
