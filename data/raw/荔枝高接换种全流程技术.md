# 荔枝高接换种全流程技术

## 摘要

荔枝高接换种是将劣种荔枝树通过嫁接技术改造为优种的高效方法，可快速实现品种更新，缩短新品种进入盛产期的年限，降低建园成本。本文系统阐述高接换种的嫁接时期选择、嫁接方法、接穗采集与处理、嫁接操作技术、嫁接后管理和成活了判定标准，为荔枝品种改良提供全流程技术指南。

## 1. 高接换种概述

荔枝高接换种适用于劣种树、退化老树、结果不良树和需要品种调整的老果园。高接换种成功后，1-2年即可试花，2-3年进入结果期，5-6年达到盛产期，比种子繁殖快6-10年。

## 2. 嫁接时期选择

### 2.1 适宜嫁接期

| 季节 | 时期 | 气温 | 适宜度 | 说明 |
|------|------|------|--------|------|
| 春季 | 2月下旬-4月上旬 | 18-28°C | ★★★★★ | 最佳时期，树液开始流动 |
| 夏季 | 6月上旬-7月下旬 | 25-32°C | ★★★★☆ | 砧木活跃，成活率高 |
| 秋季 | 9月上旬-10月上旬 | 22-28°C | ★★★☆☆ | 愈合期短，需保温 |
| 冬季 | 11月-次年1月 | 10-20°C | ★★☆☆☆ | 低温成活率低 |

### 2.2 高接换种最佳窗口期

最佳时期为3月中旬至4月上旬，此时气温稳定在18-25°C，砧木伤口愈合快，接穗萌发力强。

## 3. 嫁接方法

### 3.1 主要嫁接方法比较

| 嫁接方法 | 操作要点 | 成活率 | 适用砧木 | 推荐指数 |
|---------|---------|--------|---------|---------|
| 切接法 | 砧木切2cm斜面，接穗插入 | 85%-95% | 直径2-5cm | ★★★★★ |
| 劈接法 | 砧木劈开，插入楔形接穗 | 80%-90% | 直径5cm以上 | ★★★★☆ |
| 腹接法 | 砧木不截头，侧面腹接 | 75%-85% | 任意直径 | ★★★★☆ |
| 芽接法 | 嵌芽或切芽嫁接 | 85%-95% | 直径1-3cm | ★★★★★ |
| 桥接法 | 连接断头部位 | 70%-80% | 断头砧木 | ★★★☆☆ |
| 高空压条 | 空中压条后截接 | 90%-95% | 大型砧木 | ★★★★☆ |

### 3.2 推荐组合方案

| 砧木直径 | 主推荐方法 | 备选方法 |
|---------|-----------|---------|
| 1-2cm | 切芽接 | 切接法 |
| 2-5cm | 切接法 | 劈接法 |
| 5-10cm | 劈接法 | 腹接法 |
| 10cm以上 | 腹接法 | 高空压条 |

## 4. 接穗采集与处理

### 4.1 接穗采集标准

| 标准项目 | 要求 |
|---------|------|
| 母树选择 | 品种纯正、无病虫害、丰产稳产 |
| 枝条选择 | 一年生营养枝，直径0.5-1.0cm |
| 枝条状态 | 饱满充实，芽眼饱满 |
| 采集时间 | 嫁接前2-3天，随采随用 |
| 叶片处理 | 保留顶端2-3片叶，减少蒸腾 |

### 4.2 接穗保存

| 保存方法 | 适用时间 | 操作要点 |
|---------|---------|---------|
| 湿润沙藏 | 1-3天 | 湿沙中保存，温度5-10°C |
| 塑料袋密封 | 1-2天 | 保湿密封，常温保存 |
| 冷藏保鲜 | 5-7天 | 0-5°C冷藏，湿纸巾包裹 |
| 随采随用 | 当天 | 最佳，成活率最高 |

## 5. 嫁接操作流程

### 5.1 切接法操作流程

| 步骤 | 操作内容 | 注意事项 |
|------|---------|---------|
| 1.截砧 | 距地面80-100cm截断砧木主干 | 切口平滑，避免撕裂 |
| 2.切砧 | 砧木横切面1/3处纵切2cm | 深度一致，不伤形成层 |
| 3.削接穗 | 接穗下端削成一长一短两个斜面 | 长斜面2cm，短斜面0.5cm |
| 4.插入接穗 | 长斜面插入砧木切口，形成层对齐 | 确保至少一侧形成层对齐 |
| 5.绑扎 | 用嫁接膜包扎，露出芽眼 | 绑扎紧密，不透水 |
| 6.涂保护剂 | 切口处涂愈合剂 | 防止感染和水分蒸发 |

### 5.2 关键操作要点

- 嫁接刀具必须锋利，切口平滑
- 嫁接过程快速，减少砧穗暴露时间
- 形成层对齐是成活关键
- 绑扎力度适中，过紧影响愈合成活
- 嫁接后遮光保湿，促进愈合

## 6. 嫁接后管理

### 6.1 成活期管理（嫁接后1-3个月）

| 管理措施 | 操作要点 | 频率 |
|---------|---------|------|
| 遮光保湿 | 嫁接部位用塑料袋套袋 | 嫁接后立即 |
| 松绑 | 接穗萌芽后及时松绑 | 萌芽后3-5天 |
| 剪砧 | 砧木萌芽后及时剪除 | 发现即剪 |
| 扶梢 | 接穗萌发出梢后设立支柱 | 梢长10cm以上 |
| 施肥 | 接穗萌芽后施稀薄液肥 | 萌芽后 |

### 6.2 生长期管理（嫁接后3-12个月）

| 管理措施 | 操作要点 |
|---------|---------|
| 抹砧芽 | 定期抹除砧木萌芽，防止砧木反萌 |
| 控旺梢 | 夏梢过旺时适度摘心或化控 |
| 病虫害防治 | 重点防接穗上的害虫和病害 |
| 绑缚固定 | 接穗生长至一定高度后绑缚固定 |

## 7. 成活判定与补救

### 7.1 成活判定标准

| 时间节点 | 成活标志 | 判定方法 |
|---------|---------|---------|
| 嫁接后15天 | 接穗芽眼膨大 | 目测观察 |
| 嫁接后30天 | 接穗萌芽展叶 | 目测观察 |
| 嫁接后60天 | 新梢长至5-10cm | 测量 |
| 嫁接后90天 | 新梢老化，形成花芽 | 综合判断 |

### 7.2 未成活补救

| 未成活时间 | 补救措施 |
|-----------|---------|
| 嫁接后15-30天 | 同一位置重新嫁接 |
| 嫁接后30-60天 | 砧木不同部位补接 |
| 嫁接后60天以上 | 砧木保留，来年补接 |

## 8. 高接换种效果评价

| 评价项目 | 优良标准 |
|---------|---------|
| 成活率 | >90% |
| 接穗生长 | 当年新梢长>50cm |
| 品种表现 | 开花结果正常 |
| 砧木反萌 | 无砧木反萌现象 |
| 树势恢复 | 嫁接后2年树势正常 |

## 9. 注意事项

嫁接前应充分了解接穗品种特性。砧木和接穗亲和力需验证，不同品种间可能存在亲和性差异。嫁接后第一年重点管理，确保成活。
