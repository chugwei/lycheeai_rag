# 荔枝老树更新复壮技术

## 摘要

荔枝老树因长期结果导致树势衰弱、产量下降、品质退化，需要进行更新复壮。本文系统介绍了荔枝老树衰退的生理机制与诊断方法，详细阐述了地上部重回缩修剪、根系更新改良、培土施肥复壮、树干伤口处理等核心技术，并针对不同衰退程度的树体提出了差异化的更新复壮方案，结合案例分析说明了更新复壮的预期效果和配套管理措施，为荔枝老果园的提质增效提供技术参考。

## 一、老树衰退的原因与诊断

### 1.1 衰退原因

| 原因 | 具体表现 |
|------|---------|
| 树龄老化 | 枝干衰老，生理功能下降 |
| 根系衰退 | 吸收根减少，吸收能力下降 |
| 土壤退化 | 板结、酸化、养分失衡 |
| 病虫害累积 | 树干腐烂病、根结线虫等 |
| 负载过重 | 长期过量结果 |
| 管理粗放 | 修剪不当、肥水不足 |

### 1.2 衰退程度诊断

| 衰退等级 | 诊断指标 |
|---------|---------|
| 轻度(I级) | 新梢生长量减少30%以内，产量下降20%以内 |
| 中度(II级) | 新梢生长量减少30%-50%，产量下降20%-40%，部分枝条枯死 |
| 重度(III级) | 新梢生长量减少50%以上，产量下降40%以上，主干出现腐烂 |
| 极度(IV级) | 大部分枝条枯死，主干严重腐烂，基本无产量 |

## 二、地上部更新技术

### 2.1 重回缩修剪

| 衰退等级 | 修剪强度 | 保留枝量 | 回缩位置 |
|---------|---------|---------|---------|
| I级 | 轻回缩(15%-25%) | 保留75%-85%枝量 | 回缩至3-4年生枝 |
| II级 | 中回缩(25%-40%) | 保留60%-75%枝量 | 回缩至5-6年生枝 |
| III级 | 重回缩(40%-60%) | 保留40%-60%枝量 | 回缩至主干或主枝基部 |
| IV级 | 极重回缩(60%-80%) | 保留20%-40%枝量 | 主干锯断重新培养 |

### 2.2 更新时间

| 季节 | 适用区域 | 优缺点 |
|------|---------|-------|
| 春季(2-3月) | 所有产区 | 气温回升快，新梢抽生好 |
| 采果后(7-8月) | 广东、广西 | 恢复期长，利于积累养分 |
| 秋季(9-10月) | 海南、云南 | 避开高温，利于伤口愈合 |

### 2.3 伤口处理

| 步骤 | 操作要点 |
|------|---------|
| 锯口平整 | 用锋利锯子锯平，不撕裂树皮 |
| 消毒处理 | 涂抹70%甲基托布津或波尔多液 |
| 涂保护剂 | 涂抹伤口愈合剂或接蜡 |
| 定期检查 | 每季度检查一次，补涂保护剂 |

## 三、根系更新技术

### 3.1 断根促新

| 方法 | 操作要点 |
|------|---------|
| 分期断根 | 分2-3年完成，每次处理树冠1/3范围 |
| 断根位置 | 树冠滴水线内侧20-30厘米 |
| 断根深度 | 30-50厘米 |
| 断根粗度 | 剪断0.5-2厘米粗的根 |
| 断根时间 | 春季(2-3月)或秋季(9-10月) |

### 3.2 根系更新管理

| 步骤 | 时间 | 操作 |
|------|------|------|
| 断根 | 第一年 | 处理树冠1/3范围根系 |
| 施基肥 | 断根后 | 施有机肥30-50kg+钙镁磷肥1-2kg |
| 灌水促根 | 施肥后 | 充分灌水，保持湿润 |
| 第二年 | 第二年 | 处理树冠另外1/3范围 |
| 第三年 | 第三年 | 处理剩余部分 |

## 四、培土施肥复壮

### 4.1 培土措施

| 培土类型 | 材料 | 用量(立方米/株) | 效果 |
|---------|------|---------------|------|
| 塘泥土 | 鱼塘淤泥 | 0.5-1.0 | 富含有机质和微量元素 |
| 火烧土 | 草皮烧制的土灰 | 0.3-0.5 | 富含钾元素 |
| 腐殖土 | 森林表土堆制 | 0.5-1.0 | 改善土壤微生物环境 |
| 沙壤土与有机肥混合 | 壤土+腐熟有机肥 | 0.5-0.8 | 全面改良 |

### 4.2 复壮施肥方案

| 时期 | 肥料种类 | 用量(kg/株) | 作用 |
|------|---------|-----------|------|
| 断根施基肥 | 腐熟有机肥+钙镁磷肥 | 有机肥40-50+磷肥1.5-2 | 促发新根 |
| 新梢抽生期 | 尿素+复合肥 | 尿素0.3-0.5+复合肥0.5-1 | 促进新梢生长 |
| 新梢老熟期 | 硫酸钾+磷酸二氢钾 | 硫酸钾0.3-0.5+磷酸二氢钾0.2 | 促进枝梢充实 |
| 秋梢期 | 复合肥+有机肥 | 复合肥0.5-1+有机肥20-30 | 培养结果母枝 |

### 4.3 叶面追肥

| 时间 | 配方 | 作用 |
|------|------|------|
| 新梢抽生期 | 0.3%尿素+0.2%磷酸二氢钾 | 促进新梢展叶 |
| 新梢生长中期 | 0.1%硫酸锌+0.1%硫酸镁 | 防止缺素症 |
| 新梢老熟期 | 0.3%磷酸二氢钾 | 促进枝条充实 |

## 五、树干处理与病虫害防治

### 5.1 树干处理

| 问题 | 处理方法 |
|------|---------|
| 树皮开裂 | 刮除腐烂部分，涂杀菌剂+保护剂 |
| 树洞填补 | 清除腐朽组织→消毒→水泥砂浆填补 |
| 主干腐烂 | 锯除腐烂部分，培养萌蘖新主干 |
| 寄生植物清除 | 清除桑寄生、槲寄生等 |

### 5.2 病虫害防治

| 病虫害 | 防治方法 |
|--------|---------|
| 树干腐烂病 | 刮除病斑→涂药(多菌灵或甲基托布津) |
| 根结线虫 | 土壤消毒(石灰氮或阿维菌素) |
| 天牛 | 钩杀幼虫或棉球蘸药塞入虫孔 |
| 白蚁 | 诱杀法或喷施毒死蜱 |
| 介壳虫 | 喷施矿物油或啶虫脒 |

## 六、更新复壮配套管理

| 管理项目 | 技术要点 |
|---------|---------|
| 灌水管理 | 更新后适度控水促进生根，新梢期充足供水 |
| 抹芽定梢 | 及时抹除多余萌芽，选留健壮新梢 |
| 摘心整形 | 新梢长至30-40cm摘心，促进分枝 |
| 覆盖保墒 | 树盘覆盖稻草或地膜 |
| 逐步恢复 | 第一年轻结果，第二年恢复正常产量 |

## 七、更新复壮效果

### 7.1 预期效果

| 指标 | 更新前 | 更新后(2年后) | 变化幅度 |
|------|--------|-------------|---------|
| 新梢生长量(cm) | 5-10 | 20-40 | +100%-300% |
| 叶面积(cm²) | 20-30 | 40-60 | +50%-100% |
| 叶片叶绿素含量(SPAD) | 25-35 | 40-50 | +30%-50% |
| 单株产量(kg) | 10-20 | 25-50 | +50%-150% |
| 可溶性固形物(%) | 14-16 | 17-20 | +15%-25% |
| 果实单果重(g) | 15-20 | 22-28 | +20%-40% |

### 7.2 典型案例

广东增城某30年生糯米糍果园，由于树体衰老、产量降至每株10-15kg，品质下降。2015年进行中度更新复壮：重回缩修剪（保留50%枝量）+分期断根（两年完成）+培土施有机肥。更新后第二年新梢生长量达35cm，第三年株产恢复至35kg，可溶性固形物从15%提升至19%。
