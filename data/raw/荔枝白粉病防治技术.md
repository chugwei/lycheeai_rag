# 荔枝白粉病防治技术

## 摘要

荔枝白粉病是由白粉菌属（*Oidium* spp. 及相关属）真菌引起的叶部病害，以叶片表面产生白色粉状霉层为主要特征。该病在高温低湿条件下发生，主要危害嫩叶和新梢，影响光合作用和树势。本文系统介绍白粉病的病原特征、发病规律、诊断方法和防治技术。

## 1. 病原生物学

荔枝白粉病的主要病原为荔枝白粉菌（*Oidium* spp.），属于子囊菌亚门白粉菌目。病菌在寄主体表形成菌丝体和分生孢子链，不形成闭囊壳（不完美阶段）。

### 1.1 病原菌特性

| 项目 | 特征 |
|-----|------|
| 菌丝 | 白色，分枝，覆盖叶面 |
| 分生孢子 | 椭圆形，单胞，无色，20-30 μm |
| 侵染方式 | 直接穿透表皮细胞 |
| 最适温度 | 20-28 ℃ |
| 最适湿度 | 相对湿度 50-80%（不同于其他真菌） |
| 休眠结构 | 闭囊壳（有性阶段） |

## 2. 发病规律

白粉病菌以菌丝体和闭囊壳在病叶、嫩梢上越冬。翌年春季，分生孢子借气流传播，直接侵入嫩叶表皮。病害发生在高温低湿条件下，与大多数真菌病害的湿度需求相反。

### 2.1 症状特征

| 时期 | 症状 |
|-----|------|
| 初期 | 叶面出现淡绿色小斑点 |
| 中期 | 斑点扩大，叶背产生白色粉状霉层 |
| 后期 | 叶面黄化，叶片卷曲、畸形、早落 |
| 严重时 | 整叶枯黄脱落，枝条秃顶 |

### 2.2 发病与环境

| 条件 | 影响 | 说明 |
|-----|------|------|
| 温度 22-28 ℃ | 最适发病 | 高温期暴发 |
| 相对湿度 50-80% | 利于发病 | 干燥条件反而有利 |
| 偏施氮肥 | 加重 | 新梢嫩弱易感病 |
| 通风不良 | 加重 | 郁闭园内多发 |
| 连作果园 | 加重 | 病原菌累积 |

## 3. 诊断技术

### 3.1 田间诊断要点

- 叶面白色粉状霉层是诊断的关键特征。
- 霉层可用手抹掉，但叶面留有淡绿色至黄色斑点。
- 受害叶片常卷曲、变小、畸形。
- 严重时整片叶黄化脱落。

### 3.2 镜检诊断

| 结构 | 特征 |
|-----|------|
| 菌丝 | 白色，分隔，分枝 |
| 分生孢子梗 | 直立，单生或束生 |
| 分生孢子 | 椭圆形，单胞，无色 |
| 吸器 | 伸入寄主细胞内 |

## 4. 防治技术

### 4.1 农业防治

- **清园**：清除病叶、枯枝，减少初侵染源。
- **平衡施肥**：控制氮肥，增施磷钾肥，提高抗性。
- **合理修剪**：改善通风透光，降低叶面湿度。
- **清洁果园**：清除杂草和落叶，减少病原菌越冬场所。

### 4.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 备注 |
|-----|------|---------|------|
| 萌芽前 | 石硫合剂 | 3-5 波美度 | 清园 |
| 萌芽期 | 戊唑醇 25% | 3000-4000 倍 | 保护 |
| 新梢期 | 苯醚甲环唑 | 2000-3000 倍 | 治疗 |
| 发病初期 | 嘧菌酯 25% | 2000-3000 倍 | 快速控制 |
| 发病期 | 四氟醚唑 | 3000-4000 倍 | 轮换使用 |

### 4.3 防治关键节点

| 节点 | 措施 |
|-----|------|
| 春季萌芽前 | 石硫合剂全园清园 |
| 春梢抽生期 | 戊唑醇保护性喷施 |
| 秋季新梢期 | 苯醚甲环唑喷施 |
| 高温干旱期 | 加强监测，及时防治 |

### 4.4 注意事项

- 白粉病菌对三唑类药剂易产生抗性，需轮换用药。
- 避免在烈日下喷药，防止药害。
- 与杀菌剂复配使用时注意药剂兼容性。
