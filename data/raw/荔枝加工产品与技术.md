# 荔枝加工产品与技术

> 荔枝除鲜食外，还可加工成多种产品。加工不仅能解决荔枝集中上市期的销售压力，还能大幅提高荔枝的附加值。

---

## 一、荔枝加工产品分类

| 产品类别 | 代表产品 | 年加工消耗量(占产量%) | 主要市场 |
|---------|---------|-------------------|---------|
| **干制品** | 荔枝干、桂圆肉型荔枝干 | 15-20% | 国内、东南亚 |
| **罐头制品** | 糖水荔枝罐头 | 8-12% | 出口为主 |
| **果汁饮料** | 荔枝汁、荔枝复合果汁 | 3-5% | 国内 |
| **发酵产品** | 荔枝酒、荔枝醋 | 2-3% | 国内 |
| **速冻产品** | 速冻荔枝果肉、速冻整果 | 5-8% | 出口、国内 |
| **提取物** | 荔枝多酚、荔枝多糖 | <1% | 保健品 |
| **其他** | 荔枝蜜、荔枝冰淇淋、荔枝果酱 | 1-2% | 特色市场 |

## 二、荔枝干加工

### 加工工艺流程
```
原料选择 → 清洗 → 整果/去壳 → 护色处理 → 干燥 → 回软 → 分级 → 包装
```

### 干燥方法对比

| 干燥方法 | 干燥时间 | 品质 | 成本 | 适用规模 |
|---------|---------|------|------|---------|
| **日晒** | 15-25天 | 中（受天气影响大） | 低 | 小规模 |
| **热风干燥** | 24-48小时 | 好（可控） | 中 | 中大规模 |
| **真空干燥** | 8-12小时 | 优 | 高 | 高档产品 |
| **冷冻干燥** | 24-36小时 | 最优（营养保留好） | 最高 | 保健品 |
| **微波干燥** | 2-4小时 | 好 | 高 | 实验阶段 |

### 热风干燥工艺参数

| 阶段 | 温度(°C) | 时间(h) | 操作要点 |
|------|---------|--------|---------|
| **预处理** | - | - | 挑选成熟度一致的果实，清洗 |
| **初期** | 60-65 | 4-6 | 高风速，快速去除表面水分 |
| **中期** | 55-60 | 8-12 | 中风速，缓慢干燥 |
| **后期** | 50-55 | 6-10 | 低风速，至含水量15-18% |
| **回软** | 室温 | 24-48 | 密封堆放，水分平衡 |
| **分级包装** | - | - | 按大小分级，真空包装 |

### 不同品种荔枝干品质

| 品种 | 干制得率(%) | 干果品质 | 适宜性 |
|------|-----------|---------|-------|
| 糯米糍 | 28-32 | 肉厚，味甜，肉质软 | **最适合** |
| 桂味 | 26-30 | 有桂花香，品质优 | 适合 |
| 妃子笑 | 24-28 | 肉质爽脆 | 较适合 |
| 黑叶 | 22-26 | 风味浓郁 | 适合（产量大） |
| 三月红 | 20-24 | 偏酸 | 一般 |

## 三、荔枝罐头加工

### 工艺流程
```
原料选择 → 清洗 → 去壳去核 → 分级 → 装罐 → 注糖水 → 排气 → 密封 → 杀菌 → 冷却 → 检验
```

### 工艺参数

| 参数 | 标准 |
|------|------|
| 糖水浓度 | 15-25%（视品种而定） |
| 装罐固形物 | ≥55%（果肉重量/总重） |
| 柠檬酸添加 | 0.05-0.10%（调节pH至4.0-4.5） |
| 杀菌温度 | 85-90°C（巴氏杀菌） |
| 杀菌时间 | 15-25分钟 |
| 真空度 | 300-400mmHg |

### 常见质量问题

| 问题 | 原因 | 解决措施 |
|------|------|---------|
| **果肉褐变** | 酶促褐变+非酶褐变 | 加维生素C(0.05%)护色；真空封罐 |
| **果肉软化** | 杀菌过度 | 控制杀菌温度和时间 |
| **汤汁浑浊** | 果肉破碎 | 充分预煮使果肉定型 |
| **酸败** | 杀菌不足 | 确保中心温度达到杀菌温度 |
| **白色沉淀** | 果胶析出 | 加CaCl₂(0.05%)固形 |

## 四、荔枝汁加工

### 工艺流程
```
原料 → 清洗 → 去壳去核 → 破碎打浆 → 酶解 → 压榨 → 澄清 → 调配 → 杀菌 → 灌装
```

### 关键工艺参数

| 工序 | 参数 |
|------|------|
| 打浆 | 果肉加水1:0.5 |
| 酶解 | 果胶酶(0.02-0.05%) 45°C，1-2h |
| 澄清 | 离心或超滤 |
| 调配 | 糖度调至12-15°Brix，酸度0.2-0.4% |
| 杀菌 | UHT 121°C，3-5秒 |
| 灌装 | 无菌灌装或热灌装(>85°C) |

## 五、荔枝酒加工

### 类型

| 酒类 | 特点 | 酒精度 | 发酵时间 |
|------|------|--------|---------|
| **荔枝果酒** | 果香浓郁，甜型为主 | 8-12% | 15-30天 |
| **荔枝白兰地** | 蒸馏酒，醇香 | 40-50% | 发酵后蒸馏 |
| **荔枝配制酒** | 荔枝浸泡白酒 | 15-30% | 浸泡30-60天 |
| **荔枝起泡酒** | 清爽型，有气泡 | 6-8% | 二次发酵 |

### 荔枝果酒加工工艺
```
荔枝汁 → 调整糖度(加蔗糖至22-25°Brix) → 接种酵母(0.2g/L) 
→ 主发酵(20-25°C, 7-15天) → 后发酵(15-18°C, 15-30天)
→ 澄清(硅藻土过滤) → 陈酿(3-6月) → 灌装 → 杀菌
```

## 六、速冻荔枝加工

### 工艺流程
```
原料(8-9成熟) → 清洗 → 去壳去核(或整果) → 护色 
→ IQF速冻(-35°C至-40°C, 15-30min) → 包装 → -18°C冻藏
```

### 护色处理
| 方法 | 处理 | 护色效果 |
|------|------|---------|
| 柠檬酸浸泡 | 0.5-1.0%柠檬酸液浸泡2分钟 | 中等 |
| 维生素C浸泡 | 0.5%Vc液浸泡 | 良好 |
| 盐水浸泡 | 1-2%盐水+0.1%柠檬酸 | 良好 |
| 烫漂 | 80-90°C热水烫漂30-60秒 | 优（但风味有损失） |

### 冻藏品质变化

| 冻藏温度 | 保质期 | 品质变化 |
|---------|-------|---------|
| -18°C | 12个月 | 基本保持原有品质 |
| -25°C | 18个月 | 品质保持良好 |
| -35°C | 24个月 | 最优品质 |

## 七、荔枝功能成分提取

### 主要功能成分

| 活性成分 | 含量（干重） | 生物活性 | 应用 |
|---------|------------|---------|------|
| **荔枝多酚** | 1.5-4.5% | 抗氧化、抗炎 | 保健品、化妆品 |
| **荔枝多糖** | 2-5% | 免疫调节、抗肿瘤 | 功能食品 |
| **花青素** | 果皮中0.1-0.5% | 抗氧化、护眼 | 天然色素、保健品 |
| **荔枝核皂苷** | 种子中2-4% | 抗菌、降血糖 | 医药研发 |
| **荔枝核淀粉** | 种子中40-50% | 食品原料 | 食品工业 |

### 提取工艺流程（以荔枝多酚为例）
```
荔枝果皮/果渣 → 干燥粉碎 → 乙醇提取(60-70%乙醇, 50-60°C, 1-2h)
→ 过滤 → 浓缩 → 大孔树脂纯化 → 洗脱 → 喷雾干燥 → 多酚粉末
```

## 八、荔枝副产物综合利用

### 各部位利用途径

| 副产物 | 占鲜果重(%) | 利用途径 | 附加值 |
|-------|-----------|---------|-------|
| **果皮** | 15-20 | 提取花青素和多酚、有机肥料 | 中高 |
| **果核** | 5-10 | 提取淀粉和皂苷、中药、活性炭 | 中 |
| **果蒂/果梗** | 2-3 | 燃料、有机肥 | 低 |
| **残次果** | 5-15 | 果汁加工、果酒、果醋 | 中 |
| **加工下脚料** | 10-20 | 饲料、有机肥 | 低 |

### 荔枝核的综合利用
1. **荔枝核淀粉**：含量40-50%，可作食品工业原料
2. **中药应用**：荔枝核是传统中药（行气散结、祛寒止痛）
3. **活性炭**：果核烧制活性炭
