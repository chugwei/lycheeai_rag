# 荔枝套袋生产技术规程

> 本标准规定了荔枝果实套袋的技术要求，包括套袋时间、果袋选择、套袋操作、套袋后管理及采前处理等环节。果实套袋可有效改善果实外观品质，减少病虫害和农药残留，提高商品果率。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝各产区鲜食果实的套袋生产。特别适用于中晚熟品种和无公害、绿色荔枝生产。

### 规范性引用文件
| 标准编号 | 标准名称 |
|---------|---------|
| NY/T 393 | 绿色食品 农药使用准则 |
| GB/T 8321 | 农药合理使用准则 |

---

## 二、套袋目的与效果

### 套袋主要作用
| 作用 | 效果 |
|-----|------|
| 改善果面色泽 | 果皮色泽均匀鲜艳，减少日灼斑和药斑 |
| 减少病虫害 | 有效隔离蒂蛀虫、霜疫霉病等 |
| 降低农药残留 | 套袋后减少施药次数和药量 |
| 减少机械伤 | 减少风摩伤、枝叶擦伤 |
| 提高商品果率 | 好果率提高15-30% |

### 套袋效果对比
| 指标 | 套袋果 | 未套袋果 |
|-----|-------|---------|
| 好果率(%) | 90-98 | 60-80 |
| 果面光洁度 | 好 | 一般 |
| 农药残留检出率(%) | <5 | 15-30 |
| 日均斑发生率(%) | <2 | 5-10 |
| 蒂蛀虫为害率(%) | <3 | 10-25 |
| 果皮厚度 | 稍薄 | 正常 |
| 果实着色 | 均匀鲜艳 | 不均匀 |

## 三、果袋选择

### 果袋类型及规格
| 果袋类型 | 材质 | 规格(cm) | 特点 | 适用品种 |
|---------|-----|---------|------|---------|
| 白色纸袋 | 木浆纸+防水处理 | 20×25 | 透光性好，着色均匀 | 妃子笑、白糖罂 |
| 褐色纸袋 | 牛皮纸 | 20×25或22×28 | 遮光性强，防日均 | 桂味、糯米糍 |
| 复合纸袋 | 纸+PE薄膜 | 20×25 | 防水防潮 | 多雨地区 |
| 无纺布袋 | 聚丙烯无纺布 | 22×30 | 可重复使用，透气好 | 所有品种 |
| 塑膜网袋 | PE网+纸 | 22×28 | 通风好，价格低 | 黑叶、粗放管理 |

### 果袋质量要求
| 检测项目 | 质量要求 | 检测方法 |
|---------|---------|---------|
| 抗张强度(纵/横向) | ≥2.0kN/m | 拉力试验机 |
| 撕裂度 | ≥500mN | 撕裂度仪 |
| 透光率(白色袋) | 30-50% | 透光率仪 |
| 透光率(褐色袋) | <10% | 透光率仪 |
| 防水性 | 防水处理均匀 | 滴水测试 |
| 透气性 | ≥2000g/(m²·24h) | 透湿率测试 |
| 印刷油墨 | 食品级，无毒 | 重金属检测 |

## 四、套袋时间

### 套袋适期
| 品种 | 套袋时间 | 果实发育阶段 | 果径大小(cm) |
|-----|---------|------------|------------|
| 妃子笑 | 5月上旬-5月中旬 | 幼果期（第二次生理落果后） | 1.5-2.0 |
| 桂味 | 5月下旬-6月上旬 | 果粒稳定后 | 1.5-2.0 |
| 糯米糍 | 5月下旬-6月上旬 | 果粒稳定后 | 1.5-2.0 |
| 黑叶 | 5月中旬-5月下旬 | 幼果期 | 1.5-2.0 |
| 白糖罂 | 5月上旬-5月中旬 | 幼果期 | 1.5-2.0 |
| 鸡嘴荔 | 5月下旬-6月上旬 | 幼果期 | 1.5-2.0 |

### 套袋前准备
| 操作项目 | 技术要求 |
|---------|---------|
| 疏果定果 | 每穗留3-5个均匀健壮果，疏除小果、病虫果、畸形果 |
| 喷药保护 | 套袋前喷1次杀菌杀虫混合药（咪鲜胺+高效氯氟氰菊酯），药液干后立即套袋 |
| 喷药至套袋时限 | 喷药后2天内完成套袋 |
| 雨天处理 | 雨后待果面水分干后再套袋 |

## 五、套袋操作

### 操作步骤
```
准备工作 → 撑开袋口 → 套入果穗 → 收紧袋口 → 绑扎固定 → 检查确认
```

### 操作规程
| 操作环节 | 具体方法 | 注意要点 |
|---------|---------|---------|
| 准备工作 | 果袋用前充分揉搓，使纸袋柔软易撑开 | 检查果袋是否完好 |
| 撑开袋口 | 用手将袋口撑开，抖松袋体 | 使果袋充分张开 |
| 套入果穗 | 将果穗从袋口送入袋内 | 避免果实贴附袋壁 |
| 收紧袋口 | 将袋口收拢于果穗基部 | 袋口位于结果枝上 |
| 绑扎固定 | 用袋口自带铁丝或扎带扎紧 | 松紧适度，不漏水不伤枝 |
| 透气孔检查 | 确认果袋底部有通气孔 | 无通气孔需人工打孔 |
| 检查确认 | 逐袋检查套袋质量 | 果穗居中，袋口扎紧 |

### 质量控制要求
| 检查项目 | 合格标准 |
|---------|---------|
| 套袋位置 | 果实位于袋体中部，不贴壁 |
| 袋口扎紧度 | 不掉袋、不进水、不伤枝条 |
| 果袋完整度 | 无破损、无裂口 |
| 每穗套袋率 | ≥95% |
| 套袋均匀度 | 全园统一套袋 |
| 套袋完成时限 | 从喷药开始3天内完成 |

## 六、套袋后管理

### 套袋后病虫害防治
| 时期 | 防治重点 | 注意事项 |
|-----|---------|---------|
| 套袋后1-2周 | 检查袋内病虫害情况 | 抽检2-3%，发现异常及时处理 |
| 果实膨大期 | 天气炎热时注意防日均 | 褐色袋防日均效果好 |
| 多雨季节 | 检查果袋是否破损进水 | 破损及时更换或修补 |
| 成熟前期 | 检查蒂蛀虫为害 | 必要时从袋外喷药 |

### 套袋后果园管理
| 管理项目 | 操作要求 |
|---------|---------|
| 肥水管理 | 正常管理，不需特殊调整 |
| 夏季修剪 | 剪除套袋果穗周边的过密枝叶，增加光照 |
| 台风防护 | 台风前检查果袋，加固绑扎 |
| 日灼防护 | 高温天气可在袋外加盖遮阳网 |

## 七、采前处理

### 摘袋时间
| 品种 | 摘袋时间 | 摘袋至采收天数 |
|-----|---------|-------------|
| 白色纸袋 | 采前3-5天 | 促进果皮着色 |
| 褐色纸袋(全遮光) | 采前5-7天 | 让果皮上色 |
| 无纺布袋 | 采前3天 | - |
| 复合纸袋 | 采前5天 | - |

### 摘袋操作
- 选择阴天或傍晚摘袋，避免高温时段
- 摘袋时小心操作，避免碰伤果实
- 摘袋后检查果面，如有病虫果及时剪除
- 摘袋后如遇强日照，可先揭开袋底通风1-2天再完全摘袋

## 九、注意事项

### 套袋禁忌
- 阴雨天或果面有露水时不宜套袋
- 药剂未干不宜套袋
- 高温时段（>35°C）不宜套袋
- 弱树、病树不宜套袋
- 小年结果量少时不建议套袋

### 常见问题及处理
| 问题 | 原因 | 处理方法 |
|-----|------|---------|
| 袋内积水 | 袋口绑扎不严或袋体破损 | 更换新袋，扎紧袋口 |
| 果实日灼 | 果袋透光率过高 | 换用遮光性更强的纸袋 |
| 果实着色差 | 摘袋过晚 | 提前摘袋时间3-5天 |
| 蒂蛀虫为害 | 套袋前防治不彻底 | 套袋前彻底喷药，缩短喷药到套袋时间 |
| 果袋脱落 | 绑扎不牢或风力过大 | 加强绑扎，台风前加固 |
