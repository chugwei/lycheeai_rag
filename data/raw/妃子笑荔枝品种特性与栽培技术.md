# 妃子笑荔枝品种特性与栽培技术

> 妃子笑（*Litchi chinensis* Sonn. cv. Feizixiao）是荔枝中著名的早熟优质品种，因果皮淡红、果肉白嫩，被古人誉为"妃子笑"。该品种早熟丰产、适应性强，是中国商业化栽培面积最大的荔枝品种之一，也是海南、粤西等早熟产区的绝对主栽品种。

---

## 一、品种起源与历史

### 品种来源
妃子笑原产于广东，母树发现于广东省广州市郊，后经无性繁殖推广。品种名称源自唐代杜牧诗句"一骑红尘妃子笑，无人知是荔枝来"，寓意其品质优良、足以进贡宫廷。

### 栽培历史
妃子笑的大规模商业化种植始于20世纪80年代，因早熟、丰产、稳产等优良特性，推广速度极快。目前已成为中国栽培面积最大的荔枝品种之一，在海南、广东、广西、云南、四川等省区均有大面积种植。

### 品种地位
| 指标 | 数据 |
|------|------|
| 全国栽培面积占比 | 约25-30% |
| 海南产区占比 | 70%以上 |
| 粤西产区占比 | 50%以上 |
| 年产量 | 约50-60万吨 |
| 市场供应期 | 5月下旬至6月中旬 |

## 二、植物学特征

### 树体特征
| 部位 | 特征描述 |
|------|---------|
| 树势 | 旺盛，生长速度快 |
| 树冠 | 半圆形，开张，枝条直立性强 |
| 树干 | 灰褐色，表面粗糙 |
| 枝梢 | 一年抽梢3-4次，新梢紫红色 |
| 叶片 | 复叶4-6对小叶，叶椭圆形，叶缘平展 |
| 叶色 | 深绿色，有光泽 |

### 花穗特征
| 特征 | 描述 |
|------|------|
| 花穗类型 | 带叶花穗型（冲梢风险较大） |
| 花穗长度 | 15-30cm |
| 花量 | 极大，每穗2000-4000朵 |
| 雌雄花比例 | 1:3-1:5 |
| 开花习性 | 雄花先开，雌花后开（雌雄异熟） |
| 自花结实率 | 20-30%（相对较高） |

### 果实特征
| 指标 | 数值 |
|------|------|
| 单果重 | 25-30g |
| 果形 | 心形或卵圆形 |
| 果皮颜色 | 淡红色（未全红即已成熟） |
| 龟裂片 | 平，排列整齐 |
| 果肉颜色 | 白蜡色 |
| 果肉质地 | 爽脆，多汁 |
| 风味 | 清甜，微香 |
| 可食率 | 78-82% |
| 可溶性固形物 | 17-20% |
| 种子大小 | 中等（焦核率30-40%） |
| 果实发育期 | 60-65天（谢花至成熟） |

## 四、栽培技术要点

### 1. 园地选择与定植
| 项目 | 要求 |
|------|------|
| 土壤要求 | 土层深厚（>1m），pH 5.5-6.5，排水良好 |
| 坡度 | <15°的缓坡地或平地 |
| 定植密度 | 4m×5m（33株/亩）或4m×6m（28株/亩） |
| 定植时间 | 春植（3-4月）或秋植（9-10月） |
| 授粉树配置 | 配置黑叶或白糖罂作为授粉树，比例5:1 |

### 2. 肥水管理
| 施肥时期 | 肥料种类 | 用量（每株） | 方法 |
|---------|---------|------------|------|
| 采后肥（6-7月） | 复合肥（15-15-15） | 0.5-1.0kg | 沟施 |
| 秋梢肥（8-9月） | 尿素+复合肥 | 0.3-0.5kg+0.5kg | 兑水浇施 |
| 促花肥（1-2月） | 复合肥+硫酸钾 | 0.5kg+0.3kg | 沟施 |
| 保果肥（3-4月） | 高钾复合肥 | 0.3-0.5kg | 兑水浇施 |

### 3. 水分管理
- **花芽分化期**（12-1月）：适当控水，保持土壤相对干旱，促进花芽分化
- **开花期**（2-3月）：保持土壤湿润，提高坐果率，注意雨天排水
- **果实发育期**（3-5月）：保持水分均衡，避免忽干忽湿导致裂果
- **秋梢抽发期**（7-10月）：充足供水，保证秋梢健壮生长

### 4. 控梢促花技术
妃子笑为带叶花穗型品种，**冲梢风险较大**，需重点控制：
1. **冬季控水**：12月至1月保持土壤适度干旱
2. **螺旋环割**：11月下旬至12月上旬，对主干或主枝进行螺旋环割1-1.5圈
3. **化学调控**：秋梢老熟后喷施15%多效唑300-500倍液或乙烯利200-300mg/L
4. **人工摘除**：春季花穗抽出后，及时摘除花穗上的嫩叶（冲梢叶）

### 5. 疏花疏果
| 项目 | 操作方法 |
|------|---------|
| 疏穗 | 每枝留1-2穗，疏除过多花穗 |
| 疏花 | 短截过长花穗，保留8-10cm |
| 疏果 | 第一次（谢花后15天）疏除畸形果、病虫果 |
| 定果 | 第二次（谢花后30天）每穗留15-20个果 |

### 6. 病虫害防治
| 病虫害 | 防治时期 | 防治措施 |
|--------|---------|---------|
| 霜疫霉病 | 花期至果实成熟期 | 发病前喷施甲霜灵锰锌，7-10天一次 |
| 炭疽病 | 春梢抽发期、果实发育期 | 咪鲜胺或苯醚甲环唑轮换使用 |
| 蒂蛀虫 | 果实发育期（重点） | 成虫羽化高峰期喷施菊酯类农药 |
| 荔枝蝽象 | 花期至幼果期 | 人工捕杀+药剂防治（敌百虫） |
| 红蜘蛛 | 秋梢期 | 阿维菌素或矿物油喷施 |

## 五、采收与采后处理

### 采收标准
| 指标 | 标准 |
|------|------|
| 果皮颜色 | 淡红色（未全红） |
| 可溶性固形物 | 17%以上 |
| 果肉硬度 | 爽脆有弹性 |
| 采收时间 | 晴天早晨露水干后或傍晚 |

### 采后处理流程
1. **预冷**：采收后2小时内进入预冷库，温度4-6℃
2. **分选**：剔除病虫果、裂果、过熟果
3. **分级**：按单果重分级（特大>30g、大25-30g、中20-25g、小<20g）
4. **包装**：泡沫箱+冰袋，每箱5-10kg
5. **冷链运输**：保持2-4℃冷链运输，可保鲜7-10天

## 六、优缺点分析

### 优点
| 项目 | 说明 |
|------|------|
| 早熟上市 | 5月下旬上市，市场售价高 |
| 丰产稳产 | 适应性强，产量稳定，大小年不明显 |
| 栽培容易 | 管理相对粗放，适合大面积种植 |
| 抗病性较好 | 对霜疫霉病和炭疽病抗性中等偏强 |
| 耐贮运性 | 冷链条件下可保鲜7-10天 |
| 自花结实率 | 相对较高，减少授粉树配置压力 |

### 缺点
| 项目 | 说明 |
|------|------|
| 冲梢风险大 | 带叶花穗型，春季冲梢影响产量 |
| 品质中等 | 风味不及桂味、糯米糍等优质品种 |
| 焦核率不高 | 约30-40%，部分消费者偏好焦核 |
| 果皮颜色 | 淡红色，消费者习惯全红果 |

## 七、市场前景与建议

### 市场定位
妃子笑作为早熟优质品种，市场定位为中高端鲜食荔枝。其早熟上市的优势使其在价格上具有竞争力，是早熟产区效益最高的品种之一。

### 种植建议
1. **早熟产区**（海南、粤西）：作为主栽品种，可配套白糖罂、三月红延长供应期
2. **中熟产区**（珠三角、广西）：作为早熟搭配品种，与桂味、糯米糍错峰上市
3. **新兴产区**（云南、四川）：作为引种首选品种，适应性好、风险低
4. **出口基地**：适合面向东南亚、欧美市场出口
