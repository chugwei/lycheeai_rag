# 荔枝绿色食品生产技术指南

## 摘要

绿色食品是指在优良生态环境条件下，按照特定生产技术规程生产，经中国绿色食品发展中心认证许可使用绿色食品标志的无污染、安全、优质、营养食品。本指南系统阐述了荔枝绿色食品生产的标准体系、技术要求和认证管理，为荔枝绿色食品生产提供规范化技术指导。

## 1. 引言

绿色食品是我国具有自主知识产权的质量认证体系，分为AA级和A级两个等级。AA级绿色食品等同于国际有机食品标准，A级绿色食品允许限量使用规定的化学合成生产资料。荔枝绿色食品市场规模持续增长，2022年全国荔枝绿色食品认证面积超过10万亩。推行绿色食品生产，对提升荔枝产品品质和市场竞争力具有重要意义。

## 2. 绿色食品标准体系

### 2.1 标准框架

| 标准类型 | 标准编号 | 主要内容 |
|----------|----------|----------|
| 环境质量 | NY/T 391 | 绿色食品产地环境质量 |
| 生产技术 | NY/T 1762 | 绿色食品 荔枝生产技术规程 |
| 产品标准 | NY/T 288 | 绿色食品 荔枝 |
| 包装标识 | NY/T 7301 | 绿色食品标志使用规范 |
| 认证管理 | NY/T 392 | 绿色食品认证通则 |

### 2.2 AA级与A级差异

| 项目 | AA级绿色食品 | A级绿色食品 |
|------|-------------|-------------|
| 产地环境 | 等同有机标准 | 符合NY/T 391 |
| 投入品 | 禁用化学合成物 | 限量使用 |
| 农药残留 | 未检出 | 限量标准 |
| 重金属 | 更严格限值 | 符合NY/T 288 |
| 认证周期 | 3年 | 3年 |
| 转换期 | 3年 | 12-24个月 |

## 3. 产地环境要求

### 3.1 大气环境

| 项目 | AA级限值 | A级限值 |
|------|----------|---------|
| 二氧化硫日均值 | ≤0.02mg/m³ | ≤0.06mg/m³ |
| 总悬浮颗粒物 | ≤0.30mg/m³ | ≤0.30mg/m³ |
| 氟化物日均值 | ≤0.01mg/m³ | ≤0.07mg/m³ |

### 3.2 土壤环境

| 项目 | AA级限值 | A级限值 |
|------|----------|---------|
| pH | 5.5-8.5 | 5.5-8.5 |
| 镉(mg/kg) | ≤0.20 | ≤0.30 |
| 汞(mg/kg) | ≤0.10 | ≤0.20 |
| 砷(mg/kg) | ≤10 | ≤25 |
| 铅(mg/kg) | ≤50 | ≤80 |
| 铬(mg/kg) | ≤100 | ≤150 |

### 3.3 灌溉水质

| 项目 | AA级限值 | A级限值 |
|------|----------|---------|
| pH | 5.5-8.5 | 5.5-8.5 |
| 化学需氧量 | ≤50 | ≤80 |
| 总氮 | ≤50 | ≤100 |
| 总磷 | ≤5 | ≤10 |
| 镉 | ≤0.005 | ≤0.01 |
| 铅 | ≤0.05 | ≤0.10 |

## 4. 生产技术规程

### 4.1 土壤管理

| 措施 | AA级要求 | A级要求 |
|------|----------|---------|
| 有机肥 | 必须施用 | 鼓励施用 |
| 化肥 | 禁用 | 限量施用 |
| 绿肥 | 鼓励 | 鼓励 |
| 土壤改良 | 有机改良 | 有机改良为主 |

### 4.2 施肥技术

| 肥料类型 | AA级 | A级 |
|----------|------|-----|
| 农家肥(充分腐熟) | 允许 | 允许 |
| 商品有机肥 | 允许 | 允许 |
| 绿肥 | 允许 | 允许 |
| 生物肥料 | 允许 | 允许 |
| 矿物肥料 | 允许 | 允许 |
| 化学氮肥 | 禁用 | 限量 |
| 化学磷肥 | 禁用 | 限量 |
| 化学钾肥 | 禁用 | 限量 |

### 4.3 A级绿色食品允许使用的化学投入品

| 投入品类型 | 允许品种 | 使用限制 |
|-----------|----------|----------|
| 杀虫剂 | 吡虫啉、噻虫嗪等 | 按GB 2763限量 |
| 杀菌剂 | 嘧菌酯、吡唑醚菌酯 | 按安全间隔期 |
| 除草剂 | 禁止 | 人工或机械除草 |

### 4.4 病虫害防控

| 防控方式 | AA级 | A级 |
|----------|------|-----|
| 生态调控 | 主要手段 | 主要手段 |
| 生物防治 | 主要手段 | 主要手段 |
| 物理防治 | 允许 | 允许 |
| 化学农药 | 禁用 | 限量使用 |

## 5. 产品品质要求

### 5.1 感官指标

| 指标 | AA级要求 | A级要求 |
|------|----------|---------|
| 果实形状 | 正常 | 正常 |
| 果皮色泽 | 均匀 | 均匀 |
| 果肉 | 饱满、有光泽 | 饱满、有光泽 |
| 口感 | 清甜、化渣 | 清甜、化渣 |
| 缺陷 | 无机械损伤 | 允许轻微 |

### 5.2 安全指标

| 指标 | AA级限值 | A级限值 |
|------|----------|---------|
| 农药残留 | 未检出 | 符合GB 2763 |
| 重金属(铅) | ≤0.2mg/kg | ≤0.3mg/kg |
| 重金属(镉) | ≤0.03mg/kg | ≤0.05mg/kg |
| 二氧化硫 | 未检出 | ≤50mg/kg |
| 亚硫酸盐 | 未检出 | ≤10mg/kg |

## 6. 认证与管理

| 环节 | 内容 | 频次 |
|------|------|------|
| 产地环境评价 | 土壤、水、气检测 | 每3年 |
| 生产过程审核 | 现场检查 | 每年 |
| 产品检测 | 理化+安全指标 | 每年 |
| 标志使用 | 标志审批 | 每批次 |
| 证后监管 | 跟踪检查 | 不定期 |
