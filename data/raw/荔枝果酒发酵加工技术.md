# 荔枝果酒发酵加工技术

## 摘要

荔枝果酒是利用荔枝果肉或果汁经酒精发酵制成的低度果酒，酒精度通常为 8%~15% vol，具有荔枝独特花果香和清爽口感。本文系统介绍荔枝果酒的酿造工艺流程、酵母选择与扩培、发酵参数控制、陈酿及质量控制技术，为荔枝果酒产业化生产提供技术指导。

## 1. 引言

荔枝果酒属于酿造果酒范畴，其酿造原理与葡萄酒类似，即以果实中的糖分作为发酵底物，通过酵母代谢转化为乙醇和 CO₂。荔枝含糖量较高（14%~18%），是酿造果酒的优质原料。荔枝果酒具有色泽清亮、果香浓郁、口感清爽的特点，是荔枝深加工的重要产品。

## 2. 原料与预处理

### 2.1 原料要求

| 指标 | 要求 | 备注 |
|------|------|------|
| 品种 | 妃子笑、白糖罂、桂味 | 妃子笑糖高汁多 |
| 成熟度 | 8~9 成熟 | 糖度最高 |
| 可溶性固形物 | ≥14°Brix | 保证发酵原料 |
| 可滴定酸 | 0.20%~0.40% | 适当酸度 |
| 腐烂率 | ≤3% | 严重超标需剔除 |
| 果柄 | 保留 1~2 cm | 便于操作 |

### 2.2 预处理流程

| 步骤 | 操作 | 参数 | 目的 |
|------|------|------|------|
| 1 | 清洗 | 流动水冲洗 | 去污 |
| 2 | 沥水 | 自然沥干 30 min | 减少水分 |
| 3 | 破碎 | 破碎度 3~5 mm | 释放汁液 |
| 4 | 压榨 | 压榨出汁 | 获取汁液 |
| 5 | 澄清 | 静置 2~4 h 或离心 | 去除果渣 |
| 6 | 调整 | 调糖、调酸、调温 | 制备发酵醪 |

## 3. 发酵醪制备

### 3.1 发酵醪参数调整

| 参数 | 调整范围 | 目标值 | 调整方法 |
|------|---------|-------|---------|
| 可溶性固形物 | 18°~22°Brix | 20°Brix | 加白砂糖 |
| pH | 3.2~3.8 | 3.4~3.6 | 加柠檬酸或碳酸钙 |
| 温度 | 15~25°C | 18~20°C | 预冷/预热 |
| 溶解氧 | 适量 | 充分通气 | 搅拌或通气 |
| 营养物质 | 按需添加 | 酵母氮源充足 | 添加磷酸二氢钾、尿素 |

### 3.2 发酵醪组成

| 成分 | 含量 | 作用 |
|------|------|------|
| 荔枝果汁 | 60%~80% | 主体原料 |
| 白砂糖 | 4%~8% | 补充糖分 |
| 水（净化水） | 10%~25% | 调节浓度 |
| 柠檬酸 | 0.05%~0.1% | 调节酸度 |
| 酵母营养盐 | 0.02%~0.05% | 促进发酵 |
| SO₂ | 50~100 mg/L | 抗氧化抑菌 |

## 4. 发酵工艺

### 4.1 酵母选择

| 酵母类型 | 菌株 | 特点 | 适用性 |
|---------|------|------|-------|
| 葡萄酒酵母 | EC-1118、RC-212 | 酒精耐受高（16%） | 高酒精度果酒 |
| 果酒酵母 | 酵母 121、BE-2 | 果香保留好 | 低度果酒 |
| 天然发酵 | 荔枝果皮附生酵母 | 风味复杂 | 特色产品 |
| 啤酒酵母 | 拉格酵母 | 清爽口感 | 创新产品 |

### 4.2 发酵参数

| 参数 | 红荔枝酒 | 白荔枝酒 |
|------|---------|---------|
| 发酵温度 | 18~22°C | 15~18°C |
| 发酵时间 | 7~14 天 | 10~16 天 |
| 酒精度（vol%） | 10~14 | 8~12 |
| 酵母接种量 | 1%~2% | 1%~2% |
| 搅拌 | 每日 1~2 次 | 每日 1 次 |
| 残糖（g/L） | <2 | <4 |

### 4.3 发酵过程监控

| 监测指标 | 频率 | 方法 |
|---------|------|------|
| 温度 | 每 4 h | 温度计 |
| 可溶性固形物 | 每日 | 折光仪 |
| pH | 每日 | pH 计 |
| 酒精度 | 发酵后期 | 酒精计 |
| 酵母活度 | 每日 | 镜检 |

## 5. 后处理

### 5.1 酒液分离

| 步骤 | 操作 | 目的 |
|------|------|------|
| 压滤 | 板框压滤机 | 分离酒泥 |
| 粗滤 | 硅藻土过滤 | 去除悬浮物 |
| 精滤 | 膜过滤（0.45 μm） | 除菌 |

### 5.2 陈酿

| 参数 | 要求 |
|------|------|
| 陈酿温度 | 8~12°C |
| 陈酿时间 | 3~6 个月 |
| 容器 | 不锈钢罐或橡木桶 |
| 保护 | 满罐密封或通 N₂ |
| SO₂ 添加 | 10~20 mg/L（分次） |

### 5.3 澄清稳定

| 方法 | 用量 | 时间 |
|------|------|------|
| 蛋白质澄清 | 膨润土 0.3~0.5 g/L | 2~3 天 |
| 冷稳定 | 0~4°C 处理 | 2~4 周 |
| 过滤 | 0.45 μm 膜 | 即时 |

## 6. 产品规格

### 6.1 荔枝果酒质量标准

| 指标 | 要求 |
|------|------|
| 酒精度（vol%） | 8~15 |
| 总糖（g/L） | ≤4（干型）或 4~12（半干型） |
| 总酸（g/L） | 3.5~6.5（以酒石酸计） |
| 挥发酸（g/L） | ≤1.0 |
| 干浸出物（g/L） | ≥16 |
| SO₂ 残留（mg/L） | ≤100 |
| 铅（mg/L） | ≤0.2 |

### 6.2 感官评价

| 指标 | 要求 |
|------|------|
| 色泽 | 红荔枝酒呈粉红至琥珀色，白荔枝酒呈淡黄色 |
| 香气 | 荔枝果香浓郁，带有花香和发酵香 |
| 滋味 | 酸甜适口，酒体协调，尾味清爽 |
| 酒体 | 适中至饱满 |

## 7. 质量控制

| 控制点 | 控制限 | 监控方式 |
|-------|-------|---------|
| 原料糖度 | ≥14°Brix | 折光仪 |
| 发酵温度 | 15~22°C | 温度传感器 |
| 残糖 | <4 g/L | 折光仪/密度瓶 |
| 总酸 | 3.5~6.5 g/L | 滴定 |
| SO₂ | ≤100 mg/L | 氧化还原法 |

## 8. 经济效益

| 项目 | 数值 |
|------|------|
| 原料出酒率 | 60%~70%（按鲜果计） |
| 生产成本 | 15~25 元/瓶（750 mL） |
| 出厂价 | 30~80 元/瓶 |
| 毛利率 | 50%~70% |
| 市场潜力 | 特色果酒，增长迅速 |

## 9. 结论

荔枝果酒酿造以荔枝果汁为原料，通过控制发酵温度、酵母选择和后处理工艺，可生产酒精度 8%~15% vol 的优质果酒。关键在于发酵醪参数调整和香气保留。
