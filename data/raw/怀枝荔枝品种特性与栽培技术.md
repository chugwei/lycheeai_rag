# 怀枝荔枝品种特性与栽培技术

> 怀枝（*Litchi chinensis* Sonn. cv. Huaizhi）是荔枝中最古老的品种之一，也是中国荔枝种质资源中重要的地方品种。怀枝又称"槐枝"或"怀枝"，在广东、广西、福建等传统荔枝产区有广泛分布，是荔枝品种演化中的重要亲本之一。

---

## 一、品种起源与历史

### 品种来源
怀枝是我国最古老的荔枝品种之一，栽培历史超过千年。相传宋代已有栽培，因其果实形状似怀中的婴儿而得名"怀枝"。怀枝是许多现代荔枝品种的祖先或亲本之一，在荔枝品种演化史上占有重要地位。

### 品种地位
| 指标 | 数据 |
|------|------|
| 栽培历史 | 超过1000年 |
| 分布范围 | 广东、广西、福建、海南 |
| 单株产量（成年树） | 40-80kg |
| 丰产性 | 高 |
| 主要用途 | 鲜食、加工、砧木 |

## 二、植物学特征

### 树体特征
| 部位 | 特征描述 |
|------|---------|
| 树势 | 旺盛，树体高大 |
| 树冠 | 开张，半圆形或圆头形 |
| 枝条 | 粗壮，中等密度 |
| 叶片 | 小叶4-6对，椭圆形，叶缘平展 |
| 叶色 | 深绿色，革质有光泽 |
| 生长习性 | 一年抽梢3次，生长量中等 |

### 果实特征
| 指标 | 数值 |
|------|------|
| 单果重 | 15-20g |
| 果形 | 圆形或近圆形 |
| 果皮颜色 | 暗红色 |
| 龟裂片 | 中等突起，排列整齐 |
| 果肉颜色 | 蜡白色 |
| 果肉质地 | 爽脆 |
| 风味 | 清甜，微酸 |
| 可食率 | 70-75% |
| 可溶性固形物 | 16-18% |
| 种子大小 | 大 |
| 果实发育期 | 65-70天 |

## 四、栽培技术要点

### 1. 肥水管理
| 施肥时期 | 肥料种类 | 用量（每株） |
|---------|---------|------------|
| 采后肥 | 复合肥+有机肥 | 0.5kg+15-20kg |
| 秋梢肥 | 复合肥 | 0.3-0.5kg |
| 促花肥 | 复合肥+硼砂 | 0.5kg+15g |
| 保果肥 | 高钾复合肥 | 0.3-0.5kg |

### 2. 修剪
| 修剪时期 | 方法 |
|---------|------|
| 采后修剪 | 疏除过密枝、病虫枝、交叉枝 |
| 冬季修剪 | 剪除枯枝、弱枝，调整树形 |
| 生长季修剪 | 抹除徒长枝、无用芽 |

### 3. 病虫害防治
怀枝抗病性较强，常见的病虫害包括霜疫霉病、炭疽病和蒂蛀虫，需注意适时防治。

---

## 五、品种价值与利用

### 种质资源价值
怀枝作为古老品种，在荔枝种质资源中具有重要价值：
1. 遗传多样性丰富，是重要的育种材料
2. 抗逆性强，可作为抗性育种亲本
3. 适应性广，适合在各种环境条件下种植

### 生产应用
1. **鲜食**：风味清甜，适合大众消费
2. **加工**：适合制作荔枝干和罐头
3. **砧木**：嫁接亲和性好，是荔枝常用的砧木品种之一
