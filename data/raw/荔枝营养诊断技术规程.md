# 荔枝营养诊断技术规程

## 摘要

荔枝营养诊断是科学施肥的前提和基础，通过土壤检测、叶片分析和树体外观观察等手段，全面评估荔枝园土壤供肥能力和树体营养状况，为精准施肥提供依据。本文系统阐述荔枝营养诊断的技术规程、诊断指标体系、诊断方法及矫正建议，为荔枝园营养诊断工作提供标准化指导。

## 1. 营养诊断目的与意义

### 1.1 诊断目的

| 目的 | 具体内容 |
|------|----------|
| 摸清土壤肥力 | 全面掌握土壤养分含量及供肥能力 |
| 判断树体营养 | 通过叶片分析确定营养元素缺乏或过量 |
| 优化施肥方案 | 根据诊断结果制定精准施肥计划 |
| 提高肥料利用率 | 减少盲目施肥、降低生产成本 |
| 保障品质产量 | 确保荔枝高产优质、稳定生产 |

### 1.2 诊断内容框架

| 诊断类型 | 检测对象 | 主要指标 | 频率 |
|----------|----------|----------|------|
| 土壤诊断 | 果园土壤 | N、P、K、pH、有机质等 | 每年1-2次 |
| 叶片诊断 | 功能叶片 | N、P、K、Ca、Mg、Fe等 | 每季1次 |
| 外观诊断 | 树体整体 | 叶色、梢长、花果等 | 每月 |
| 产量诊断 | 产量数据 | 产量、品质指标 | 每年 |

## 2. 土壤营养诊断

### 2.1 采样技术

| 采样环节 | 技术要求 |
|----------|----------|
| 采样时期 | 采后(11-12月)或春梢期(3-4月) |
| 采样方法 | "S"形或梅花形布点，每园不少于20点 |
| 采样深度 | 0-20 cm(表土)和20-40 cm(心土)分层 |
| 采样工具 | 不锈钢土钻或十字镐 |
| 样品处理 | 剔除根茎石块，混匀后四分法缩分至1 kg |

### 2.2 土壤检测指标及标准

| 检测指标 | 检测方法 | 丰缺评价标准 | 单位 |
|----------|----------|--------------|------|
| 有机质 | 重铬酸钾氧化法 | 高>3.0，中1.5-3.0，低<1.5 | % |
| 全氮 | 凯氏蒸馏法 | 高>0.25，中0.15-0.25，低<0.15 | % |
| 碱解氮 | 碱解扩散法 | 高>200，中100-200，低<100 | mg/kg |
| 有效磷(Olsen-P) | 碳酸氢钠浸提-钼锑抗比色 | 高>40，中15-40，低<15 | mg/kg |
| 速效钾(NH4OAc-K) | 乙酸铵浸提-火焰光度 | 高>150，中80-150，低<80 | mg/kg |
| pH(H2O) | 电位法 | 适5.5-6.5，偏酸<5.5，偏碱>7.0 | - |
| 交换性钙 | 乙酸铵浸提-EDTA滴定 | 高>1500，中800-1500，低<800 | mg/kg |
| 交换性镁 | 乙酸铵浸提-EDTA滴定 | 高>200，中100-200，低<100 | mg/kg |
| 有效铁(DTPA-Fe) | DTPA浸提-原子吸收 | 高>5，中2-5，低<2 | mg/kg |
| 有效锌(DTPA-Zn) | DTPA浸提-原子吸收 | 高>2，中0.8-2，低<0.8 | mg/kg |
| 有效锰(DTPA-Mn) | DTPA浸提-原子吸收 | 高>15，中5-15，低<5 | mg/kg |
| 有效硼(HB-硼) | 热水浸提-曲比色 | 高>1.5，中0.5-1.5，低<0.5 | mg/kg |

## 3. 叶片营养诊断

### 3.1 采样技术

| 采样环节 | 技术要求 |
|----------|----------|
| 采样时期 | 花后(5-6月)、采后(9-10月)为最佳 |
| 采样部位 | 树冠中部、向阳面当年生营养枝末端的第3-5片功能叶 |
| 采样数量 | 每园采集30-50片叶，混匀取500 g |
| 样品处理 | 清水冲洗→蒸馏水漂洗→滤纸吸干→烘干(65℃)→粉碎 |

### 3.2 叶片营养诊断标准

| 元素 | 充足范围 | 缺乏临界值 | 过量警戒值 | 单位 |
|------|----------|------------|------------|------|
| 全氮(N) | 2.0-3.0 | <1.8 | >3.5 | % |
| 全磷(P) | 0.20-0.40 | <0.15 | >0.50 | % |
| 全钾(K) | 2.0-3.0 | <1.8 | >4.0 | % |
| 全钙(Ca) | 1.0-2.5 | <0.8 | >3.0 | % |
| 全镁(Mg) | 0.50-1.00 | <0.40 | >1.50 | % |
| 铁(Fe) | 50-150 | <40 | >300 | mg/kg |
| 锌(Zn) | 25-75 | <20 | >100 | mg/kg |
| 锰(Mn) | 50-200 | <40 | >300 | mg/kg |
| 硼(B) | 25-75 | <20 | >100 | mg/kg |
| 铜(Cu) | 8-25 | <5 | >40 | mg/kg |

## 4. 外观诊断

### 4.1 营养元素缺乏外观特征

| 元素 | 发病部位 | 典型症状 | 与其他元素区别 |
|------|----------|----------|----------------|
| N | 老叶 | 全叶均匀黄化 | 叶脉也黄化 |
| P | 全株 | 叶片暗绿、紫红、生长缓慢 | 整体矮化 |
| K | 老叶叶尖叶缘 | 叶尖焦枯、黄化 | 有焦枯斑 |
| Ca | 嫩叶生长点 | 叶缘卷曲、生长点坏死 | 有畸形 |
| Mg | 老叶 | V形脉间黄化、主脉绿 | 绿脉明显 |
| Fe | 嫩叶 | 对称脉间黄化、无斑点 | 无斑点 |
| Zn | 嫩叶新梢 | 小叶、节间缩短、簇叶 | 小叶明显 |
| Mn | 嫩叶 | 脉间黄化+细小斑点 | 有斑点 |
| B | 花器嫩叶 | 花器畸形、大小粒、小叶 | 影响花果 |

### 4.2 诊断流程

| 步骤 | 内容 | 方法 |
|------|------|------|
| 1. 观察树势 | 整体树冠、枝梢、叶色 | 目测记录 |
| 2. 叶片症状 | 黄化部位、形状、斑点 | 拍照记录 |
| 3. 新梢状况 | 梢长、节间、叶片大小 | 测量记录 |
| 4. 花果状况 | 花量、坐果率、大小粒 | 统计记录 |
| 5. 综合判断 | 对照标准确定缺乏元素 | 结合化验 |
| 6. 制定方案 | 矫正措施和施肥计划 | 书面记录 |

## 5. 综合诊断与施肥建议

### 5.1 土壤-叶片综合诊断表

| 土壤状况 | 叶片状况 | 施肥建议 |
|----------|----------|----------|
| 土壤养分充足 | 叶片营养充足 | 维持施肥量，适当减量 |
| 土壤养分充足 | 叶片缺乏某元素 | 针对性补施缺乏元素 |
| 土壤养分缺乏 | 叶片营养充足 | 增施土壤肥料，树体尚可 |
| 土壤养分缺乏 | 叶片缺乏某元素 | 土壤补肥+叶面喷施双管齐下 |
| 土壤养分过量 | 叶片过量某元素 | 停施该元素，注意拮抗 |

### 5.2 诊断报告模板

| 报告项目 | 内容 |
|----------|------|
| 果园基本信息 | 品种、树龄、面积、位置 |
| 土壤诊断结果 | 各指标含量及丰缺等级 |
| 叶片诊断结果 | 各元素含量及丰缺等级 |
| 外观诊断结果 | 典型症状描述及照片 |
| 问题诊断结论 | 主要缺乏或过量元素 |
| 施肥矫正建议 | 具体肥料种类、用量、方法 |
| 后续监测计划 | 下次检测时间和项目 |

## 6. 注意事项

| 注意事项 | 说明 |
|----------|------|
| 采样代表性 | 多点采样，避免单一位置偏差 |
| 样品保存 | 及时送检，避免降解变质 |
| 检测资质 | 选择有资质的检测机构 |
| 标准适用性 | 不同品种、树龄标准略有差异 |
| 定期诊断 | 建立长期监测档案 |
