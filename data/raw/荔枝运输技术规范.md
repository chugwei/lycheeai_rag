# 荔枝运输技术规范

> 本标准规定了荔枝鲜果运输的术语和定义、运输方式、运输条件、装载要求、运输管理及温度监控等技术要求。适用于荔枝鲜果的各种运输方式。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝鲜果的公路运输、铁路运输和海运。不适用于空运（空运特殊要求另行规定）。

### 规范性引用文件
| 标准编号 | 标准名称 |
|---------|---------|

## 二、运输方式选择

### 运输方式对比
| 运输方式 | 适用距离 | 运输时间 | 温控精度 | 成本 | 适用场景 |
|---------|---------|---------|---------|-----|---------|
| 冷藏公路运输 | 500km以内 | 3-8小时 | ±1.5°C | 中 | 省内及邻省运输 |
| 冷藏公路运输(长途) | 500-2000km | 8-36小时 | ±1.0°C | 中 | 跨省运输 |
| 铁路冷藏运输 | 1000km以上 | 24-72小时 | ±2.0°C | 低 | 大批量长途运输 |
| 冷藏集装箱海运 | 5000km以上 | 7-30天 | ±0.5°C | 低 | 出口远洋运输 |
| 航空运输 | 任何距离 | 2-8小时 | 不稳定 | 高 | 高价值精品紧急运输 |

## 三、装载前准备

### 运输车辆/容器要求
| 类型 | 技术要求 | 装载前检查项目 |
|-----|---------|--------------|
| 机械冷藏车 | 制冷量充足，温度可控范围-5-10°C | 制冷系统、温控仪、密封性、清洁度 |
| 蓄冷板冷藏车 | 蓄冷板蓄冷量满足全程需求 | 蓄冷板状态、箱体保温性 |
| 冷藏集装箱 | 独立制冷机组，控温精度±0.5°C | 制冷机组、温度记录仪、气密性 |
| 隔热保温车 | 配合冰源或干冰使用 | 保温层完整性、密封条状况 |

### 预冷要求
- **装车前**：果实必须充分预冷，果心温度≤5°C
- **预冷检查**：抽检比例≥5%，使用探针温度计检测果心温度
- **未达标处理**：果心温度>5°C的果实不得装车，需继续预冷
- **运输工具预冷**：装车前冷藏车需预冷至2-4°C，预冷时间≥30分钟

## 四、装载技术

### 装载方式与要求
| 包装类型 | 堆码方式 | 层数限制 | 风道要求 |
|---------|---------|---------|---------|
| 泡沫箱 | 骑缝交错堆码 | ≤7层 | 排间留10-15cm垂直风道 |
| 瓦楞纸箱 | 对齐堆码 | ≤6层 | 箱体通风孔对齐 |
| 塑料周转筐 | 骑缝堆码 | ≤5层 | 筐体自然通风 |
| 木箱/竹筐 | 对齐堆码 | ≤4层 | 单件之间留2-3cm |

### 装载量控制
| 车辆吨位 | 装载容量(%额定) | 每立方米装载量(kg) |
|---------|----------------|------------------|
| 5吨 | 70-80 | 200-250 |
| 10吨 | 75-85 | 220-260 |
| 15吨 | 75-85 | 220-260 |
| 20英尺集装箱 | 70-80 | 180-220 |
| 40英尺集装箱 | 70-80 | 180-220 |

### 装载注意事项
- 装载前检查车厢底板是否清洁、干燥、无异味
- 重不压轻，大不压小
- 包装箱箭头标识朝上，严禁倒置
- 装载高度不超过车厢顶部回风口下沿
- 货物与车厢壁之间留5-10cm间隙
- 装载完毕固定货物，防止运输中移位碰撞

## 五、运输过程管理

### 温度控制
| 运输阶段 | 温度要求(°C) | 控制措施 |
|---------|-------------|---------|
| 装载过程 | ≤5 | 快速装载（单批次≤30分钟），使用月台对接密封 |
| 运输全程 | 2-4 | 恒温控制，自动温度记录 |
| 中途卸货 | ≤8（单次开门≤5分钟） | 减少开门次数和时间 |
| 到货验收 | ≤5 | 到货后立即测量果心温度 |

### 温湿度记录
| 记录项目 | 记录方式 | 记录频率 |
|---------|---------|---------|
| 回风温度 | 自动 | 每10分钟1次 |
| 送风温度 | 自动 | 每10分钟1次 |
| 果品温度 | 人工+探针 | 装车、到货、中途各1次 |
| 环境温度 | 自动 | 连续记录 |
| 相对湿度 | 自动 | 每30分钟1次 |
| 制冷机组运行状态 | 自动 | 连续监测 |

### 运输注意事项
| 事项 | 具体要求 |
|-----|---------|
| 运输前 | 核对品种、数量、等级、目的地、温度设置 |
| 运输中 | 驾驶员每2小时检查1次温度记录 |
| 途中故障 | 制冷故障时立即联系就近维修点，如4小时内无法修复需就近租用冷库 |
| 堵车处理 | 减少开门，如堵车超过4小时需开启备用制冷 |
| 到货前 | 提前30分钟联系收货方，做好卸货准备 |
| 到货后 | 立即测量果心温度，检查包装完整性和品质 |

## 六、不同运输距离的技术方案

### 短途运输（<200km，当日达）
| 环节 | 方案 |
|-----|------|
| 运输工具 | 保温车或普通货车（配冰源） |
| 预冷要求 | 强制通风预冷至5°C以下 |
| 包装方式 | 泡沫箱+冰袋或保温箱 |
| 堆码要求 | ≤4层 |
| 温度管理 | 常温运输，加冰辅助 |
| 运输时限 | 从采收到目的地≤8小时 |

### 中长途运输（200-1000km，1-2日达）
| 环节 | 方案 |
|-----|------|
| 运输工具 | 机械冷藏车 |
| 预冷要求 | 强制通风或差压预冷至5°C以下 |
| 包装方式 | 微孔保鲜袋+泡沫箱或塑料筐 |
| 装载方式 | 留风道，≤6层 |
| 温度管理 | 2-4°C恒温，自动温度记录 |
| 运输时限 | 从采收到目的地≤36小时 |

### 长途运输（>1000km，2-5日达）
| 环节 | 方案 |
|-----|------|
| 运输工具 | 高档机械冷藏车或冷藏集装箱 |
| 预冷要求 | 差压预冷或真空预冷至3°C以下 |
| 保鲜处理 | 咪鲜胺处理+气调包装（MAP） |
| 包装方式 | 气调包装+泡沫箱 |
| 温度管理 | 2-3°C恒温，温度记录仪全程记录 |
| 运输时限 | 从采收到目的地≤96小时 |

## 七、到货验收

### 到货验收标准
| 检查项目 | 合格标准 |
|---------|---------|
| 果心温度(°C) | ≤5 |
| 褐变指数 | ≤1级 |
| 腐烂率(%) | ≤3 |
| 机械伤(%) | ≤3 |
| 失重率(%) | ≤3 |
| 包装完好率(%) | ≥98 |
| 冷链断裂时间 | 全程累计≤1小时 |

### 验收不合格处理
| 不合格情况 | 处理方式 |
|-----------|---------|
| 果心温度>5°C但≤8°C | 立即入库冷藏，优先销售 |
| 果心温度>8°C | 立即检验品质，按品质降级或转为加工 |
| 褐变指数>1级 | 降价处理或转为加工原料 |
| 腐烂率>5% | 拒收或重新协商价格 |
| 包装严重破损 | 重新包装后再入库 |

## 八、运输安全与卫生

### 运输卫生要求
- 运输工具使用前后需清洗消毒
- 严禁与有毒、有害、有异味物品混装运输
- 运输工具内部材料应无毒、无味、耐腐蚀
- 装卸人员需持有健康证
- 装卸过程应佩戴手套

### 运输安全规范
| 项目 | 要求 |
|-----|------|
| 车辆安全 | 定期检修制冷设备，确保正常运行 |
| 装载安全 | 捆扎牢固，防止运输中倾倒、碰撞 |
| 应急预案 | 配备故障应急处理方案 |
| 人员培训 | 驾驶员需接受冷链运输操作规程培训 |
| 保险 | 运输货物应投保货运险 |
