# 荔枝品种特征描述规范

## 摘要

标准化、规范化的品种特征描述是荔枝品种鉴定、登记、审定与推广的基础环节。本文依据国际植物遗传资源研究所（IPGRI）品种描述符及国家标准GB/T 16343，系统阐述荔枝品种特征描述的内容体系、评价指标与记录规范，涵盖树体、叶、花、果实、种子及物候期等六大描述模块，为品种资源普查、品种审定及商品品种宣传提供标准参考。

## 1 概述

品种特征描述是将品种的可遗传性状以文字、数值和分级量表等形式进行系统记录的过程。科学的特征描述规范有助于实现以下目的：品种身份的快速识别与准确鉴定；新品种审定中的特异性（Distinctness）判定；品种资源信息的国际交换与共享；商品品种的标准化市场宣传。

## 2 描述内容体系

荔枝品种特征描述分为六个模块：树体特征、叶部特征、花序特征、果实特征、种子特征与物候特征。

### 2.1 树体特征

| 描述项 | 评价指标 | 记录方式 |
| --- | --- | --- |
| 树高 | 成年树自然树高（m） | 实测数值（精确至0.1m） |
| 树冠类型 | 开心型、自然圆头型、垂枝型等 | 定性描述 |
| 枝条生长势 | 强、中、弱 | 三级定性 |
| 叶片密度 | 叶量等级 | 1-5级（1最稀，5最密） |
| 树皮颜色 | 灰褐、黑褐、红褐 | 目视比对标准色卡 |

### 2.2 叶部特征

| 描述项 | 评价指标 | 记录方式 |
| --- | --- | --- |
| 叶片形状 | 长椭圆形、倒披针形、倒卵形等 | 标准图谱对照 |
| 叶长/宽（cm） | 长度与宽度 | 游标卡尺实测 |
| 叶色 | 浅绿、深绿、暗绿、灰绿 | 1-5级色阶 |
| 叶尖形态 | 急尖、渐尖、钝圆 | 标准图谱对照 |
| 叶柄长度（mm） | 叶柄长短 | 游标卡尺实测 |

### 2.3 花序特征

| 描述项 | 评价指标 | 记录方式 |
| --- | --- | --- |
| 花序类型 | 圆锥花序 | 定性 |
| 花序大小（cm） | 长×宽 | 实测 |
| 单株花序数 | 数量范围 | 估计或计数 |
| 雄花比率 | 雌花与雄花比例 | 计数统计 |
| 着花量 | 花芽密度 | 1-5级（1最稀，5最密） |

### 2.4 果实特征（核心模块）

果实特征是品种鉴定的最重要指标，应在自然成熟期采集不少于30个单果进行测量统计。

| 描述项 | 评价指标 | 记录方式 |
| --- | --- | --- |
| 果形 | 圆形、卵形、近圆形、偏心形 | 标准图谱对照 |
| 果形指数 | 纵径/横径 | 数值（保留2位小数） |
| 单果质量（g） | 重量 | 电子天平（精确至0.01g） |
| 果皮颜色 | 红色、紫红、暗红、黄绿 | 标准色卡比对 |
| 龟裂片类型 | 尖峰形、平滑形、钝圆粒状 | 标准图谱对照 |
| 果皮厚度（mm） | 最厚处 | 游标卡尺实测 |
| 假种皮厚度（mm） | 果肉厚度 | 游标卡尺实测 |
| 可食率（%） | （果肉重/单果重）×100 | 称重计算 |
| 汁液量 | 丰富、中等、少 | 1-3级定性 |
| 核类型 | 大核、小核、焦核（退化核） | 目测+测量 |

### 2.5 种子特征

| 描述项 | 评价指标 | 记录方式 |
| --- | --- | --- |
| 种子形态 | 肾脏形、椭圆形 | 标准图谱对照 |
| 种皮颜色 | 黑褐、褐、红褐 | 目视比对 |
| 种子质量（g） | 单粒重量 | 电子天平 |
| 发芽率（%） | 田间发芽统计 | 发芽试验 |

### 2.6 物候特征

| 描述项 | 记录内容 | 记录格式 |
| --- | --- | --- |
| 萌芽期 | 春季抽梢时间 | 月-日上限/下限 |
| 始花期 | 第一批花开放日期 | 月-日 |
| 终花期 | 最后花谢日期 | 月-日 |
| 生理落果期 | 第一次/第二次落果集中期 | 月-日 |
| 成熟期 | 果实可采期 | 月-日 |

## 3 描述记录规范

1. 描述应在品种代表性植株上进行，取样不少于10株。
2. 果实描述以充分成熟的自然果为准，避免使用催熟或贮藏果。
3. 所有实测数据需注明测量工具与精度。
4. 定级描述需附照片与实物标本参照。
5. 品种描述表应包含：品种名称、来源地、采集时间、调查人、描述日期等元信息。
