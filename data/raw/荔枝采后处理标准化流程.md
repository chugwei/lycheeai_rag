# 荔枝采后处理标准化流程

## 摘要

荔枝采后处理标准化流程是保障荔枝从采收到终端销售全链条品质一致性的核心管理体系。本文系统规定了荔枝采后处理的标准作业流程，涵盖采收、分级、预冷、保鲜、包装、贮藏、运输和销售八大环节的操作规范、质量标准和关键控制点，为荔枝产业标准化和规模化发展提供技术依据。

## 1. 引言

荔枝采后处理标准化是实现荔枝优质优价、降低损耗和保障食品安全的关键。本文参考国家标准、行业标准和地方标准，结合荔枝产业实际，制定涵盖全链条的标准化操作规范。

## 2. 总流程

### 2.1 采后处理全流程图

```
采收 → 田间初拣 → 运输至处理中心 → 分级分拣 → 预冷 → 保鲜处理 → 包装 → 贮藏 → 冷链运输 → 终端销售
```

### 2.2 各环节时间要求

| 环节 | 时间要求 | 关键控制点 |
|------|---------|----------|
| 采收 | 避高温，带柄采收 | 成熟度、无损伤 |
| 田间初拣 | 采收后 30 min 内 | 剔除烂果 |
| 运输至处理中心 | ≤2 h | 温度 <20°C |
| 分级分拣 | ≤30 min | 分级准确率 >90% |
| 预冷 | ≤2 h（采后 4 h 内完成） | 果心温度 5~8°C |
| 保鲜处理 | ≤30 min | 杀菌效果 |
| 包装 | ≤60 min | 保鲜包装 |
| 入冷库 | ≤1 h | 冷库温度 2~5°C |
| 冷链运输 | 全程 0~5°C | 不断链 |

## 3. 采收环节

### 3.1 采收标准

| 指标 | 要求 |
|------|------|
| 成熟度 | 8~9 成熟，果皮转红 |
| 可溶性固形物 | ≥14°Brix |
| 采收时间 | 清晨或傍晚，避免高温 |
| 果柄长度 | 1~2 cm（带柄采收） |
| 果实状态 | 无病虫、无损伤、无褐变 |
| 采果工具 | 锋利的剪刀或指甲刀 |

### 3.2 采收操作规程

| 步骤 | 操作 | 质量要求 |
|------|------|---------|
| 1 | 采前 7 天检查果园 | 无暴雨，病虫害可控 |
| 2 | 采摘 | 保留果柄，轻拿轻放 |
| 3 | 装筐 | 单层或双层，不堆压 |
| 4 | 遮盖 | 遮阳网覆盖 |
| 5 | 记录 | 品种、时间、地点、批次 |

## 4. 田间初拣与运输

### 4.1 田间初拣

| 操作 | 要求 |
|------|------|
| 剔除对象 | 病果、烂果、畸形果、严重损伤果 |
| 操作时间 | 采收后 30 min 内 |
| 剔出率 | ≤5% |
| 筐体清洁 | 无残留果屑 |

### 4.2 运输至处理中心

| 参数 | 要求 |
|------|------|
| 运输时间 | ≤2 h |
| 运输工具 | 带遮阳篷的车辆 |
| 车厢温度 | <20°C |
| 码放 | 不超过 3 层 |
| 震动控制 | 平稳驾驶 |

## 5. 分级分拣环节

### 5.1 分级标准

| 级别 | 单果重（g） | 可溶性固形物（°Brix） | 果皮褐变率 |
|------|-----------|-------------------|----------|
| 特级 | ≥12 | ≥16 | 0% |
| 一级 | ≥9 | ≥14 | ≤5% |
| 二级 | ≥6 | ≥12 | ≤15% |
| 加工级 | ≥4 | ≥10 | ≤30% |

### 5.2 分拣操作

| 方式 | 准确率 | 处理量 | 适用 |
|------|-------|-------|------|
| 人工分拣 | 85%~92% | 500 kg/人/日 | 小规模 |
| 光电分选 | >95% | 3000 kg/h | 大规模 |

## 6. 预冷环节

### 6.1 预冷方式选择

| 方式 | 时间 | 温度 | 适用 |
|------|------|------|------|
| 强制风冷 | 60~90 min | 5~8°C | 常规 |
| 冷水预冷 | 15~30 min | 5~8°C | 快速 |
| 真空预冷 | 8~15 min | 5~8°C | 出口 |

### 6.2 预冷操作要求

| 参数 | 要求 |
|------|------|
| 预冷开始时间 | 采后 ≤2 h |
| 预冷终点温度 | 果心 5~8°C |
| 冷却均匀性 | 批内温差 ≤1°C |
| 失重率 | ≤3% |

## 7. 保鲜处理环节

### 7.1 保鲜处理流程

| 步骤 | 操作 | 参数 |
|------|------|------|
| 1 | 热水处理（可选） | 50~55°C，30~60 s |
| 2 | 杀菌浸渍 | 保鲜剂，1~3 min |
| 3 | 风干 | 自然沥干 10~15 min |
| 4 | 涂膜处理（可选） | 壳聚糖膜，2~3 min |

### 7.2 保鲜剂使用规范

| 成分 | 浓度 | 效果 |
|------|------|------|
| 咪鲜胺 | 20~50 mg/L | 杀菌 |
| 噻霉酮 | 5~20 mg/L | 杀菌 |
| 抗坏血酸 | 100~300 mg/L | 抗氧化 |

## 8. 包装环节

### 8.1 包装层级

| 层级 | 材料 | 功能 |
|------|------|------|
| 内层 | PE 保鲜袋（打孔） | 保湿 |
| 中层 | 泡沫网套 | 缓冲 |
| 外层 | 瓦楞纸箱 | 支撑 |

### 8.2 包装操作

| 步骤 | 操作 | 时间 |
|------|------|------|
| 1 | 装袋 | 1~2 min/袋 |
| 2 | 套网套 | 快速 |
| 3 | 装箱 | 整齐码放 |
| 4 | 封箱贴标 | 信息完整 |

### 8.3 标识信息

| 标识项 | 要求 |
|-------|------|
| 品种名称 | 中文标准名 |
| 等级 | 特级/一级/二级 |
| 产地 | 省/市/县 |
| 采摘日期 | YYYY-MM-DD |
| 净含量 | kg |
| 温度要求 | "冷藏运输 0~5°C" |
| 保质期 | 天 |

## 9. 贮藏环节

### 9.1 冷库条件

| 参数 | 常规冷藏 | 气调冷藏 |
|------|---------|---------|
| 温度 | 2~5°C | 0~2°C |
| 湿度 | 85%~92% | 88%~93% |
| 气调 | - | O₂ 1~3%，CO₂ 5%~8% |
| 货架期 | 14~21 天 | 40~60 天 |

### 9.2 码放规范

| 要求 | 规定 |
|------|------|
| 堆垛高度 | ≤2.5 m |
| 垛间通道 | ≥60 cm |
| 垛与墙间距 | ≥40 cm |
| 底层离地 | ≥10 cm |

### 9.3 出库管理

| 原则 | FIFO（先进先出） |
|------|----------------|
| 出库验收 | 品质检查、计数核对 |
| 回温 | 过渡间 30~60 min |

## 10. 运输与销售环节

### 10.1 冷链运输

| 参数 | 要求 |
|------|------|
| 车温 | 0~5°C |
| 装载温度 | 果实 ≤8°C |
| 在途监控 | 温度记录+GPS |
| 装卸时间 | ≤30 min |
| 全程损耗 | ≤2% |

### 10.2 终端销售

| 环境 | 要求 |
|------|------|
| 陈列温度 | 0~5°C |
| 货架期 | 销售期 ≤3 天 |
| 陈列方式 | 单层展示 |
| 标签 | 品名、等级、产地、日期 |

## 11. 质量控制体系

### 11.1 关键控制点（CCP）

| CCP | 控制限 | 监控频率 |
|-----|-------|---------|
| 采收成熟度 | 8~9 成熟 | 每批次 |
| 预冷终点温度 | 5~8°C | 每批 |
| 杀菌效果 | 杀菌率 ≥95% | 每班 |
| 包装标识 | 信息完整 | 每箱 |
| 冷库温度 | 2~5°C | 每 4 h |
| 运输温度 | 0~5°C | 全程记录 |

### 11.2 记录与追溯

| 记录项 | 保存期限 |
|-------|---------|
| 采收记录 | 12 个月 |
| 分级记录 | 12 个月 |
| 预冷记录 | 12 个月 |
| 杀菌记录 | 24 个月 |
| 出库记录 | 24 个月 |
| 运输记录 | 24 个月 |

## 12. 标准化管理效益

| 指标 | 非标准化 | 标准化后 | 改善 |
|------|---------|---------|------|
| 损耗率 | 15%~25% | 3%~8% | -70% |
| 货架期 | 2~5 天 | 10~30 天 | +500% |
| 商品合格率 | 70%~80% | >95% | +20% |
| 平均售价 | 基准 | +30%~50% | 溢价 |
| 客户投诉率 | 5%~10% | <1% | -90% |

## 13. 结论

荔枝采后处理标准化流程是保障品质、降低损耗和实现产业规模化的基础。通过建立八大环节的标准作业规范和质量控制体系，可将荔枝损耗率从 15%~25% 降至 3%~8%，货架期从 2~5 天延长至 10~30 天，实现品质和效益的双重提升。
