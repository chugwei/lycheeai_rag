# 荔枝高接换种技术规程

> 本标准规定了荔枝高接换种技术的要求，包括换种对象选择、换种前准备、嫁接技术、嫁接后管理及换种后树体管理等内容。适用于荔枝成年树或低产树的高接换种（品种改良）。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝成年树因品种不良、品质差、产量低或市场变化需要进行品种改良的高接换种。适用于树龄5-30年的荔枝树。

## 二、换种对象与品种选择

### 适宜换种的对象
| 换种对象 | 换种原因 | 换种后预期效益 |
|---------|---------|--------------|
| 低产品种 | 品种产量低，经济价值低 | 产量提高50-100% |
| 品质劣的品种 | 果实品质差，市场售价低 | 售价提高1-3倍 |
| 感病品种 | 易感霜疫霉病、炭疽病 | 病害减轻，管理成本降低 |
| 市场不匹配品种 | 成熟期与市场需求错位 | 延长供应期，提高效益 |
| 树龄老化品种 | 树龄大但树势尚可 | 更新品种，延长经济寿命 |

### 推荐换种品种
| 原品种 | 推荐换种品种 | 换种优势 | 换种适宜区域 |
|-------|------------|---------|------------|
| 黑叶 | 桂味、妃子笑 | 品质提升，售价提高 | 广东、广西 |
| 三月红 | 白糖罂、妃子笑 | 调整早熟品种结构 | 海南、广东 |
| 怀枝 | 桂味、糯米糍 | 品质大幅提升 | 广东、广西 |
| 大红袍 | 妃子笑、桂味 | 提高市场竞争力 | 四川、云南 |
| 乌叶 | 兰竹、桂味 | 提高品质和售价 | 福建 |

## 三、高接换种前准备

### 换种树准备
| 准备工作 | 技术要求 | 实施时间 |
|---------|---------|---------|
| 树体选择 | 树势健壮，无严重病虫害，主干直径≥10cm | 换种前1年 |
| 肥水管理 | 加强肥水，增强树势 | 换种前6个月 |
| 病虫害防治 | 全面防治病虫害，确保树体健康 | 换种前3个月 |
| 灌水 | 嫁接前3-5天灌透水一次 | 嫁接前3-5天 |

### 工具与材料准备
| 材料/工具 | 规格要求 | 数量(每100株) |
|---------|---------|-------------|
| 嫁接刀 | 锋利，刃口薄 | 3-5把 |
| 修枝剪 | 大号果树剪 | 2-3把 |
| 手锯 | 细齿手锯 | 2-3把 |
| 嫁接膜 | 宽2-3cm，PE材质 | 5-8卷 |
| 接穗 | 优良品种，芽饱满 | 500-800枝 |
| 蜡封剂 | 接穗封口用 | 1kg |
| 杀菌剂 | 多菌灵或甲基托布津 | 0.5kg |
| 标签 | 注明品种、日期 | 100个 |

## 四、高接换种技术

### 嫁接时期
| 地区 | 适宜嫁接时期 | 说明 |
|-----|------------|------|
| 广东、广西 | 2月下旬-4月上旬 | 春季回暖后，树液流动 |
| 海南 | 1月下旬-3月上旬 | 冬季温暖，早春嫁接 |
| 福建 | 3月上旬-4月中旬 | 气温回升后 |
| 云南 | 2月-4月 | 干季末期，雨季前 |
| 四川 | 3月中旬-4月下旬 | 气温稳定后 |

### 砧桩处理
| 处理步骤 | 操作要点 |
|---------|---------|
| 锯主干 | 在离地面80-120cm处锯断主干 |
| 锯主枝 | 保留3-4个方位好的主枝，在离主干30-50cm处锯断 |
| 锯口处理 | 锯口削平，用锋利刀削光滑 |
| 涂药保护 | 锯口涂抹多菌灵或甲基托布津 |
| 留枝 | 每株留1-2根辅养枝（不嫁接），维持光合作用 |

### 嫁接方法

#### 插皮接法（最常用）
| 操作步骤 | 技术要点 |
|---------|---------|
| 1.削砧木 | 在砧桩光滑处，纵向切2-3cm皮层，深达木质部 |
| 2.削接穗 | 接穗下端削成3-4cm马耳形斜面，对侧削一小斜面 |
| 3.插入 | 将接穗长斜面朝向木质部插入皮层下 |
| 4.绑扎 | 嫁接膜严密包扎，密封接合处 |
| 5.套袋 | 套上透明塑料袋保湿（春季可不套） |

#### 切接法
- 适用于砧桩直径<5cm的枝条
- 操作方法同嫁接育苗的切接法
- 每桩接2-3个接穗

### 每株嫁接数量
| 砧桩直径(cm) | 嫁接点数 | 每点接穗数 | 总接穗数 |
|-------------|---------|-----------|---------|
| 3-5 | 3-4 | 1 | 3-4 |
| 5-8 | 4-5 | 1-2 | 5-8 |
| 8-12 | 5-6 | 1-2 | 6-10 |
| >12 | 6-8 | 1-2 | 8-12 |

## 五、嫁接后管理

### 短期管理（嫁接后1-3个月）
| 管理项目 | 操作要求 | 管理周期 |
|---------|---------|---------|
| 遮荫 | 套袋保湿，外侧遮荫 | 嫁接后立即 |
| 抹芽 | 抹除砧木上萌发的芽 | 每7-10天1次 |
| 刺孔透气 | 接穗萌芽后，在塑料袋上刺小孔 | 逐步增加透气 |
| 摘袋 | 新梢长5-10cm时去除塑料袋 | 嫁接后30-40天 |
| 引绑 | 新梢长20-30cm时绑缚引枝 | 新梢木质化前 |
| 除萌 | 继续抹除砧木萌芽 | 每10-15天1次 |

### 中期管理（嫁接后3-6个月）
| 管理项目 | 操作要求 |
|---------|---------|
| 解绑 | 嫁接后3-4个月解除嫁接膜 |
| 施肥 | 薄施复合肥(0.2-0.3kg/株)，每月1次 |
| 浇水 | 干旱时及时浇水，保持土壤湿润 |
| 病虫害防治 | 防治炭疽病、瘿螨、蚜虫 |
| 防风 | 新梢绑缚固定，防止风折 |

### 长期管理（嫁接后6个月以上）
| 管理项目 | 操作要求 |
|---------|---------|
| 整形修剪 | 培养新的树冠骨架，选留3-4个主枝 |
| 疏梢 | 每嫁接点留2-3条健壮新梢，其余疏除 |
| 辅养枝处理 | 逐步回缩辅养枝，2-3年后全部去除 |
| 施肥 | 正常施肥管理，以氮肥为主促进生长 |
| 花期管理 | 嫁接后第2年可适当留花结果 |

## 六、高接换种树体管理

### 树冠重建
| 年份 | 树冠重建目标 | 技术措施 |
|-----|------------|---------|
| 第1年 | 培养新树冠骨架 | 选留3-4个主枝，培养副主枝 |
| 第2年 | 扩大树冠 | 继续培养枝组，适当留果 |
| 第3年 | 形成丰产树冠 | 基本恢复产量，进入正常管理 |

### 辅养枝管理
| 阶段 | 辅养枝作用 | 处理方法 |
|-----|-----------|---------|
| 嫁接当年 | 提供光合产物，维持根系活力 | 保留，不嫁接 |
| 嫁接后半年 | 辅助新梢生长 | 逐步回缩 |
| 嫁接后1-2年 | 过渡作用 | 全部去除 |
