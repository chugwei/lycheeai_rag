# 荔枝黄化病防治技术

## 摘要

荔枝黄化病是一种由根结线虫、土壤缺素、病害复合因素引起的生理性-病理性综合障碍，以叶片黄化、树势衰退为主要特征。该病在华南荔枝产区广泛存在，严重影响产量和品质。本文从黄化病的类型、诊断和综合矫正措施等方面进行系统阐述。

## 1. 黄化病类型

荔枝黄化病并非单一病害，而是多种原因导致的综合性状。根据病因可分为以下几类：

| 类型 | 主要病因 | 特征 |
|-----|---------|------|
| 缺素黄化 | 缺铁、缺锌、缺氮 | 叶片均匀或脉间黄化 |
| 线虫黄化 | 根结线虫侵染 | 根系结瘤，叶片黄化脱落 |
| 病害黄化 | 根腐病、黄萎病 | 根系腐烂，全株黄化 |
| 生理性黄化 | 土壤过酸、积水 | 根系缺氧，营养吸收障碍 |
| 退化黄化 | 品种退化、老树衰退 | 全株生长缓慢，叶片黄化 |

## 2. 各类型诊断与矫正

### 2.1 缺素黄化

| 缺素类型 | 症状特征 | 矫正方法 | 用量 |
|---------|---------|---------|------|
| 缺铁 | 新叶脉间黄化，叶脉绿色 | 螯合铁（EDTA-Fe）叶面喷施 | 0.2-0.3% |
| 缺锌 | 小叶、簇生，叶脉间黄化 | 硫酸锌叶面喷施 + 土施 | 0.1-0.2% |
| 缺氮 | 全叶均匀黄化，老叶先黄 | 增施氮肥（尿素） | 按树龄施用 |
| 缺镁 | 老叶脉间黄化，叶缘褐色 | 硫酸镁叶面喷施 | 1-2% |
| 缺锰 | 新叶脉间黄化，严重时褐变 | 硫酸锰叶面喷施 | 0.1-0.2% |

### 2.2 线虫黄化

| 项目 | 内容 |
|-----|------|
| 诊断依据 | 根系有指形或球形虫瘿，叶片黄化 |
| 发生条件 | 沙质土壤、连作果园、高温高湿 |
| 化学防治 | 噻唑膦 15% 颗粒剂，10-15 kg/亩 |
| 生物防治 | 淡紫拟青霉（*P. lilacinum*）1×10⁸ CFU/g |
| 农业防治 | 轮作非寄主作物、增施有机肥 |
| 根际处理 | 石灰氮 500 g/株，改良根际土壤 |

### 2.3 病害黄化

| 病害 | 病原 | 诊断 | 防治 |
|-----|------|------|------|
| 根腐病 | 镰刀菌、腐霉菌 | 根系褐色腐烂 | 恶霉灵灌根 |
| 黄萎病 | 镰刀菌枯萎菌 | 维管束褐色，叶片黄化 | 甲基托布津灌根 |
| 根结线虫病 | 根结线虫 | 根系虫瘿 | 噻唑膦 + 生物防治 |

## 3. 综合诊断流程

```
叶片黄化观察
    ↓
取样检测（叶片营养分析 + 根系检查）
    ↓
判断类型（缺素 / 线虫 / 病害 / 生理）
    ↓
针对性矫正（施肥 / 杀菌 / 杀线虫 / 土壤改良）
```

### 3.1 叶片营养诊断标准

| 元素 | 正常范围 | 缺乏阈值 | 毒害阈值 |
|-----|---------|---------|---------|
| N (%) | 2.0-3.0 | <1.5 | >4.0 |
| P (%) | 0.2-0.4 | <0.15 | >0.6 |
| K (%) | 1.5-2.5 | <1.0 | >3.5 |
| Fe (mg/kg) | 20-80 | <15 | >200 |
| Zn (mg/kg) | 20-60 | <15 | >150 |
| Mg (%) | 0.2-0.5 | <0.15 | >0.8 |

## 4. 矫正与防治技术

### 4.1 土壤改良

- **调节 pH**：酸性土壤（pH<5.5）施用生石灰 200-300 kg/亩。
- **排水**：开挖排水沟，降低地下水位。
- **增施有机肥**：每年施腐熟有机肥 30-50 kg/株。
- **菌根接种**：接种菌根真菌，促进根系发育。

### 4.2 施肥矫正

| 类型 | 方案 |
|-----|------|
| 缺铁黄化 | 螯合铁 200 g/株 + 硫酸亚铁 500 g/株 |
| 缺锌黄化 | 硫酸锌 200 g/株 + 0.2% 叶面喷施 |
| 缺氮黄化 | 尿素 300-500 g/株 + 复合肥补充 |
| 综合性黄化 | 高氮复合肥 + 微量元素肥 + 有机肥 |

### 4.3 灌根处理方案

| 药剂 | 浓度 | 用量/株 | 间隔 |
|-----|------|---------|------|
| 恶霉灵 45% | 1000 倍 | 500 mL | 14 天 |
| 噻唑膦 15% | 1000 倍 | 500 mL | 21 天 |
| 木霉菌 | 1×10⁶ CFU/mL | 500 mL | 7 天 |

## 5. 预防与日常管理

- 建园时进行土壤检测，根据结果配方施肥。
- 定期（每年 1-2 次）进行叶片营养分析。
- 避免大水漫灌，采用滴灌或微喷。
- 加强苗期管理，从源头预防线虫和病害。
