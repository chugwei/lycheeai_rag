# 荔枝果醋发酵加工技术

## 摘要

荔枝果醋是以荔枝果肉或果汁为原料，经酒精发酵和醋酸发酵两段发酵制成的含醋酸的发酵饮品，总酸含量 ≥3.5 g/100 mL，具有荔枝果香和醋酸双重风味。本文介绍荔枝果醋的发酵工艺、菌种选择、发酵参数控制及产品质量标准。

## 1. 引言

果醋是近年来快速发展的新型发酵饮品，具有降血脂、抗氧化等健康功能。荔枝果醋以荔枝独特的花果香为特色，结合醋酸的酸爽口感，是一款兼具风味与功能的发酵产品。

## 2. 原料与预处理

### 2.1 原料要求

| 指标 | 要求 | 备注 |
|------|------|------|
| 品种 | 妃子笑、白糖罂 | 汁多味甜 |
| 成熟度 | 8~9 成熟 | 糖度高 |
| 可溶性固形物 | ≥14°Brix | 保证发酵 |
| 可滴定酸 | 0.20%~0.40% | 适当 |
| 腐烂率 | ≤5% | 果醋可容忍度稍高 |

### 2.2 预处理流程

| 步骤 | 操作 | 目的 |
|------|------|------|
| 1 | 清洗、破碎 | 去污、出汁 |
| 2 | 压榨取汁 | 获取发酵底物 |
| 3 | 调糖 | 调整至 16°~20°Brix |
| 4 | 调酸 | 调至 pH 4.0~4.5 |
| 5 | 杀菌 | 巴氏杀菌 80°C/30 min |
| 6 | 冷却 | 降至 25~28°C 接种 |

## 3. 酒精发酵（一段发酵）

### 3.1 酒精发酵参数

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 发酵温度 | 25~28°C | 酒精酵母最适 |
| 发酵时间 | 7~12 天 | 至残糖 <2 g/100 mL |
| 酒精度 | 6%~10% vol | 醋酸发酵底物 |
| 酵母 | 酵母 121 或啤酒酵母 | 接种量 1%~2% |
| pH | 3.5~4.0 | 抑菌保发酵 |
| SO₂ | 50~80 mg/L | 抑制杂菌 |

### 3.2 酒精发酵监控

| 指标 | 频率 | 合格标准 |
|------|------|---------|
| 温度 | 每 4 h | 25~28°C |
| 可溶性固形物 | 每日 | 持续下降 |
| 酒精度 | 每日 | 逐步上升 |
| pH | 每日 | 缓慢下降 |

## 4. 醋酸发酵（二段发酵）

### 4.1 醋酸发酵参数

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 发酵温度 | 28~32°C | 醋酸菌最适 |
| 发酵时间 | 7~15 天 | 至总酸达标 |
| 接种量 | 5%~10% | 醋酸菌液 |
| 通气 | 持续搅拌通气 | 醋酸菌好氧 |
| 初始酒精度 | 6%~10% vol | 酒精底物 |
| 目标总酸 | ≥3.5 g/100 mL | 成品要求 |

### 4.2 醋酸菌种

| 菌种 | 特点 | 产酸速率 | 适用性 |
|------|------|---------|-------|
| 巴氏醋酸杆菌 | 经典菌种、产酸稳定 | 中 | 传统酿造 |
| 葡糖杆菌 | 产酸快、酒精耐受高 | 快 | 工业化 |
| 里氏木霉（固态） | 固态发酵 | 慢 | 固态果醋 |

### 4.3 醋酸发酵过程监控

| 监测指标 | 频率 | 方法 |
|---------|------|------|
| 总酸 | 每日 | 滴定法 |
| 酒精度 | 每日 | 酒精计（应下降） |
| 温度 | 每 4 h | 温度计（放热） |
| 菌体浓度 | 每 2 天 | 镜检/OD 值 |

## 5. 后处理

### 5.1 陈酿与调配

| 步骤 | 操作 | 参数 |
|------|------|------|
| 过滤 | 硅藻土或膜过滤 | 去除菌体 |
| 调配 | 加水、加糖、加风味 | 调整口感 |
| 杀菌 | 巴氏杀菌 75°C/15 min | 商业无菌 |
| 陈酿 | 1~3 个月 | 风味融合 |
| 澄清 | 离心或静置 | 透明澄清 |

### 5.2 调配配方参考

| 成分 | 用量 | 作用 |
|------|------|------|
| 原醋 | 基准 | 主体 |
| 净化水 | 10%~30% | 稀释至饮用浓度 |
| 白砂糖 | 2%~5% | 改善口感 |
| 荔枝浓缩汁 | 2%~5% | 补充果香 |
| 柠檬酸 | 适量 | 调节酸度 |

## 6. 产品规格

### 6.1 荔枝果醋质量标准

| 指标 | 要求 |
|------|------|
| 总酸（以醋酸计） | ≥3.5 g/100 mL（原醋） |
| 酒精度 | ≤1.0% vol |
| 可溶性固形物 | ≥1.0% |
| 色泽 | 红褐至琥珀色，透明 |
| 香气 | 荔枝果香与醋酸香协调 |
| 滋味 | 酸甜适口，无异味 |
| 微生物 | 符合 GB 2719 标准 |

### 6.2 饮用型果醋调配标准

| 指标 | 要求 |
|------|------|
| 总酸 | 1.0~3.0 g/100 mL |
| 可溶性固形物 | 8°~12°Brix |
| 酒精度 | ≤1.0% vol |

## 7. 质量控制

| 控制点 | 控制限 | 监控方式 |
|-------|-------|---------|
| 原料糖度 | ≥14°Brix | 折光仪 |
| 酒精发酵残糖 | <2 g/100 mL | 折光仪 |
| 醋酸发酵温度 | 28~32°C | 温度计 |
| 总酸 | ≥3.5 g/100 mL | 滴定法 |
| 酒精度（成品） | ≤1.0% vol | 酒精计 |

## 8. 经济效益

| 项目 | 数值 |
|------|------|
| 原料出醋率 | 55%~65%（按鲜果计） |
| 生产成本 | 10~18 元/瓶（500 mL） |
| 出厂价 | 20~40 元/瓶 |
| 毛利率 | 50%~65% |

## 9. 结论

荔枝果醋通过酒精发酵和醋酸发酵两段工艺制成，关键在于控制酒精度（6%~10%）作为醋酸发酵底物和稳定的通气条件。成品总酸 ≥3.5 g/100 mL，口感酸甜适口。
