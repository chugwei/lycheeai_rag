# 荔枝园灌溉制度制定方法

## 摘要

本文件规定了荔枝园灌溉制度的制定方法和程序，包括水分需求分析、灌溉指标确定、灌水周期与灌水定额计算、灌溉制度编制等核心内容。灌溉制度是荔枝园水分管理的技术核心，合理的灌溉制度应根据当地气象条件、土壤特性、荔枝品种和物候期需水规律综合确定。文件为荔枝园灌溉制度的科学编制提供系统方法指导。

## 1 总则

### 1.1 适用范围

适用于荔枝主产区规模化荔枝园的灌溉制度制定。

### 1.2 基本要求

- 灌溉制度应以气象资料、土壤墒情和作物需水为基础
- 因地制宜，不同产区、不同品种应区别对待
- 动态调整，根据实际气象条件和土壤水分状况灵活修正
- 节水高效，在保证产量的前提下最大限度节约用水

## 2 灌溉制度组成要素

灌溉制度由灌水次数、灌水时间、灌水周期和灌水定额四个要素组成。

| 要素 | 定义 | 单位 |
|------|------|------|
| 灌水次数 | 全生育期总灌溉次数 | 次 |
| 灌水时间 | 每次灌水的日期 | 月/日 |
| 灌水周期 | 相邻两次灌溉的间隔天数 | 天 |
| 灌水定额 | 每次每亩灌溉用水量 | m³/亩 |

## 3 水分需求分析

### 3.1 蒸散发量计算

采用Penman-Monteith公式计算参考作物蒸散发量(ET₀)：

**ET₀ = [0.408 × Δ × (Rn - G) + γ × (900/(T + 273)) × u₂ × (es - ea)] / [Δ + γ × (1 + 0.34 × u₂)]**

其中：Δ为饱和水汽压曲线斜率，Rn为净辐射，G为土壤热通量，γ为干湿表常数，T为气温，u₂为2m处风速，es和ea分别为饱和和实际水汽压。

| 月份 | 参考ET₀(mm/d) | 备注 |
|------|-------------|------|
| 1月 | 2.5-3.5 | 低温少蒸腾 |
| 2月 | 3.5-4.5 | 萌芽期需水增加 |
| 3月 | 4.5-6.0 | 花期 |
| 4月 | 5.5-7.0 | 高温，蒸腾强 |
| 5月 | 6.5-8.0 | 幼果期，需水高峰 |
| 6月 | 7.0-8.5 | 果实膨大期 |
| 7月 | 7.5-9.0 | 全年最高 |
| 8月 | 7.0-8.5 | 秋梢期 |
| 9月 | 5.5-7.0 | 渐降 |
| 10月 | 4.0-5.5 | 花芽分化 |
| 11月 | 3.0-4.0 | |
| 12月 | 2.5-3.5 | |

### 3.2 作物系数(Kc)

| 物候期 | 作物系数Kc | 说明 |
|--------|----------|------|
| 萌芽期 | 0.45-0.55 | 新梢生长 |
| 花期 | 0.35-0.45 | 枝叶覆盖少 |
| 幼果期 | 0.60-0.70 | 枝叶渐茂 |
| 果实膨大期 | 0.70-0.85 | 叶量最大 |
| 采果前 | 0.75-0.85 | |
| 采果后 | 0.55-0.65 | 枝叶修剪后 |
| 秋梢期 | 0.50-0.60 | 新梢生长 |
| 花芽分化期 | 0.30-0.40 | 生长缓慢 |
| 休眠期 | 0.20-0.30 | 生长停滞 |

### 3.3 作物蒸散发(ETc)

ETc = Kc × ET₀

荔枝园实际需水总量 = ETc - 有效降雨量

有效降雨量计算：有效降雨(mm) = 总降雨(mm) × 有效系数(0.6-0.8)

## 4 灌溉指标确定

### 4.1 土壤水分指标

| 指标类型 | 数值范围 | 应用 |
|---------|---------|------|
| 田间持水量(θfc) | 28%-42% | 灌溉上限参考 |
| 萎蔫系数(θwp) | 8%-15% | 灌溉下限参考 |
| 适宜水分上限 | θfc × 85% | 不宜超过 |
| 适宜水分下限 | θfc × 45% | 不宜低于 |
| 启动灌溉阈值 | θfc × 50% | 开始灌溉 |

### 4.2 灌溉允许耗水系数(PEM)

PEM = (θfc - θw) / (θfc - θpwp)

其中：θw为启动灌溉时土壤含水率，θpwp为永久萎蔫系数。

| 物候期 | PEM | 说明 |
|--------|-----|------|
| 萌芽期 | 0.35-0.40 | 对水分较敏感 |
| 花期 | 0.45-0.55 | 需控水 |
| 幼果期 | 0.30-0.35 | 最敏感期 |
| 果实膨大期 | 0.25-0.35 | 最敏感期 |
| 秋梢期 | 0.35-0.40 | 较敏感 |
| 花芽分化期 | 0.55-0.70 | 耐旱 |

## 5 灌水周期与灌水定额计算

### 5.1 灌水周期计算

灌水周期 T = (PEM × (θfc - θpwp) × H × ρw × 10000) / (ETc × 666.7)

其中：T为灌水周期(天)，PEM为允许耗水系数，θfc和田间持水量体积含水率，θpwp为永久萎蔫系数，H为湿润层深度(m)，ρw为水的容重(取1)，ETc为作物蒸散发量(mm/d)。

### 5.2 灌水定额计算

灌水定额 m = (θfc - θirr) × H × ρw × 10000

其中：θirr为灌前土壤含水率，H为湿润层深度(m)。

| 物候期 | 湿润层深度(m) | 灌前含水率 | 目标含水率 | 灌水定额(m³/亩) |
|--------|-------------|----------|----------|--------------|
| 萌芽期 | 0.8 | 0.45 | 0.70 | 16-21 |
| 幼果期 | 1.0 | 0.40 | 0.75 | 23-35 |
| 果实膨大期 | 1.0 | 0.50 | 0.80 | 20-30 |
| 采果前 | 1.0 | 0.55 | 0.75 | 13-20 |
| 秋梢期 | 0.8 | 0.45 | 0.70 | 16-21 |
| 花芽分化期 | 0.6 | 0.35 | 0.50 | 10-15 |

### 5.3 实际考虑因素

- 灌溉水利用效率系数：取0.85-0.90
- 降雨补给修正：连续降雨后减少或取消灌溉
- 蒸发修正：高温干旱天气增加灌水次数

## 7 灌溉制度执行与调整

### 7.1 执行要求

- 严格按制度执行，不得随意增减
- 根据天气变化灵活调整，连续降雨3天以上取消灌溉
- 记录每次灌溉时间、水量、天气情况

### 7.2 动态调整

| 调整条件 | 调整方式 |
|---------|---------|
| 持续高温(>35℃) | 缩短周期1-2天，增加水量10%-20% |
| 持续降雨 | 推迟或取消灌溉 |
| 大风天气 | 避免喷灌，采用滴灌 |
| 土壤含水量超标 | 延迟灌溉 |
| 土壤含水量不足 | 提前灌溉，增加水量 |
