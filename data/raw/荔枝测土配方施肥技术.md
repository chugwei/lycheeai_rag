# 荔枝测土配方施肥技术

## 摘要

测土配方施肥是荔枝科学施肥的核心技术，通过土壤养分测定和肥效试验确定最优施肥方案。本文系统介绍了荔枝测土配方施肥的技术原理、土壤样品采集与检测方法、养分丰缺指标的建立、配方设计的计算方法以及施肥方案的制定与实施，结合荔枝不同物候期的养分需求特点，提出了各生育阶段的配方施肥技术参数，为荔枝养分精准管理和化肥减施增效提供技术支撑。

## 一、测土配方施肥的技术原理

### 1.1 基本原理

测土配方施肥基于三个核心原理：
1. **养分归还原理：** 荔枝从土壤中带走多少养分，就需补充多少养分
2. **最小养分律：** 作物产量受土壤中相对含量最低的养分因子制约
3. **报酬递减律：** 单位施肥量的增产量随施肥量增加而递减

### 1.2 技术流程

土壤测试→肥效试验→配方设计→肥料生产→科学施肥→效果评价

## 二、土壤样品采集与检测

### 2.1 采样方法

| 采样要素 | 技术要求 |
|---------|---------|
| 采样时间 | 采果后至施肥前(7-8月) |
| 采样深度 | 0-20cm和20-40cm两层 |
| 采样密度 | 每2-3公顷一个混合样 |
| 采样点数 | 每混合样取15-20个点 |
| 采样路线 | S形或棋盘式采样 |
| 样品重量 | 混合样不少于1kg |

### 2.2 检测项目与方法

| 检测项目 | 检测方法 | 评价指标 |
|---------|---------|---------|
| 土壤pH | 电位法(水土比2.5:1) | 酸化程度 |
| 有机质 | 重铬酸钾氧化法 | 肥力水平 |
| 全氮(N) | 凯氏定氮法 | 氮素储备 |
| 碱解氮 | 碱解扩散法 | 速效氮供应 |
| 有效磷(P) | 碳酸氢钠法(Olsen法) | 磷供应水平 |
| 速效钾(K) | 乙酸铵提取法 | 钾供应水平 |
| 交换性钙 | 乙酸铵提取-原子吸收法 | 钙供应水平 |
| 交换性镁 | 乙酸铵提取-原子吸收法 | 镁供应水平 |
| 有效硼(B) | 沸水提取-甲亚胺法 | 硼供应水平 |
| 有效锌(Zn) | DTPA提取法 | 锌供应水平 |

## 三、荔枝养分需求规律

### 3.1 年周期养分吸收量

| 树龄 | 产量(kg/株) | 吸收N(kg) | 吸收P₂O₅(kg) | 吸收K₂O(kg) | N:P₂O₅:K₂O |
|------|-----------|---------|------------|----------|----------|
| 幼树(3年生) | 5-10 | 0.08-0.12 | 0.03-0.05 | 0.08-0.12 | 1:0.3-0.5:1.0 |
| 初果树(5年生) | 15-25 | 0.20-0.35 | 0.08-0.15 | 0.25-0.40 | 1:0.4:1.2 |
| 盛果树(8年生) | 40-60 | 0.50-0.80 | 0.15-0.25 | 0.60-0.90 | 1:0.3:1.2 |
| 高产树(10年以上) | 60-80 | 0.80-1.00 | 0.25-0.35 | 0.90-1.20 | 1:0.3:1.2 |

### 3.2 各物候期养分需求比例

| 物候期 | 氮(%) | 磷(%) | 钾(%) | 需求特点 |
|--------|------|------|------|---------|
| 采果至秋梢(7-9月) | 40-45 | 30-35 | 20-25 | 恢复树势，培养结果母枝 |
| 花芽分化(10-1月) | 10-15 | 15-20 | 20-25 | 促进花芽分化 |
| 开花坐果(2-4月) | 15-20 | 25-30 | 20-25 | 提高花质和坐果率 |
| 果实发育(5-7月) | 20-25 | 20-25 | 30-35 | 促进果实膨大和品质形成 |

## 五、配方设计与计算

### 5.1 施肥量计算方法

目标产量法计算公式：
\
施肥量 = (目标产量需肥量 - 土壤供肥量) / 肥料利用率

| 参数 | 计算方法 |
|------|---------|
| 目标产量需肥量 | 每100kg果实需N 0.8-1.0kg, P₂O₅ 0.3-0.4kg, K₂O 0.9-1.2kg |
| 土壤供肥量 | 土壤养分测定值 × 校正系数 |
| 肥料利用率 | N 30%-40%, P₂O₅ 15%-25%, K₂O 30%-50% |

### 5.2 不同肥力水平推荐配方

| 土壤肥力 | 目标产量(kg/亩) | 推荐N-P₂O₅-K₂O配方 | 施肥量(kg/亩) |
|---------|--------------|------------------|------------|
| 低肥力 | 800-1000 | 15-8-22 | 80-120 |
| 中肥力 | 1000-1500 | 15-6-20 | 70-100 |
| 高肥力 | 1500-2000 | 12-5-18 | 60-80 |

### 5.3 配方肥的配制

| 原料 | 含N(%) | 含P₂O₅(%) | 含K₂O(%) | 配制比例(kg/吨) |
|------|-------|----------|---------|--------------|
| 尿素 | 46 | 0 | 0 | 220 |
| 磷酸一铵 | 11 | 44 | 0 | 90 |
| 氯化钾 | 0 | 0 | 60 | 230 |
| 硫酸镁 | 0 | 0 | 0 | 50 |
| 填料(有机质等) | - | - | - | 410 |

## 六、配方施肥实施方案

### 6.1 基肥施用

| 肥料 | 用量(kg/亩) | 施用时间 | 施用方法 |
|------|-----------|---------|---------|
| 腐熟有机肥 | 2000-3000 | 7-8月(采果后) | 沟施或撒施翻耕 |
| 钙镁磷肥 | 50-80 | 7-8月 | 与有机肥混施 |
| 配方肥(15-8-22) | 20-30 | 7-8月 | 沟施 |

### 6.2 追肥施用

| 追肥时期 | 配方肥用量(kg/亩) | N-P₂O₅-K₂O | 补充元素 |
|---------|----------------|-----------|---------|
| 花前(1-2月) | 15-25 | 12-10-18 | 硼砂0.5kg/亩 |
| 谢花后(4月) | 20-30 | 15-6-20 | 硝酸钙5-10kg/亩 |
| 果实膨大(5月) | 15-20 | 10-5-25 | 硫酸钾5-8kg/亩 |

### 6.3 叶面追肥

| 时期 | 肥料配方 | 浓度 | 作用 |
|------|---------|------|------|
| 花前 | 磷酸二氢钾+硼砂 | 0.3%+0.1% | 提高花质 |
| 谢花后 | 尿素+磷酸二氢钾 | 0.2%+0.2% | 补充营养 |
| 幼果期 | 磷酸二氢钾+氯化钙 | 0.3%+0.2% | 促果防裂 |
| 秋梢期 | 尿素+磷酸二氢钾 | 0.3%+0.3% | 促梢老熟 |
