# 荔枝果汁饮料加工技术

## 摘要

荔枝果汁饮料是以荔枝果汁为主要原料，经调配、杀菌、灌装制成的饮料产品，包括荔枝汁饮料、荔枝果肉饮料、荔枝低糖果汁饮料等多种品类。本文系统介绍荔枝果汁饮料的加工工艺、配方设计、杀菌灌装技术及质量控制标准。

## 1. 引言

荔枝果汁饮料是荔枝加工领域增长最快的产品品类之一，市场接受度高，消费群体广泛。产品按果汁含量可分为果汁饮料（≥25%）、果汁果肉饮料（≥20%）和风味饮料（≥10%）等类型。

## 2. 原料与配方

### 2.1 主要原料

| 原料 | 要求 | 备注 |
|------|------|------|
| 荔枝浓缩汁 | 可溶性固形物 35°~45°Brix | 还原后使用 |
| 荔枝果肉 | 速冻或新鲜，直径 3~5 mm | 果肉饮料 |
| 白砂糖/赤藓糖醇 | 食品级 | 甜味剂 |
| 柠檬酸 | 食品级 | 酸味剂 |
| 水 | 符合 GB 5749 | 基料 |
| 果胶/CMC | 增稠稳定剂 | 0.1%~0.3% |

## 3. 加工工艺

### 3.1 荔枝汁饮料流程

水预处理 → 荔枝浓缩汁还原 → 加糖溶解 → 加酸调酸 → 加增稠剂 → 脱气 → 杀菌 → 灌装 → 封口 → 杀菌 → 冷却 → 检验

### 3.2 荔枝果肉饮料流程

水预处理 → 荔枝浓缩汁还原 → 加糖溶解 → 加酸调酸 → 加增稠剂 → 加果肉 → 脱气 → 灌装 → 封口 → 杀菌 → 冷却

### 3.3 各工序参数

| 步骤 | 操作 | 参数 | 目的 |
|------|------|------|------|
| 还原 | 浓缩汁+水 | 至 25%~30% 果汁含量 | 制备果汁 |
| 溶解 | 加糖+搅拌 | 70~80°C 搅拌 30 min | 糖完全溶解 |
| 调酸 | 加柠檬酸 | 调至 pH 3.2~3.8 | 风味平衡 |
| 增稠 | 果胶/CMC 水合 | 60~70°C 充分水合 | 稳定体系 |
| 脱气 | 真空脱气 | 50~70 kPa | 去除氧气 |
| 灌装 | 热灌装 | 80~85°C | 减少微生物 |

## 4. 杀菌与灌装

### 4.1 杀菌方式

| 杀菌方式 | 温度（°C） | 时间 | 适用产品 |
|---------|----------|------|---------|
| UHT 杀菌 | 135~145 | 2~5 s | 无菌灌装 |
| 高温短时 | 100~110 | 15~30 s | PET 瓶灌装 |
| 巴氏杀菌 | 85~90 | 30~60 s | 玻璃瓶 |
| 超高压 | 常温 | 200~400 MPa | NFC 饮料 |
| 膜过滤+冷灌装 | 常温 | 0.45 μm 过滤 | 低温饮料 |

### 4.2 灌装工艺

| 项目 | 热灌装 | 冷灌装 |
|------|-------|-------|
| 灌装温度 | 80~85°C | 5~10°C |
| 杀菌方式 | 灌装后杀菌 | 膜过滤/超高压 |
| 容器 | PET/玻璃瓶 | PET/易拉罐 |
| 保质期 | 12~18 个月（常温） | 6~9 个月（冷藏） |
| 营养保留 | 一般 | 优 |

## 5. 果肉饮料特殊要求

### 5.1 果肉处理

| 项目 | 要求 |
|------|------|
| 果肉规格 | 直径 3~5 mm，大小均匀 |
| 预处理 | 0.05% 抗坏血酸浸泡 |
| 杀菌 | 巴氏杀菌 80°C/30 s |
| 添加量 | ≥10%（以产品总量计） |
| 分散均匀性 | 充分搅拌，不分层 |

### 5.2 稳定剂使用

| 稳定剂 | 用量 | 作用 |
|-------|------|------|
| 果胶（LM 型） | 0.1%~0.2% | 悬浮果肉 |
| CMC（羧甲基纤维素钠） | 0.1%~0.2% | 增稠 |
| 琼脂 | 0.05%~0.1% | 凝胶 |
| 复合稳定剂 | 0.15%~0.3% | 综合效果 |

## 6. 质量控制

### 6.1 理化指标

| 指标 | 荔枝汁饮料 | 荔枝果肉饮料 |
|------|----------|-----------|
| 可溶性固形物（°Brix） | 10~14 | 11~14 |
| 果汁含量（%） | ≥25 | ≥20 |
| 果肉含量（%） | - | ≥10 |
| 可滴定酸（%） | 0.3~0.6 | 0.3~0.6 |
| pH | 3.2~3.8 | 3.2~3.8 |

### 6.2 微生物指标

| 指标 | 要求 |
|------|------|
| 菌落总数 | ≤100 CFU/mL |
| 大肠菌群 | ≤3 MPN/100 mL |
| 霉菌酵母 | ≤10 CFU/mL |
| 致病菌 | 不得检出 |

### 6.3 感官指标

| 指标 | 要求 |
|------|------|
| 色泽 | 红褐至琥珀色，有光泽 |
| 香气 | 荔枝果香浓郁 |
| 滋味 | 酸甜适口 |
| 组织状态 | 均匀，果肉饮料果肉分散均匀 |

## 7. 包装规格

| 包装形式 | 规格 | 材质 | 保质期 |
|---------|------|------|-------|
| 瓶装 | 330 mL、500 mL、1 L | PET | 12~18 个月 |
| 罐装 | 250 mL、330 mL | 易拉罐 | 18~24 个月 |
| 利乐包 | 250 mL、1 L | 复合纸包 | 6~12 个月 |

## 8. 结论

荔枝果汁饮料加工的关键在于果汁还原、配方调配和杀菌灌装。热灌装工艺适合大规模生产和常温销售，膜过滤冷灌装适合高端 NFC 产品。
