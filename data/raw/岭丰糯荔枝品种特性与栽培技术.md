# 岭丰糯荔枝品种特性与栽培技术

## 摘要

岭丰糯（Litchi chinensis Sonn. cv. 'Lingfengnuo'）是广东省东莞市选育的优质荔枝新品种，以其果肉软糯香甜、焦核率高、丰产稳产而著称。本文系统阐述了岭丰糯的品种来源、植物学特征、果实品质特性、物候期规律及配套栽培技术，包括园地选择、土肥水管理、整形修剪、花果调控、病虫害防治等核心技术环节，为岭丰糯的高效栽培和产业化发展提供技术支撑。

## 一、品种来源

岭丰糯荔枝是东莞市农业技术推广中心从当地荔枝实生变异群体中选育出的优良新品种。2005年在东莞大岭山镇发现优良单株，经过连续多年的品比试验和区域适应性试验，于2015年通过广东省农作物品种审定委员会审定，正式定名"岭丰糯"。该品种综合了糯米糍的优良品质和怀枝的丰产特性，在广东珠三角地区表现优异，目前已推广至广西、海南、福建等荔枝产区。

## 二、植物学特性

### 2.1 树体形态特征

树势中等，树冠半圆头形至圆头形，树姿半开张。成年树高4-6米，冠幅5-7米。主干灰褐色，树皮较粗糙。枝条粗壮，分枝角度中等，新梢呈紫红色。叶片为偶数羽状复叶，小叶2-4对，叶片长椭圆形，叶尖渐尖，叶基楔形，叶缘平展或微波浪状。叶片长12-16厘米，宽3-4.5厘米，叶色浓绿，叶面光滑，叶背浅绿色。叶脉网状，侧脉明显。

### 2.2 花器特征

花序为圆锥形聚伞花序，长20-35厘米，着生于一年生结果母枝顶端。雌雄同株异花，雄花占70%-80%，雌花占20%-30%，雌花比例较高。雄花萼片5枚，浅杯状，花瓣退化，雄蕊6-8枚，花药黄色。雌花子房2-3室，柱头二裂。单花序花量400-900朵。花期较集中，单株花期15-20天。

### 2.3 果实品质特征

| 性状 | 描述 |
|------|------|
| 果形 | 近圆形或卵圆形，果肩平，果顶钝圆 |
| 单果重 | 20-28克，平均24-26克 |
| 果皮 | 鲜红色至暗红色，有光泽 |
| 龟裂片 | 中等大，隆起明显，排列较整齐 |
| 缝合线 | 明显，颜色稍淡 |
| 果皮厚度 | 1.0-1.3毫米 |
| 果肉 | 乳白色，半透明，软糯香甜，汁多 |
| 可食率 | 80%-86% |
| 可溶性固形物 | 18%-22% |
| 总糖含量 | 15%-18% |
| 总酸含量 | 0.10%-0.18% |
| 维生素C | 30-50 mg/100g |
| 种子 | 绝大多数退化，焦核率80%以上 |

岭丰糯最突出的品质特点是果肉软糯香甜、焦核率极高，口感接近糯米糍，但丰产性优于糯米糍。

## 三、物候期

岭丰糯在东莞地区的主要物候期：

| 物候期 | 时间（月/旬） |
|--------|-------------|
| 萌芽期 | 2月中旬-3月上旬 |
| 春梢抽生期 | 3月上旬-4月上旬 |
| 现蕾期 | 3月中旬-4月上旬 |
| 开花期 | 4月上旬-4月下旬 |
| 第一次生理落果 | 4月下旬-5月上旬 |
| 第二次生理落果 | 5月中旬-5月下旬 |
| 果实膨大期 | 5月上旬-6月中旬 |
| 果实成熟期 | 6月下旬-7月上旬 |
| 秋梢抽生期 | 7月中旬-9月下旬 |
| 花芽分化期 | 11月-次年1月 |

岭丰糯属于中熟品种，在东莞地区6月下旬至7月上旬成熟，与桂味成熟期相近。

## 四、适应性

### 4.1 气候适应性

岭丰糯喜温暖湿润气候，年均温21-23℃适宜。耐寒性中等，可耐短期-1℃低温。花期适温20-26℃，低于15℃影响坐果，高于30℃花药开裂不良。果实发育期需25-32℃温度和充足日照。年降水量1500-2000mm。对空气湿度要求较高，花期若遇干燥天气需及时喷雾增湿。

### 4.2 土壤适应性

以土层深厚、排水良好、有机质丰富的微酸性土壤为佳，pH5.5-6.5。在红壤、砖红壤上均能较好生长。对土壤钾、钙、硼需求较高，缺硼会导致花而不实，缺钙易引起裂果。

## 五、栽培技术

### 5.1 定植

| 项目 | 技术参数 |
|------|---------|
| 株行距 | 5米×6米或4米×6米 |
| 密度 | 330-420株/公顷 |
| 定植穴 | 0.8m×0.8m×0.8m |
| 基肥 | 有机肥20-30kg/穴+钙镁磷肥1.5kg/穴 |
| 定植时间 | 春植3-4月或秋植9-10月 |
| 套种作物 | 花生、黄豆、蔬菜等 |

### 5.2 土壤管理

**扩穴改土：** 定植后1-3年，每年秋季向外扩穴，深度40-50厘米，结合施入有机肥和石灰。成年园每2-3年深翻一次，深20-30厘米。

**树盘覆盖：** 树盘覆盖厚度10-15厘米的稻草、杂草或地膜，可有效保水、控草、调节土温。

**生草栽培：** 行间自然生草或种植绿肥，如柱花草、印度豇豆等，提高土壤有机质含量。

### 5.3 营养管理

岭丰糯不同树龄推荐施肥量（每株/年）：

| 树龄 | 氮(N)(kg) | 磷(P₂O₅)(kg) | 钾(K₂O)(kg) | 有机肥(kg) |
|------|----------|-------------|-----------|-----------|
| 1-3年 | 0.2-0.4 | 0.15-0.3 | 0.2-0.4 | 10-20 |
| 4-6年 | 0.5-0.8 | 0.3-0.5 | 0.5-0.8 | 25-35 |
| 7年以上 | 0.8-1.2 | 0.5-0.7 | 0.8-1.3 | 35-50 |

**施肥时期与分配比例：**
- 采果肥（7月）：占全年35%，以有机肥+速效氮肥为主
- 秋梢壮梢肥（8-9月）：占全年15%，可结合喷施叶面肥
- 促花肥（1-2月）：占全年20%，以磷钾肥为主，配合硼、锌
- 壮果肥（4月）：占全年30%，以钾肥为主，配合氮肥和钙肥

岭丰糯对钾肥需求量大，壮果期钾肥不足直接影响果实品质和焦核率。

### 5.4 水分管理

| 物候期 | 水分管理要点 |
|--------|-------------|
| 花芽分化期(11-1月) | 控水，土壤含水量55%-65%，促进花芽分化 |
| 开花期(4月) | 保持土壤湿润(70%-80%)，遇旱及时灌水 |
| 果实发育期(4-6月) | 充足供水(75%-85%)，防干旱 |
| 成熟期(6-7月) | 适当控水(60%-70%)，提高糖度 |
| 秋梢期(7-9月) | 及时灌水促梢，保持70%-80%含水量 |

干旱季节采用滴灌或沟灌，每次灌水渗透深度30-40厘米。雨季做好排水工作，防止积水。

### 5.5 整形修剪

**树形培养：** 采用自然圆头形或开心形。定干高50-60厘米，选留3-4个主枝，主枝与主干夹角50-60度。主枝长至30-40厘米时摘心，促进分枝。

**结果树修剪：** 采果后立即修剪，剪除过密枝、交叉枝、病虫枝、下垂枝和弱枝。保留健壮秋梢，结果母枝长度15-25厘米、粗度0.4-0.6厘米。修剪量控制在总枝叶量的15%-20%。

**疏枝原则：** 去密留疏、去弱留强、去直留斜、去内留外。

### 5.6 花果管理

**控梢促花：**
- 秋梢老熟后喷施多效唑300-500倍液
- 11月对生长旺盛树进行环割（环割一圈，深达木质部）
- 控制冬梢，确保花芽分化质量

**保花保果综合措施：**
- 花期放蜂，每公顷15箱
- 盛花期喷施0.1%硼砂+0.2%磷酸二氢钾
- 谢花后7天喷施赤霉素(GA3) 10-15mg/L
- 幼果期喷施0.1%硫酸锌+0.2%尿素
- 生理落果后果实豌豆大时疏果，每穗留15-20个

**提高焦核率技术：**
- 谢花后5-7天喷施GA3 25-30mg/L
- 增施钾肥，控制氮肥用量
- 适当干旱胁迫，促进种子败育

### 5.7 病虫害防治

| 病虫害 | 危害时期 | 防治药剂 | 防治方法 |
|--------|---------|---------|---------|
| 霜疫霉病 | 花期、幼果期 | 烯酰吗啉、甲霜灵·锰锌 | 花前、花后各喷1次 |
| 炭疽病 | 全年 | 咪鲜胺、苯醚甲环唑 | 抽梢期和果实生长期 |
| 蒂蛀虫 | 果实发育期 | 高效氯氟氰菊酯 | 卵孵盛期喷药 |
| 荔枝蝽象 | 花、幼果 | 啶虫脒、高效氯氟氰菊酯 | 越冬期捕杀+若虫期喷药 |
| 红蜘蛛 | 春梢期 | 阿维菌素、哒螨灵 | 孵化高峰期喷药 |
| 卷叶蛾 | 新梢期 | 苏云金杆菌、甲维盐 | 幼虫初孵期防治 |

## 六、采收与采后处理

### 6.1 采收标准

岭丰糯在6月下旬至7月上旬成熟。适采标准：果皮全面转红，果肉饱满有弹性，可溶性固形物达18%以上。采收宜在晴天早晨或傍晚，采用"一果两剪"法，保留果梗1-2厘米。

### 6.2 分级标准

| 等级 | 单果重(g) | 色泽 | 可溶性固形物(%) | 焦核要求 |
|------|----------|------|-----------------|---------|
| 特级 | ≥26 | 鲜红有光泽 | ≥20 | 焦核率≥90% |
| 一级 | 22-26 | 鲜红 | 18-20 | 焦核率≥80% |
| 二级 | 18-22 | 红色 | 16-18 | 焦核率≥60% |

### 6.3 保鲜贮运

采后2小时内预冷至5-8℃，经杀菌处理后包装。采用泡沫箱+冰袋方式，冷藏运输温度3-5℃。岭丰糯耐贮性中等，冷藏条件下保鲜期7-10天。

## 七、产量与效益

岭丰糯定植后第4年始果，第6-7年进入盛产期。盛产期株产30-60公斤，每公顷产量10000-18000公斤。市场售价40-80元/公斤，每公顷产值40-144万元。该品种以其优良品质和丰产性能，经济效益显著高于糯米糍，是荔枝品种升级换代的重要选择。
