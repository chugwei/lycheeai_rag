# 荔枝蛀果飞蛾防治技术

## 摘要

荔枝蛀果飞蛾主要包括荔枝蒂蛀虫（*Conothes* spp.）和荔枝卷叶蛾蛀果型等，幼虫蛀入果实内部取食，造成果实腐烂、脱落，严重影响产量和品质。该害虫是荔枝生产中最难防治的害虫之一，必须在幼虫蛀果前进行有效防控。本文系统介绍蛀果飞蛾的生物学特性和综合防治技术。

## 1. 生物学特性

### 1.1 荔枝蒂蛀虫

| 虫态 | 发育期（天） | 形态特征 |
|-----|-----------|---------|
| 卵 | 3-5 | 椭圆形，白色，单产或群产 |
| 幼虫（1-4 龄） | 20-30 | 蠕虫状，体色乳白至淡黄 |
| 蛹 | 8-12 | 在果内或土中化蛹 |
| 成虫 | 7-10 | 小型飞蛾，翅展 15-25 mm |

### 1.2 蛀果过程

| 阶段 | 时间 | 行为 |
|-----|------|------|
| 产卵 | 果实膨大期 | 成虫将卵产于果皮上 |
| 孵化 | 3-5 天 | 幼虫孵化后钻入果实 |
| 蛀食 | 15-25 天 | 幼虫在果内蛀食果肉 |
| 化蛹 | 果实内或土中 | 完成发育 |
| 羽化 | 8-12 天 | 成虫飞出 |

## 2. 发生规律

| 时期 | 发生程度 | 原因 |
|-----|---------|------|
| 幼果期（4-5 月） | 轻发 | 果实小，不适宜产卵 |
| 膨大期（5-6 月） | 开始发生 | 果实增大，开始产卵 |
| 成熟期（6-7 月） | 重发 | 果实适合作为繁殖场所 |
| 采后果 | 继续发生 | 采后果仍为产卵场所 |

## 3. 防治技术

### 3.1 农业防治

- **及时采收**：成熟果实及时采收，减少在树上的繁殖时间。
- **清除采后果**：及时清除树上的采后果和落果。
- **清理果园**：清除杂草和落叶，减少成虫栖息场所。

### 3.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 备注 |
|-----|------|---------|------|
| 膨大期（产卵前） | 甲维盐 1% | 3000-5000 倍 | 预防性喷施 |
| 卵孵盛期 | 氯虫苯甲酰胺 | 4000-6000 倍 | 杀幼虫 |
| 卵孵盛期 | 高效氯氟氰菊酯 | 2000-3000 倍 | 速效 |
| 蛀果初期 | 溴氰菊酯 | 2000-3000 倍 | 补充防治 |
| 综合防治 | 甲维盐 + 氯虫苯甲酰胺 | 3000-5000 倍 | 复配增效 |

### 3.3 生物防治

| 方法 | 材料 | 效果 |
|-----|------|------|
| 释放天敌 | 寄生蜂（*Agathis* spp.） | 寄生幼虫 |
| 微生物农药 | 苏云金杆菌（Bt） | 杀幼虫 |
| 核型多角体病毒 | NPV | 特异性杀幼虫 |

### 3.4 物理防治

- **灯光诱杀**：黑光灯诱杀成虫。
- **性信息素诱杀**：性诱剂诱杀雄蛾。

### 3.5 关键防治节点

| 节点 | 措施 |
|-----|------|
| 果实膨大初期 | 甲维盐预防性喷施 |
| 产卵盛期 | 性诱剂诱杀 + 灯光诱杀 |
| 卵孵盛期 | 氯虫苯甲酰胺 + 甲维盐 |
| 蛀果初期 | 高效氯氟氰菊酯应急 |
