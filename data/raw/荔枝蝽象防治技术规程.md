# 荔枝蝽象防治技术规程

> 本规程规定了荔枝蝽象（俗称臭屁虫）的形态识别、发生规律、监测方法和综合防治技术，适用于荔枝产区荔枝蝽象的防治管理。

---

## 一、害虫概述

荔枝蝽象（*Tessaratoma papillosa* Drury）属半翅目蝽科，是荔枝和龙眼的重要害虫。成虫和若虫均以刺吸式口器吸食荔枝嫩梢、花穗和幼果的汁液，造成落花落果，影响产量和品质。该虫在华南荔枝产区普遍发生，是荔枝生产中最主要的害虫之一。

---

## 二、形态特征

### 2.1 各虫态特征
| 虫态 | 形态特征 | 体长 | 识别要点 |
|------|---------|------|---------|
| 成虫 | 体盾形，黄褐色至褐色，腹面有白色蜡粉 | 雄20-25mm，雌22-27mm | 体型大，盾形，受惊时喷射臭液 |
| 卵 | 椭圆形，淡绿色至淡黄色，14粒排列成块 | 直径约2.5mm | 卵块14粒，排列整齐 |
| 1龄若虫 | 体椭圆形，鲜红色至橙红色 | 约5mm | 群集，不取食 |
| 2龄若虫 | 体橙红色，出现翅芽 | 约8mm | 开始分散取食 |
| 3龄若虫 | 体黄褐色，翅芽明显 | 约12mm | 活动能力增强 |
| 4龄若虫 | 体黄褐色，翅芽达第2腹节 | 约16mm | 取食量大增 |
| 5龄若虫 | 体黄褐色，翅芽达第4腹节 | 约20mm | 即将羽化 |

### 2.2 与近似种的区别
| 种类 | 体型 | 体色 | 主要寄主 |
|------|------|------|---------|
| 荔枝蝽象 | 大(20-27mm) | 黄褐色 | 荔枝、龙眼 |
| 稻绿蝽 | 中(12-16mm) | 绿色 | 水稻、豆类 |
| 麻皮蝽 | 中(18-22mm) | 灰褐色 | 多种果树 |
| 角肩蝽 | 中(15-18mm) | 绿色带黄 | 柑橘 |

## 三、发生规律

### 3.1 生活史
| 世代参数 | 数据 |
|---------|------|
| 年发生代数 | 华南地区1代/年 |
| 越冬虫态 | 成虫 |
| 越冬场所 | 树冠、屋檐、石缝、杂草 |
| 越冬期 | 11月-翌年2月 |
| 出蛰期 | 2月下旬-3月上旬 |
| 产卵期 | 3月中旬-5月 |
| 若虫期 | 4-7月 |
| 新成虫出现 | 6-7月 |
| 寿命 | 成虫可达12个月 |

### 3.2 生物学特性
| 特性 | 描述 |
|------|------|
| 取食习性 | 刺吸嫩梢、花穗、幼果汁液 |
| 产卵习性 | 卵产于叶背，每卵块14粒，排列整齐 |
| 雌虫产卵量 | 每雌可产卵5-10块，共70-140粒 |
| 臭腺 | 成虫胸部和若虫腹部有臭腺，受惊时喷射臭液 |
| 趋性 | 趋光性弱，早晨和傍晚活动最盛 |
| 天敌 | 平腹小蜂(卵寄生)、鸟类、螳螂 |

### 3.3 发生与环境关系
| 环境因素 | 影响 |
|---------|------|
| 温度 | 20-28°C最适宜，>35°C或<10°C活动减少 |
| 湿度 | 干旱年份发生较重 |
| 品种 | 妃子笑、黑叶受害较轻，桂味、糯米糍受害较重 |
| 树势 | 树势旺盛的果园发生轻 |
| 天敌 | 平腹小蜂寄生率高时发生轻 |

## 四、监测方法

### 4.1 调查方法
| 调查项目 | 调查方法 | 频次 | 调查时期 |
|---------|---------|------|---------|
| 越冬成虫量 | 清晨震动树枝计数 | 每月1次 | 12-2月 |
| 产卵量 | 调查叶背卵块数 | 每周1次 | 3-5月 |
| 卵寄生率 | 采集卵块室内观察 | 每周1次 | 3-5月 |
| 若虫密度 | 五点取样，每点2株 | 每周1次 | 4-6月 |
| 新成虫量 | 清晨震动树枝计数 | 每月1次 | 6-8月 |

### 4.2 防治指标
| 时期 | 指标 |
|------|------|
| 越冬期(12-2月) | 每株≥2头成虫时需防治 |
| 产卵期(3-5月) | 卵寄生率<50%时需防治 |
| 若虫期(4-6月) | 每株≥5头若虫时需防治 |
| 花穗期 | 每株≥3头成虫/若虫时需防治 |
| 幼果期 | 每株≥8头若虫时需防治 |

## 五、综合防治技术

### 5.1 农业防治
| 防治措施 | 技术要求 | 实施时间 |
|---------|---------|---------|
| 冬季清园 | 清除园内杂草、落叶，破坏越冬场所 | 12-1月 |
| 人工捕杀 | 清晨震动树枝，捕杀落地成虫 | 越冬期、春季 |
| 摘除卵块 | 发现卵块及时摘除 | 3-5月 |
| 合理修剪 | 改善通风透光，减少藏匿空间 | 采果后 |

### 5.2 生物防治
| 天敌 | 防治对象 | 保护/利用方法 | 效果 |
|------|---------|-------------|------|
| 平腹小蜂(*Anastatus* sp.) | 卵 | 人工释放，每代每亩释放2000-3000头 | 卵寄生率可达70-90% |
| 螳螂 | 若虫、成虫 | 保护天敌，减少化学农药 | 中等 |
| 鸟类 | 成虫 | 果园周围植树引鸟 | 辅助性 |
| 白僵菌 | 若虫、成虫 | 高湿条件下喷施 | 60-70% |

#### 平腹小蜂释放技术
| 释放时期 | 释放量 | 释放方法 | 注意事项 |
|---------|-------|---------|---------|
| 产卵初期(3月中旬) | 1000头/亩 | 将卵卡挂于树冠 | 释放前3天停用杀虫剂 |
| 产卵盛期(4月上旬) | 2000头/亩 | 分点释放于园中 | 阴天或傍晚释放 |
| 产卵后期(4月下旬) | 1000头/亩 | 补充释放 | 避开雨天 |

### 5.3 化学防治
#### 若虫期防治（最佳防治时期）
| 药剂名称 | 浓度 | 施药时期 | 安全间隔期(天) |
|---------|------|---------|--------------|
| 敌百虫 | 90%SP 800倍液 | 若虫3龄前 | 7 |
| 溴氰菊酯 | 2.5%EC 3000倍液 | 若虫期 | 7 |
| 高效氯氟氰菊酯 | 2.5%EC 3000倍液 | 若虫期 | 7 |
| 高效氯氰菊酯 | 4.5%EC 2000倍液 | 若虫期 | 7 |
| 啶虫脒 | 5%EC 1500倍液 | 若虫期 | 7 |

#### 成虫期防治
| 药剂名称 | 浓度 | 施药时期 | 安全间隔期(天) |
|---------|------|---------|--------------|
| 敌百虫 | 90%SP 800倍液 | 越冬成虫出蛰期 | 7 |
| 溴氰菊酯 | 2.5%EC 3000倍液 | 成虫活动期 | 7 |
| 杀螟丹 | 50%SP 1000倍液 | 成虫期 | 14 |

#### 注意：花期施药
| 注意事项 | 要求 |
|---------|------|
| 花期严禁 | 使用高毒农药和菊酯类农药 |
| 花期推荐 | 尽量避免施药，如需施药选择低毒品种 |
| 对蜜蜂影响 | 菊酯类农药对蜜蜂高毒，花期禁用 |
| 替代方案 | 花期以生物防治为主 |

## 六、药剂轮换方案

| 轮次 | 药剂 | 防治阶段 |
|------|------|---------|
| 第1次 | 敌百虫90%SP 800倍液 | 越冬成虫出蛰期 |
| 第2次 | 平腹小蜂释放 | 产卵期 |
| 第3次 | 高效氯氟氰菊酯2.5%EC 3000倍液 | 若虫3龄前 |
| 第4次 | 啶虫脒5%EC 1500倍液 | 若虫盛期 |

## 七、防治效果评价

### 7.1 效果指标
| 指标 | 计算方法 | 优秀标准 |
|------|---------|---------|
| 虫口减退率 | (防治前虫量-防治后虫量)/防治前虫量×100% | ≥90% |
| 卵寄生率 | 被寄生卵粒数/总卵粒数×100% | ≥80%(天敌防治) |
| 花穗受害率 | 受害花穗数/调查花穗数×100% | <5% |
| 果实受害率 | 受害果数/调查果数×100% | <3% |
