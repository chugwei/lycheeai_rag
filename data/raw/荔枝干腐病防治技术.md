# 荔枝干腐病防治技术

## 摘要

荔枝干腐病是由多种真菌（包括炭疽菌、干腐菌 *Lasiodiplodia theobromae* 及核果腔尾孢菌等）引起的果实和枝条病害，以果实腐烂后干枯、枝条干枯为主要特征。该病在果实成熟后期至贮藏期危害严重，可导致果实失水干枯、失去商品价值。本文系统介绍荔枝干腐病的病原、发病规律、诊断和防治技术。

## 1. 病原生物学

荔枝干腐病的主要病原包括：

| 病原菌 | 学名 | 主要危害 |
|-------|------|---------|
| 干腐菌 | *Lasiodiplodia theobromae* | 果实腐烂干枯、枝条枯死 |
| 炭疽菌 | *Colletotrichum gloeosporioides* | 果皮腐烂后干瘪 |
| 核果腔尾孢菌 | *Glomerella cingulata* | 果皮褐变后干腐 |
| 镰刀菌 | *Fusarium* spp. | 果实软腐后继发干腐 |

干腐菌（*L. theobromae*）是该病最重要的病原。菌丝淡褐色，在寄主体内形成拟菌核。分生孢子器黑色球形，分生孢子卵形，单胞，无色，8-12 μm × 3-4 μm。

## 2. 发病规律

病菌以菌丝体和拟菌核在病果、枯枝及树体伤口处越冬。春季高温高湿时释放孢子，通过风雨传播。果实成熟期组织软化、糖度升高，最易感病。

### 2.1 症状发展过程

| 阶段 | 症状 | 时间 |
|-----|------|------|
| 侵染期 | 果皮出现褐色小斑点 | 成熟期 |
| 扩展期 | 斑点扩大，果皮失水凹陷 | 3-5 天 |
| 腐烂期 | 果肉软腐，有发酵气味 | 5-7 天 |
| 干枯期 | 果实失水干枯，呈褐色干果 | 7-14 天 |

### 2.2 发病与采收后关系

| 采收后处理 | 干腐发病率 | 说明 |
|-----------|-----------|------|
| 常温堆放 | >40% | 高温高湿促进病菌繁殖 |
| 24 h 内预冷 | 15-20% | 及时降温抑制病菌 |
| 预冷 + 杀菌处理 | 5-10% | 综合效果最佳 |
| 套袋 + 预冷 | 3-8% | 机械伤减少 + 杀菌 |

## 3. 诊断技术

### 3.1 症状识别

- 果实成熟期出现褐色凹陷斑点，斑点中央逐渐干瘪凹陷。
- 病斑扩展后，果皮失水呈褐色或黑褐色，触感变软后转硬。
- 后期果实完全干枯，挂在树上呈褐色干果状。
- 枝条受害后枯死，枯死部与健康部界限明显，有时可见黑色小粒（分生孢子器）。

### 3.2 干腐菌镜检特征

| 结构 | 特征描述 |
|-----|---------|
| 孢子器 | 黑色，球形，100-200 μm |
| 分生孢子 | 卵形，单胞，无色，8-12 μm |
| 拟菌核 | 褐色，在寄主组织内形成 |
| 菌丝 | 淡褐色，多隔 |

## 4. 防治技术

### 4.1 栽培管理

- **减少伤口**：修剪、采收时减少机械损伤。
- **清园**：清除病果、枯枝，减少初侵染源。
- **控水**：采收前适度控水，降低果实含水量。
- **合理密植**：保证通风透光，降低树冠湿度。
- **增施钾肥**：提高果实品质和抗病能力。

### 4.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 用途 |
|-----|------|---------|------|
| 萌芽前 | 石硫合剂 | 3-5 波美度 | 清园 |
| 果实膨大期 | 苯醚甲环唑 | 2000-3000 倍 | 保护 |
| 转色期 | 咪鲜胺 70% | 1500-2000 倍 | 保护 |
| 采收前 | 嘧霉胺 | 1500-2000 倍 | 安全期用药 |
| 采后处理 | 咪鲜胺浸果 | 500 mg/L | 杀菌防腐 |

### 4.3 采后防控

- 采收后 2 h 内完成预冷处理（0-2 ℃）。
- 使用杀菌剂浸果处理 1-2 min。
- 贮藏条件：0-2 ℃，相对湿度 85-90%。
- 运输过程避免挤压和机械损伤。

### 4.4 综合防控技术路线

```
清园 → 膨大期保护 → 转色期重点保护 → 安全采收 → 预冷杀菌 → 低温贮藏
```
