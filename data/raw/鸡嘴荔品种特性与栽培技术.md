# 鸡嘴荔荔枝品种特性与栽培技术

## 摘要

鸡嘴荔（Litchi chinensis Sonn. cv. 'Jizuili'）是广西壮族自治区的主栽荔枝品种之一，因果实核小如鸡嘴而得名，具有肉质爽脆、清甜微香、丰产稳产等特点。本文全面介绍了鸡嘴荔的品种来源、植物学特征、果实品质、物候期等品种特性，并从育苗定植、土肥水管理、整形修剪、花果调控及病虫害防治等方面系统总结了其配套栽培技术，为鸡嘴荔的高效栽培和产业发展提供技术指导。

## 一、品种来源与分布

鸡嘴荔原产于广西壮族自治区钦州市灵山县，是当地荔枝实生变异选育的优良品种，栽培历史超过100年。20世纪80年代后通过系统选种和无性繁殖逐步推广，现已成为广西荔枝的主栽品种之一。主要分布在广西灵山、浦北、钦北、合浦、北流等县市，在广东、海南、云南等地也有引种栽培。目前全国栽培面积约1.5万公顷，年产量约12万吨。

## 二、植物学特性

### 2.1 树体特征

树势强健，树冠高大开张，呈自然半圆头形。成年树高可达5-8米，冠幅6-10米。主干灰褐色，表面粗糙纵裂。枝条粗壮而柔软，分枝角度大，枝条自然下垂。叶片为偶数羽状复叶，小叶2-4对，长椭圆形，叶尖渐尖，叶基楔形。叶片长10-18厘米，宽3.5-5.5厘米，叶色浓绿，叶面光滑，叶背灰绿色。叶脉网状，侧脉每边10-14条。

### 2.2 花器特征

花序为圆锥形聚伞花序，长20-35厘米，着生于一年生枝梢顶端。花型雌雄同株异花，雄花占70%-85%，雌花占15%-30%。雄花萼片4-5枚，花瓣缺失或极小，雄蕊6-8枚，花药黄色。雌花子房2-3室，花柱短，柱头二裂。单花序花量300-1000朵。雌花比例较高是鸡嘴荔丰产的基础。

### 2.3 果实特征

| 性状 | 描述 |
|------|------|
| 果形 | 近圆形，果肩宽，果顶钝圆 |
| 单果重 | 22-35克，平均28克 |
| 果皮 | 鲜红色至暗红色，成熟时有光泽 |
| 果皮厚度 | 1.0-1.3毫米，较厚韧 |
| 龟裂片 | 中等大，隆起明显，排列较整齐 |
| 缝合线 | 明显，色稍淡 |
| 果肉 | 乳白色，半透明，爽脆，清甜微香 |
| 可食率 | 78%-85% |
| 可溶性固形物 | 17%-21% |
| 总糖含量 | 14%-17% |
| 总酸含量 | 0.12%-0.22% |
| 维生素C | 25-45 mg/100g |
| 种子 | 显著退化，呈鸡嘴状，焦核率85%以上 |
| 种子重 | 0.2-0.5克 |

鸡嘴荔最突出的特征是种子极小，呈扁平鸡嘴状，焦核率极高，是该品种最受市场欢迎的品质特点。

## 三、物候期

鸡嘴荔在广西灵山地区的主要物候期：

| 物候期 | 时间（月/旬） |
|--------|-------------|
| 萌动期 | 2月上旬-2月下旬 |
| 春梢抽生期 | 2月下旬-4月上旬 |
| 花序原基分化 | 12月-次年1月 |
| 现蕾期 | 3月上旬-3月下旬 |
| 开花期 | 3月下旬-4月下旬 |
| 第一次生理落果 | 4月下旬-5月上旬 |
| 第二次生理落果 | 5月中旬-5月下旬 |
| 果实膨大期 | 5月上旬-6月中旬 |
| 果实成熟期 | 6月中旬-7月上旬 |
| 秋梢抽生期 | 7月中旬-9月中旬 |
| 花芽分化生理期 | 10月-11月 |

鸡嘴荔在广西南部地区成熟期比妃子笑晚5-7天，比桂味早3-5天，属于中熟品种。

## 四、环境适应性

### 4.1 气候适应性

鸡嘴荔对气候适应性强，表现突出的丰产稳产性状。年均温21-23℃适宜，能耐短期-2℃低温。花期温度以20-26℃为宜，低于15℃或高于30℃影响坐果。果实发育期需25-32℃和充足日照。年降雨量1300-1800mm均可正常生长。耐旱性较强，但不耐涝。果实成熟期遇持续高温干旱易出现日灼。

### 4.2 土壤适应性

对土壤要求不严格，但以土层深厚、有机质丰富、微酸性至中性（pH5.5-7.0）的沙质壤土或粘质壤土为佳。在红壤、砖红壤性土上均能正常生长结果。但仍以排水良好、地下水位低的土地为优。鸡嘴荔对镁、锌等微量元素需求较高。

## 五、栽培技术

### 5.1 育苗与定植

**嫁接育苗：** 砧木选用怀枝或山荔种子繁殖的实生苗，砧木粗度0.8-1.2厘米时进行切接或合接。春季2-3月嫁接成活率最高，达85%以上。

**定植技术：** 种植密度根据土壤肥力而定，中等肥力园地推荐株行距5米×6米（每公顷330株）；肥沃园地6米×7米（每公顷240株）。定植前1-2个月挖穴，规格0.8立方米，每穴施腐熟有机肥25-30公斤、钙镁磷肥1.5-2公斤。定植时注意嫁接口露出地面5-10厘米，踩实后浇足定根水。

### 5.2 土壤管理

**深翻扩穴：** 定植后1-3年内逐年向外深翻扩穴，深度40-50厘米，结合施有机肥改良土壤。成年园每2-3年深翻一次，深度20-30厘米。

**覆盖保墒：** 树盘覆盖稻草、甘蔗渣或地膜，厚度10-15厘米，可保湿、控草、调节地温。

**间作套种：** 幼龄园可间作花生、黄豆、西瓜、蔬菜等矮秆作物，增加前期收益，改善土壤生态。

### 5.3 营养管理

鸡嘴荔不同树龄推荐施肥量（每株/年）：

| 树龄 | 尿素(kg) | 过磷酸钙(kg) | 氯化钾(kg) | 有机肥(kg) |
|------|---------|-------------|-----------|-----------|
| 1-2年 | 0.2-0.3 | 0.2-0.3 | 0.15-0.25 | 10-15 |
| 3-4年 | 0.4-0.6 | 0.4-0.5 | 0.3-0.5 | 20-30 |
| 5-6年 | 0.7-0.9 | 0.6-0.7 | 0.6-0.8 | 30-40 |
| 7年以上 | 1.0-1.3 | 0.7-0.9 | 0.9-1.3 | 40-50 |

**施肥时期与分配：**
- 采果肥（6-7月）：占全年30%-35%，以速效氮肥为主，配合有机肥
- 秋梢肥（8月）：占全年15%-20%，促进秋梢充实
- 促花肥（1-2月）：占全年20%-25%，以磷钾肥为主
- 壮果肥（4月）：占全年20%-25%，氮钾配合，补充钙镁

### 5.4 水分管理

| 生育期 | 需水特点 | 管理措施 |
|--------|---------|---------|
| 花芽分化期 | 适当干旱有利分化 | 控水，土壤含水量60%左右 |
| 现蕾开花期 | 需水适中 | 保持湿润，防干旱和积水 |
| 幼果发育期 | 需水量大 | 及时灌溉，每5-7天灌一次 |
| 果实膨大期 | 需水量最大 | 灌水频率加大，保持土壤湿润 |
| 成熟期 | 减少水分 | 适当控水，提高糖度 |
| 秋梢生长期 | 需水量中等 | 灌水促梢，保持70%-80%含水量 |

### 5.5 整形修剪

**幼树整形：** 采用自然开心形或圆头形。定干高度50-70厘米，选留3-4个分布均匀的枝条作主枝，主枝与主干夹角45-60度。主枝长至30-40厘米时摘心，促发侧枝。

**结果树修剪：** 采果后及时修剪，剪除病虫枝、过密枝、交叉枝、下垂枝和徒长枝。保留健壮秋梢作为翌年结果母枝，结果母枝长度以12-20厘米为宜。修剪强度以剪除枝叶量的15%-20%为宜。

**老树更新：** 对衰老树进行重回缩修剪，保留主干和3-4个主枝骨架，促发新梢重新培养树冠。

### 5.6 花果管理

**控梢促花：** 10-11月对生长旺盛树喷施多效唑（15%可湿性粉剂300-500倍）+ 磷酸二氢钾500倍液，抑制冬梢，促进花芽分化。必要时可配合环割、弯枝等物理措施。

**保花保果：**
- 花期放蜂，每公顷15箱
- 花期遇干旱及时灌水
- 花期喷施0.1%硼酸+0.3%尿素+0.2%磷酸二氢钾
- 谢花后喷施碧护（芸苔素内酯）0.01-0.02mg/L
- 第二次生理落果后定果，每穗留15-25个果

**提高焦核率措施：**
- 谢花后7-10天喷施赤霉素(GA3) 20-30mg/L
- 增施钾肥和硼肥
- 避免氮肥过量
- 保持树体适度水分胁迫

### 5.7 病虫害防治

| 病虫害 | 主要症状 | 防治要点 |
|--------|---------|---------|
| 霜疫霉病 | 花穗、果实褐色腐烂 | 花前、花后各喷药一次，选用烯酰吗啉 |
| 炭疽病 | 叶斑、果斑、枝枯 | 抽梢期喷咪鲜胺，15天一次 |
| 蒂蛀虫 | 果蒂蛀食，果内虫粪 | 卵孵盛期喷高效氯氟氰菊酯 |
| 荔枝蝽象 | 吸食汁液，果面斑痕 | 越冬成虫期捕杀，若虫期喷药 |
| 红蜘蛛 | 叶片褪绿黄化 | 春梢期喷阿维菌素或哒螨灵 |
| 蛀蒂虫 | 果蒂部黑腐 | 采果前15-20天喷药保护 |

## 六、采收与采后处理

### 6.1 适期采收

果实成熟期从6月中旬开始，集中采收期为6月下旬至7月上旬。采收标准：果皮转为鲜红色，缝合线颜色变浅，可溶性固形物达17%以上。采收应选择晴天早晨露干后进行，采用"一果两剪"法：第一剪从果穗基部剪下，第二剪保留1-2厘米果梗。

### 6.2 采后处理流程

采收→挑选分级→预冷（快速降温至5-8℃）→保鲜处理（二氧化氯或咪鲜胺浸泡）→包装（泡沫箱+冰袋）→冷藏运输（3-5℃）。鸡嘴荔耐贮性较好，冷藏条件下保鲜期可达10-15天。

## 七、产量潜力

鸡嘴荔丰产性能好，定植后第4年开始挂果，第6-7年进入盛产期。盛产期株产40-80公斤，每公顷产量12000-20000公斤。大小年结果现象较轻微，表现出良好的丰产稳产性。按市场价20-40元/公斤计算，每公顷年产值24-80万元。

## 八、发展建议

1. 优化区域布局，选择适宜气候区集中发展
2. 推广标准化生产技术，提高果品一致性
3. 加强品种提纯复壮，保持焦核优势特性
4. 发展冷链物流，延长市场供应期
5. 打造区域品牌，提升市场竞争力和附加值
