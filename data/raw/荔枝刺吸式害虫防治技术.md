# 荔枝刺吸式害虫防治技术

## 摘要

荔枝刺吸式害虫主要包括介壳虫、粉虱、蚜虫、蓟马、蝽象、瘿螨等，以刺吸口器吸取植物汁液，导致叶片黄化、卷曲、脱落，分泌蜜露诱发煤烟病，是荔枝生产中最普遍的害虫类群。本文系统介绍刺吸式害虫的分类、识别特征和综合防治技术。

## 1. 刺吸式害虫分类

### 1.1 主要类群

| 类群 | 代表种类 | 主要危害 |
|-----|---------|---------|
| 介壳虫 | 荔枝蝽象、红蜡蚧、粉蚧 | 吸食汁液，蜜露诱发煤烟病 |
| 粉虱 | 黄绿粉虱、荔粉虱 | 吸食汁液，分泌蜜露 |
| 蚜虫 | 荔枝二叉蚜、桃蚜 | 吸食嫩梢汁液，传播病毒 |
| 蓟马 | 烟蓟马、棕榈蓟马 | 锉吸汁液，造成银白色斑 |
| 蝽象 | 荔蝽、点蜂缘蝽 | 刺吸果实，造成凹陷斑 |
| 瘿螨 | 荔枝瘿螨 | 刺吸嫩梢，导致卷曲畸形 |

### 1.2 识别特征

| 害虫 | 体色 | 形态 | 发生部位 |
|-----|------|------|---------|
| 介壳虫 | 褐色/白色 | 椭圆形，固定不动 | 枝条、叶柄 |
| 粉虱 | 白色 | 小型，翅膀有蜡粉 | 叶背 |
| 蚜虫 | 黄绿色/黑色 | 小型，体软 | 嫩梢、叶背 |
| 蓟马 | 黑色/黄色 | 细长，飞行迅速 | 嫩梢、花穗 |
| 蝽象 | 褐色/绿色 | 中型，有臭腺 | 果实、嫩梢 |
| 瘿螨 | 微小型 | 蠕虫状，体背有刚毛 | 嫩梢 |

## 2. 综合防治技术

### 2.1 农业防治

- 合理修剪，改善通风透光。
- 清除杂草和落叶，减少越冬场所。
- 平衡施肥，增强树势。
- 控梢放梢，统一嫩梢生长期。

### 2.2 化学防治

| 害虫 | 药剂 | 稀释倍数 | 备注 |
|-----|------|---------|------|
| 介壳虫 | 噻嗪酮 25% | 1500-2000 倍 | 杀虫卵和若虫 |
| 介壳虫 | 毒死蜱 48% | 1000-1500 倍 | 杀成虫 |
| 粉虱 | 螺虫乙酯 22.2% | 6000-8000 倍 | 内吸性 |
| 粉虱 | 吡虫啉 10% | 2000-3000 倍 | 触杀 + 内吸 |
| 蚜虫 | 啶虫脒 20% | 2000-3000 倍 | 触杀 |
| 蚜虫 | 烯啶虫胺 10% | 3000-4000 倍 | 长残效 |
| 蓟马 | 乙基多杀菌素 | 3000-4000 倍 | 专用 |
| 蓟马 | 啶虫·噻虫嗪 | 2000-3000 倍 | 复配 |
| 蝽象 | 溴氰菊酯 | 2000-3000 倍 | 速效 |
| 瘿螨 | 阿维菌素 1.8% | 3000-5000 倍 | 杀螨 |

### 2.3 生物防治

| 天敌 | 防治对象 |
|-----|---------|
| 瓢虫 | 蚜虫、粉虱 |
| 草蛉 | 蚜虫、粉虱、介壳虫 |
| 丽蚜小蜂 | 粉虱 |
| 蚜小蜂 | 蚜虫 |
| 捕食螨 | 瘿螨 |

### 2.4 物理防治

- 黄板诱杀：诱杀粉虱、蚜虫、蓟马成虫。
- 灯光诱杀：诱杀蝽象成虫。
