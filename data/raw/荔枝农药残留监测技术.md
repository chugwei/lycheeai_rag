# 荔枝农药残留监测技术

## 摘要

荔枝农药残留监测是保障荔枝产品质量安全的重要手段，通过对荔枝产品中农药残留进行检测和风险评估，为农产品安全监管提供技术支撑。本指南系统阐述了荔枝农药残留监测的标准体系、检测方法、样品采集和数据分析技术，为荔枝生产者和监管部门提供农药残留监测技术指导。

## 1. 引言

农药残留是指使用农药后残存于农产品及其环境中的农药原体、代谢物、反应产物及杂质的总称。荔枝在生长过程中常使用多种杀虫剂和杀菌剂防治病虫害，如不严格管理，可能导致农药残留超标。我国已建立农产品质量安全例行监测制度，荔枝作为大宗水果，农药残留监测覆盖率逐年提高。规范监测技术，提高监测能力，对保障荔枝食品安全具有重要意义。

## 3. 监测方法

### 3.1 样品采集

| 环节 | 要求 | 方法 |
|------|------|------|
| 采样时间 | 成熟期至采收期 | 按计划采样 |
| 采样点数 | 每批次不少于5点 | 五点采样 |
| 采样量 | 每样不少于500g | 代表性样品 |
| 样品处理 | 去核、取果肉 | 标准处理 |
| 样品保存 | 4℃冷藏 | 48h内检测 |

### 3.2 样品前处理

| 方法 | 步骤 | 适用对象 |
|------|------|----------|
| QuEChERS法 | 称样→加缓冲液→混匀→离心→净化 | 有机磷、菊酯类 |
| 超声萃取 | 称样→加溶剂→超声→离心→净化 | 多种农药 |
| 均质萃取 | 称样→加溶剂→均质→离心→净化 | 常规检测 |

**QuEChERS前处理标准流程**：

| 步骤 | 操作 | 参数 |
|------|------|------|
| 称样 | 称取5.0g样品 | 精确至0.01g |
| 加水 | 加2mL水 | - |
| 加缓冲液 | 加6mL MgSO₄/NaCl | - |
| 加提取液 | 加10mL乙腈 | - |
| 涡旋 | 涡旋1分钟 | - |
| 离心 | 5000rpm离心5分钟 | 4℃ |
| 净化 | 加净化剂后离心 | - |
| 上样 | 滤膜过滤后上机 | 0.22μm |

### 3.3 仪器检测方法

| 检测方法 | 适用农药 | 检出限(μg/kg) | 检测时间(min) |
|----------|----------|---------------|---------------|
| GC-MS | 有机磷、菊酯类 | 1-5 | 20-30 |
| LC-MS/MS | 氨基甲酸酯、拟除虫菊酯 | 0.1-1 | 10-15 |
| GC-MS/MS | 有机氯、有机磷 | 0.1-0.5 | 20-30 |
| LC-MS | 有机磷、杀菌剂 | 1-5 | 15-20 |
| ELISA | 特定农药 | 10-50 | 1-2 |

### 3.4 多残留同时检测

| 参数 | 说明 |
|------|------|
| 检测范围 | 同时检测200+种农药 |
| 基质 | 荔枝果肉 |
| 方法 | LC-MS/MS多残留 |
| 前处理 | QuEChERS |
| 定量方式 | 内标法定量 |
| 线性范围 | 0.01-10mg/L |
| 回收率 | 70%-120% |

## 4. 监测方案

### 4.1 例行监测方案

| 指标 | 内容 |
|------|------|
| 监测范围 | 荔枝主产区 |
| 监测时间 | 主要产季(4-8月) |
| 监测品种 | 主要荔枝品种 |
| 监测项目 | 常规农药残留 |
| 监测频次 | 每月1次 |
| 样品数量 | 每县不少于20个 |

### 4.2 监督抽检方案

| 指标 | 内容 |
|------|------|
| 抽检对象 | 市场、超市、网店 |
| 抽检项目 | 重点农药+重金属 |
| 抽检频次 | 不定期 |
| 样品数量 | 按风险确定 |
| 合格判定 | 符合GB 2763 |

## 5. 监测数据分析

### 5.1 合格率计算

合格率 = (合格样品数 / 总样品数) × 100%

### 5.2 风险评估

| 风险等级 | 超标率 | 风险描述 |
|----------|--------|----------|
| 低风险 | <5% | 产品质量总体可控 |
| 中风险 | 5%-15% | 需加强监管 |
| 高风险 | >15% | 需重点整治 |

### 5.3 趋势分析

定期分析农药残留监测数据，识别农药使用趋势和高风险品种，为精准监管提供依据。
