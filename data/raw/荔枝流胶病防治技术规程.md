# 荔枝流胶病防治技术规程

> 本规程规定了荔枝流胶病的症状识别、病原鉴定、发病规律和综合防治技术，适用于荔枝产区树干流胶病的防治管理。

---

## 一、病害概述

荔枝流胶病（Lychee Gummosis）是一种危害荔枝枝干的病害，可由多种病原真菌（*Botryosphaeria* spp.、*Fusarium* spp.等）侵染引起，也可由非生物因素（机械损伤、冻害、日灼等）诱发。该病在荔枝产区普遍发生，严重时导致枝干枯死、树势衰弱，产量大幅下降。

---

## 二、症状识别

### 2.1 症状特征
| 受害部位 | 症状描述 | 发展阶段 |
|---------|---------|---------|
| 主干 | 初期树皮出现水渍状斑点，随后树皮开裂，流出褐色胶状物 | 初期 |
| 主枝 | 胶状物呈琥珀色至褐色，干燥后变为黑褐色硬块 | 中期 |
| 枝条 | 树皮坏死脱落，木质部裸露，表面着生黑色子实体 | 后期 |
| 树冠 | 发病一侧的枝叶黄化、枯萎，严重时整枝枯死 | 终期 |

### 2.2 流胶物特征
| 特征 | 描述 | 诊断意义 |
|------|------|---------|
| 颜色 | 初期琥珀色透明，后期褐色至黑褐色 | 颜色越深，病程越长 |
| 质地 | 初期粘稠胶状，干燥后坚硬 | 可用于判断发病时间 |
| 气味 | 稍有酸味或发酵味 | 与酸腐病区别(酸腐病有强烈酸臭味) |
| 位置 | 多在枝干分叉处、伤口周围 | 常见于机械损伤部位 |

### 2.3 与其他树干病害的区别
| 病害 | 关键区别 |
|------|---------|
| 流胶病 | 树干流胶，树皮坏死，胶状物明显 |
| 树干腐烂病 | 树皮腐烂，有酒糟味，不流胶 |
| 膏药病 | 枝干有膏药状菌膜，不流胶 |
| 日灼病 | 树皮龟裂，不流胶或少量流胶 |

## 三、病原与发病规律

### 3.1 病原种类
| 病原 | 分类 | 侵染特点 |
|------|------|---------|
| *Botryosphaeria dothidea* | 子囊菌门葡萄座腔菌属 | 弱寄生菌，从伤口侵入 |
| *Fusarium* spp. | 半知菌亚门镰刀菌属 | 弱寄生菌，土壤传播 |
| *Diplodia* spp. | 半知菌亚门色二孢属 | 弱寄生菌，从伤口侵入 |
| *Phomopsis* spp. | 半知菌亚门拟茎点霉属 | 弱寄生菌 |

### 3.2 发病规律
| 因素 | 规律描述 |
|------|---------|
| 越冬 | 以菌丝体和子囊壳在病枝干上越冬 |
| 传播 | 分生孢子借风雨传播，从伤口、皮孔侵入 |
| 侵染途径 | 机械损伤、冻害、日灼、虫伤等造成的伤口 |
| 温度 | 20-30°C适宜发病 |
| 湿度 | 多雨季节发病加重 |
| 树势 | 树势衰弱、管理粗放的果园发病重 |
| 品种 | 桂味、糯米糍等优质品种较感病 |
| 土壤 | 排水不良、土壤板结的果园发病重 |

### 3.3 诱因分析
| 诱因类型 | 具体因素 | 预防措施 |
|---------|---------|---------|
| 机械损伤 | 修剪伤口、农事操作损伤 | 修剪后及时涂抹保护剂 |
| 冻害 | 冬季低温导致树皮冻裂 | 树干涂白、防寒覆盖 |
| 日灼 | 夏季高温强光灼伤树皮 | 保留适当枝叶遮挡 |
| 虫害 | 天牛、木蠹蛾等蛀干害虫 | 及时防治蛀干害虫 |
| 水肥不当 | 水分过多或过少，营养不良 | 合理水肥管理 |

## 四、防治技术

### 4.1 农业防治
| 防治措施 | 技术要求 | 实施时间 |
|---------|---------|---------|
| 增强树势 | 增施有机肥15-20kg/株，合理配施N、P、K | 全年 |
| 合理修剪 | 修剪伤口平滑，留桩短，大伤口涂抹保护剂 | 采果后 |
| 树干涂白 | 生石灰:硫磺:食盐:水=10:1:0.2:40 | 冬季(11-12月) |
| 防冻害 | 低温前树干包扎稻草或防寒布 | 寒潮前 |
| 排水防涝 | 低洼果园开沟排水，降低土壤湿度 | 雨季 |
| 防日灼 | 夏季保留树冠外围枝条遮挡强光 | 夏季 |

### 4.2 物理防治
| 措施 | 操作方法 |
|------|---------|
| 刮除病皮 | 用刮刀彻底刮除病部树皮，至露出健康组织 |
| 伤口消毒 | 用75%酒精或0.1%高锰酸钾溶液消毒伤口 |
| 涂抹保护剂 | 消毒后及时涂抹伤口愈合剂或保护性药剂 |
| 清理病残体 | 刮下的病皮、病枝集中烧毁 |

### 4.3 化学防治
#### 伤口处理药剂
| 药剂名称 | 浓度 | 使用方法 | 备注 |
|---------|------|---------|------|
| 石硫合剂原液 | 29%AS | 涂抹伤口 | 冬季使用 |
| 波尔多浆 | 硫酸铜:石灰:水=1:1:10 | 涂抹伤口 | 保护伤口 |
| 甲基硫菌灵糊剂 | 70%WP调成糊状 | 涂抹伤口 | 内吸治疗 |
| 多菌灵糊剂 | 50%WP调成糊状 | 涂抹伤口 | 内吸治疗 |
| 腐植酸铜 | 原液 | 涂抹伤口 | 愈合伤口 |

#### 全树喷施
| 药剂名称 | 浓度 | 施药时期 | 安全间隔期(天) |
|---------|------|---------|--------------|
| 代森锰锌 | 80%WP 600倍液 | 发病初期 | 15 |
| 甲基硫菌灵 | 70%WP 800倍液 | 发病初期 | 14 |
| 多菌灵 | 50%WP 500倍液 | 发病初期 | 10 |
| 苯醚甲环唑 | 10%WG 1500倍液 | 发病初期 | 10 |
| 氢氧化铜 | 77%WP 800倍液 | 预防 | 7 |

## 五、防治方案

### 5.1 预防方案
| 时期 | 措施 | 技术要求 |
|------|------|---------|
| 11-12月 | 树干涂白 | 涂白高度1-1.5m |
| 12-1月 | 冬季修剪+伤口保护 | 大伤口涂抹保护剂 |
| 2-3月 | 喷施代森锰锌600倍 | 全树喷洒保护 |
| 5-6月 | 检查树干，发现流胶及时处理 | 刮除+涂药 |
| 8-9月 | 采果后修剪+保护 | 修剪+涂抹 |

### 5.2 治疗方案
| 步骤 | 措施 | 详细操作 |
|------|------|---------|
| 第1步 | 刮除病部 | 用锋利的刮刀将病部树皮刮除，深达木质部，边缘超出病部1-2cm |
| 第2步 | 清洗消毒 | 用75%酒精或0.1%高锰酸钾液清洗消毒伤口 |
| 第3步 | 涂药保护 | 涂抹甲基硫菌灵糊剂或波尔多浆 |
| 第4步 | 包扎 | 用塑料薄膜包扎伤口，保持湿润促进愈合 |
| 第5步 | 树势恢复 | 叶面喷0.3%磷酸二氢钾+0.2%尿素，土壤追施有机肥 |

---

## 六、防治效果评价

### 6.1 效果指标
| 指标 | 评价方法 | 优秀 | 良好 | 合格 |
|------|---------|------|------|------|
| 伤口愈合率 | 愈合伤口数/处理伤口数×100% | >90% | 70-90% | 50-70% |
| 新流胶率 | 新流胶株数/处理株数×100% | <5% | 5-10% | 10-20% |
| 树势恢复 | 新梢生长量 | 恢复正常 | 明显改善 | 有所改善 |
| 发病率 | 发病株率 | <5% | 5-15% | 15-30% |

### 6.2 伤口愈合分级标准
| 级别 | 愈合情况 |
|------|---------|
| 优 | 伤口完全愈合，新皮覆盖面积>90% |
| 良 | 伤口大部分愈合，新皮覆盖70-90% |
| 中 | 伤口部分愈合，新皮覆盖50-70% |
| 差 | 伤口未愈合或继续流胶 |
