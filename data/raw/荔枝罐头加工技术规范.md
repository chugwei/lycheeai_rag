# 荔枝罐头加工技术规范

> 荔枝罐头是荔枝加工的传统出口产品，以糖水荔枝罐头为主，具有风味保持好、保质期长的特点。我国是世界上最大的荔枝罐头生产国和出口国，年产量超10万吨。

---

## 一、荔枝罐头产品分类

### 产品类型

| 产品类型 | 果肉形态 | 糖水浓度(°Brix) | 包装规格 | 主要市场 |
|---------|---------|--------------|---------|---------|
| **糖水整果罐头** | 去核整果 | 15-25 | 300-850g马口铁罐 | 欧美、东南亚 |
| **糖水半片罐头** | 半片果肉 | 15-20 | 300-500g玻璃罐 | 国内、日本 |
| **糖水碎果罐头** | 果肉碎块 | 18-22 | 1-5kg大罐 | 餐饮工业 |
| **荔枝糖水** | 仅糖水 | 12-16 | 各规格 | 饮料原料 |
| **清爽型罐头** | 整果/半片 | 8-12（低糖） | 300-500g | 健康市场 |
| **混合水果罐头** | 混合多种水果 | 14-18 | 500-850g | 家庭消费 |

### 原料要求

| 指标 | 要求标准 |
|------|---------|
| 品种 | 妃子笑、黑叶、三月红（果肉洁白、紧实） |
| 成熟度 | 8-9成熟（果肉充实，不过软） |
| 果径 | ≥28mm |
| 色泽 | 果肉洁白，无褐变 |
| 新鲜度 | 采后24h内加工 |
| 卫生 | 无腐烂果、虫蛀果 |
| 硬度 | 果肉紧实，耐煮制 |

## 二、加工工艺流程

### 标准工艺流程

```
原料验收 → 清洗 → 去壳 → 去核（或整果）→ 护色处理 → 
分级 → 装罐 → 注糖水 → 排气 → 密封 → 杀菌 → 
冷却 → 擦罐 → 检验 → 包装 → 入库
```

### 各工序操作参数

| 工序 | 设备 | 工艺参数 | 操作要点 |
|------|------|---------|---------|
| **清洗** | 喷淋清洗机 | 清水喷淋，水压0.2-0.3MPa | 去除表面污物 |
| **去壳** | 人工/去壳机 | 手工去壳保护果肉完整 | 避免损伤果肉 |
| **去核** | 通核机 | 通核杆直径8-12mm | 保持果形完整 |
| **护色** | 浸泡槽 | 0.5%柠檬酸+0.2%VC，浸泡5min | 防止果肉褐变 |
| **分级** | 振动分级机 | 按果径分3-4级 | 同一罐果肉大小均匀 |
| **装罐** | 自动装罐机 | 固形物≥55% | 果肉排列整齐 |
| **注糖水** | 注液机 | 糖水温度80-85°C | 定量灌装，误差±2% |
| **排气** | 排气箱/真空封罐 | 中心温度≥80°C/真空度300-400mmHg | 充分排气 |
| **密封** | 封罐机 | 二重卷边结构 | 检查密封性 |
| **杀菌** | 立式/卧式杀菌釜 | 85-90°C巴氏杀菌或105-110°C高温杀菌 | 按罐型调整 |
| **冷却** | 冷却槽 | 分段冷却（80°C→60°C→40°C→室温） | 防止急冷爆罐 |

## 三、关键工艺参数

### 糖水配制

| 糖水浓度(°Brix) | 加糖量(kg/100L水) | 适用品种 | 适用市场 |
|---------------|-----------------|---------|---------|
| 15 | 16.8 | 甜味品种（糯米糍） | 低糖健康市场 |
| 18 | 20.5 | 中甜品种（妃子笑） | 通用 |
| 20 | 23.0 | 偏酸品种（三月红） | 东南亚市场 |
| 22 | 25.6 | 通用 | 欧美市场 |
| 25 | 29.5 | 偏酸品种 | 日本市场 |

### 糖水配方

| 成分 | 添加量 | 作用 |
|------|-------|------|
| 白砂糖 | 按目标浓度 | 甜味剂 |
| 柠檬酸 | 0.05-0.15% | 调节pH至4.0-4.5，护色 |
| 抗坏血酸(VC) | 0.02-0.05% | 抗氧化，护色 |
| 氯化钙 | 0.05-0.10% | 保持果肉硬度 |
| EDTA-2Na | 0.01-0.02% | 金属螯合剂，防变色 |

### 杀菌工艺

| 罐型 | 罐重(g) | 杀菌温度(°C) | 杀菌时间(min) | 冷却方式 |
|------|--------|------------|------------|---------|
| 7113#（300g） | 300 | 88-90 | 12-15 | 水冷 |
| 7116#（425g） | 425 | 88-90 | 15-18 | 水冷 |
| 7100#（500g） | 500 | 90-92 | 18-22 | 水冷 |
| 9121#（850g） | 850 | 90-92 | 22-28 | 水冷 |
| 玻璃瓶（500g） | 500 | 85-88 | 20-25 | 分段冷却 |

|------|------------|---------|
| 马口铁罐 | 250-350 | 真空计检测 |
| 玻璃罐 | 200-300 | 真空计检测 |

## 四、常见质量问题及控制

### 质量问题分析

| 质量问题 | 症状 | 原因 | 预防措施 |
|---------|------|------|---------|
| **果肉褐变** | 果肉变为黄褐色 | 加工延迟，护色不足，杀菌过度 | 采后4h内加工，加强护色，控制杀菌温度 |
| **果肉软化** | 果肉失去弹性 | 成熟度过高，杀菌过度，Ca²⁺不足 | 8成熟采收，加CaCl₂，优化杀菌参数 |
| **糖水浑浊** | 糖水不透明 | 果肉碎屑过多，果胶溶出 | 减少破碎，增加过滤工序 |
| **罐内腐蚀** | 罐内壁变色 | 酸度过高，排气不充分，罐材不良 | 控制pH4.0-4.5，充分排气，使用涂料罐 |
| **真空度不足** | 罐盖凸起 | 排气不足，密封不良，微生物产气 | 延长排气时间，检查封罐质量 |
| **果肉发红** | 果肉呈粉红色 | 花青素迁移，加工用水铁离子超标 | 使用去离子水，控制铁离子<0.1mg/L |
| **异味产生** | 有硫味或金属味 | 罐材反应，硫化物产生 | 使用抗硫涂料罐，控制工艺 |

### 品质控制关键点

| CCP点 | 控制指标 | 监控方式 | 纠偏措施 |
|-------|---------|---------|---------|
| CCP-1 原料验收 | 品种、成熟度、新鲜度 | 抽检+记录 | 不合格原料退货 |
| CCP-2 护色处理 | 浸泡时间、药液浓度 | 定时检查 | 调整浓度和时间 |
| CCP-3 排气 | 中心温度/真空度 | 连续监测 | 延长排气时间 |
| CCP-4 密封 | 卷边尺寸 | 每30分钟检查 | 调整封罐机 |
| CCP-5 杀菌 | 温度、时间 | 连续记录 | 延长杀菌时间 |
| CCP-6 冷却 | 冷却水余氯≥0.5ppm | 每批检测 | 调整加氯量 |

## 五、产品质量标准

### 感官指标

| 项目 | 要求 |
|------|------|
| 色泽 | 果肉洁白或乳白色，糖水清澈透明 |
| 滋味气味 | 具有荔枝罐头应有风味，无异味 |
| 组织形态 | 果肉完整，形状良好，软硬适度 |
| 杂质 | 不允许外来杂质 |
| 罐型 | 外观正常，无锈蚀，无胖听 |

### 理化指标

| 检测项目 | 标准 | 检测方法 |
|---------|------|---------|
| 净重(g) | 标示值±3% | 称重法 |
| 固形物含量(%) | ≥55 | QB/T 1006 |
| 糖水浓度(°Brix) | 14-22（按规格） | 折光计法 |
| pH值 | 4.0-4.5 | pH计法 |
| 总酸(以柠檬酸计, %) | 0.05-0.15 | 滴定法 |
| 锡(mg/kg, 马口铁罐) | ≤200 | GB 5009.16 |
| 铅(mg/kg) | ≤1.0 | GB 5009.12 |
| 砷(mg/kg) | ≤0.5 | GB 5009.11 |
| 铜(mg/kg) | ≤5.0 | GB 5009.13 |

### 微生物指标

| 检测项目 | 指标 |
|---------|------|
| 商业无菌 | 符合商业无菌要求 |
| 致病菌（沙门氏菌、金黄色葡萄球菌等） | 不得检出 |

## 六、包装与贮藏

### 包装要求

| 包装类型 | 材料 | 特点 | 适用 |
|---------|------|------|------|
| 马口铁罐 | 镀锡薄钢板 | 密封性好，保质期长（2-3年） | 出口为主 |
| 涂料罐 | 内涂环氧树脂的马口铁罐 | 抗酸性好，防腐蚀 | 高酸水果罐头 |
| 玻璃罐 | 钠钙玻璃 | 透明可见，可重复使用 | 国内精品 |
| 铝箔密封杯 | PP/铝箔复合 | 轻便，易开启 | 即食小包装 |

### 贮藏条件

| 条件 | 要求 |
|------|------|
| 温度 | 0-25°C（最佳15-20°C） |
| 相对湿度 | <75% |
| 堆码高度 | 马口铁罐≤12层，玻璃罐≤6层 |
| 避光 | 避免阳光直射 |
| 保质期 | 马口铁罐24-36月，玻璃罐18-24月 |
