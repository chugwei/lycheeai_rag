# 荔枝品种DUS测试技术标准

## 摘要

DUS（Distinctness特异性、Uniformity一致性、Stability稳定性）测试是植物新品种权保护与新品种审定的核心技术标准。本文系统阐述荔枝品种DUS测试的技术标准体系，包括测试指标选取、田间小区设计、数据记录与统计分析方法、判定阈值与结论标准等内容，为荔枝品种审定、品种权申请及品种鉴定提供标准化技术参考。

## 1 概述

DUS测试起源于国际植物新品种保护联盟（UPOV）框架，是授予植物新品种权的法定依据。我国自2000年加入UPOV公约（1978文本）以来，逐步建立了作物品种DUS测试体系。荔枝作为重要的热带亚热带果树，其DUS测试标准的制定和规范化应用对保护育种成果、维护品种权人合法权益具有重要意义。

## 2 DUS测试原理与原则

| 测试维度 | 定义 | 判定核心 |
| --- | --- | --- |
| 特异性（D） | 品种至少有一个性状明显区别于所有已知品种 | 与最相近比对品种的差异显著性 |
| 一致性（U） | 同一品种个体之间性状表现基本一致 | 品种内变异率低于阈值 |
| 稳定性（S） | 经反复繁殖或适宜繁殖周期后，品种特征保持相对稳定 | 连续两代以上性状不变 |

测试原则：特异性与一致性在单次世代测试中可判定；稳定性需通过至少连续两代繁殖试验验证。

## 3 荔枝DUS测试指标体系

### 3.1 测试性状选择

荔枝DUS测试性状选自品种特征描述符中可遗传、变异幅度大、易于观察的性状指标，主要包括：

| 性状类别 | 测试性状 | 测试方式 |
| --- | --- | --- |
| 树体 | 树势、树姿、分枝角度、分枝密度 | 目测定级（1-9） |
| 叶 | 叶长、叶宽、叶色、叶尖形态 | 实测+目测 |
| 花 | 花序类型、花蕾数量、花瓣形态 | 目测+计数 |
| 果实 | 果形、果形指数、单果重、果皮颜色、龟裂片类型、假种皮厚度、核大小 | 实测+目测 |
| 种子 | 种子形态、种皮颜色 | 目测 |
| 物候 | 始花期、终花期、成熟期 | 日历记录 |

### 3.2 测试材料要求

- 被测品种（待测品种）：至少10株，无病虫害
- 比对品种（参照品种）：已知品种，品种权申请中最接近的品种
- 标准品种（检查品种）：用于田间试验对照，品种特征稳定

## 4 田间试验设计

### 4.1 小区设计

| 参数 | 技术要求 |
| --- | --- |
| 种植方式 | 单株定植，保护地或大田 |
| 株行距 | 3m×3m 或 3m×4m |
| 被测品种株数 | ≥10株/品种 |
| 比对品种株数 | ≥10株/品种 |
| 重复次数 | ≥3次重复 |
| 随机排列 | 随机区组设计（RCBD） |
| 试验区环境 | 统一栽培管理、相同土壤气候条件 |

### 4.2 数据记录与统计分析

数据记录需遵循UPOV测试指南，使用标准化数据记录表。统计分析方法包括：

- 定性性状：卡方检验或秩和检验
- 定量性状：单因素方差分析（ANOVA），Tukey多重比较
- 特异性判定：被测品种与比对品种间差异达5%显著性水平

### 4.3 DUS判定标准

| 判定项 | 通过标准 |
| --- | --- |
| 特异性 | 至少1个测试性状与被测品种间存在显著差异（P<0.05），差异等级≥2级 |
| 一致性 | 品种内变异个体比例≤5%（品种权申请）或≤10%（登记品种） |
| 稳定性 | 连续两代性状表现一致，无退化为其他品种迹象 |

## 5 荔枝DUS测试难点与对策

| 难点 | 原因分析 | 应对策略 |
| --- | --- | --- |
| 雌雄花比率变异大 | 荔枝雌花比率受气候和管理影响 | 设置多年多点试验，取平均值 |
| 果实性状受环境影响 | 同一品种不同年份果实表现有差异 | 设置标准化管理，3年连续测试 |
| 嫁接材料一致性 | 不同母本枝条可能导致性状偏移 | 统一嫁接母本、标准化接穗 |
| 比对品种不足 | 荔枝品种比对库尚不完整 | 加强品种资源收集与比对库建设 |
