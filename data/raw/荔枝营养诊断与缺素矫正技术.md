# 荔枝营养诊断与缺素矫正技术

> 营养诊断是通过分析荔枝叶片和土壤的养分状况，科学指导施肥的关键技术。荔枝缺素症在田间有典型的形态表现，准确识别是及时矫正的前提。

---

## 一、营养诊断方法体系

### 诊断方法分类

| 诊断方法 | 原理 | 准确性 |  时效性 | 成本 |
|---------|------|-------|--------|------|
| **症状诊断** | 观察叶片和果实缺素典型症状 | 中 | 快 | 低 |
| **叶分析** | 测定叶片矿质元素含量 | 高 | 中 | 中 |
| **土壤分析** | 测定土壤有效养分含量 | 中高 | 慢 | 中 |
| **树体汁液分析** | 快速测定汁液养分浓度 | 中 | 快 | 中 |
| **SPAD叶绿素仪** | 测定叶片叶绿素相对含量 | 中 | 快 | 低 |

## 二、叶分析诊断标准

### 采样方法

| 项目 | 标准 |
|------|------|
| **采样时期** | 秋梢老熟期（9-10月） |
| **叶龄** | 充分老熟的当年生春梢或秋梢叶片 |
| **叶片位置** | 枝条顶端向下第2-3片复叶的小叶 |
| **每株采样量** | 10-20片 |
| **每园采样量** | 30-50株树混合样（不少于100片叶） |
| **采样时间** | 晴天上午8-10点 |
| **样品处理** | 清洗→105°C杀青15min→70°C烘干→粉碎 |

| 营养元素 | 缺乏 | 偏低 | 正常 | 偏高 | 过量 |
|---------|------|------|------|------|------|

| **K(g/kg)** | <7 | 7-9 | 9-15 | 15-18 | >18 |

| **S(g/kg)** | <1.2 | 1.2-1.5 | 1.5-3.0 | 3.0-4.0 | >4.0 |

## 三、缺素症状识别图谱

### 大量元素缺乏

#### 缺氮(N)

| 项目 | 描述 |
|------|------|
| **典型症状** | 老叶首先均匀黄化，新叶淡绿 |
| **叶片** | 全叶均匀褪绿呈黄绿色，无斑点 |
| **新梢** | 新梢生长缓慢，节间短 |
| **果实** | 果小，产量低 |
| **树势** | 整体衰弱 |
| **易发生条件** | 砂质土、有机质低的土壤、多雨淋溶 |
| **叶片诊断值** | N<13g/kg |
| **矫治方法** | 叶面喷0.3%尿素，土壤追施尿素0.2-0.3kg/株 |

#### 缺磷(P)

| 项目 | 描述 |
|------|------|
| **典型症状** | 叶片暗绿无光泽，老叶紫红色 |
| **叶片** | 叶片小，质地硬脆，叶脉呈紫红色 |
| **新梢** | 新梢生长弱，分枝少 |
| **花果** | 花芽分化不良，坐果率低 |
| **易发生条件** | 强酸性红壤(pH<5.0)、石灰性土壤(pH>7.5) |
| **叶片诊断值** | P<0.8g/kg |
| **矫治方法** | 施过磷酸钙1.0-1.5kg/株（深施），叶面喷0.3%磷酸二氢钾 |

#### 缺钾(K)

| 项目 | 描述 |
|------|------|
| **典型症状** | 老叶叶缘焦枯，卷曲 |
| **叶片** | 叶尖和叶缘褪绿黄化→焦枯，叶缘向上卷曲 |
| **果实** | 果小，**裂果增多**，糖度降低 |
| **易发生条件** | 砂质土、多雨地区、高产树 |
| **叶片诊断值** | K<7g/kg |
| **矫治方法** | 施硫酸钾0.3-0.5kg/株，叶面喷0.3%磷酸二氢钾 |

### 中量元素缺乏

#### 缺钙(Ca)

| 项目 | 描述 |
|------|------|
| **典型症状** | 新叶畸形，叶尖叶缘焦枯，裂果 |
| **叶片** | 新叶小、皱缩、畸形，叶缘焦枯呈灼烧状 |
| **果实** | **裂果率显著增加**，果皮软 |
| **根系** | 根尖坏死，根短而粗 |
| **易发生条件** | 酸性砂质土、长期偏施氮钾肥 |
| **叶片诊断值** | Ca<4g/kg |
| **矫治方法** | 施硝酸钙0.2-0.3kg/株或石灰1-2kg/亩；叶面喷0.1%硝酸钙 |

#### 缺镁(Mg)

| 项目 | 描述 |
|------|------|
| **典型症状** | 老叶脉间失绿呈"鱼骨状" |
| **叶片** | 老叶叶脉保持绿色，脉间黄化（倒V形） |
| **严重时** | 黄化区扩大，叶片脱落 |
| **易发生条件** | 酸性砂质土、大量施钾肥抑制镁吸收 |
| **叶片诊断值** | Mg<2.0g/kg |
| **矫治方法** | 施硫酸镁0.1-0.2kg/株或白云石粉1-2kg/亩；叶面喷0.1%硫酸镁 |

### 微量元素缺乏

#### 缺硼(B) —— 荔枝最常见缺素症之一

| 项目 | 描述 |
|------|------|
| **典型症状** | "花而不实"，坐果率低 |
| **叶片** | 新叶厚脆，叶脉凸起，叶面不平 |
| **花** | 花药和花粉发育不良，**授粉率低** |
| **果实** | 坐果少，果肉出现**木栓化斑块** |
| **易发生条件** | 酸性砂质土、淋溶强烈地区 |
| **叶片诊断值** | B<15mg/kg |
| **矫治方法** | 花前喷0.1-0.2%硼砂（2次），土壤施硼砂15-20g/株 |

#### 缺锌(Zn)

| 项目 | 描述 |
|------|------|
| **典型症状** | "小叶病"——新叶变小簇生 |
| **叶片** | 新叶显著变小，节间缩短，呈簇生状，叶脉间失绿 |
| **新梢** | 新梢生长停滞 |
| **易发生条件** | 酸性砂质土、石灰性土壤、过量施磷 |
| **叶片诊断值** | Zn<12mg/kg |
| **矫治方法** | 叶面喷0.1%硫酸锌+0.3%尿素（新梢期喷2次） |

#### 缺铁(Fe) —— 石灰性土壤最常见

| 项目 | 描述 |
|------|------|
| **典型症状** | 新叶黄白化（缺绿症） |
| **叶片** | 新叶从叶脉间开始黄化，严重时全叶呈黄白色 |
| **与缺氮区别** | 缺铁首先出现在新叶（缺氮在老叶） |
| **易发生条件** | 石灰性土壤(pH>7.0)、排水不良 |
| **叶片诊断值** | Fe<40mg/kg |
| **矫治方法** | 叶面喷0.2%硫酸亚铁+0.3%柠檬酸；土壤施螯合铁(EDTA-Fe)20-30g/株 |

#### 缺锰(Mn)

| 项目 | 描述 |
|------|------|
| **典型症状** | 新叶脉间失绿，呈花叶状 |
| **叶片** | 新叶脉间黄化，叶脉仍为绿色 |
| **严重时** | 黄化区枯死形成褐色斑点 |
| **易发生条件** | 酸性砂质土（锰淋溶）或石灰性土壤（锰固定） |
| **矫治方法** | 叶面喷0.1%硫酸锰 |

#### 缺钼(Mo)

| 项目 | 描述 |
|------|------|
| **典型症状** | 老叶黄斑，叶片卷曲 |
| **叶片** | 老叶出现黄色斑点，叶片边缘卷曲 |
| **矫治方法** | 叶面喷0.05-0.1%钼酸铵（花期前后喷1次） |

## 四、缺素症综合诊断表

### 按叶片部位快速诊断

| 症状部位 | 症状特征 | 可能缺乏的元素 |
|---------|---------|--------------|
| **新叶** | 均匀黄化 | N、S |
| **新叶** | 叶脉间黄化（脉绿） | Fe、Mn、Zn、Mg |
| **新叶** | 叶脉间黄化（脉黄） | 病毒病（非缺素） |
| **新叶** | 畸形、变小 | Zn（小叶）、Ca、B |
| **新叶** | 叶尖叶缘焦枯 | Ca、K |
| **老叶** | 均匀黄化 | N |
| **老叶** | 叶脉间黄化（鱼骨状） | Mg |
| **老叶** | 紫红色 | P |
| **老叶** | 叶缘焦枯 | K |
| **果实** | 裂果 | Ca、K(水分失调) |
| **果实** | 木栓化斑块 | B |
| **花** | 授粉不良，坐果少 | B、Zn、P |

## 五、缺素症综合防治方案

### 预防为主（推荐方案）

| 物候期 | 叶面追肥（预防缺素） | 目的 |
|-------|--------------------|------|
| 花穗抽生期(2月) | 0.2%硼砂+0.3%磷酸二氢钾 | 花器发育，提高花质 |
| 谢花后(4月) | 0.2%硼砂+0.3%磷酸二氢钾+0.1%钼酸铵 | 保果 |
| 幼果期(5月) | 0.1%硝酸钙+0.1%硫酸镁 | 防裂果，促发育 |
| 果实膨大期(5-6月) | 0.3%磷酸二氢钾+0.1%氨基酸螯合钙 | 增糖防裂 |
| 秋梢期(7-8月) | 0.3%尿素+0.2%磷酸二氢钾 | 促梢壮梢 |
| 秋梢老熟期(9-10月) | 0.3%磷酸二氢钾+0.1%硫酸锌 | 促进老熟和花芽分化 |

### 缺素矫治（针对已出现症状）

| 缺素类型 | 土壤矫治（长效） | 叶面喷施（速效） | 见效时间 |
|---------|---------------|----------------|---------|
| 缺N | 尿素0.2-0.3kg/株 | 0.3%尿素 | 3-5天 |
| 缺P | 过磷酸钙1.0-1.5kg/株 | 0.3%磷酸二氢钾 | 7-10天 |
| 缺K | 硫酸钾0.3-0.5kg/株 | 0.3%磷酸二氢钾 | 5-7天 |
| 缺Ca | 硝酸钙0.2-0.3kg/株 | 0.1%硝酸钙 | 7-10天 |
| 缺Mg | 硫酸镁0.1-0.2kg/株 | 0.1%硫酸镁 | 5-7天 |
| 缺B | 硼砂15-20g/株 | 0.1-0.2%硼砂 | 7-10天 |
| 缺Zn | 硫酸锌50-100g/株 | 0.1%硫酸锌+0.3%尿素 | 5-7天 |
| 缺Fe | 螯合铁(EDTA-Fe)20-30g/株 | 0.2%硫酸亚铁+0.3%柠檬酸 | 7-10天 |

## 六、土壤分析诊断

### 采样方法

| 项目 | 标准 |
|------|------|
| **采样时间** | 秋梢老熟期或采果后 |
| **采样深度** | 0-20cm（表土层）和20-40cm（心土层） |
| **采样点** | 树盘滴水线内外（S形布点，每园10-20点混合） |
| **采样频率** | 每2-3年1次 |

### 推荐土壤养分含量

| 项目 | 适宜范围 | 测定方法 |
|------|---------|---------|
| pH | 5.5-6.5 | 水浸提法 |
| 有机质(g/kg) | 15-25 | 重铬酸钾氧化法 |
| 全氮(g/kg) | 1.0-1.5 | 凯氏定氮法 |
| 碱解氮(mg/kg) | 80-150 | 碱解扩散法 |
| 有效磷(mg/kg) | 15-30 | Olsen法 |
| 速效钾(mg/kg) | 100-200 | NH₄OAc浸提 |
| 交换性钙(cmol/kg) | 5-10 | EDTA法 |
| 交换性镁(cmol/kg) | 1-3 | EDTA法 |
| 有效硼(mg/kg) | 0.5-1.0 | 热水浸提 |
| 有效锌(mg/kg) | 1.0-2.0 | DTPA浸提 |
| 有效铁(mg/kg) | 10-30 | DTPA浸提 |
| 有效锰(mg/kg) | 10-30 | DTPA浸提 |
| 有效铜(mg/kg) | 1-5 | DTPA浸提 |
