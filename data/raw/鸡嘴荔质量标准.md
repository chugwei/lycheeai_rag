# 鸡嘴荔质量标准

> 本标准规定了地理标志产品鸡嘴荔的质量要求、等级规格、检验方法、标志包装及运输贮藏标准。鸡嘴荔是广西壮族自治区钦州市和北海市的名优荔枝品种，因果实形似鸡嘴而得名，以其品质优良、核小肉厚、脆甜爽口而著称。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于鸡嘴荔品种的生产、收购、销售和流通环节。适用于广西主产区（合浦、浦北、灵山等县）及引种栽培区的鸡嘴荔质量评定。

### 规范性引用文件
| 标准编号 | 标准名称 |
|---------|---------|
| SB/T 10059 | 荔枝 |
| GB 2763 | 食品安全国家标准 食品中农药最大残留限量 |
| GB/T 5009 | 食品卫生检验方法 |

## 二、品种特征

### 植物学特征
| 特征项目 | 描述 |
|---------|------|
| 果实形状 | 歪心形或偏圆形，前端尖似鸡嘴 |
| 果皮 | 鲜红色至暗红色，龟裂片较平 |
| 果肩 | 一侧耸起，一侧平（嘴状特征） |
| 缝合线 | 明显 |
| 果肉 | 白蜡色，肉质爽脆 |
| 核 | 焦核或小核（退化的种子） |
| 风味 | 清甜爽脆，微香 |

### 果实特性指标
| 指标项目 | 数值范围 | 最优值 |
|---------|---------|-------|
| 单果重(g) | 20-35 | 28-32 |
| 纵径(mm) | 30-38 | 33-36 |
| 横径(mm) | 28-35 | 30-33 |
| 果形指数 | 1.05-1.15 | 1.08-1.12 |
| 果皮厚度(mm) | 0.6-1.0 | 0.7-0.8 |
| 可食率(%) | 78-85 | 82-85 |
| 可溶性固形物(%) | 16.0-19.5 | 18.0-19.0 |
| 总酸度(%) | 0.15-0.30 | 0.18-0.25 |
| 维生素C(mg/100g) | 25-45 | 35-40 |

## 三、质量等级

### 等级划分
| 项目 | 特级 | 一级 | 二级 |
|-----|------|-----|------|
| 单果重(g) | ≥30 | ≥25 | ≥20 |
| 果形 | 典型鸡嘴形，特征明显 | 鸡嘴形，较典型 | 基本呈鸡嘴形 |
| 果皮色泽 | 鲜红色，色泽鲜艳 | 鲜红至暗红 | 暗红色 |
| 果肉 | 白蜡色，爽脆化渣 | 白蜡色，爽脆 | 白蜡色 |
| 核 | 焦核(核重<0.5g) | 焦核或小核(<1.0g) | 小核 |
| 可溶性固形物(%) | ≥18.0 | ≥17.0 | ≥16.0 |
| 可食率(%) | ≥83 | ≥80 | ≥78 |
| 风味 | 清甜爽脆，典型鸡嘴荔风味 | 清甜爽口 | 较清甜 |
| 褐变 | ≤3% | ≤5% | ≤10% |
| 病虫害 | 无 | 无 | 无 |
| 机械伤 | 无 | 无 | 轻微 |

### 规格分级（按单果重）
| 规格代码 | 单果重(g) | 对应等级 |
|---------|----------|---------|
| 3L | ≥35 | 特级+ |
| 2L | 30-34 | 特级 |
| L | 25-29 | 一级 |
| M | 20-24 | 二级 |
| S | <20 | 等外 |

## 五、理化与安全指标

### 理化指标
| 项目 | 指标要求 | 检测方法 |
|-----|---------|---------|
| 可溶性固形物(%) | ≥16.0 | 手持折射仪法 |

## 六、检验规则

### 组批
同一品种、同一产地、同一等级、同一批次的鸡嘴荔作为一个检验批次。

### 抽样
| 批量(件) | 抽样(件) | 抽样数量(颗) |
|---------|---------|------------|
| ≤100 | 5 | 50 |
| 101-500 | 10 | 80 |
| 501-1000 | 15 | 100 |
| >1000 | 20 | 150 |

### 判定规则
- 全部指标合格判为合格批次
- 不合格项目可通过加倍抽样复检
- 复检仍不合格，判为不合格批次
- 安全指标不合格不得复检

## 八、贮藏与运输

### 贮藏条件
| 贮藏方式 | 温度(°C) | 相对湿度(%) | 贮藏期限(天) |
|---------|---------|------------|-----------|
| 常温贮藏 | 25-30 | 75-85 | 2-3 |
| 冷藏贮藏 | 2-4 | 90-95 | 15-20 |
| 气调贮藏 | 2-3 | 92-95 | 25-30 |

### 运输要求
- 短途（<200km）：保温车或常温运输（配冰源）
- 中长途（>200km）：冷藏车运输，温度2-4°C
- 装卸要求：轻装轻卸，堆码≤5层
- 运输时限：采后24小时内发出
