# 荔枝病虫害专业化统防统治技术规程

> 本规程规定了荔枝病虫害专业化统防统治的组织形式、服务流程、技术方案、质量控制和效果评估要求，适用于从事荔枝病虫害专业化防治服务的组织和个人。

---

## 一、范围与术语定义

### 适用范围
本规程适用于专业化防治服务组织开展的荔枝病虫害统防统治作业，包括服务组织资质要求、作业流程、技术规范和效果评价。

### 术语定义
| 术语 | 定义 |
|-----|------|
| 专业化统防统治 | 由专业服务组织统一实施病虫害防治作业 |
| 服务组织 | 具备相应资质和能力的专业防治服务单位 |
| 作业单元 | 统一实施防治作业的最小地理单元 |
| 防治方案 | 针对特定病虫害制定的药剂、器械、时间安排 |
| 作业档案 | 记录防治作业全过程的技术资料 |

## 三、服务流程

### 3.1 服务流程总图
```
签订服务合同 → 果园调查评估 → 制定防治方案 
→ 药械准备 → 实施防治作业 → 效果评估 
→ 结算费用 → 档案归档
```

### 3.2 各环节要求
| 环节 | 工作内容 | 标准要求 |
|------|---------|---------|
| 合同签订 | 明确服务范围、内容、费用、责任 | 合同文本规范 |
| 果园调查 | 调查病虫害种类、发生程度、果园环境 | 填写调查表 |
| 方案制定 | 确定药剂、浓度、施药时间、器械 | 针对性方案 |
| 药械准备 | 农药采购、器械调试、安全防护 | 药品三证齐全 |
| 作业实施 | 按方案规范施药 | 全程记录 |
| 效果评估 | 防效调查、满意度评价 | 达标率≥85% |
| 档案归档 | 收集整理全过程资料 | 保存2年以上 |

## 五、作业实施技术规范

### 5.1 施药技术要求
| 项目 | 技术参数 |
|------|---------|
| 喷雾压力 | 0.3-0.5MPa |
| 喷雾量 | 成龄树20-30L/株 |
| 雾滴大小 | 200-300μm |
| 施药高度 | 喷头距靶标50-80cm |
| 行走速度 | 匀速40-60m/min |
| 风向风速 | 风力<3级 |
| 施药时间 | 上午8-10时，下午4-6时 |

### 5.2 无人机施药技术参数
| 项目 | 技术参数 |
|------|---------|
| 飞行高度 | 距树冠2-3m |
| 飞行速度 | 3-5m/s |
| 喷雾量 | 1-2L/亩 |
| 雾滴大小 | 100-200μm |
| 喷幅宽度 | 3-5m |
| 作业效率 | 40-60亩/小时 |
| 气象条件 | 风力<4级，无雨 |

### 5.3 农药混配操作规程
1. 核对农药名称、剂型、浓度、有效期
2. 检查农药有无沉淀、结块、变质
3. 按二次稀释法配制：先用少量水稀释母液，再加水至规定浓度
4. 混用顺序：先粉剂后乳油，先叶面肥后农药
5. 配制好的药液应在24小时内用完

## 六、质量与安全管理

### 6.1 作业质量要求
| 质量指标 | 要求 | 检查方法 |
|---------|------|---------|
| 雾化均匀度 | 变异系数<15% | 雾滴测试卡 |
| 覆盖密度 | 叶片正面≥30滴/cm² | 水敏纸检测 |
| 漏喷率 | <5% | 目测检查 |
| 药害率 | <1% | 施药后3天检查 |
| 防治效果 | ≥85% | 施药后7-14天调查 |

### 6.2 安全管理要求
| 安全项目 | 具体要求 |
|---------|---------|
| 人员培训 | 每年至少1次安全培训 |
| 健康检查 | 作业人员每年体检1次 |
| 防护装备 | 必须穿戴防护服、口罩、手套 |
| 施药安全 | 严禁逆风施药，严禁高温作业 |
| 食品安全 | 严格遵守安全间隔期 |
| 应急处理 | 制定农药中毒应急预案 |

### 6.3 农药包装废弃物处理
- 设立农药包装废弃物回收点
- 空包装集中收集，交专业机构处理
- 建立回收台账，记录回收数量和处理方式
- 严禁随意丢弃、焚烧或掩埋

## 七、防治效果评价

### 7.1 效果评价方法
| 评价项目 | 计算方法 | 评价标准 |
|---------|---------|---------|
| 防治效果 | (对照区病情-处理区病情)/对照区病情×100% | ≥85%合格 |
| 保产效果 | (处理区产量-对照区产量)/对照区产量×100% | ≥20%合格 |
| 满意度 | 满意户数/调查户数×100% | ≥90%合格 |

### 7.2 评价等级
| 等级 | 防治效果 | 综合评价 |
|------|---------|---------|
| 优秀 | ≥90% | 防治方案科学，执行到位 |
| 良好 | 80-89% | 基本达到防治目标 |
| 合格 | 70-79% | 部分目标未达成需改进 |
| 不合格 | <70% | 需重新评估方案 |

## 九、档案管理

### 9.1 档案内容
| 档案类别 | 内容 | 保存期限 |
|---------|------|---------|
| 合同档案 | 服务合同、补充协议 | 合同期满后3年 |
| 作业档案 | 防治方案、作业记录、用药记录 | 3年 |

- 定期备份，防止数据丢失
