# 桂味荔枝品种特性与栽培技术

> 桂味（*Litchi chinensis* Sonn. cv. Guiwei）是荔枝中的顶级优质品种，因果实带有独特的桂花香气而得名。该品种以品质极优、风味独特著称，是高端鲜食荔枝市场的代表品种，在广东从化、增城等地产量品质最佳。

---

## 一、品种起源与历史

### 品种来源
桂味原产广东省，母树发现于广州市郊及增城一带。因其果肉具有浓郁的桂花香气，故得名"桂味"。该品种栽培历史悠久，是岭南荔枝中的传统名种，在清代已有记载。

### 品种地位
桂味是中国荔枝品种中品质最优的品种之一，与糯米糍并称为"荔枝双绝"。其市场售价通常为普通品种的2-3倍，是高端水果市场的宠儿。

| 指标 | 数据 |
|------|------|
| 全国栽培面积占比 | 约8-10% |
| 珠三角产区占比 | 20-25% |
| 单株产量（成年树） | 30-50kg |
| 市场售价 | 通常为妃子笑的2-3倍 |
| 焦核率 | 60-80%（优质果） |

## 二、植物学特征

### 树体特征
| 部位 | 特征描述 |
|------|---------|
| 树势 | 中等偏旺 |
| 树冠 | 半圆形，枝梢较密 |
| 枝条 | 中等粗度，分枝力强 |
| 叶片 | 小叶4-6对，狭椭圆形，叶缘略卷 |
| 叶色 | 深绿色，叶片厚实有光泽 |
| 生长习性 | 一年抽梢3次，秋梢为重点结果母枝 |

### 花穗特征
| 特征 | 描述 |
|------|------|
| 花穗类型 | 纯花穗为主，偶有带叶花穗 |
| 花穗长度 | 10-20cm |
| 花量 | 中等 |
| 雌雄花比例 | 1:4-1:8 |
| 开花习性 | 雌雄异熟，雌花开放时间短 |
| 自花结实率 | 极低（<5%），需配置授粉树 |

### 果实特征
| 指标 | 数值 |
|------|------|
| 单果重 | 17-20g |
| 果形 | 圆形或近圆形 |
| 果皮颜色 | 鲜红色，果肩常带绿斑（典型特征） |
| 龟裂片 | 突起尖锐，排列不规则 |
| 果肉颜色 | 乳白色 |
| 果肉质地 | 爽脆，清甜多汁 |
| 风味 | 桂花香气浓郁（典型特征） |
| 可食率 | 75-80% |
| 可溶性固形物 | 18-21% |
| 种子大小 | 小（焦核率60-80%） |
| 果实发育期 | 68-73天 |

## 四、栽培技术要点

### 1. 园地选择与定植
| 项目 | 要求 |
|------|------|
| 土壤要求 | 土层深厚肥沃，pH 5.5-6.5，有机质含量>2% |
| 环境要求 | 冬季需有适量低温（<15℃）以促进花芽分化 |
| 定植密度 | 5m×6m（22株/亩）或6m×6m（18株/亩） |
| 授粉树配置 | 必须配置授粉树，推荐糯米糍或黑叶，比例4:1 |
| 定植时间 | 春植（2-3月）或秋植（9-10月） |

### 2. 肥水管理（精细化管理）

| 施肥时期 | 肥料种类 | 用量（每株） | 注意事项 |
|---------|---------|------------|---------|
| 基肥（采果后） | 腐熟有机肥+钙镁磷肥 | 15-20kg+0.5kg | 深翻沟施 |
| 秋梢肥（8月） | 复合肥（15-15-15） | 0.5-0.8kg | 促进秋梢健壮 |
| 促花肥（12-1月） | 复合肥+硫酸钾+硼肥 | 0.5kg+0.3kg+10g | 促进花芽分化 |
| 壮花肥（3月） | 复合肥+硫酸锌 | 0.3-0.5kg+15g | 提高花质 |
| 保果肥（4-5月） | 高钾复合肥+硝酸钙 | 0.3-0.5kg+0.2kg | 减少落果、防裂果 |

### 3. 水分管理
桂味对水分要求较高，管理要点如下：
- **秋梢期**（7-10月）：保持土壤湿润，促进秋梢充实
- **花芽分化期**（12-1月）：适当控水但不完全干旱
- **开花期**（3-4月）：保持土壤适度湿润，空气湿度70-80%
- **果实发育期**（4-6月）：**水分均衡最为关键**，忽干忽湿会导致严重裂果
- **果实着色期**（6月）：适当控水可增加糖度

### 4. 整形修剪
| 树龄 | 修剪目标 | 修剪方法 |
|------|---------|---------|
| 幼树期（1-3年） | 培养树形 | 定干50-60cm，培养3-4个主枝 |
| 初果期（4-6年） | 扩大树冠 | 短截延长枝，疏除过密枝 |
| 盛果期（7-20年） | 保持丰产 | 采后重剪，疏除交叉枝、病虫枝 |
| 衰老期（>20年） | 更新复壮 | 回缩骨干枝，利用徒长枝更新 |

### 5. 控梢促花
1. **末次秋梢**：控制末次秋梢在10月下旬至11月上旬老熟
2. **冬季控水**：11月至12月保持土壤适度干旱
3. **环割促花**：11月下旬对主干进行环割1圈或螺旋环割1.5圈
4. **化学调控**：秋梢老熟后喷施多效唑500mg/L或稀效唑200mg/L
5. **断根处理**：11月在树冠滴水线内侧挖沟断根，控制营养生长

### 6. 保花保果
| 措施 | 时期 | 操作方法 |
|------|------|---------|
| 放蜂授粉 | 盛花期 | 每10亩放置蜜蜂5-8箱 |
| 人工授粉 | 雌花开放期 | 采集雄花花粉，人工点授 |
| 叶面追肥 | 谢花后 | 喷施0.3%磷酸二氢钾+0.1%硼砂 |
| 生长调节 | 谢花后7天 | 喷施赤霉素20mg/L+细胞分裂素 |
| 环割保果 | 谢花后10-15天 | 对营养枝进行环割1圈 |

### 7. 病虫害防治
| 病虫害 | 为害特点 | 防治要点 |
|--------|---------|---------|
| 霜疫霉病 | 果实、花穗腐烂 | 预防为主，甲霜灵锰锌+代森锰锌轮用 |
| 炭疽病 | 叶片、果实病斑 | 咪鲜胺1500倍液，7-10天喷一次 |
| 藻斑病 | 枝干附着藻类 | 冬季清园，喷施波尔多液 |
| 蒂蛀虫 | 果实蛀食 | 成虫羽化期喷施高效氯氟氰菊酯 |
| 荔枝蝽象 | 吸食花果汁液 | 人工捕杀越冬成虫+药剂防治 |
| 红蜘蛛 | 叶片失绿 | 冬季矿物油清园+生长期阿维菌素 |

## 五、采收与品质保证

### 采收标准
| 指标 | 最优标准 |
|------|---------|
| 果皮颜色 | 鲜红色，果肩带绿（成熟标志） |
| 香气 | 桂花香气浓郁 |
| 可溶性固形物 | 19%以上 |
| 采收时间 | 晴天上午或阴天全天 |

### 采后处理
桂味耐贮运性中等，采后品质下降较快，需注意：
1. **立即预冷**：采后1小时内预冷至4-6℃
2. **冷链运输**：全程2-4℃冷链运输
3. **保鲜期**：2-3天内品质最佳，冷链可维持5-7天
4. **避免堆积**：采后迅速摊晾，避免堆积发热导致褐变

## 六、优缺点分析

### 优点
| 项目 | 说明 |
|------|------|
| 品质极优 | 桂花香独特，肉质爽脆，风味极佳 |
| 焦核率高 | 优质果焦核率60-80%，食用率高 |
| 市场价值高 | 高端鲜食荔枝，售价高 |
| 知名度广 | 消费者认知度极高，品牌价值大 |

### 缺点
| 项目 | 说明 |
|------|------|
| 自花结实率低 | 需配置授粉树，管理成本增加 |
| 大小年明显 | 丰产性不稳定，大小年结果现象突出 |
| 管理要求高 | 对肥水条件要求严格，不适宜粗放管理 |
| 易感炭疽病 | 对炭疽病抗性较差 |
| 耐贮运性一般 | 采后品质下降快，货架期短 |

## 七、区域适应性

### 最适产区
| 地区 | 评价 |
|------|------|
| 广东从化 | 最适产区，品质最优，桂花香气最浓郁 |
| 广东增城 | 优质产区，果品色泽和风味俱佳 |
| 广东东莞 | 传统优质产区 |
| 广东惠东 | 新兴优质产区 |

### 适宜产区
| 地区 | 评价 |
|------|------|
| 广西灵山 | 品质较好，产量稳定 |
| 福建莆田 | 可正常栽培，品质中等 |
| 云南红河 | 新兴产区，发展潜力大 |
| 四川泸州 | 晚熟优势，错峰上市 |

### 不适宜区域
冬季温度过高（最低温>15℃）的地区，花芽分化不良，产量低，不宜发展。
