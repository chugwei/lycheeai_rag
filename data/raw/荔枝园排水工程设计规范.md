# 荔枝园排水工程设计规范

## 摘要

本规范规定了荔枝园排水工程的设计标准、设计要求、排水沟渠设计、暗管排水设计、排水泵站设计、施工要求和验收标准等技术内容。荔枝园排水工程是保障荔枝园免受涝害的重要基础设施，合理的排水系统可有效防止土壤渍涝，确保根系正常生长，提高荔枝产量和品质。本规范适用于平地、丘陵地荔枝园的排水工程设计。

## 1 总则

### 1.1 适用范围

本规范适用于年降水量800mm以上的荔枝产区，包括广东、广西、海南、福建、云南、四川等地区的荔枝园排水工程设计。

### 1.2 设计原则

- 因势利导，充分利用自然排水条件
- 明沟暗管结合，因地制宜选择排水方式
- 灌排结合，灌溉设施与排水设施统筹设计
- 生态排水，保护流域生态环境

### 1.3 设计标准

| 排水标准 | 重现期(年) | 排涝时间(天) | 适用条件 |
|---------|----------|------------|---------|
| 一般果园 | 5-10 | 3-5 | 水资源丰富地区 |
| 规模化果园 | 10-20 | 2-3 | 一般地区 |
| 重要产区 | 20-50 | 1-2 | 经济价值高地区 |

## 2 排水工程组成

### 2.1 排水系统构成

| 组成 | 功能 | 设计要点 |
|------|------|---------|
| 田间排水沟 | 排除田面多余积水 | 浅沟(30-50cm深) |
| 园间排水沟 | 汇集田间排水 | 中沟(60-80cm深) |
| 支排水沟 | 汇集园间排水 | 深沟(1.0-1.5m深) |
| 干排水沟 | 汇集全园排水 | 主沟(1.5-2.0m深) |
| 排水泵站 | 低洼地区强排 | 根据地形确定 |
| 暗管排水系统 | 降低地下水位 | PVC波纹管，埋深1.0-1.5m |

### 2.2 排水沟渠等级

| 沟渠等级 | 服务面积(亩) | 底宽(m) | 深(m) | 纵坡 |
|---------|------------|---------|------|------|
| 田间沟 | 5-10 | 0.3-0.4 | 0.3-0.5 | ≥0.05% |
| 园间沟 | 20-50 | 0.5-0.8 | 0.6-1.0 | ≥0.10% |
| 支沟 | 50-200 | 0.8-1.2 | 1.0-1.5 | ≥0.15% |
| 干沟 | 200+ | 1.2-2.0 | 1.5-2.5 | ≥0.20% |

## 3 排水沟渠设计

### 3.1 设计流量计算

排水沟渠设计流量采用公式：

**Q = q × A / 3.6**

其中：Q为设计流量(m³/s)，q为设计排水模数(L/(s·ha))，A为汇水面积(ha)。

| 地形条件 | 排水模数q(L/(s·ha)) | 备注 |
|---------|-------------------|------|
| 平原缓坡 | 10-20 | 地下排水为主 |
| 丘陵坡地 | 30-60 | 地表排水为主 |
| 山地 | 50-100 | 雨水集中 |

### 3.2 沟渠断面设计

| 断面类型 | 边坡比 | 适用条件 | 优缺点 |
|---------|--------|---------|--------|
| 矩形断面 | 1:0 | 城市/硬地 | 占地少，开挖量大 |
| 梯形断面 | 1:1-1:1.5 | 土质沟渠 | 稳定好，占地较多 |
| 复式断面 | 多级 | 大流量 | 适应不同流量 |

### 3.3 沟渠流速控制

| 土壤类型 | 最大流速(m/s) | 最小流速(m/s) |
|---------|-------------|-------------|
| 砂土 | 1.2 | 0.4 |
| 壤土 | 1.5 | 0.5 |
| 粘土 | 2.0 | 0.6 |
| 混凝土衬砌 | 3.0 | 0.6 |

## 4 暗管排水设计

### 4.1 暗管系统组成

| 组成部分 | 材料规格 | 功能 |
|---------|---------|------|
| 横向暗管 | PVC波纹管φ100-150mm | 汇集土层水分 |
| 纵向集水管 | PVC实壁管φ160-200mm | 汇集横向暗管水 |
| 出水管 | PVC实壁管φ200mm | 将水排入排水沟 |
| 检查井 | 砖砌φ600mm | 清理维护 |

### 4.2 暗管设计参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 埋深 | 1.0-1.5m | 根系以下 |
| 间距 | 8-15m | 根据土壤渗透性 |
| 纵向坡度 | ≥0.3% | 保证自流 |
| 管材 | PVC波纹穿孔管 | 抗腐蚀 |
| 反滤层 | 碎石或无纺布 | 防止堵塞 |

### 4.3 暗管间距计算

暗管间距采用Hooghoudt公式：

**S = 8Kh × (H² + 2Hd) / q**

其中：S为暗管间距(m)，Kh为水平渗透系数(m/d)，H为积水层厚度(m)，d为暗管半径(m)，q为排水流量(L/(s·ha))。

| 土壤类型 | 渗透系数Kh(m/d) | 暗管间距(m) |
|---------|---------------|-----------|
| 砂土 | 5-20 | 15-25 |
| 砂壤土 | 1-5 | 10-15 |
| 壤土 | 0.3-1 | 6-10 |
| 粘壤土 | 0.05-0.3 | 4-6 |

## 5 排水泵站设计

### 5.1 泵站设计参数

| 参数 | 确定方法 |
|------|---------|
| 设计流量 | 排水沟渠设计流量×1.2 |
| 扬程 | 外河最高水位+渠内水位差+管路损失 |
| 运行方式 | 汛期连续运行，平时备用 |
| 电源 | 双电源或柴油机备用 |

### 5.2 泵站设备选型

| 设备 | 选型要求 |
|------|---------|
| 水泵 | 流量≥设计流量，扬程≥计算扬程 |
| 电机 | 额定功率≥水泵功率×1.1 |
| 启闭机 | 手动或电动 |
| 控制柜 | 自动/手动切换 |

## 6 施工要求

### 6.1 沟渠施工

| 工序 | 技术要求 |
|------|---------|
| 测量放线 | 按设计坐标放线，允许偏差±5cm |
| 开挖 | 分层开挖，边坡稳定 |
| 衬砌 | 浆砌石或混凝土衬砌，厚度≥15cm |
| 回填 | 分层压实，密实度≥90% |
| 清理 | 清除杂物、杂草 |

### 6.2 暗管施工

| 工序 | 技术要求 |
|------|---------|
| 管沟开挖 | 按设计深度和宽度开挖 |
| 垫层铺设 | 10cm砂砾垫层 |
| 管道安装 | 波纹管连接，坡度控制 |
| 反滤层 | 碎石或无纺布包裹 |
| 回填 | 先填管沟两侧，再回填上部 |
| 检查 | 通水试验，无渗漏 |

## 7 验收标准

| 验收项目 | 标准要求 |
|---------|---------|
| 排水沟断面尺寸 | 与设计偏差≤5% |
| 沟渠纵坡 | 与设计偏差≤10% |
| 暗管埋深 | 与设计偏差≤5cm |
| 排水通畅性 | 设计流量下无积水 |
| 抗冲刷性 | 大流量下边坡无冲刷 |
| 防渗效果 | 衬砌沟无渗漏 |
