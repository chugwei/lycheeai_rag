# 灵山荔枝质量标准

> 本标准规定了地理标志产品灵山荔枝的术语和定义、保护范围、品种特征、质量等级、品质要求、检验方法及标志包装运输要求。灵山荔枝是广西壮族自治区钦州市灵山县的特色农产品，以其悠久的栽培历史和优良的品质著称。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于国家地理标志产品灵山荔枝的生产、流通和销售。

## 二、地理标志产品保护范围

### 保护区域
灵山荔枝地理标志产品保护范围限于广西壮族自治区钦州市灵山县行政区域内，包括灵城镇、新圩镇、檀圩镇、那隆镇、武利镇、伯劳镇、陆屋镇、沙坪镇、平山镇、石塘镇、烟墩镇、太平镇等管辖区域。

### 产地环境条件
| 环境因子 | 适宜条件 | 特征说明 |
|---------|---------|---------|
| 年均气温(°C) | 21.7-22.5 | 热量充足 |
| ≥10°C年积温 | 7500-8000 | 生长期长 |
| 年降雨量(mm) | 1600-1800 | 雨量充沛 |
| 无霜期(天) | 350-365 | 少霜冻 |
| 土壤类型 | 赤红壤、砖红壤 | pH 5.0-6.0，土层深厚 |

## 六、标志、包装与运输

### 专用标志使用
- 使用国家地理标志产品专用标志
- 标志应标注在包装的显著位置
- 标志使用需经灵山县地理标志产品保护管理机构批准

### 包装标识内容
| 标识项目 | 内容要求 |
|---------|---------|
| 产品名称 | 灵山荔枝（注明品种） |
| 地理标志 | 国家地理标志保护产品 |
| 等级 | 特级/一级/二级 |
| 产地 | 广西灵山县（注明具体乡镇） |
| 净重 | kg |
| 采摘日期 | 年-月-日 |
| 保质期 | 建议冷藏食用期限 |
| 生产者 | 名称、地址、联系电话 |
| 执行标准 | DB45/T XXX |

### 运输贮藏要求
- 运输工具：冷藏车，温度2-4°C
- 贮藏条件：2-3°C，RH 90-95%
- 保鲜期：从采收起，特级≤7天，一级≤10天，二级≤12天
- 运输时限：采后24小时内发货

## 七、文化价值

灵山县种植荔枝历史悠久，史料记载始于唐代，距今已有1300多年历史。灵山荔枝以"灵山香荔"为代表品种，果皮暗红、肉爽味甜、香气独特。灵山县被誉为"中国荔枝之乡"，全县荔枝种植面积超过40万亩，年产量约30万吨。灵山荔枝于2007年获国家地理标志保护产品认证。
