# 荔枝植物学基础

> 荔枝（*Litchi chinensis* Sonn.）属无患子科(Sapindaceae)荔枝属植物，是中国南方最具代表性的热带亚热带果树之一。了解荔枝的植物学特征是科学栽培管理的基础。

---

## 一、分类学地位

| 分类等级 | 名称 |
|---------|------|
| 界 | 植物界 Plantae |
| 门 | 被子植物门 Angiospermae |
| 纲 | 双子叶植物纲 Dicotyledoneae |
| 目 | 无患子目 Sapindales |
| 科 | 无患子科 Sapindaceae |
| 属 | 荔枝属 *Litchi* |
| 种 | 荔枝 *Litchi chinensis* Sonn. |

### 变种及近缘种
- **荔枝（原变种）** *Litchi chinensis* var. *chinensis* —— 中国主栽类型
- **海南荔枝（变种）** *Litchi chinensis* var. *euspontanea* —— 分布于海南，果小
- **菲律宾荔枝（变种）** *Litchi chinensis* var. *philippinensis* —— 菲律宾分布
- **龙荔（近缘种）** *Dimocarpus confinis* —— 与荔枝近缘，常作砧木

## 二、根的形态与特性

### 根系结构
荔枝为**深根性**果树，根系由骨干根、侧根和须根组成：

| 根类型 | 特征 | 功能 |
|-------|------|------|
| **主根** | 垂直向下生长，深度可达2-3m | 固定树体，吸收深层水分 |
| **骨干根** | 水平扩展，延伸至树冠滴水线外 | 支撑树体，运输养分 |
| **须根** | 密集分布在20-60cm土层 | 主要吸收根，吸收水分和矿质营养 |
| **菌根** | 与真菌共生形成 | 增强磷吸收，提高抗逆性 |

### 根系分布特征
- **水平分布**：主要分布在树冠滴水线内外0-1m范围
- **垂直分布**：80%以上的吸收根集中在20-60cm土层
- **根幅**：成年树的根幅可达树冠直径的2-3倍

### 根系生长规律
- **年生长周期**：有3次生长高峰
  - 第1次：2-4月（春梢萌发前）
  - 第2次：5-6月（果实发育期）
  - 第3次：9-11月（秋梢老熟后）
- **最适温度**：25-30°C
- **最适pH**：5.5-6.5
- **需氧性**：荔枝根系对土壤通气性要求高，缺氧条件下易烂根

## 三、枝干形态与特性

### 树冠结构
荔枝为常绿乔木，树冠自然半圆形或圆头形：

| 树龄 | 树高(m) | 冠幅(m) | 树形特征 |
|------|--------|---------|---------|
| 幼树(1-3年) | 1.5-2.5 | 1.0-2.0 | 直立生长，分枝少 |
| 初果树(4-6年) | 2.5-3.5 | 2.5-4.0 | 树冠形成，开张度增加 |
| 盛果树(7-15年) | 3.0-5.0 | 4.0-6.0 | 树冠饱满，开张 |
| 老树(15年以上) | 5.0-10.0 | 6.0-12.0 | 树冠庞大，主干粗壮 |

### 枝条类型
| 枝类型 | 特征 | 功能 |
|-------|------|------|
| **营养枝** | 只长叶不开花 | 扩大树冠，制造养分 |
| **结果枝** | 着生花穗并结果 | 生殖生长 |
| **徒长枝** | 直立生长，节间长，叶片大 | 扰乱树形，需控制 |
| **秋梢（结果母枝）** | 秋季抽生，次年开花结果 | 最重要的结果枝类型 |

### 枝梢生长规律
- **年抽梢次数**：幼树年抽梢4-5次，成年树2-3次
- **每次抽梢长度**：15-30cm
- **梢期**：春梢(2-3月)、夏梢(4-6月)、秋梢(7-9月)、冬梢(10-12月)
- **自剪现象**：新梢顶端停止生长后，顶芽自行脱落（荔枝的典型特征）

## 四、叶的形态与生理

### 叶片特征
| 特征 | 描述 |
|------|------|
| **叶型** | 偶数羽状复叶，小叶2-4对 |
| **小叶形状** | 长椭圆形至披针形 |
| **叶长** | 6-15cm |
| **叶宽** | 2-5cm |
| **叶色** | 幼叶浅红色→淡绿色→深绿色（老熟） |
| **叶脉** | 中脉明显，侧脉羽状 |
| **叶缘** | 全缘，稍反卷 |
| **叶质** | 革质，有光泽 |
| **叶柄** | 短，约0.5-1.0cm |

### 光合特性
- **光饱和点**：约400-600 μmol·m⁻²·s⁻¹（荔枝为耐荫果树）
- **光补偿点**：约20-30 μmol·m⁻²·s⁻¹
- **最适光合温度**：25-30°C
- **叶片寿命**：12-18个月，老叶在新梢抽发期集中脱落
- **光合产物分配**：果实发育期50-70%的光合产物运往果实

### 叶片诊断（营养诊断）
参见《荔枝营养诊断与缺素矫正技术.md》

## 五、花的形态与生物学

### 花器结构
荔枝的花为**杂性同株**，同一花穗上存在不同类型的花：

| 花类型 | 雄蕊 | 雌蕊 | 比例 | 功能 |
|-------|------|------|------|------|
| **雄花** | 发育正常(7-8枚) | 退化 | 60-80% | 提供花粉 |
| **雌花** | 退化(花丝短) | 发育正常(2-3心皮) | 10-20% | 受精结果 |
| **两性花** | 正常 | 正常 | 5-10% | 可自花受精 |

### 花穗特征
| 特征 | 描述 |
|------|------|
| **花穗类型** | 圆锥花序，顶生或腋生 |
| **花穗大小** | 长10-30cm，有花数百至数千朵 |
| **小花直径** | 4-6mm |
| **花色** | 黄白色至淡绿色 |
| **花期** | 单花花期1-3天，整穗花期10-20天 |
| **雌雄异熟** | 同一花穗雌雄蕊不同时成熟 |

### 开花顺序
```
花穗基部 → 花穗中部 → 花穗顶部（由下而上开放）
雄花先开（3-5天）→ 雌花开放（1-2天）→ 雄花再开（3-5天）
```

### 花芽分化过程
| 分化阶段 | 时间 | 形态特征 |
|---------|------|---------|
| 生理分化期 | 11月-12月上旬 | 芽体内部分生化变化，不可见 |
| 形态分化期 | 12月中旬-1月 | 生长点突起，花序原基形成 |
| 花序分化期 | 1-2月 | 花轴伸长，各级分枝形成 |
| 花器分化期 | 2月 | 花萼→花瓣→雄蕊→雌蕊依次分化 |
| 花器官成熟 | 3月 | 花粉粒成熟，胚囊发育完善 |

## 六、果实的形态与发育

### 果实结构
荔枝果实为**核果**状，由果柄、果皮（ pericarp）、果肉（假种皮， aril）和种子组成：

| 果皮部分 | 特征 | 功能 |
|---------|------|------|
| **果皮/果壳** | 革质，龟裂片状 | 保护，蒸腾 |
| **龟裂片** | 隆起或平坦的瘤状突起 | 品种特征 |
| **果肉（假种皮）** | 由珠柄发育而来，乳白色/蜡白色 | 食用部分 |
| **种子** | 褐色至深褐色 | 繁殖器官 |

### 果实发育阶段
荔枝果实发育呈**S形曲线**，分3个阶段：

| 阶段 | 时间(谢花后天数) | 发育内容 | 历时 |
|------|----------------|---------|------|
| **第1阶段**（缓慢生长期） | 0-20天 | 果皮细胞分裂，胚乳发育，果实体积增长缓慢 | 约20天 |
| **第2阶段**（快速生长期） | 20-50天 | 果肉（假种皮）细胞快速膨大，果核硬化，积累糖分 | 约30天 |
| **第3阶段**（成熟期） | 50-75天 | 糖分快速积累，酸度下降，色素合成，果皮着色 | 约15-20天 |

### 不同品种果实发育期
| 品种 | 谢花至成熟天数 | 单果重(g) | 果肉率(%) | 种子特征 |
|------|-------------|----------|----------|---------|
| 三月红 | 55-60 | 20-30 | 70-75 | 大核 |
| 白糖罂 | 58-63 | 18-22 | 72-76 | 大核/小核 |
| 妃子笑 | 60-65 | 25-30 | 78-82 | 大核为主 |
| 黑叶 | 65-70 | 18-22 | 70-75 | 大核 |
| 鸡嘴荔 | 62-68 | 20-25 | 75-80 | 小核 |
| 桂味 | 68-73 | 17-20 | 75-80 | 焦核为主 |
| 糯米糍 | 70-75 | 20-25 | 82-86 | 焦核 |
| 增城挂绿 | 70-75 | 15-20 | 70-75 | 大核/小核 |

### 裂果生理
- 裂果敏感期：果实快速膨大期（谢花后30-55天）
- 裂果原因：果肉膨大速度快于果皮伸展速度
- 品种差异：糯米糍裂果率最高(20-30%)，妃子笑裂果率较低(5-10%)
- 预防措施：保持土壤水分均衡、增施钙肥、套袋、避雨栽培

## 七、种子的生物学特性

### 种子特征
| 特征 | 描述 |
|------|------|
| **形状** | 椭圆形至扁卵形 |
| **大小** | 长1.5-2.5cm，宽1.0-1.5cm |
| **重量** | 大核种0.5-1.5g/粒 |
| **颜色** | 新鲜种子深褐色有光泽 |
| **种皮** | 薄，革质 |
| **种仁** | 乳白色，含丰富淀粉 |
| **焦核** | 种子退化（仅种皮，无种仁） |

### 种子活力
- **寿命极短**：在自然条件下4-5天后活力丧失80%以上
- **发芽适温**：25-28°C
- **发芽时间**：播种后10-15天开始发芽
- **保湿方法**：采种后立即播种或用湿沙贮藏（不超过7天）
- **贮藏条件**：4°C保湿可延长寿命至15-20天

## 八、荔枝生长与结果习性

### 年生长周期（广东地区）
| 月份 | 物候期 | 主要生命活动 |
|------|-------|------------|
| 1月 | 花芽分化/休眠期 | 花芽形态分化，营养积累 |
| 2月 | 花穗生长期 | 花穗抽生，花器发育 |
| 3月 | 开花期 | 开花，授粉受精 |
| 4月 | 幼果期 | 第一次生理落果，胚发育 |
| 5月 | 果实膨大期 | 果肉快速生长，种子硬化 |
| 6月 | 成熟期 | 果实成熟，采收 |
| 7-8月 | 秋梢期 | 采果后修剪，第一次秋梢抽发 |
| 8-9月 | 秋梢期 | 第二次秋梢抽发 |
| 9-10月 | 秋梢老熟/花芽分化前期 | 秋梢老熟，开始花芽生理分化 |
| 11-12月 | 花芽分化期 | 花芽分化，冬梢控制 |

### 结果习性
- **结果母枝**：以秋梢为主（占总结果枝数80%以上）
- **花芽着生**：顶生花序，结果枝顶芽抽生花穗
- **坐果率**：一般品种的雌花坐果率仅1-5%
- **自然落果**：3次生理落果（谢花后7-15天，20-35天，采前）
- **大小年结果**：荔枝普遍存在大小年现象，可通过管理减轻
- **经济寿命**：盛产期可达30-50年

## 九、荔枝的生态适应性

### 气候要求
| 生态因子 | 适宜范围 | 耐受极限 |
|---------|---------|---------|
| **年均温** | 20-24°C | 最低18°C |
| **最冷月均温** | 8-15°C | >5°C |
| **极端低温** | >0°C | 幼树-2°C，成年树-4°C |
| **年降雨量** | 1200-1800mm | 800-2500mm |
| **相对湿度** | 75-85% | - |
| **年日照时数** | 1800-2200小时 | - |
| **海拔** | <500m | 可至800m |

### 土壤要求
| 因子 | 适宜 | 不适宜 |
|------|------|--------|
| **土壤类型** | 深厚冲积土、砂壤土、红壤 | 纯砂土、重粘土 |
| **pH** | 5.5-6.5 | <4.5或>7.5 |
| **有机质** | >1.5% | <0.8% |
| **地下水位** | >1.0m | <0.5m（积水） |
| **排水** | 良好 | 积水 |

### 中国荔枝适宜种植区
| 区域 | 省份 | 气候特点 | 主栽品种 |
|------|------|---------|---------|
| **华南区** | 广东、广西、海南、福建 | 热带亚热带气候，温暖湿润 | 妃子笑、桂味、糯米糍、黑叶 |
| **西南区** | 云南、四川、贵州 | 高原立体气候，冬春干旱 | 妃子笑、桂味、大红袍 |
| **华东区** | 浙江南部 | 亚热带北缘，冬季有冻害风险 | 少量种植 |
