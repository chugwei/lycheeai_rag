# 荔枝寒害防御技术规程

## 摘要

本规程规定了荔枝园寒害防御的技术要求，包括寒害预警、防寒保温、应急防护、冻后恢复和灾后管理等技术内容。荔枝为亚热带果树，耐寒能力较弱，当气温低于5℃时即可能出现寒害，-2℃以下可造成严重冻害甚至整株死亡。本规程适用于广东、广西、海南、福建、云南、四川等荔枝主产区的寒害防御，通过科学的防御措施，可将寒害损失降低60%以上。

## 1 总则

### 1.1 适用范围

适用于中国南方荔枝产区冬季寒害的预防和防御。

### 1.2 寒害分级

| 等级 | 气温范围(℃) | 持续时间 | 危害程度 |
|------|-----------|---------|---------|
| 轻度寒害 | 0-5 | 1-3天 | 嫩梢叶片受损伤 |
| 中度寒害 | -2-0 | 3-5天 | 枝条受冻，落叶 |
| 重度寒害 | -5--2 | 5-10天 | 大枝受冻，树冠受损 |
| 极重寒害 | <-5 | >10天 | 主干受冻，整株死亡风险 |

### 1.3 荔枝各生育期耐寒能力

| 生育期 | 临界温度(℃) | 致死温度(℃) |
|--------|-----------|-----------|
| 成年大树 | -2~-3 | -5~-7 |
| 成年小树 | -1~-2 | -4~-5 |
| 幼树(1-3年) | 0~-1 | -3~-4 |
| 萌芽期 | 3~5 | 0~2 |
| 花期 | 5~8 | 2~4 |
| 幼果期 | 3~5 | 0~2 |

## 2 寒害预警

### 2.1 预警指标

| 预警指标 | 阈值 | 数据来源 |
|---------|------|---------|
| 最低气温预报 | <8℃ | 气象部门 |
| 连续低温天数 | ≥3天 | 气象预报 |
| 辐射冷却强度 | >5℃温差 | 本地观测 |
| 风速 | <2m/s | 气象站 |
| 湿度 | >80% | 气象站 |

### 2.2 预警等级

| 等级 | 温度预报 | 颜色 | 措施 |
|------|---------|------|------|
| 四级 | 最低5-8℃ | 蓝色 | 准备防寒物资 |
| 三级 | 最低2-5℃ | 黄色 | 启动防寒措施 |
| 二级 | 最低-2-2℃ | 橙色 | 全面防寒，人员到位 |
| 一级 | 最低<-2℃ | 红色 | 紧急防护，连续作业 |

### 2.3 预警发布

气象预警 → 果园值班员接收 → 判断等级 → 启动预案 → 通知管理人员 → 组织防护作业 → 跟踪监测 → 解除预警

## 3 防寒保温技术

### 3.1 覆盖保温

| 覆盖方式 | 材料 | 适用树龄 | 降温幅度 | 成本(元/亩) |
|---------|------|---------|---------|-----------|
| 地膜覆盖 | 农用塑料地膜 | 幼树 | 1-2℃ | 50-100 |
| 秸秆覆盖 | 稻草/玉米秆 | 成年树 | 1-3℃ | 30-60 |
| 无纺布覆盖 | 农用无纺布 | 幼树 | 2-4℃ | 80-150 |
| 树枝覆盖 | 松枝/棕榈叶 | 成年树 | 1-2℃ | 20-50 |

### 3.2 熏烟保温

| 参数 | 技术要求 |
|------|---------|
| 点火时间 | 气温降至5℃前30分钟 |
| 烟堆密度 | 每亩3-5个，间距20-30m |
| 燃料 | 杂草、秸秆、松枝(避免塑料) |
| 烟堆高度 | 1.5-2.0m |
| 点火顺序 | 从下风方向开始，逆风点燃 |
| 维持时间 | 通宵至日出 |
| 升温效果 | 提高气温1-3℃ |

### 3.3 喷水保温

| 方式 | 技术要求 | 效果 |
|------|---------|------|
| 树干喷水 | 持续喷湿树干和主枝 | 延迟降温2-4℃ |
| 树冠喷淋 | 喷淋树冠，形成冰衣保护 | 防止冰晶损伤 |
| 喷雾降温 | 雾状水增加湿度 | 减少辐射冷却 |
| 注意事项 | 喷水时间>结冰时间，避免冻伤 | |

### 3.4 搭建防风障

| 参数 | 技术要求 |
|------|---------|------|
| 材料 | 竹竿+塑料薄膜/无纺布 |
| 高度 | 3-4m |
| 间距 | 每30-50m设一道 |
| 方向 | 迎风面设置 |
| 效果 | 减少寒风侵袭，保温1-2℃ |

## 4 应急防护技术

### 4.1 防冻剂应用

| 防冻剂类型 | 浓度 | 施用时 | 效果 |
|-----------|------|--------|------|
| 磷酸二氢钾 | 0.3%-0.5% | 寒潮前7天 | 增强抗寒性 |
| 芸苔素内酯 | 0.01% | 寒潮前3-5天 | 提高抗逆性 |
| 氨基酸叶面肥 | 按说明书 | 寒潮前5天 | 提高树体抗性 |
| 乙烯利 | 100-150mg/L | 寒潮前10天 | 促进老熟 |

### 4.2 树干涂白

| 涂白剂配方 | 石灰:硫磺:食盐:水 = 10:1:1:40 |
|-----------|---------------------------|
| 涂刷高度 | 树干基部1-1.5m |
| 涂刷时间 | 寒潮前10-15天 |
| 效果 | 反射阳光，减少昼夜温差 |

### 4.3 幼树专项保护

| 保护措施 | 操作方法 | 效果 |
|---------|---------|------|
| 树干包裹 | 草绳或保温棉包裹树干 | 防止冻裂 |
| 设挡风障 | 树干周围立竹片挡风 | 减少寒风 |
| 覆盖根部 | 根部覆盖30cm厚草帘 | 保护根系 |
| 搭建小棚 | 幼树周围搭小型保温棚 | 全面保护 |

## 5 冻后恢复技术

### 5.1 冻害诊断

| 部位 | 轻微冻害 | 中度冻害 | 严重冻害 |
|------|---------|---------|---------|
| 叶片 | 边缘枯焦 | 大部分枯死 | 全部脱落 |
| 嫩梢 | 尖端受冻 | 1/3受冻 | 全部受冻 |
| 枝条 | 轻微褐变 | 1/2褐变 | 全部褐变 |
| 树干 | 无影响 | 局部开裂 | 大面积开裂 |

### 5.2 恢复措施

| 措施 | 操作内容 | 时间 |
|------|---------|------|
| 伤口处理 | 清除枯死组织，涂伤口愈合剂 | 冻后3-5天 |
| 疏枝修剪 | 剪除冻死枝条，保留活组织 | 冻后10-15天 |
| 根部培土 | 培土5-10cm保温保湿 | 冻后当天 |
| 喷水增湿 | 叶面喷水2-3天 | 冻后1-3天 |
| 追施肥 | 施速效肥恢复树势 | 冻后15-20天 |

### 5.3 恢复时间表

| 恢复阶段 | 时间 | 操作重点 |
|---------|------|---------|
| 紧急期 | 冻后0-3天 | 伤口处理、喷水 |
| 清理期 | 冻后3-10天 | 清除枯死组织 |
| 恢复期 | 冻后10-30天 | 修剪、施肥 |
| 生长期 | 冻后30天+ | 正常管理 |
