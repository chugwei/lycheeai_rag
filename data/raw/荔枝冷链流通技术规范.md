# 荔枝冷链流通技术规范

> 本标准规定了荔枝鲜果冷链流通的各个环节技术要求，包括采收、预冷、贮藏、运输、销售等全过程的温度控制和管理要求。荔枝是极不耐贮运的水果，完善的冷链体系是保障荔枝品质的关键。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝鲜果从采收到消费全过程的冷链流通，包括产地预冷、冷库贮藏、冷藏运输、冷柜销售等环节。

### 术语定义
| 术语 | 定义 |
|-----|------|
| 冷链流通 | 荔枝从采收到消费全过程持续处于适宜低温环境 |
| 预冷 | 采后迅速去除田间热，使果心温度降至适宜温度的过程 |
| 田间热 | 采后果实从田间带入的热量 |
| 冷害 | 荔枝在冰点以上的低温下发生的生理伤害 |
| 冷链断裂 | 冷链流通中某一环节温度失控的现象 |

---

## 二、冷链流通总体要求

### 冷链各环节温度要求
| 流通环节 | 目标温度(°C) | 时间要求 | 关键控制点 |
|---------|-------------|---------|-----------|
| 采收 | <30 | 清晨采收，1小时内入遮荫处 | 避免日晒 |
| 预冷 | 2-4 | 采后2小时内完成 | 降温速度 |
| 贮藏 | 2-4 | 按品种确定期限 | 温度稳定 |
| 运输 | 2-4 | 全程温控 | 温度记录 |
| 批发 | 2-5 | <48小时 | 周转速度 |
| 零售 | 3-6 | <24小时 | 冷柜性能 |
| 消费 | 4-8 | 当日食用或冷藏 | 家用冰箱 |

### 冷链流通模式
```
模式一（短途）: 采收 → 预冷 → 常温运输(4h内) → 销售
模式二（中长途）: 采收 → 预冷 → 冷库贮藏 → 冷藏车运输 → 批发/零售
模式三（出口）: 采收 → 真空预冷 → 气调贮藏 → 冷藏集装箱 → 目的地
```

## 三、预冷技术

### 预冷方法比较
| 预冷方法 | 降温时间 | 设备投资 | 运行成本 | 失水率(%) | 适用规模 |
|---------|---------|---------|---------|-----------|---------|
| 强制通风预冷 | 3-6小时 | 低 | 低 | 1-3 | 中小规模 |
| 差压预冷 | 1-3小时 | 中 | 中 | 1-2 | 中大规模 |
| 真空预冷 | 20-40分钟 | 高 | 高 | 2-5 | 出口/高端 |
| 冷水预冷 | 10-30分钟 | 中 | 中 | 0 | 中大规模 |
| 冷库预冷 | 12-24小时 | 低 | 低 | 1-2 | 小规模 |

### 强制通风预冷技术参数
| 参数项目 | 技术要求 |
|---------|---------|
| 冷风温度(°C) | 1-2 |
| 风速(m/s) | 3-5 |
| 相对湿度(%) | 90-95 |
| 包装开孔率(%) | ≥15 |
| 冷却时间(小时) | 3-6 |
| 终温(°C) | 果心温度≤5 |

### 预冷操作规范
- **采后时限**：采后2小时内开始预冷，越早越好
- **装载方式**：果箱有间隙摆放，保证冷风流通
- **堆码要求**：堆高不超过8层，每排之间留10-15cm风道
- **预冷终点**：果心温度降至5°C以下
- **预冷后处理**：预冷后立即转入冷藏库或直接装车

## 四、冷库贮藏

### 冷库技术参数
| 参数 | 要求 |
|-----|------|
| 库温(°C) | 2-4（±0.5） |
| 相对湿度(%) | 90-95 |
| 冷风循环次数(次/小时) | 20-30 |
| 温度传感器精度 | ±0.3°C |
| 温度记录频率 | 每30分钟1次 |
| 库体保温厚度 | ≥100mm聚氨酯 |

### 贮藏管理要求
| 管理项目 | 操作要求 |
|---------|---------|
| 入库前 | 预冷至5°C以下的果实方可入库 |
| 码垛要求 | 距墙20cm，距顶50cm，间距10cm |
| 堆码高度 | 不超过5层（泡沫箱），不超过4层（塑料筐） |
| 温湿度监测 | 每日记录3次（早、中、晚） |
| 抽检频率 | 每3天抽检1次品质变化 |
| 出库要求 | 出库前不开冷库门，减少温度波动 |
| 清洁消毒 | 每月消毒1次，使用过氧乙酸或次氯酸钠 |

### 不同品种贮藏期
| 品种 | 最适温度(°C) | 适合湿度(%) | 贮藏期(天) | 注意事项 |
|-----|-------------|------------|-----------|---------|
| 妃子笑 | 2-3 | 90-95 | 20-25 | 贮前需精选中大果 |
| 桂味 | 2-3 | 90-95 | 15-20 | 容易失水 |
| 糯米糍 | 3-4 | 90-95 | 10-15 | 皮薄，易机械伤 |
| 黑叶 | 2-4 | 90-95 | 25-30 | 耐贮性好 |
| 白糖罂 | 2-4 | 90-95 | 15-20 | 品质优良 |
| 三月红 | 3-5 | 90-95 | 10-15 | 早熟品种，耐贮性差 |

## 五、冷藏运输

### 运输设备要求
| 运输工具 | 温控能力 | 适用距离 | 装载量 |
|---------|---------|---------|-------|
| 冷藏车(机械制冷) | ±1°C | 500km以上 | 5-30吨 |
| 冷藏车(蓄冷板) | ±2°C | 200-500km | 3-10吨 |
| 冷藏集装箱 | ±0.5°C | 海运(出口) | 20-40英尺 |
| 保温车(加冰) | ±3°C | 200km以下 | 2-8吨 |

### 运输操作规范
| 操作环节 | 技术要求 |
|---------|---------|
| 装车前 | 冷藏车预冷至2-4°C（预冷时间≥30分钟） |
| 装载温度 | 果心温度≤5°C |
| 装载方式 | 留风道，不超载，轻装轻卸 |
| 装载量 | 不超过额定载重的80% |
| 运输温度 | 2-4°C，维持恒定 |
| 温度监测 | 配备自动温度记录仪，每1小时记录1次 |
| 运输时长 | 装载后6小时内必须出发，直达目的地 |
| 途中管理 | 尽量减少开门次数，每次开门不超过5分钟 |

### 温度异常处理
| 异常情况 | 处理方法 |
|---------|---------|
| 温度>6°C持续30分钟 | 检查制冷系统，加速冷风循环 |
| 温度>8°C持续1小时 | 调整制冷设定，通知目的地做好快速周转准备 |
| 温度<1°C持续30分钟 | 调整温度设定，防止冷害 |
| 制冷系统故障 | 就近维修，如无法及时修复需就近卸载入库 |
| 长时间堵车 | 减少开门，若超过4小时需就近寻找冷库存放 |

## 六、批发与零售冷链

### 批发市场要求
| 项目 | 要求 |
|-----|------|
| 卸货区温度 | 应设卸货月台，有门帘或对接密封 |
| 周转冷库 | 温度2-5°C，周转期不超过48小时 |
| 陈列温度 | 2-5°C |
| 销售时限 | 批发后24小时内到零售端 |

### 零售终端要求
| 项目 | 要求 |
|-----|------|
| 冷柜类型 | 风冷式冷藏柜，温度3-6°C |
| 陈列方式 | 单层摆放，避免堆叠挤压 |
| 补货管理 | 少量多次，避免冷柜超载 |
| 温度监测 | 每日检查并记录冷柜温度 |
| 货架期 | 从出库到销售完毕不超过24小时 |
| 退货处理 | 货架期超期或品质下降的退货及时处理 |

## 七、冷链质量追溯

### 温度记录管理
| 记录环节 | 记录内容 | 记录保存期 |
|---------|---------|-----------|
| 产地预冷 | 品种、数量、预冷时间、终温 | ≥2年 |
| 冷库贮藏 | 入库时间、库温、湿度、出库时间 | ≥2年 |
| 冷藏运输 | 装车时间、运输温度、到货时间 | ≥2年 |
| 批发零售 | 到货温度、冷柜温度、销售记录 | ≥1年 |

### 冷链断裂风险评估
| 风险环节 | 风险等级 | 预防措施 |
|---------|---------|---------|
| 采收至预冷 | 高 | 缩短田间停留时间，遮荫处理 |
| 预冷至入库 | 中 | 预冷后及时入库 |
| 出库至装车 | 中 | 使用保温中转区 |
| 卸货至入库 | 高 | 卸货月台配置冷风幕 |
| 冷柜故障 | 中 | 备用冷柜，定期维护 |

## 八、冷链设备维护

### 设备维护计划
| 设备类型 | 日常维护 | 定期保养 | 大修周期 |
|---------|---------|---------|---------|
| 压缩机组 | 检查运行参数 | 每季度清洗冷凝器 | 每3年 |
| 冷风机 | 检查结霜情况 | 每月清洗滤网 | 每年检修 |
| 温控系统 | 每日核对温度 | 每月校准传感器 | 每半年 |
| 冷藏车制冷机 | 发车前检查 | 每3个月保养 | 每年大修 |
| 冷柜 | 每日温度检查 | 每月除霜清洗 | 每年检修 |
