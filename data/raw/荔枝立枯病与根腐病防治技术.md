# 荔枝立枯病与根腐病防治技术

## 摘要

荔枝立枯病和根腐病是幼苗和幼树期的主要土传病害，主要由镰刀菌（*Fusarium* spp.）、腐霉菌（*Pythium* spp.）和立枯丝核菌（*Rhizoctonia* spp.）引起。病害导致根系腐烂、茎基部坏死，严重时全株枯死。本文系统阐述两种病害的病原、发病规律、诊断和综合防治技术。

## 1. 病原生物学

### 1.1 病原菌种类

| 病原菌 | 病害类型 | 特征 |
|-------|---------|------|
| *Fusarium oxysporum* f. sp. *litchi* | 根腐病 | 产生镰刀形分生孢子，暗色厚垣孢子 |
| *Pythium aphanidermatum* | 根腐病 | 产生游动孢子和厚垣孢子 |
| *Rhizoctonia solani* | 立枯病 | 菌丝褐色，形成菌核 |
| *Phytophthora* spp. | 根腐病 | 产生游动孢子，侵染力强 |

### 1.2 镰刀菌根腐病病原特性

| 项目 | 特征 |
|-----|------|
| 菌丝 | 淡粉红色，多隔 |
| 分生孢子 | 镰刀形，2-4 隔，15-35 μm |
| 厚垣孢子 | 圆形，单胞，5-10 μm |
| 最适温度 | 25-30 ℃ |
| 土壤 pH | 5.5-7.0 |

## 2. 发病规律

病菌在病根、病土及腐殖质中越冬。翌年通过灌溉水、风雨或农事操作传播。病菌从幼根或伤口侵入，在根际扩展。

### 2.1 立枯病与根腐病症状对比

| 特征 | 立枯病 | 根腐病 |
|-----|--------|--------|
| 受害对象 | 幼苗、幼树 | 各年龄段 |
| 主要症状 | 茎基部褐色坏死，地上部萎蔫枯死 | 根系腐烂，叶片黄化 |
| 病部特征 | 茎基部缢缩，表面有白色菌丝 | 根部褐色至黑褐色腐烂 |
| 发展速度 | 较快（数天至 1-2 周） | 较慢（数周至数月） |
| 天气关系 | 高温高湿易发 | 积水涝渍易发 |

### 2.2 发病影响因素

| 因素 | 影响 | 说明 |
|-----|------|------|
| 土壤积水 | 重发 | 根系缺氧，抗病力下降 |
| 高温高湿 | 重发 | 病原菌繁殖旺盛 |
| 连作 | 重发 | 病原菌在土壤中累积 |
| 土壤偏酸 | 加重 | 不利于有益微生物 |
| 有机肥不足 | 加重 | 土壤微生物多样性低 |
| 苗木带菌 | 初侵染源 | 苗圃期感染带入 |

## 3. 诊断技术

### 3.1 田间诊断

- 立枯病：幼苗茎基部缢缩坏死，整株迅速萎蔫枯死，不倒伏。
- 根腐病：根系褐色腐烂，主根和侧根均受害，叶片自下而上黄化脱落。
- 拔起病株可见根系褐色或黑褐色，有腐烂气味。
- 湿润土壤条件下，病部可见白色菌丝。

### 3.2 实验室检测

| 方法 | 要点 |
|-----|------|
| 病根分离 | 表面消毒→PDA 培养基→28 ℃培养 |
| 镰刀菌镜检 | 见镰刀形分生孢子 |
| 腐霉菌镜检 | 见游动孢子和厚垣孢子 |
| 立枯丝核菌 | 见褐色菌丝和菌核 |
| 柯赫验证 | 接种后重现症状 |

## 4. 防治技术

### 4.1 农业防治

- **选用无病苗木**：从正规苗圃购买经检疫的苗木。
- **土壤消毒**：新园或老园翻耕前进行土壤消毒。
- **排水**：开好排水沟，避免积水。
- **轮作**：避免连作，与非寄主作物轮作。
- **增施有机肥**：提高土壤微生物多样性。
- **调节土壤 pH**：施用石灰改良酸性土壤。

### 4.2 化学防治

| 时期 | 药剂 | 用法 | 备注 |
|-----|------|------|------|
| 植前 | 多菌灵 50% | 拌土 5 g/m³ | 土壤消毒 |
| 植前 | 甲霜灵 64% | 灌根 800 倍 | 灌根处理 |
| 发病初期 | 恶霉灵 45% | 灌根 1000 倍 | 防治根腐 |
| 发病期 | 甲基托布津 70% | 灌根 800 倍 | 治疗根腐 |
| 发病期 | 噻呋酰胺 25% | 灌根 1500 倍 | 防治镰刀菌 |
| 防治立枯 | 甲霜·锰锌 | 灌根 600 倍 | 针对腐霉菌 |

### 4.3 生物防治

| 方法 | 材料 | 效果 |
|-----|------|------|
| 木霉菌拌土 | *T. harzianum* 1×10⁸ CFU/g | 减少根腐 60-80% |
| 木霉菌灌根 | 1×10⁶ CFU/mL | 促进根系生长 |
| 枯草芽孢杆菌 | 1×10⁹ CFU/mL | 竞争性占位 |
| 生物有机肥 | 含有益菌群 | 改良根际微生态 |

### 4.4 综合防治技术路线

```
选无病苗 → 土壤消毒 → 合理栽植 → 排水管理 → 发病期灌根 → 生物菌剂补充
```
