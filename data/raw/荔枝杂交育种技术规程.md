# 荔枝杂交育种技术规程

## 摘要

杂交育种是荔枝新品种选育的核心技术，通过不同品种或种质间的人工杂交，实现优良基因的重组与组合，创造新的遗传变异。本文依据《农作物育种技术规范》及荔枝生产实际，系统规定了荔枝杂交育种的操作规程，涵盖杂交亲本选配、花期调控、人工授粉、种子采集成熟、杂交后代管理等全流程技术要点。

## 1 适用范围

本规程适用于荔枝新品种的杂交育种工作，包括品种间杂交、品种与野生种质间杂交以及远缘杂交（荔枝属内不同种间）的制种与后代管理。

## 2 亲本选配要求

### 2.1 亲本选择标准

| 选择依据 | 要求 |
| --- | --- |
| 品种特性 | 亲本应分别携带互补的优良性状 |
| 花期匹配 | 开花时间重合或可调节至同期 |
| 亲和性 | 亲本间需具有杂交亲和性（一般远缘种间亲和性低） |
| 遗传距离 | 亲本SSR遗传相似系数建议0.2-0.7 |
| 健康状态 | 无检疫性病虫害，遗传稳定性好 |

### 2.2 亲本组合设计

| 组合类型 | 示例 | 预期目标 |
| --- | --- | --- |
| 同系杂交 | 桂味×双核桂味 | 优化桂味系性状 |
| 异系杂交 | 糯米糍×桂味 | 融合糯米糍甜糯与桂味清香 |
| 野生杂交 | 海南野生荔枝×糯米糍 | 导入抗逆与抗病基因 |

## 3 杂交操作技术

### 3.1 杂交前准备

- 工具：毛笔、镊子、授粉管、回形针、标签、纸袋/塑料袋、酒精
- 环境：选择晴朗无风天气，花粉采集应在上午8-10时（花粉活力最高）
- 母本准备：选取花穗健壮、花量丰富的母本植株

### 3.2 杂交操作流程

| 步骤 | 操作内容 | 注意事项 |
| --- | --- | --- |
| 1. 去雄 | 母本花穗在开花前套袋隔离 | 确保无外源花粉污染 |
| 2. 套袋 | 用塑料袋或牛皮纸袋套住花穗 | 扎紧袋口 |
| 3. 采粉 | 采集父本完全开放花的成熟花粉 | 上午操作，花粉新鲜 |
| 4. 授粉 | 花粉涂抹柱头或撒粉于花穗 | 轻轻震动，花粉附着 |
| 5. 标记 | 挂牌记录组合、日期、操作人 | 格式：母本×父本-日期 |
| 6. 再套袋 | 授粉后重新套袋保护 | 防止再次污染 |

### 3.3 授粉后管理

- 保持套袋直至果实开始膨大
- 定期检查花穗发育情况，清除败育花穗
- 果实发育期加强肥水管理，减少落果

## 4 种子采集与处理

| 项目 | 技术要求 |
| --- | --- |
| 采种时间 | 果实充分成熟后 |
| 种子处理 | 剥除果皮和假种皮，清水洗净 |
| 催芽处理 | 温水浸种24h或层积沙藏处理 |
| 播种时间 | 随采随播效果最佳，贮藏不超过7天 |

## 5 杂交后代管理

### 5.1 苗圃建立

| 项目 | 技术要求 |
| --- | --- |
| 播种密度 | 5cm×10cm（营养钵育苗） |
| 基质配比 | 园土:腐叶土:河沙 = 5:3:2 |
| 遮阴管理 | 出苗后遮阴70%-80%，苗高30cm后逐步撤除 |
| 水肥管理 | 薄肥勤施，每两周一次稀薄氮肥 |

### 5.2 实生苗鉴定与筛选

| 时间 | 鉴定内容 | 淘汰标准 |
| --- | --- | --- |
| 播种后1年 | 苗势、叶片形态 | 苗势弱、叶片异常 |
| 播种后3-4年 | 初果品质 | 品质明显劣于亲本 |
| 播种后5-7年 | 综合表现 | 产量、品质、适应性综合评定 |

## 6 技术记录要求

杂交育种全程应建立详细的技术档案，记录内容包括：亲本信息、杂交日期、授粉方式、套袋情况、种子产量、播种情况、各代筛选记录等。技术档案应保存至品种审定通过为止。
