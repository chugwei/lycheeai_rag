# 荔枝果酱加工技术规程

## 摘要

荔枝果酱是以荔枝果肉为主要原料，经破碎、熬煮、浓缩、罐装等工序制成的果味酱料，固形物含量高（≥60%），具有浓郁的荔枝风味。本文系统介绍荔枝果酱的加工工艺、配方设计、熬煮参数控制、包装及质量控制标准，适用于荔枝果酱的规模化生产。

## 1. 引言

荔枝果酱属于果味酱类食品，具有保质期长、便于携带和食用方便的特点，是荔枝深加工的重要产品。优质荔枝果酱应果肉颗粒清晰、色泽红亮、酸甜适口、无糖结晶。

## 2. 原料要求

### 2.1 主要原料

| 原料 | 要求 | 备注 |
|------|------|------|
| 荔枝果肉 | 可溶性固形物 ≥14°Brix | 去壳去核 |
| 白砂糖 | 符合 GB 317 标准 | 蔗糖 |
| 柠檬酸 | 食品级 | 调酸 |
| 果胶 | 食品级 LM 型或 HM 型 | 增稠凝胶 |
| 水 | 符合 GB 5749 | 饮用净化水 |

### 2.2 荔枝果肉品质要求

| 指标 | 要求 |
|------|------|
| 成熟度 | 8~9 成熟 |
| 可溶性固形物 | ≥14°Brix |
| 可滴定酸 | 0.15%~0.35% |
| 色泽 | 半透明乳白 |
| 腐烂率 | ≤2% |

## 3. 配方设计

### 3.1 标准配方

| 配料 | 用量（g） | 占比 | 作用 |
|------|---------|------|------|
| 荔枝果肉 | 400 | 40% | 主体原料 |
| 白砂糖 | 450 | 45% | 甜味、防腐 |
| 水 | 100 | 10% | 溶解 |
| 柠檬酸 | 3 | 0.3% | 调酸、护色 |
| 果胶 | 6~10 | 0.6%~1% | 凝胶、增稠 |
| 维生素 C | 2 | 0.2% | 抗氧化 |

### 3.2 不同糖度配方

| 类型 | 果肉 | 砂糖 | 可溶性固形物 | 适用人群 |
|------|------|------|-----------|---------|
| 高糖果酱 | 350 g | 550 g | ≥65% | 传统 |
| 中糖果酱 | 400 g | 400 g | ≥60% | 一般 |
| 低糖果酱 | 450 g | 250 g | ≥55% | 健康型 |
| 代糖果酱 | 450 g | 赤藓糖醇 300 g | ≥55% | 无糖型 |

## 4. 加工工艺流程

### 4.1 整体流程

荔枝鲜果 → 清洗 → 剥壳去核 → 破碎 → 熬煮 → 浓缩 → 罐装 → 杀菌 → 冷却 → 成品

### 4.2 各工序参数

| 步骤 | 操作 | 参数 | 目的 |
|------|------|------|------|
| 1 | 清洗 | 流动水 | 去污 |
| 2 | 剥壳去核 | 手工或机械 | 取果肉 |
| 3 | 破碎 | 破碎机至 3~5 mm | 便于熬煮 |
| 4 | 熬煮 | 90~95°C | 溶糖、凝胶 |
| 5 | 浓缩 | 至 65°~70°Brix | 达到成品浓度 |
| 6 | 罐装 | 80~85°C 热罐装 | 减少污染 |
| 7 | 杀菌 | 85~90°C/10~15 min | 商业无菌 |
| 8 | 冷却 | 自然冷却 | 凝固成型 |

## 5. 熬煮工艺

### 5.1 熬煮参数

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 熬煮温度 | 90~95°C | 避免焦糊 |
| 熬煮时间 | 20~30 min | 至终点糖度 |
| 搅拌频率 | 持续搅拌 | 防焦底 |
| 终点糖度 | 65°~70°Brix | 关键控制点 |
| 终点温度 | 103~105°C（果酱沸点） | 辅助判断 |
| 果胶添加时机 | 熬煮中期（糖度 30°Brix） | 充分溶解 |

### 5.2 熬煮过程糖度变化

| 阶段 | 时间（min） | 温度（°C） | 糖度（°Brix） |
|------|----------|----------|------------|
| 初始 | 0 | 70 | 15~20 |
| 溶糖期 | 0~5 | 70~80 | 25~35 |
| 熬煮期 | 5~20 | 85~95 | 40~60 |
| 浓缩期 | 20~25 | 95~100 | 60~68 |
| 终点 | 25~30 | 100~105 | 65~70 |

### 5.3 果胶添加方法

| 方法 | 操作 | 注意事项 |
|------|------|---------|
| 干粉混合法 | 果胶与砂糖混合后加入 | 避免结块 |
| 水合溶解法 | 果胶先用水溶解成胶体 | 充分水合 |
| 添加时机 | 糖度 30°Brix 时加入 | 温度 <80°C |

## 6. 杀菌工艺

### 6.1 杀菌方式

| 杀菌方式 | 温度（°C） | 时间 | 适用包装 |
|---------|----------|------|---------|
| 巴氏杀菌 | 85~90 | 10~15 min | 玻璃瓶 |
| 高温短时 | 100 | 2~5 min | 金属罐 |
| 超高温瞬时 | 135~150 | 2~5 s | 无菌灌装 |
| 热罐装 | 80~85（灌装温度） | 即时 | 小容量瓶 |

### 6.2 杀菌 F₀ 值

| 产品 | F₀ 值（min） | 杀菌条件 |
|------|------------|---------|
| 荔枝果酱 | 3~5 | 85~90°C/10~15 min |

## 7. 产品质量标准

### 7.1 理化指标

| 指标 | 要求 |
|------|------|
| 可溶性固形物 | ≥60% |
| 可滴定酸 | 0.3%~0.8%（以柠檬酸计） |
| 净含量 | 符合 GB 7718 要求 |
| 铅（Pb） | ≤0.5 mg/kg |
| 二氧化硫 | ≤10 mg/kg |
| 大肠菌群 | ≤3 MPN/g |
| 霉菌 | ≤10 CFU/g |

### 7.2 感官指标

| 指标 | 要求 |
|------|------|
| 色泽 | 红褐至棕红色，有光泽 |
| 香气 | 荔枝特征香气浓郁 |
| 滋味 | 酸甜适口，荔枝风味典型 |
| 组织状态 | 黏稠均匀，果肉颗粒清晰，无杂质 |

## 8. 包装与贮藏

| 项目 | 要求 |
|------|------|
| 包装材料 | 玻璃瓶或食品级 PET 瓶 |
| 包装规格 | 180g、260g、500g |
| 封盖 | 真空封盖或旋盖密封 |
| 贮藏温度 | 常温（<25°C） |
| 保质期 | 12~18 个月 |
| 标签 | 品种、生产日期、配料表、营养成分 |

## 9. 结论

荔枝果酱加工的关键在于熬煮终点糖度控制（65°~70°Brix）和果胶的合理添加。通过巴氏杀菌可实现商业无菌，常温保质期 12~18 个月。
