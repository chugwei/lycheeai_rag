# 荔枝浓缩果汁加工技术

## 摘要

荔枝浓缩果汁是荔枝果汁加工的高附加值产品，通过真空浓缩技术去除鲜果汁中大部分水分，使可溶性固形物浓度提高至 35°~45°Brix，具有体积小、易储运、便于还原和调配的特点。本文系统介绍荔枝浓缩果汁的加工工艺流程、浓缩设备选型、香气回收技术及质量控制方法。

## 1. 引言

荔枝浓缩果汁是国际果汁贸易的主要形式，浓缩比通常为 3:1~6:1。浓缩果汁可在常温下储运 12~18 个月，还原后风味品质接近鲜榨果汁。荔枝浓缩汁可用于饮料调配、烘焙馅料、调味酱汁等多种用途。

## 2. 工艺流程

### 2.1 整体流程

荔枝鲜果 → 清洗 → 预冷 → 剥壳去核 → 破碎 → 酶解 → 压榨 → 过滤 → 脱气 → 预热 → 蒸发浓缩 → 香气回收 → 杀菌 → 包装

### 2.2 各工序参数

| 工序 | 关键参数 | 控制要点 |
|------|---------|---------|
| 原料预处理 | 温度 5~8°C | 防止褐变和酶活 |
| 破碎 | 破碎度 2~3 mm | 充分破碎不糊化 |
| 酶解 | 45~50°C/30~60 min | 果胶酶 0.05%~0.1% |
| 压榨 | 压榨力 0.3~0.5 MPa | 出汁率 ≥65% |
| 脱气 | 真空 50~70 kPa | 去除 O₂ 防氧化 |
| 预热 | 60~65°C | 灭酶防褐变 |
| 蒸发浓缩 | 40~50°C/30 kPa | 低温浓缩保风味 |
| 香气回收 | 冷凝温度 <20°C | 收集挥发性香气 |

## 3. 浓缩技术

### 3.1 浓缩方式对比

| 浓缩方式 | 温度（°C） | 真空度（kPa） | 浓缩时间 | 品质 | 能耗 |
|---------|----------|-------------|---------|------|------|
| 降膜蒸发器 | 40~55 | 30~50 | 1~3 h | 良好 | 中 |
| 刮板式蒸发器 | 45~60 | 20~40 | 1~2 h | 优 | 中 |
| 薄膜蒸发器 | 35~50 | 5~15 | 0.5~1 h | 极佳 | 中高 |
| 冷冻浓缩 | 0~-5 | - | 4~8 h | 极佳 | 高 |
| 反渗透浓缩 | 常温 | - | 2~4 h | 良好 | 低 |

### 3.2 降膜蒸发参数

| 参数 | 设定值 | 说明 |
|------|-------|------|
| 蒸发温度 | 40~50°C | 果汁沸点降低 |
| 加热蒸汽温度 | 60~70°C | 温和加热 |
| 真空度 | 30~50 kPa | 保证低温 |
| 蒸发速率 | 1~2 m/s（膜速） | 均匀传热 |
| 单效蒸发量 | 0.8~1.2 t/h（水/效） | 生产能力 |
| 浓缩比 | 3~6 倍 | 目标固形物 35~45°Brix |

### 3.3 多效蒸发节能

| 效数 | 蒸汽利用率 | 节能效果 | 投资增幅 |
|------|----------|---------|---------|
| 单效 | 100% | 基准 | 基准 |
| 双效 | 200% | 节能 35% | +40% |
| 三效 | 300% | 节能 55% | +80% |
| 四效 | 400% | 节能 70% | +120% |

## 4. 香气回收技术

### 4.1 香气物质组成

荔枝香气主要由挥发性芳香化合物构成，主要成分包括：

| 香气组分 | 种类 | 感官特征 |
|---------|------|---------|
| 酯类 | 乙酸苯乙酯、己酸乙酯等 | 花香、果香 |
| 醇类 | 苯乙醇、芳樟醇等 | 花香、木质香 |
| 醛类 | 己醛、辛醛等 | 青草香 |
| 萜烯类 | 柠檬烯、蒎烯等 | 柑橘香 |
| 内酯类 | γ-壬内酯等 | 奶香、椰子香 |

### 4.2 香气回收工艺

| 步骤 | 操作 | 参数 |
|------|------|------|
| 1 | 蒸汽夹带 | 浓缩过程中挥发出的香气 |
| 2 | 冷凝回收 | 冷凝温度 <20°C |
| 3 | 油水分离 | 分离香气油和水分 |
| 4 | 储存 | 5~10°C，避光 |
| 5 | 添加 | 还原时按 0.01%~0.05% 添加 |

### 4.3 香气回收率

| 浓缩方式 | 香气回收率（%） | 风味还原度 |
|---------|-------------|----------|
| 无回收浓缩 | 0 | 60%~70% |
| 单效回收 | 40%~60% | 80%~85% |
| 多效回收 | 60%~80% | 90%~95% |

## 5. 浓缩汁品质指标

### 5.1 理化指标

| 指标 | 要求 | 检测方法 |
|------|------|---------|
| 可溶性固形物 | 35°~45°Brix | 折光仪法 |
| 可滴定酸 | 1.5%~3.0%（以柠檬酸计） | 滴定法 |
| 糖酸比 | 15~25 | 计算 |
| 蛋白质 | ≥1.5% | 凯氏定氮法 |
| 维生素 C | ≥50 mg/100 mL（还原后） | 2,6-二氯靛酚法 |
| pH | 3.2~3.8 | pH 计 |
| 澄清度 | 透光率 ≥85% | 浊度仪 |

### 5.2 感官指标

| 指标 | 要求 |
|------|------|
| 色泽 | 还原后呈荔枝果色，红褐至琥珀色 |
| 香气 | 荔枝特征香气浓郁，无异味 |
| 滋味 | 酸甜适中，荔枝风味典型 |
| 组织状态 | 均匀透明或微浊，无沉淀 |

### 5.3 微生物指标

| 指标 | 要求 |
|------|------|
| 菌落总数 | ≤100 CFU/mL |
| 大肠菌群 | ≤3 MPN/100 mL |
| 霉菌酵母 | ≤10 CFU/mL |
| 致病菌 | 不得检出 |

## 6. 包装与贮藏

| 项目 | 要求 |
|------|------|
| 包装材料 | 食品级塑料桶（25 kg）或不锈钢桶（300 L） |
| 包装环境 | 洁净车间，温度 <25°C |
| 贮藏温度 | 0~5°C（最佳）或常温（<25°C） |
| 保质期 | 0~5°C 贮藏 18~24 个月 |
| 避光 | 避光贮藏，防止维生素 C 降解 |
| 标签 | 品种、浓度、生产日期、批次号 |

## 7. 还原与调配

### 7.1 还原工艺

| 参数 | 要求 |
|------|------|
| 还原比 | 1:3~1:6（浓缩汁:水） |
| 还原用水 | 符合 GB 5749 饮用水标准 |
| 还原后固形物 | 10°~14°Brix |
| 还原后风味 | 加回香气料（如回收） |
| 混合 | 充分搅拌 5~10 min |

### 7.2 风味调配

| 调配成分 | 用量 | 作用 |
|---------|------|------|
| 水 | 基准 | 调节固形物 |
| 白砂糖 | 0.5%~2% | 调整甜度 |
| 柠檬酸 | 0.02%~0.05% | 调整酸度 |
| 香气料 | 0.01%~0.05% | 恢复香气 |
| 维生素 C | 50~100 mg/L | 抗氧化 |

| 项目 | 数值 |

## 9. 结论

荔枝浓缩果汁加工以真空低温浓缩为核心，结合香气回收技术，可在保持荔枝风味的同时实现长保质期和高浓缩比。浓缩比 4:1、固形物 40°Brix 的产品是市场主流规格。
