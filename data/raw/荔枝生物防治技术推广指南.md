# 荔枝生物防治技术推广指南

## 摘要

荔枝生物防治是利用天敌昆虫、微生物农药、植物源农药等生物资源控制病虫害的绿色防控技术，具有环境友好、无农药残留、不易产生抗药性等优势。本指南系统介绍荔枝生物防治的常用技术、推广策略和注意事项，为荔枝园绿色防控提供技术支撑。

## 1. 荔枝生物防治技术体系

### 1.1 天敌昆虫利用

| 天敌种类 | 防治对象 | 释放方式 |
|---------|---------|---------|
| 赤眼蜂（*Trichogramma* spp.） | 卷叶蛾、夜蛾、棉铃虫卵 | 田间释放蜂卡 |
| 丽蚜小蜂（*Encarsia* spp.） | 粉虱若虫 | 田间释放蜂卡 |
| 捕食螨（*Phytoseiulus* spp.） | 红蜘蛛、瘿螨 | 树上释放 |
| 瓢虫（*Coccinella* spp.） | 蚜虫、粉虱 | 田间释放 |
| 草蛉（*Chrysopa* spp.） | 蚜虫、粉虱、介壳虫 | 田间释放 |
| 寄生蜂（*Agathis* spp.） | 天牛幼虫、蒂蛀虫 | 田间释放 |

### 1.2 微生物农药

| 农药名称 | 防治对象 | 使用浓度 |
|---------|---------|---------|
| 苏云金杆菌（Bt） | 卷叶蛾、夜蛾、刺蛾幼虫 | 1000-2000 倍 |
| 核型多角体病毒（NPV） | 特异性害虫（刺蛾、夜蛾） | 按说明书 |
| 白僵菌（*Beauveria bassiana*） | 天牛成虫、蚜虫 | 500-1000 倍 |
| 木霉菌（*Trichoderma* spp.） | 霜霉病、灰霉病、炭疽病 | 1×10⁸ CFU/mL |
| 枯草芽孢杆菌 | 细菌性穿孔病、果腐病 | 1×10⁹ CFU/mL |
| 短波紫外线（UV-C） | 细菌、真菌 | 种苗处理 |

### 1.3 植物源农药

| 农药名称 | 防治对象 | 使用浓度 |
|---------|---------|---------|
| 苦参碱 0.5% | 蚜虫、粉虱、蓟马 | 800-1000 倍 |
| 鱼藤酮 0.5% | 蚜虫、蓟马 | 1000-1500 倍 |
| 除虫菊素 2.5% | 多种害虫 | 1000-1500 倍 |
| 印楝素 0.3% | 蚜虫、介壳虫 | 1000-1500 倍 |

## 2. 生物防治技术推广策略

### 2.1 推广原则

- 以生态调控为基础，生物防治为主导。
- 因地制宜，因害施策。
- 化学防治与生物防治相结合。
- 保护利用自然天敌资源。

### 2.2 推广模式

| 模式 | 内容 | 适用场景 |
|-----|------|---------|
| 示范园推广 | 建立生物防治示范园，展示效果 | 规模化果园 |
| 技术培训 | 对种植户和技术人员进行培训 | 区域性推广 |
| 合作社推广 | 通过专业合作社统一实施 | 合作社管理果园 |
| 政府补贴 | 政府补贴天敌和生物农药费用 | 贫困地区 |

### 2.3 推广流程

```
示范园建设 → 技术培训 → 实施推广 → 效果评估 → 持续优化
```

## 3. 生物防治技术要点

### 3.1 天敌释放技术

| 项目 | 要点 |
|-----|------|
| 释放时间 | 害虫发生初期，成虫羽化前 |
| 释放密度 | 赤眼蜂 5-10 万头/亩，捕食螨 50-100 头/株 |
| 释放方法 | 蜂卡悬挂或树上释放 |
| 环境条件 | 温度 20-30 ℃，湿度 60-80% |
| 注意事项 | 释放前后 7 天禁止喷施化学农药 |

### 3.2 微生物农药使用技术

| 项目 | 要点 |
|-----|------|
| 使用时期 | 害虫发生初期或病害发生前 |
| 施用方法 | 叶面喷雾或灌根 |
| 环境条件 | 避免高温（>35 ℃）和强光直射 |
| 与化学农药混配 | 避免与杀菌剂和抗生素类混配 |
| 储存条件 | 阴凉干燥处，避免高温 |

## 4. 效果评估

| 评估指标 | 标准 |
|---------|------|
| 虫口减退率 | >60% 为有效，>80% 为高效 |
| 病害防效 | >60% 为有效，>80% 为高效 |
| 天敌存活率 | >50% 为良好 |
| 生态效益 | 天敌数量增加，生物多样性提高 |
