# 荔枝品种亲本选配技术

## 摘要

亲本选配是杂交育种成败的关键环节，合理的亲本组合决定杂交后代分离群体的遗传变异范围和优良基因重组概率。本文系统阐述荔枝品种杂交亲本选配的原则、方法与技术要点，介绍了基于遗传距离的选配策略和基于目标性状的选配策略，分析了不同选配方式的预期效果和实际应用案例，为荔枝杂交育种中的亲本选配提供科学依据。

## 1 亲本选配的重要性

杂交育种中，亲本选配直接决定F1后代的遗传变异幅度和优良基因的组合概率。选配得当，可在实生后代中获得大量优于亲本的个体；选配不当，后代变异小、优良个体少，严重影响育种效率。

## 2 亲本选配原则

### 2.1 目标导向原则

选配前必须明确育种目标，根据目标确定双亲携带的互补性状组合。

| 育种目标 | 亲本选配要求 |
| --- | --- |
| 提升果实品质 | 一方高糖，一方小核/焦核 |
| 扩大适栽区 | 一方抗寒/抗旱，一方优质 |
| 延长供应期 | 一方早熟，一方优质大果 |
| 提高抗逆性 | 一方抗病/抗逆，一方丰产优质 |

### 2.2 互补性原则

双亲应各有优势和缺陷，通过杂交使优势互补、缺陷掩盖。避免双亲携带相同不良性状。

### 2.3 花期匹配原则

荔枝雌花和雄花分化时间差异较大，亲本花期重合是杂交成功的前提。花期差异超过15天的组合需进行花期调控。

| 花期类型 | 代表品种 | 花期（月-日） |
| --- | --- | --- |
| 早花 | 三月红、黑叶 | 2月中-3月中 |
| 中花 | 白糖罂、怀枝 | 3月中-4月中 |
| 晚花 | 桂味、糯米糍、妃子笑 | 4月中-5月中 |

### 2.4 遗传多样性原则

亲本遗传距离越大，后代分离群体遗传变异越丰富，选育优良个体的概率越高。SSR遗传相似系数建议控制在0.2-0.7之间。

## 3 亲本选配方法

### 3.1 基于性状的选配

根据亲本表型性状选配，是最直观的方法。

| 选配方式 | 描述 | 应用 |
| --- | --- | --- |
| 强×强 | 两个优良品种杂交 | 创造更优品种 |
| 强×弱 | 优良品种×特殊种质 | 导入特殊基因 |
| 异型×异型 | 表型差异大 | 扩大变异幅度 |

### 3.2 基于遗传距离的选配

利用SSR或SNP数据计算亲本间遗传距离，选取遗传距离适中的组合。遗传距离过大（>0.7）可能导致杂种优势利用困难；遗传距离过小（<0.2）后代变异不足。

### 3.3 基于基因型的选配

利用分子标记定位目标基因位点，选择在目标基因位点上具有互补等位基因的个体作为亲本，实现目标性状的定向组合。

## 4 选配流程

| 步骤 | 内容 |
| --- | --- |
| 1. 确定育种目标 | 明确目标性状优先级 |
| 2. 候选亲本初筛 | 从品种资源库中筛选符合目标的候选亲本 |
| 3. 亲本鉴定 | 形态鉴定+分子指纹图谱鉴定，确认品种身份 |
| 4. 花期分析 | 分析候选亲本花期是否匹配 |
| 5. 遗传距离分析 | 计算候选亲本组合的遗传距离 |
| 6. 组合设计 | 设计杂交组合方案 |
| 7. 试杂交 | 先小范围试杂交，评估亲和性 |
| 8. 正式杂交 | 大规模制种 |

## 5 选配案例

| 组合 | 选配理由 | 预期后代优势 |
| --- | --- | --- |
| 桂味×糯米糍 | 桂味清香+糯米糍甜糯 | 高品质、小核 |
| 妃子笑×桂味 | 妃子笑大果+桂味风味 | 大果高风味 |
| 怀枝×糯米糍 | 怀枝适应广+糯米糍品质优 | 广适性优质品种 |
| 海南野生×黑叶 | 野生抗逆+栽培丰产 | 抗逆丰产品种 |

## 6 注意事项

- 选配前必须确认亲本品种身份，避免同品种误杂交
- 远缘杂交（如荔枝×龙荔）亲和力低，需采用特殊授粉技术
- 同一组合应设置重复，增加杂交种子数量
- 注意花粉活力，父本花粉采集后应在4h内使用
