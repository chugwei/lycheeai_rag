# 荔枝茎点霉病防治技术

## 摘要

荔枝茎点霉病（*Phomopsis* spp.）是由茎点霉属真菌引起的果实和枝条病害，主要危害荔枝果实和嫩梢，造成果实腐烂和枝条枯死。该病在华南高温高湿地区发生普遍，尤其在果实成熟期和雨季危害严重。本文系统介绍茎点霉病的病原特征、发病规律、诊断方法和防治技术。

## 1. 病原生物学

荔枝茎点霉病的主要病原为荔枝茎点霉（*Phomopsis litchii*），属于半知菌亚门。病菌在病组织上产生分生孢子器，内产分生孢子。孢子器球形，直径 100-200 μm，分生孢子卵形或椭圆形，单胞，无色，2-4 μm × 1-2 μm。

### 1.1 病原菌特性

| 项目 | 特征 |
|-----|------|
| 菌丝 | 多隔，褐色 |
| 孢子器 | 球形，直径 100-200 μm |
| 分生孢子 | 卵形，2-4 μm × 1-2 μm |
| 最适温度 | 25-28 ℃ |
| 最适湿度 | 相对湿度 >90% |
| 寄主范围 | 荔枝、龙眼等无患子科植物 |

## 2. 发病规律

病菌以菌丝体和孢子器在病果、病枝及落叶上越冬。翌年 4-5 月，分生孢子释放，通过雨水飞溅传播。主要侵染途径为伤口和自然孔口。果实膨大期至成熟期为感病高峰期。

### 2.1 症状类型

| 症状类型 | 部位 | 描述 |
|---------|------|------|
| 果实褐腐 | 果蒂部 | 果蒂褐变腐烂，向果面扩展，呈褐色凹陷斑 |
| 果实斑腐 | 果皮 | 果皮出现圆形褐色斑，后期扩大融合 |
| 枝条枯梢 | 嫩梢 | 嫩梢节间变褐枯死，自上而下蔓延 |
| 叶枯斑 | 叶片 | 叶尖或叶缘褐变，向叶片内部扩展 |

### 2.2 发病高峰与气象

| 时期 | 气象条件 | 发病率 |
|-----|---------|--------|
| 4-5 月（幼果期） | 梅雨期，高湿 | 中等 |
| 6-7 月（膨大期） | 高温多雨 | 较高 |
| 7-8 月（成熟期） | 雨季 + 高温 | 最高 |
| 9-10 月（秋梢期） | 秋雨 | 中等 |

## 3. 诊断技术

### 3.1 田间诊断要点

- 果蒂部腐烂是该病最重要的诊断特征。
- 果皮病斑边缘清晰，中央凹陷，呈褐色至黑褐色。
- 潮湿条件下，病斑表面可见黑色小点（分生孢子器）。
- 嫩梢受害后枯死下垂，枯死部分与健康部分界限明显。

### 3.2 实验室检测

| 方法 | 要点 | 结果判读 |
|-----|------|---------|
| 病原分离 | PDA 培养基，25 ℃培养 | 菌落白色至淡灰色，后期黑色 |
| 镜检 | 乳酸酚棉蓝染色 | 见分生孢子器及卵形孢子 |
| 致病性测定 | 柯赫法则验证 | 接种后重现症状 |
| PCR 检测 | 扩增 ITS 区 | 特异性条带确认 |

## 4. 防治技术

### 4.1 农业防治

- **清园**：采收后及时清除病果、病枝，减少越冬菌源。
- **通风透光**：合理修剪，改善果园通风条件。
- **排水**：雨季及时排水，降低果园湿度。
- **合理负载**：避免树体负担过重导致抗性下降。
- **施肥管理**：增施有机肥和钾肥，提高树体抗性。

### 4.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 目的 |
|-----|------|---------|------|
| 萌芽前 | 石硫合剂 | 3-5 波美度 | 清园消毒 |
| 幼果期 | 苯醚甲环唑 10% | 2000-3000 倍 | 保护性喷施 |
| 膨大期 | 戊唑醇 25% | 3000-4000 倍 | 治疗 + 保护 |
| 成熟期前 | 嘧霉胺 50% | 1500-2000 倍 | 重点保护 |
| 雨季 | 烯酰吗啉 50% | 1500-2000 倍 | 补充防治 |

### 4.3 关键防治时期

| 节点 | 措施 |
|-----|------|
| 采收后清园 | 清除病果 + 石硫合剂全园喷施 |
| 幼果期（4 月中） | 苯醚甲环唑首次喷施 |
| 膨大期（5 月） | 戊唑醇喷施，间隔 10-14 天 |
| 转色期前（6 月） | 嘧霉胺重点保护，雨前喷施 |
