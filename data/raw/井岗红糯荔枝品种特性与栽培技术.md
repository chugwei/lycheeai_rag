# 井岗红糯荔枝品种特性与栽培技术

## 摘要

井岗红糯（Litchi chinensis Sonn. cv. 'Jingganghongnuo'）是华南农业大学从广东省增城井冈镇荔枝实生变异中选育出的优质荔枝新品种，以果皮鲜红、肉质嫩滑、焦核率高、品质优良而著称。本文详细介绍了井岗红糯的选育过程、植物学特征、果实品质特性、物候期规律以及配套栽培技术，为井岗红糯在适宜区域的推广种植和标准化生产提供技术参考。

## 一、品种来源与选育

井岗红糯荔枝是华南农业大学园艺学院与增城井冈镇农业技术推广站合作，从当地荔枝实生群体中选育出的优良新品种。2004年在增城井冈镇发现优良单株，果实品质优异，连续多年进行无性繁殖、品比试验、区域适应性试验。2012年通过广东省农作物品种审定委员会审定，定名为"井岗红糯"。该品种兼具糯米糍的优良品质和怀枝的丰产性能，在广东、广西、海南等产区推广表现良好，栽培面积约3000公顷。

## 二、品种特征特性

### 2.1 树体特征

树势中等偏强，树冠半圆头形至圆头形，树姿开张。成年树高4-6米，冠幅5-8米。主干灰褐色，表面较粗糙。枝条中粗，分枝角度50-65度，新梢紫红色。叶片为偶数羽状复叶，小叶2-4对，长椭圆形或披针形，叶尖渐尖，叶基楔形。叶长11-16厘米，宽3-4.5厘米，叶色浓绿，叶面光滑有光泽，叶背浅绿。叶脉明显，侧脉每边10-14条。

### 2.2 花器特征

花序为圆锥形聚伞花序，长度20-35厘米。雌雄同株异花，雄花占70%-85%，雌花占15%-30%。雄花萼片5枚，花瓣退化，雄蕊6-8枚。雌花子房2-3室，柱头二裂。单花序花量500-1200朵。雌花比例较高，为丰产奠定基础。

### 2.3 果实品质特征

| 性状 | 描述 |
|------|------|
| 果形 | 近心形或卵圆形，果肩微耸 |
| 单果重 | 20-30克，平均25-27克 |
| 果皮 | 鲜红色至深红色，富有光泽 |
| 龟裂片 | 中等大，隆起较平，排列整齐 |
| 缝合线 | 明显，颜色稍淡 |
| 果皮厚度 | 1.0-1.4毫米 |
| 果肉 | 乳白色，半透明，嫩滑爽脆，清甜微香 |
| 可食率 | 78%-85% |
| 可溶性固形物 | 18%-22% |
| 总糖含量 | 15%-18% |
| 总酸含量 | 0.10%-0.20% |
| 维生素C | 35-52 mg/100g |
| 种子 | 大部分退化，焦核率70%-90% |
| 耐贮性 | 常温3-5天，冷藏10-14天 |

井岗红糯最突出的特点是焦核率高、肉质嫩滑、果实外观鲜红艳丽，极具市场竞争力。

## 三、物候期

井岗红糯在广州地区的主要物候期：

| 物候期 | 时间（月/旬） |
|--------|-------------|
| 萌芽期 | 2月中旬-3月上旬 |
| 春梢抽生期 | 2月下旬-3月下旬 |
| 现蕾期 | 3月中旬-4月上旬 |
| 开花期 | 4月上旬-4月下旬 |
| 幼果发育期 | 4月中旬-5月下旬 |
| 果实膨大期 | 5月上中旬-6月下旬 |
| 果实成熟期 | 6月下旬-7月上旬 |
| 秋梢抽生期 | 7月中旬-9月中旬 |
| 花芽分化期 | 11月-次年1月 |

井岗红糯属中熟品种，成熟期与桂味相近，比糯米糍稍早3-5天。

## 四、适应性

### 4.1 气候适应性

喜温暖湿润气候，年均温21-23℃最适。可耐短期-1℃低温。花期适温20-26℃，低于15℃或高于30℃影响坐果。果实发育期需25-32℃充足日照。年降雨量1400-2000mm。开花期和果实成熟期忌连续阴雨，但对干燥天气适应性较强。

### 4.2 土壤适应性

对土壤要求不严格，在红壤、砖红壤、赤红壤上均可种植。以pH5.5-6.5、有机质含量1.5%以上、排水良好的沙质壤土为佳。对硼、锌等微量元素较为敏感。

## 五、栽培技术

### 5.1 定植技术

| 项目 | 技术参数 |
|------|---------|
| 株行距 | 5米×6米（平地），5米×5米（山地） |
| 密度 | 330-400株/公顷 |
| 定植穴 | 0.8m×0.8m×0.8m |
| 基肥 | 有机肥20-30kg/穴+钙镁磷肥1.5-2kg/穴 |
| 回土 | 表土回穴，混匀肥料 |
| 定植时间 | 春植3-4月或秋植9-10月 |

### 5.2 土壤管理

**扩穴改土：** 定植后逐年向外扩穴深翻，深度40-50厘米，结合施入有机肥和石灰改良土壤。成年园每2-3年深翻一次，深度20-30厘米。

**生草覆盖：** 树盘覆盖稻草或杂草，厚度10-15厘米。行间种植绿肥或自然生草，增加土壤有机质，改善果园生态。

**间作套种：** 幼龄园间作花生、大豆、西瓜等矮秆作物，提高土地利用率。

### 5.3 营养管理

井岗红糯盛果树年施肥量推荐（每株/年）：

| 肥料种类 | 用量(kg) | 备注 |
|---------|---------|------|
| 尿素(含N46%) | 0.8-1.2 | 分次施用 |
| 过磷酸钙(含P₂O₅12%) | 0.6-0.9 | 基肥和花前肥 |
| 氯化钾(含K₂O60%) | 0.8-1.2 | 分次施用 |
| 硼砂 | 0.05-0.10 | 花前根施或叶面喷施 |
| 硫酸锌 | 0.05-0.08 | 叶面喷施 |
| 有机肥 | 40-50 | 采果后施入 |

施肥分配方案：
- 采果肥（7月）：占35%，以有机肥为主，配合速效氮肥
- 秋梢肥（8-9月）：占15%，促进秋梢健壮
- 促花肥（1-2月）：占20%，以磷钾肥为主，配合微量元素
- 壮果肥（4月）：占30%，以钾肥为主，配合氮肥和钙肥

### 5.4 水分管理

| 生育阶段 | 需水特性 | 管理措施 |
|---------|---------|---------|
| 花芽分化期(11-1月) | 需适度干旱 | 控水，土壤相对含水量55%-65% |
| 开花期(4月) | 需充足水分 | 保持湿润，遇旱灌水 |
| 幼果期(4-5月) | 需水量大 | 每5-7天灌水一次 |
| 果实膨大期(5-6月) | 需水量最大 | 及时灌溉，保持土壤湿润 |
| 成熟期(6-7月) | 适当减少 | 控水提高品质 |
| 秋梢期(7-9月) | 需水量中等 | 灌水促梢 |

### 5.5 整形修剪

**幼树整形：** 采用自然圆头形，定干高50-70厘米，选留3-4个主枝。主枝长30-40厘米时摘心促分枝。剪除影响骨干枝的竞争枝和交叉枝。

**结果树修剪：** 采果后立即修剪，剪除病虫枝、交叉枝、过密枝、弱枝和下垂枝。保留健壮秋梢作为结果母枝，结果母枝长度15-25厘米为佳。修剪量占总枝叶量的15%-20%。

### 5.6 花果管理

**控梢促花：**
- 秋梢老熟后喷施多效唑(15%可湿性粉剂)300-500倍液
- 11月上旬对旺长树进行环割
- 弯枝、拉枝等物理措施辅助控梢

**保花保果措施：**
- 花期放蜂，每公顷12-15箱
- 盛花期喷施0.1%硼砂+0.2%磷酸二氢钾+0.1%尿素
- 谢花后5-7天喷施赤霉素(GA3)10-15mg/L+芸苔素内酯0.01-0.02mg/L
- 第一次生理落果后喷施0.2%尿素+0.2%磷酸二氢钾
- 第二次生理落果后定果，每穗保留15-20个果

**提高焦核率：**
- 谢花后立即喷施GA3 20-30mg/L
- 果实发育期增施钾肥
- 适当控水促进种子败育

### 5.7 病虫害防治

| 病虫害 | 危害特点 | 推荐药剂 | 防治关键期 |
|--------|---------|---------|---------|
| 霜疫霉病 | 果腐、花腐 | 烯酰吗啉、甲霜灵·锰锌 | 花前和花后各1次 |
| 炭疽病 | 叶斑、果斑 | 咪鲜胺、苯醚甲环唑 | 抽梢期、果实膨大期 |
| 蒂蛀虫 | 蛀食果实 | 高效氯氟氰菊酯、甲维盐 | 果实发育期每15天1次 |
| 荔枝蝽象 | 吸食汁液 | 啶虫脒、高效氯氟氰菊酯 | 花期和幼果期 |
| 瘿螨 | 危害嫩梢叶 | 阿维菌素、炔螨特 | 春梢抽生期 |
| 红蜘蛛 | 叶片危害 | 哒螨灵、噻螨酮 | 春梢和秋梢期 |

## 六、采收与采后处理

### 6.1 采收标准

成熟期6月下旬至7月上旬。采收指标：果皮鲜红至深红色，果肉饱满，可溶性固形物达18%以上。采收宜在晴天早晨进行，避开高温时段。

### 6.2 分级包装

| 等级 | 单果重(g) | 外观要求 | 焦核率要求 |
|------|----------|---------|-----------|
| 特级 | ≥27 | 色泽鲜红，果形端正，无瑕疵 | ≥85% |
| 一级 | 23-27 | 色泽鲜红，果形端正 | ≥75% |
| 二级 | 20-23 | 色泽较好，允许轻微瑕疵 | ≥60% |

### 6.3 保鲜运输

采后2小时内预冷至5-8℃，采用咪鲜胺500-1000倍液浸泡杀菌。包装采用泡沫箱+冰袋方式，冷藏运输温度3-5℃。筐装容量不超过15公斤，避免挤压。

## 七、产量与效益

井岗红糯定植后第3-4年始果，第6-7年进入盛产期。盛产期株产30-60公斤，每公顷产量10000-18000公斤。市场售价40-80元/公斤，每公顷产值40-144万元。该品种因其焦核率高、品质优、外观美，市场竞争力强。
