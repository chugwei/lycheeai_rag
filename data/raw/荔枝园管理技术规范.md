# 荔枝园管理技术规范

> 本标准规定了荔枝投产果园周年管理的技术要求，包括各物候期的管理目标、农事操作、肥水管理、树体管理、花果管理和病虫害防治等。适用于荔枝投产果园（4年生以上）的全年管理。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝各产区投产果园的周年管理，包括初果期（4-6年生）、盛果期（7-20年生）和衰老期（20年以上）果园。

| 标准编号 | 标准名称 |

## 二、周年管理总则

### 荔枝年生长周期
```
1月  2月  3月  4月  5月  6月  7月  8月  9月  10月 11月 12月
│    │    │    │    │    │    │    │    │    │    │    │
休眠  花芽  现蕾  开花  幼果  果实  采收  采后  秋梢  秋梢  花芽  休眠
期    分化  期    期    期    膨大  期    修剪  生长  老熟  分化  期
           期                        期          期    期    期
```

### 四季管理重点
| 季节 | 月份 | 物候期 | 管理重点 |
|-----|------|-------|---------|
| 春季 | 2-4月 | 花芽分化→开花 | 促花保花，防治蝽象和霜疫霉病 |
| 夏季 | 5-7月 | 幼果→成熟→采收 | 保果壮果，防治蒂蛀虫，及时采收 |
| 秋季 | 8-10月 | 采后→秋梢生长期 | 采后修剪施肥，培养健壮结果母枝 |
| 冬季 | 11-1月 | 花芽分化→休眠 | 控梢促花，清园，防寒 |

## 三、春季管理（2-4月）

### 2月（花芽分化-现蕾期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 修剪 | 春季清园修剪 | 剪除枯枝、病虫枝、过密枝 |
| 施肥 | 花前肥 | 复合肥0.5-1.0kg/株+硼砂0.1kg/株 |
| 水分 | 适当控水 | 保持土壤适度干燥，促进花穗发育 |
| 病虫害 | 防治蝽象、瘿螨 | 吡虫啉+阿维菌素 |
| 控梢 | 抹除花穗上的小叶 | 人工抹除或喷施小叶脱 |

### 3月（开花期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 放蜂 | 引入蜜蜂授粉 | 每5-10亩放1箱蜜蜂 |
| 水分 | 开花期控水 | 花期不宜灌水，有利授粉 |
| 病虫害 | 防治霜疫霉病、炭疽病 | 烯酰吗啉+嘧菌酯 |
| 营养 | 叶面追肥 | 0.3%硼砂+0.3%磷酸二氢钾 |
| 疏花 | 疏除过多花穗 | 每条基枝留1-2个健壮花穗 |

### 4月（谢花-幼果期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 保果 | 喷施保果剂 | 防落素20ppm或赤霉素50ppm |
| 施肥 | 谢花后追肥 | 复合肥0.3-0.5kg/株+钾肥0.3kg/株 |
| 水分 | 保持水分均匀 | 干旱时及时灌水 |
| 病虫害 | 防治蒂蛀虫、霜疫霉病 | 高效氯氟氰菊酯+甲霜灵 |
| 疏果 | 生理落果后疏果 | 每穗留3-5个果 |

---

## 四、夏季管理（5-7月）

### 5月（果实膨大期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 施肥 | 壮果肥 | 高钾复合肥0.5-1.0kg/株+硫酸钾0.3kg/株 |
| 水分 | 均匀供水 | 保持土壤湿度65-80%，干湿交替 |
| 套袋 | 果实套袋 | 套袋前喷药，药干后立即套袋 |
| 病虫害 | 重点防治蒂蛀虫 | 氯氟氰菊酯+毒死蜱交替使用 |
| 地面覆盖 | 树盘覆盖 | 稻草或地膜覆盖，保湿防草 |

### 6月（果实成熟-采收期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 采收 | 分期采收 | 8-9成熟时采收，清晨或傍晚 |
| 采前控水 | 适度控水 | 采前7-10天停止灌水 |
| 采前喷药 | 采前防病 | 采前15天喷保护性杀菌剂 |
| 采后处理 | 快速预冷 | 采后2小时内完成预冷 |

### 7月（采果后-夏剪期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 采后修剪 | 回缩结果枝 | 留5-10cm桩，疏除过密枝 |
| 施肥 | 采后肥（最重要） | 有机肥15-20kg/株+复合肥1.0-1.5kg/株 |
| 清园 | 清理园内杂物 | 清除病果、落果、病枝叶 |
| 灌水 | 结合施肥灌水 | 采后及时灌水，促进树势恢复 |
| 病虫害 | 防治炭疽病 | 咪鲜胺或代森锰锌 |

---

## 五、秋季管理（8-10月）

### 8月（秋梢萌发期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 修剪 | 疏梢定梢 | 每条基枝留2-3条健壮秋梢 |
| 施肥 | 促梢肥 | 复合肥0.5-1.0kg/株+尿素0.3kg/株 |
| 水分 | 保证供水 | 保持土壤湿润，促秋梢生长 |
| 病虫害 | 防治秋梢害虫 | 防治尺蠖、卷叶蛾、瘿螨 |
| 除草 | 清除杂草 | 行间生草刈割覆盖树盘 |

### 9月（秋梢生长期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 施肥 | 壮梢肥 | 复合肥0.3-0.5kg/株 |
| 水分 | 正常供水 | 干旱及时灌水 |
| 病虫害 | 防治炭疽病、红蜘蛛 | 咪鲜胺+阿维菌素 |
| 修剪 | 疏除弱梢 | 及时疏除弱秋梢、病虫梢 |
| 生草管理 | 刈割绿肥 | 刈割行间绿肥覆盖树盘 |

### 10月（秋梢老熟期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 控水 | 开始控水 | 逐步减少灌水，促进枝梢老熟 |
| 施肥 | 增施磷钾肥 | 磷钾肥促枝梢老熟 |
| 病虫害 | 防治越冬病虫 | 防治蚧壳虫、煤烟病 |
| 修剪 | 整形修剪 | 疏除过密枝、下垂枝 |
| 扩穴 | 深翻改土 | 结合施有机肥深翻扩穴 |

---

## 六、冬季管理（11-1月）

### 11月（花芽分化初期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 控梢 | 控冬梢 | 人工抹除或喷施多效唑300-500ppm |
| 控水 | 保持干燥 | 彻底控水，保持土壤干燥 |
| 环割 | 促花环割 | 主干环割1圈，深达木质部 |
| 清园 | 冬季清园 | 清除落叶、落果，集中烧毁 |
| 涂白 | 树干涂白 | 石灰+硫磺+食盐(10:1:0.2) |

### 12月（花芽分化期）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 施肥 | 冬肥（基肥） | 有机肥15-25kg/株+钙镁磷肥1-1.5kg/株 |
| 修剪 | 冬季整形 | 疏除大枝、交叉枝、病虫枝 |
| 清园 | 喷石硫合剂 | 3-5波美度石硫合剂全园喷洒 |
| 防寒 | 防寒措施 | 树干涂白、树盘覆盖、灌防冻水 |
| 灌溉 | 防冻水 | 寒潮前灌透水 |

### 1月（休眠-花芽分化完成）
| 管理项目 | 操作内容 | 技术要求 |
|---------|---------|---------|
| 深翻 | 冬季深翻 | 深翻20-30cm，不伤大根 |
| 修梯田 | 水土保持 | 修整梯田、排水沟 |
| 检修 | 设备检修 | 检修灌溉系统、工具设备 |
| 规划 | 年度计划 | 制定全年管理计划，准备农资 |
| 培训 | 技术培训 | 组织果农技术培训 |

## 七、周年施肥方案

### 结果树周年施肥
| 施肥时期 | 肥料种类 | 单株用量(kg) | 占全年比例(%) |
|---------|---------|------------|-------------|
| 花前肥(2月) | 复合肥+硼砂 | 复合肥0.5-1.0+硼砂0.1 | 15-20 |
| 谢花肥(4月) | 复合肥+硫酸钾 | 复合肥0.3-0.5+硫酸钾0.3 | 10-15 |
| 壮果肥(5月) | 高钾复合肥+硫酸钾 | 高钾复合肥0.5-1.0+硫酸钾0.3 | 15-20 |
| 采后肥(7月) | 有机肥+复合肥 | 有机肥15-20+复合肥1.0-1.5 | 35-40 |
| 促梢肥(9月) | 复合肥+尿素 | 复合肥0.3-0.5+尿素0.2 | 10-15 |

## 八、周年病虫害防治方案

### 关键防治节点
| 防治时间 | 防治对象 | 推荐药剂 | 防治方法 |
|---------|---------|---------|---------|
| 1-2月(休眠期) | 越冬病虫源 | 3-5波美度石硫合剂 | 全园喷洒清园 |
| 3月(花期) | 霜疫霉病、蝽象 | 烯酰吗啉+吡虫啉 | 花前和谢花后各1次 |
| 4月(幼果期) | 蒂蛀虫、霜疫霉病 | 高效氯氟氰菊酯+甲霜灵 | 果径10mm和20mm时各1次 |
| 5月(果实膨大) | 蒂蛀虫 | 毒死蜱+阿维菌素 | 套袋前1次 |
| 6月(成熟期) | 采前病害 | 保护性杀菌剂 | 采前15天1次 |
| 7月(采后) | 炭疽病 | 咪鲜胺 | 修剪后立即喷施 |
| 8-9月(秋梢) | 尺蠖、瘿螨 | 氯氰菊酯+阿维菌素 | 秋梢抽出期 |
| 10-11月 | 越冬防治 | 矿物油 | 蚧壳虫若虫期 |
