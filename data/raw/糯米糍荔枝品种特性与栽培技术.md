# 糯米糍荔枝品种特性与栽培技术

> 糯米糍（*Litchi chinensis* Sonn. cv. Nuomici）被誉为"荔枝之王"，是荔枝品种中品质最顶级的品种之一。其果肉极厚、软滑香甜、入口即化、核极小，鲜食品质堪称荔枝之最。该品种主产于广东珠三角地区，是高端荔枝市场的标杆品种。

---

## 一、品种起源与历史

### 品种来源
糯米糍原产于广东，母树发现于广州市郊及东莞、深圳一带。因其果肉软滑如糯米糍（糯米制品），口感独特，故得名"糯米糍"。该品种在岭南地区已有数百年栽培历史，是广东荔枝中最负盛名的品种之一。

### 品种地位
糯米糍与桂味并称为"荔枝双绝"，在高端鲜食荔枝市场中占据不可替代的地位。

| 指标 | 数据 |
|------|------|
| 全国栽培面积占比 | 约5-8% |
| 珠三角产区占比 | 15-20% |
| 单株产量（成年树） | 20-40kg |
| 市场售价 | 高端品种，通常为普通品种的3-5倍 |
| 焦核率 | 90%以上（焦核率最高品种之一） |

## 二、植物学特征

### 树体特征
| 部位 | 特征描述 |
|------|---------|
| 树势 | 旺盛，树冠开张 |
| 枝条 | 较软易下垂，分枝力强 |
| 叶片 | 小叶4-6对，叶椭圆形，叶缘平展 |
| 叶色 | 淡绿色（区别于深绿品种） |
| 生长习性 | 一年抽梢3次，营养生长旺盛 |

### 花穗特征
| 特征 | 描述 |
|------|------|
| 花穗类型 | 纯花穗为主 |
| 花穗长度 | 12-20cm |
| 花量 | 中等偏多 |
| 雌雄花比例 | 1:5-1:10 |
| 开花习性 | 雌雄异熟，雄花量大 |
| 自花结实率 | 极低（<8%），需配置授粉树 |

### 果实特征
| 指标 | 数值 |
|------|------|
| 单果重 | 20-25g |
| 果形 | 心形或扁心形 |
| 果皮颜色 | 鲜红色，光滑有光泽 |
| 龟裂片 | 平（手感光滑），排列整齐 |
| 果肉颜色 | 蜡白色 |
| 果肉质地 | 极软滑，入口即化 |
| 风味 | 极甜，微香 |
| 可食率 | 82-86%（最高品种之一） |
| 可溶性固形物 | 19-22% |
| 种子大小 | 极小（焦核率>90%） |
| 焦核类型 | 完全退化焦核 |
| 果实发育期 | 70-75天 |

## 四、栽培技术要点

### 1. 园地选择与定植
| 项目 | 要求 |
|------|------|
| 土壤要求 | 土层深厚、肥沃、排水良好，pH 5.5-6.5 |
| 环境要求 | 冬季需<15℃低温积累，春季温暖无倒春寒 |
| 坡度要求 | <10°的缓坡或平地，避免冷空气沉积 |
| 定植密度 | 5m×6m（22株/亩） |
| 授粉树配置 | **必须配置**，推荐桂味或黑叶，比例4:1 |
| 定植时间 | 春植（2-3月）或秋植（9-10月） |

### 2. 肥水管理（极高要求）

| 施肥时期 | 肥料种类 | 用量（每株） | 作用 |
|---------|---------|------------|------|
| 采果肥（6-7月） | 腐熟有机肥+复合肥 | 20kg+0.8kg | 恢复树势 |
| 秋梢肥（8月） | 复合肥+尿素 | 0.5kg+0.3kg | 促秋梢健壮 |
| 促花肥（12月） | 复合肥+硼砂 | 0.5kg+20g | 促进花芽分化 |
| 壮花肥（2-3月） | 高磷复合肥 | 0.3-0.5kg | 提高花质 |
| 保果肥（4月） | 高钾复合肥+硝酸钙 | 0.5kg+0.3kg | 防裂果、减少落果 |

### 3. 水分管理（防裂果核心）
糯米糍栽培中**水分管理是决定成败的关键**：
- **花芽分化期**（12-1月）：适当控水，保持土壤相对干燥
- **开花期**（2-3月）：保持土壤湿润，田间持水量70-80%
- **果实发育前期**（4月）：保持稳定水分供给
- **果实发育中后期**（5-6月）：**严格保持水分均衡**，避免因暴雨、干旱交替导致裂果
- **采收前**（6月）：适度控水提升糖度

### 4. 防裂果综合技术（重中之重）
糯米糍的裂果率可达20-30%，严重时超过50%，需采取综合措施：

| 措施 | 具体方法 | 效果 |
|------|---------|------|
| 盖膜避雨 | 果实发育期搭建避雨棚或覆盖地膜 | 降低裂果率50-70% |
| 钙肥补充 | 谢花后喷0.1%硝酸钙+0.1%硼砂，7天/次×3-4次 | 增强果皮韧性 |
| 水分均衡 | 采用滴灌系统，保持土壤含水量稳定 | 减少水分剧烈变化 |
| 合理负载 | 每穗留果10-15个，避免负载过大 | 均衡营养供给 |
| 增施有机肥 | 有机肥改善土壤保水保肥能力 | 长期效果显著 |

### 5. 整形修剪
| 树龄 | 修剪重点 |
|------|---------|
| 幼树（1-3年） | 培养开张树形，定干50-60cm |
| 初果期（4-5年） | 疏除过密枝，培养结果枝组 |
| 盛果期（6-15年） | 采后重剪，更新结果母枝 |
| 老树（>15年） | 回缩更新，去弱留强 |

### 6. 保花保果
1. **放蜂授粉**：每10亩放置蜜蜂6-10箱
2. **辅助授粉**：采集黑叶等雄花花粉进行人工授粉
3. **叶面追肥**：谢花后喷施0.3%磷酸二氢钾+0.1%硼砂+0.1%氨基酸
4. **激素保果**：谢花后10天喷施赤霉素20mg/L+萘乙酸10mg/L
5. **环割保果**：谢花后对主干或主枝进行环割1圈

### 7. 病虫害防治
糯米糍是荔枝中**最易感病**的品种之一，需全程重点防治：

| 病虫害 | 为害严重性 | 防治策略 |
|--------|-----------|---------|
| 霜疫霉病 | **极为严重** | 重点全程防治，花穗期至成熟期每7-10天喷药一次 |
| 炭疽病 | 中等偏重 | 春梢期和果实发育期防治 |
| 褐斑病 | 中等 | 叶片发病初期防治 |
| 蒂蛀虫 | 严重 | 成虫羽化高峰期精准用药 |
| 荔枝蝽象 | 较重 | 花期重点防治 |
| 裂果相关病害 | 严重 | 防裂果为首要任务 |

## 五、采收与采后处理

### 采收标准
| 指标 | 标准 |
|------|------|
| 果皮颜色 | 鲜红色至深红色 |
| 可溶性固形物 | 20%以上 |
| 风味 | 极甜，软滑 |
| 采收时间 | 晴天早晨，避免高温时段 |

### 采后处理要点
糯米糍**耐贮运性差**，采后处理需格外重视：
1. **快速预冷**：采收后1小时内完成预冷（2-4℃）
2. **轻拿轻放**：果皮薄、肉质软，避免挤压损伤
3. **冷链运输**：全程2-4℃，相对湿度90-95%
4. **气调保鲜**：采用5%CO₂+5%O₂+90%N₂气调包装可延长保鲜至7-10天
5. **货架期**：常温货架期仅1-2天，需快速消费

## 六、优缺点分析

### 优点
| 项目 | 说明 |
|------|------|
| 品质顶级 | 果肉极厚、软滑香甜、焦核率最高 |
| 可食率最高 | 82-86%，为荔枝之最 |
| 市场价值极高 | 高端水果市场标杆品种 |
| 品牌效应强 | 消费者认知度极高 |

### 缺点
| 项目 | 说明 |
|------|------|
| 易裂果 | 裂果率20-30%，严重影响商品果率 |
| 易感霜疫霉病 | 抗病性极弱，需全程重点防控 |
| 耐贮运性差 | 采后褐变快，货架期短 |
| 对气候敏感 | 阴雨、干旱均影响产量 |
| 管理要求极高 | 需精细化管理，人力成本高 |
| 适应性窄 | 适宜产区局限于珠三角 |

## 七、适宜区域与发展建议

### 最适产区
珠三角的东莞、深圳、广州增城、广州从化等传统产区，以及具有类似气候条件的区域。

### 发展建议
1. **不宜盲目扩大种植**：适应性窄，非适宜区品质和产量难以保证
2. **配套防裂果设施**：避雨棚是糯米糍优质高产的重要保障
3. **品牌化经营**：依托产地品牌（如"东莞糯米糍"）提升附加值
4. **避雨栽培+精细管理**：采用避雨设施可大幅降低裂果率，提高商品果率至70%以上
5. **适量发展**：建议与桂味、妃子笑等品种搭配种植，分散风险
