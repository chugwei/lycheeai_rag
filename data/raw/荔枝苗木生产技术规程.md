# 荔枝苗木生产技术规程

> 本标准规定了荔枝苗木生产的术语和定义、苗圃建设、砧木培育、嫁接苗培育、苗木出圃及质量分级等技术要求。适用于荔枝苗木的规模化生产。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于荔枝各品种苗木的繁育生产，包括实生砧木苗培育、嫁接苗培育和容器苗培育。

## 二、苗圃建设

### 苗圃选址要求
| 条件 | 要求 |
|-----|------|
| 地形 | 平地或缓坡，排水良好 |
| 水源 | 水源充足，水质良好 |
| 土壤 | 砂壤土或壤土，pH 5.5-6.5 |
| 前茬 | 非荔枝连作地（避免连作障碍） |
| 交通 | 交通便利，便于苗木运输 |
| 环境 | 无污染源，远离疫区 |

### 苗圃规划
| 功能区 | 面积占比(%) | 功能 |
|-------|-----------|------|
| 砧木育苗区 | 30-40 | 培育实生砧木苗 |
| 嫁接育苗区 | 30-40 | 培育嫁接苗 |
| 采穗圃 | 5-10 | 提供优质接穗 |
| 母本园 | 5-10 | 提供优良母树 |
| 容器苗区 | 10-15 | 培育容器袋苗 |
| 附属设施 | 5-10 | 道路、排灌、工具房等 |

## 三、砧木培育

### 砧木品种选择
| 砧木品种 | 特性 | 嫁接亲和性 | 适用范围 |
|---------|------|----------|---------|
| 怀枝 | 根系发达，生长势强 | 优 | 通用砧木 |
| 山枝(野生荔枝) | 耐瘠薄，抗逆性强 | 优 | 山地果园 |
| 酸荔枝 | 适应性强，耐湿 | 优 | 低洼地 |
| 黑叶 | 生长快，根系发达 | 良 | 早产早丰 |

### 种子处理
| 操作环节 | 技术要求 |
|---------|---------|
| 种子采集 | 选用充分成熟的果实，去除果肉 |
| 种子清洗 | 清水洗净果肉残渣 |
| 种子消毒 | 50%多菌灵500倍液浸泡15分钟 |
| 催芽 | 湿沙层积催芽，温度25-30°C |
| 播种时间 | 种子采集后立即播种（新鲜种子发芽率高） |
| 播种密度 | 行距20-25cm，株距10-15cm |

### 砧木苗管理
| 管理项目 | 技术要求 |
|---------|---------|
| 遮荫 | 播种后搭建遮荫棚，遮光率50-60% |
| 浇水 | 保持土壤湿润，避免过干过湿 |
| 施肥 | 苗高10cm后开始追施稀薄尿素水(0.2%) |
| 除草 | 及时除草，防止杂草竞争 |
| 病虫害防治 | 重点防治炭疽病、蚜虫 |
| 间苗 | 苗高10-15cm时间苗，保留健壮苗 |
| 达到嫁接标准 | 苗高30-50cm，茎粗0.5-0.8cm |

## 四、接穗采集与处理

### 接穗选择
| 项目 | 技术要求 |
|-----|---------|
| 母树 | 品种纯正，树势健壮，丰产稳产，无检疫性病虫害 |
| 枝条类型 | 向阳、充实、芽眼饱满的一年生木质化枝条 |
| 枝条粗度 | 直径0.5-1.0cm |
| 采穗时间 | 春季嫁接于萌芽前15-20天采集，秋季嫁接随采随接 |
| 枝条长度 | 每段10-15cm，含2-3个饱满芽 |

### 接穗保存
| 保存方式 | 保存条件 | 保存期限 |
|---------|---------|---------|
| 沙藏 | 湿沙层积，温度10-15°C | 15-20天 |
| 冷藏 | 塑料袋密封，2-4°C | 30-60天 |
| 蜡封 | 接穗两端蜡封 | 7-10天 |

## 五、嫁接育苗

### 嫁接时期
| 季节 | 嫁接适期 | 成活率 | 说明 |
|-----|---------|-------|------|
| 春季 | 2月下旬-4月上旬 | 高(85-95%) | 最佳嫁接期 |
| 夏季 | 5-6月 | 中(70-80%) | 温度高，需遮荫 |
| 秋季 | 9-10月 | 高(80-90%) | 次佳嫁接期 |
| 冬季 | 11-1月 | 低(50-60%) | 低温，不宜嫁接 |

### 嫁接方法
| 嫁接方法 | 操作要点 | 适用 |
|---------|---------|------|
| 切接法 | 砧木剪断，切2-3cm切口，接穗楔形插入对齐形成层 | 砧木粗度0.5-1.0cm |
| 劈接法 | 砧木劈开2-3cm，接穗削成楔形插入 | 砧木粗度>1.0cm |
| 腹接法 | 砧木不剪断，在侧面切接口嫁接 | 补接或大树改接 |
| 芽接法 | 取单芽片贴接于砧木 | 接穗紧缺时 |

### 嫁接后管理
| 管理项目 | 技术要求 |
|---------|---------|
| 绑扎 | 嫁接膜包扎严密，仅露出芽眼 |
| 遮荫 | 嫁接后搭棚遮荫7-10天 |
| 抹芽 | 及时抹除砧木萌芽（每7天1次） |
| 解绑 | 新梢木质化后解除嫁接膜 |
| 立支柱 | 新梢长30cm时立竹竿绑缚 |
| 追肥 | 新梢老熟后追施复合肥 |
| 整形 | 苗高40-50cm时摘心定干 |

## 六、苗木出圃

### 苗木出圃标准
| 苗木类型 | 苗龄(月) | 苗高(cm) | 茎粗(cm) | 分枝数 | 根系 |
|---------|---------|---------|---------|-------|------|
| 嫁接苗(一级) | 12-18 | 50-80 | ≥1.0 | 2-3条 | 发达 |
| 嫁接苗(二级) | 12-18 | 40-60 | 0.8-1.0 | 1-2条 | 较发达 |
| 容器苗(一级) | 10-14 | 40-60 | ≥0.8 | 2-3条 | 根系充满袋 |
| 容器苗(二级) | 10-14 | 30-50 | 0.6-0.8 | 1-2条 | 根系较满 |

### 起苗要求
| 起苗方式 | 操作方法 | 注意事项 |
|---------|---------|---------|
| 裸根起苗 | 挖苗时保持根系完整，主根长≥25cm | 根系蘸泥浆保湿 |
| 带土起苗 | 土球直径15-20cm，用稻草或布包扎 | 土球不散 |
| 容器苗 | 直接搬运，保持容器完整 | 防止根系穿出袋外 |

### 苗木分级
| 等级 | 要求 | 用途 |
|-----|------|------|
| 一级苗 | 品种纯正，生长健壮，根系发达，无病虫害 | 新建果园 |
| 二级苗 | 品种纯正，生长正常，根系较发达，无病虫害 | 补植或一般果园 |
| 等外苗 | 不符合二级苗标准 | 留圃继续培育 |

### 苗木包装与运输
| 包装方式 | 操作方法 | 保鲜期(天) |
|---------|---------|-----------|
| 裸根苗 | 根部蘸泥浆+保湿袋+捆扎 | 3-5 |
| 带土苗 | 土球包扎+树冠捆绑 | 7-10 |
| 容器苗 | 直接装车，排列整齐 | 15-30 |

## 七、苗木检疫

### 检疫性病虫害
| 病虫害名称 | 检疫要求 |
|-----------|---------|
| 荔枝溃疡病 | 不得检出 |
| 荔枝根结线虫 | 不得检出 |
| 荔枝瘿螨 | 不得检出 |
| 红蜘蛛 | 活体不得检出 |

### 检疫证书
- 苗木出圃前必须经检疫部门检疫
- 凭检疫合格证书出圃和调运
- 跨省调运需办理植物检疫证书
