# 荔枝果醋发酵技术

> 荔枝果醋是以荔枝为原料，经酒精发酵和醋酸发酵两步发酵制成的酸性调味品。荔枝果醋兼具荔枝的果香和醋的酸爽，营养价值高，富含有机酸、氨基酸和矿物质。

---

## 一、荔枝果醋产品分类

### 产品类型

| 产品类型 | 总酸含量(g/100mL) | 发酵方式 | 特征 | 主要用途 |
|---------|----------------|---------|------|---------|
| **荔枝酿造醋** | ≥5.0 | 全发酵（酒精+醋酸） | 纯天然，营养丰富 | 调味品 |
| **荔枝果醋饮料** | 0.3-0.8 | 醋+果汁+糖调配 | 酸甜可口，可直接饮用 | 饮料 |
| **荔枝复合醋** | 3.5-5.0 | 荔枝醋+其他果醋调配 | 复合风味 | 特色调味 |
| **荔枝醋膏** | ≥10.0 | 浓缩 | 浓稠，风味浓郁 | 凉拌/蘸料 |
| **有机荔枝醋** | ≥5.0 | 有机原料发酵 | 有机认证 | 高端调味品 |

### 原料要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 品种 | 黑叶、妃子笑、三月红 | 高酸度品种为首选 |
| 成熟度 | 充分成熟（SSC≥16°Brix） | 糖度影响酒精度进而影响醋产量 |
| 新鲜度 | 采后48h内 | 次果、落果亦可利用 |
| 糖度 | ≥16°Brix | 不足可加糖调整 |
| 卫生 | 无腐烂变质 | 腐烂果影响醋品质 |

## 二、酒精发酵工艺

### 工艺流程

```
原料 → 清洗 → 去壳去核 → 破碎 → 成分调整 →
酒精发酵 → 酒醪 → 醋酸发酵 → 后熟 → 
澄清 → 调配 → 杀菌 → 灌装 → 成品
```

### 酒精发酵参数

| 工艺参数 | 推荐值 | 说明 |
|---------|-------|------|
| 发酵温度 | 25-28°C | 稍高于果酒，适合酒精产量 |
| 酵母菌种 | 酿酒酵母(Saccharomyces cerevisiae) | 耐酒精、产酒率高 |
| 接种量 | 0.3-0.5 g/L（活化后） | 30°C温水活化15-20min |
| 初始糖度 | 18-22°Brix | 不足加糖调整 |
| 初始pH | 3.8-4.2 | 用柠檬酸调整 |
| SO₂添加量 | 30-50 mg/L | 抑杂菌 |
| 发酵时间 | 5-8天 | 至残糖<5g/L |
| 终点酒精度 | 8-12%vol | 影响醋酸发酵速率 |

### 酒精发酵过程监控

| 时间(天) | 糖度(°Brix) | 酒精度(%vol) | 温度(°C) | 操作 |
|---------|-----------|------------|---------|------|
| 0 | 20-22 | 0 | 26-28 | 接种酵母 |
| 1 | 16-18 | 1-2 | 26-28 | 充氧30min |
| 2 | 12-14 | 3-4 | 26-28 | 控温 |
| 3 | 8-10 | 5-6 | 25-27 | 测糖度 |
| 5 | 4-6 | 8-9 | 24-26 | 测糖度+酒精度 |
| 7 | 2-4 | 9-11 | 24-26 | 糖度不再下降终止 |

## 三、醋酸发酵工艺

### 表面静置发酵法

| 参数 | 条件 |
|------|------|
| 酒精度 | 7-9%vol（稀释至6-7%vol最佳） |
| 醋酸菌种 | 醋酸杆菌(Acetobacter aceti/BA-1) |
| 接种量 | 10-20%（种醋或菌液） |
| 初始酸度 | 1-2% |
| 发酵温度 | 28-32°C |
| 发酵时间 | 15-25天 |
| 液面高度 | 10-15cm |
| 表面覆盖 | 纱布或透气膜 |

### 深层液体发酵法

| 参数 | 条件 |
|------|------|
| 酒精度 | 6-8%vol |
| 醋酸菌种 | 醋酸杆菌(Acetobacter pasteurianus) |
| 接种量 | 10-15%（种醋或菌液） |
| 发酵温度 | 30-32°C |
| 通风量 | 0.1-0.15 vvm |
| 搅拌转速 | 200-300 rpm |
| 溶解氧 | 2-4 mg/L |
| 发酵时间 | 48-72小时 |
| 产酸速率 | 0.08-0.12%/h |

### 两种发酵方式对比

| 对比项 | 表面静置发酵 | 深层液体发酵 |
|-------|------------|------------|
| 发酵时间 | 15-25天 | 48-72小时 |
| 设备投资 | 低 | 高 |
| 操作难度 | 简单 | 较高 |
| 产酸效率 | 低 | 高（5-10倍） |
| 风味品质 | 优（酯类丰富） | 良好（略逊于静置） |
| 适用规模 | 小-中型 | 中-大型 |
| 占地面积 | 大 | 小 |

### 醋酸发酵过程监控

| 时间(表面/深层) | 总酸(g/100mL) | 酒精度(%vol) | 操作 |
|---------------|-------------|------------|------|
| 0天/0h | 1.0-2.0 | 6-7 | 接种醋酸菌 |
| 5天/12h | 2.0-2.5 | 5-6 | 检测酸度 |
| 10天/24h | 3.0-3.5 | 4-5 | 检测酸度+酒精度 |
| 15天/36h | 4.0-4.5 | 3-4 | 加强通风 |
| 20天/48h | 5.0-5.5 | 1-2 | 接近终点 |
| 25天/60h | 5.5-6.0 | <0.5 | 终止发酵 |

## 四、后熟与陈酿

### 陈酿工艺

| 陈酿阶段 | 温度(°C) | 时间(月) | 容器 | 变化 |
|---------|---------|--------|------|------|
| 初步陈酿 | 15-20 | 1-3 | 不锈钢罐 | 酸味柔和，酯类增加 |
| 深度陈酿 | 10-15 | 3-6 | 橡木桶（可选） | 风味复杂化 |
| 澄清稳定 | 0-4 | 1-2 | 不锈钢罐 | 沉淀析出，澄清 |

## 五、澄清与过滤

### 澄清方法

| 方法 | 条件 | 效果 | 对品质影响 | 成本 |
|------|------|------|----------|------|
| **自然澄清** | 0-4°C, 1-2月 | 一般 | 无 | 低 |
| **硅藻土过滤** | 硅藻土0.5-1%, 板框过滤 | 良好 | 轻微影响 | 中 |
| **膜过滤** | 0.45-0.65μm微滤膜 | 优 | 几乎无影响 | 高 |
| **下胶澄清** | 明胶0.05-0.1g/L | 良好 | 需控制用量 | 中 |
| **离心澄清** | 4000-6000rpm | 良好 | 轻微影响 | 中 |

### 常见澄清问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 后浑浊 | 蛋白质-多酚复合物 | 添加PVPP或明胶处理 |
| 果胶浑浊 | 果胶未充分分解 | 加果胶酶处理 |
| 金属浑浊 | 铁/铜离子超标 | 加植酸或EDTA |
| 微生物浑浊 | 灭菌不彻底 | 加强灭菌，无菌灌装 |

## 六、调配与杀菌

### 调配标准

| 产品类型 | 总酸(g/100mL) | 糖度(°Brix) | 酒精度(%vol) | pH |
|---------|-------------|-----------|------------|----|
| 酿造醋（调味） | 5.0-6.0 | <1.0 | <0.5 | 2.8-3.2 |
| 果醋饮料（直饮） | 0.3-0.8 | 8-12 | <0.5 | 3.5-4.0 |
| 果醋饮料（浓缩） | 1.5-2.5 | 20-30 | <0.5 | 3.0-3.5 |

### 杀菌工艺

| 产品类型 | 杀菌方式 | 条件 | 效果 |
|---------|---------|------|------|
| 酿造醋 | 热灌装 | 75-80°C, 5min | 利用醋酸自身抑菌性 |
| 果醋饮料 | UHT | 121°C, 5-10s | 商业无菌 |
| 果醋饮料 | 巴氏杀菌 | 85°C, 15min | 冷藏保存 |

## 七、产品质量标准

### 感官指标

| 项目 | 酿造醋 | 果醋饮料 |
|------|-------|---------|
| 色泽 | 淡黄或琥珀色 | 荔枝原色或调配色 |
| 香气 | 荔枝果香+醋香协调 | 荔枝果香明显 |
| 口感 | 酸味柔和，回味中果香 | 酸甜适口，清爽 |
| 体态 | 澄清透明，无沉淀 | 澄清或微浊（若含果肉） |

### 理化指标

| 检测项目 | 酿造醋（GB 18187） | 果醋饮料（企标） |
|---------|-----------------|--------------|
| 总酸(以乙酸计, g/100mL) | ≥5.0 | 0.3-0.8 |
| 不挥发酸(g/100mL) | ≥0.5 | — |
| 可溶性固形物(°Brix) | — | 8-12 |
| 氨基态氮(g/100mL) | ≥0.05 | ≥0.01 |
| 砷(以As计, mg/L) | ≤0.5 | ≤0.5 |
| 铅(以Pb计, mg/L) | ≤1.0 | ≤1.0 |
| 菌落总数(CFU/mL) | ≤10000 | ≤100 |
| 大肠菌群(MPN/100mL) | ≤3 | ≤3 |
| 致病菌 | 不得检出 | 不得检出 |
