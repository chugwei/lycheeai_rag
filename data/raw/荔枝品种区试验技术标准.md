# 荔枝品种区试验技术标准

## 摘要

品种区域试验（区试）是评价新品种在不同生态环境下适应性、丰产性、稳产性和品质表现的关键环节，是品种推广和品种审定的必要程序。本文系统阐述荔枝品种区试验的技术标准体系，包括试验地选择、试验设计、评价指标、数据记录、统计分析方法以及试验结论判定标准，为荔枝新品种的区试工作提供标准化技术参考。

## 1 概述

品种区域试验是将候选品种在多个具有代表性的生态区域进行多点、多年栽培试验，以评估其跨区域适应能力。荔枝作为亚热带果树，不同品种对温度、降水、海拔和土壤的适应性差异显著，通过区试可以有效识别品种的最适栽培区域，为品种区域化推广提供科学依据。

## 2 试验地选择

### 2.1 试验地基本要求

| 选择指标 | 技术要求 |
| --- | --- |
| 代表性 | 能代表该生态区域典型气候和土壤条件 |
| 土壤 | 土壤类型典型，土层深厚（>100cm），pH值4.5-6.5 |
| 气候 | 无严重自然灾害频发，年均温≥18℃ |
| 灌溉 | 具备可靠灌溉条件，排水良好 |
| 管理水平 | 统一管理，排除人为管理差异 |

### 2.2 生态区域划分

荔枝区试应覆盖以下生态区：

| 生态区 | 代表地点 | 气候特点 |
| --- | --- | --- |
| 岭南核心区 | 广东增城、高州 | 温暖湿润，无霜或轻霜 |
| 华南沿海区 | 广西南宁、海南陵水 | 高温高湿，台风频繁 |
| 闽南区 | 福建平和、漳州 | 温暖湿润，偶有霜冻 |
| 西南区 | 四川泸州、云南德宏 | 干热河谷或亚热带高原 |
| 新兴栽培区 | 湖南怀化、江西赣州 | 冬季冷害风险较大 |

## 3 试验设计

### 3.1 设计原则

| 原则 | 说明 |
| --- | --- |
| 随机化 | 各处理随机排列，消除系统误差 |
| 重复 | 每个品种设置≥3次重复 |
| 局部控制 | 采用随机区组设计或裂区设计 |

### 3.2 试验规模

| 参数 | 技术要求 |
| --- | --- |
| 品种数量 | 候选品种+对照品种，每点≥8个品种 |
| 每品种株数 | ≥20株/品种/点 |
| 株行距 | 3m×4m 或 4m×5m |
| 试验年限 | 连续≥3年（从定植后第2年起至第4年） |
| 参试点 | 覆盖≥4个生态区，≥6个点 |

### 3.3 对照品种设置

每个试验区至少设置2个对照品种：一个全国推广品种（如桂味、妃子笑）和一个本地当家品种，用于比较候选品种的表现。

## 4 评价指标体系

### 4.1 生长指标

| 指标 | 测量方法 | 评价等级 |
| --- | --- | --- |
| 树高 | 实测（m） | — |
| 干径 | 地面以上10cm处实测（cm） | — |
| 冠幅 | 东西×南北实测（m） | — |
| 年生长量 | 当年新梢长度（cm） | 强/中/弱 |

### 4.2 丰产性指标

| 指标 | 测量方法 |
| --- | --- |
| 单株产量（kg/株） | 实测称重 |
| 产量稳定性系数（CV） | 多年产量变异系数 |
| 挂果率 | 结果株数/总株数×100% |
| 单位面积产量（kg/667m²） | 按株行距计算 |

### 4.3 品质指标

| 指标 | 测量方法 |
| --- | --- |
| 单果质量（g） | 30个单果均值 |
| 可溶性固形物（°Brix） | 糖度仪测定 |
| 可溶性糖（g/100g） | 蒽酮比色法 |
| 可滴定酸（g/100g） | 酸碱滴定法 |
| 可食率（%） | 称重计算 |

### 4.4 适应性指标

| 指标 | 观测内容 |
| --- | --- |
| 抗寒性 | 低温胁迫后存活率、恢复率 |
| 抗风性 | 台风后倒伏率、断枝率 |
| 抗病性 | 主要病害发病率、病情指数 |
| 抗旱性 | 水分胁迫下存活率 |

## 5 数据记录与统计分析

### 5.1 统计分析方法

- 产量数据：随机区组设计单因素方差分析，Duncan法或LSD法多重比较
- 品质数据：多因素方差分析（品种×地点×年份）
- 遗传增益分析：计算候选品种较对照品种的相对增益率
- 稳定性分析：Eberhart-Russell模型或多点试验的BLUP值分析

### 5.2 区试结论判定标准

| 结论类别 | 判定标准 |
| --- | --- |
| 表现优良 | 丰产性显著优于对照（P<0.05），品质优良，适应性强 |
| 表现一般 | 丰产性不劣于对照，品质可接受，有局部推广价值 |
| 不宜推广 | 丰产性显著劣于对照或品质不合格或适应性差 |
