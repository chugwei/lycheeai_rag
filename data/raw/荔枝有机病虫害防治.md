# 荔枝有机病虫害防治

## 摘要

有机病虫害防治是荔枝有机生产的核心技术环节，要求在禁止使用化学合成农药的前提下，通过生态调控、生物防治和物理防治等手段有效控制病虫害。本指南系统阐述了荔枝主要病虫害的有机防治技术体系，为有机荔枝园提供安全有效的病虫害管理方案。

## 1. 引言

在有机生产条件下，荔枝病虫害防治面临较大挑战。传统化学农药的禁用，使得病虫害防控更加依赖生态调控和生物防治。据调查，有机荔枝园在转换初期病虫害发生率较常规果园高30%-50%，但经过2-3年的生态调控，病虫害发生率可降至常规水平以下。建立科学的有机病虫害防治体系，是实现有机荔枝优质高产的关键。

## 2. 有机病虫害防治原则

| 原则 | 内容 | 实施方法 |
|------|------|----------|
| 预防为主 | 优先预防而非治疗 | 加强监测、生态调控 |
| 生态优先 | 利用自然生态力量 | 天敌保护、生物多样性 |
| 生物防治 | 优先使用生物制剂 | 微生物农药、天敌昆虫 |
| 物理辅助 | 辅以物理防治手段 | 诱捕、阻隔、物理清除 |
| 最后手段 | 必要时使用允许药剂 | 矿物源和植物源农药 |

## 3. 荔枝主要病虫害有机防治

### 3.1 荔枝蝽防治

| 防治阶段 | 技术措施 | 具体方法 | 效果 |
|----------|----------|----------|------|
| 成虫期 | 性信息素诱杀 | 性诱剂悬挂诱捕 | 减少成虫60% |
| 若虫期 | 白僵菌防治 | 喷洒白僵菌悬浮液 | 死亡率70% |
| 若虫期 | 大斑蝽释放 | 人工释放天敌 | 捕食率50% |
| 卵期 | 赤眼蜂释放 | 释放寄生蜂 | 寄生率60% |
| 全年 | 粘虫板诱杀 | 黄色粘虫板 | 辅助控制 |

**白僵菌使用规范**：

| 参数 | 标准 |
|------|------|
| 有效菌量 | ≥20亿孢子/g |
| 使用浓度 | 50-80亿孢子/mL |
| 施用时期 | 若虫盛发期 |
| 施用频次 | 每10-15天1次 |
| 注意事项 | 避免阳光直射 |

### 3.2 荔枝蒂蛀虫防治

| 防治阶段 | 技术措施 | 具体方法 | 效果 |
|----------|----------|----------|------|
| 成虫期 | 性诱剂诱杀 | 悬挂诱捕器 | 诱杀率50% |
| 卵期 | 核型多角体病毒 | 喷洒病毒悬浮液 | 死亡率60% |
| 幼虫期 | 苏云金杆菌(BT) | 喷洒BT乳剂 | 死亡率50% |
| 果实期 | 套袋防护 | 双层纸袋套果 | 防治率90% |
| 全年 | 清洁果园 | 清除落果 | 减少虫源40% |

**套袋技术规范**：

| 参数 | 标准 |
|------|------|
| 套袋时期 | 谢花后15-20天 |
| 袋型 | 双层套袋(内白外黑) |
| 套袋密度 | 每果1袋 |
| 除袋时期 | 采收前7-10天 |
