# 荔枝病虫防控效果评估标准

## 摘要

荔枝病虫防控效果评估是评价病虫害防治措施有效性的关键环节，也是优化防控方案、指导生产的重要依据。本文系统介绍荔枝病虫防控效果评估的指标体系、评估方法、评估标准和数据记录要求。

## 1. 评估指标体系

### 1.1 病害防控效果指标

| 指标 | 定义 | 计算方法 |
|-----|------|---------|
| 病害防效 | 防治后病害减少的程度 | (对照区发病率 - 处理区发病率)/对照区发病率 ×100% |
| 发病率 | 发病植株或果实比例 | 发病数/调查总数 ×100% |
| 病情指数 | 病害严重程度的加权平均值 | Σ(各级病叶数×级别值)/(总调查叶数×最高级别)×100 |
| 减产率 | 因病虫造成的产量损失 | (理论产量 - 实际产量)/理论产量 ×100% |

### 1.2 虫害防控效果指标

| 指标 | 定义 | 计算方法 |
|-----|------|---------|
| 虫口减退率 | 防治后虫口减少的程度 | (防治前虫口 - 防治后虫口)/防治前虫口 ×100% |
| 诱杀率 | 诱杀器诱杀害虫的比例 | 诱杀数/总发生数 ×100% |
| 受害率 | 受害植株或果实比例 | 受害数/调查总数 ×100% |
| 经济损失率 | 害虫造成的产量损失 | 受害造成的产量损失/总产量 ×100% |

## 2. 评估方法

### 2.1 田间调查方法

| 调查项目 | 方法 | 样本量 |
|---------|------|--------|
| 病害调查 | 五点取样法，每点调查 10 株 | 50 株/园 |
| 虫害调查 | 五点取样法，每点调查 20 株 | 100 株/园 |
| 灯诱调查 | 记录灯诱害虫种类和数量 | 每日记录 |
| 黄板调查 | 记录黄板诱杀数量 | 每周记录 |

### 2.2 病害分级标准

| 病害 | 级别 | 标准 |
|-----|------|------|
| 霜疫霉病 | 0 级 | 无病斑 |
| 霜疫霉病 | 1 级 | 病斑面积 <10% |
| 霜疫霉病 | 2 级 | 病斑面积 10-25% |
| 霜疫霉病 | 3 级 | 病斑面积 25-50% |
| 霜疫霉病 | 4 级 | 病斑面积 50-75% |
| 霜疫霉病 | 5 级 | 病斑面积 >75% |

### 2.3 虫害分级标准

| 害虫 | 级别 | 标准（每叶虫数） |
|-----|------|----------------|
| 红蜘蛛 | 0 级 | 0 头 |
| 红蜘蛛 | 1 级 | 1-5 头 |
| 红蜘蛛 | 2 级 | 6-20 头 |
| 红蜘蛛 | 3 级 | 21-50 头 |
| 红蜘蛛 | 4 级 | 51-100 头 |
| 红蜘蛛 | 5 级 | >100 头 |

## 3. 评估标准

### 3.1 病害防控效果评价

| 防效（%） | 评价等级 |
|---------|---------|
| ≥80 | 极显著（非常有效） |
| 60-79 | 显著（有效） |
| 40-59 | 一般 |
| 20-39 | 较差 |
| <20 | 无效 |

### 3.2 虫害防控效果评价

| 虫口减退率（%） | 评价等级 |
|--------------|---------|
| ≥80 | 极显著 |
| 60-79 | 显著 |
| 40-59 | 一般 |
| 20-39 | 较差 |
| <20 | 无效 |

### 3.3 综合防控效果评价

| 评价维度 | 权重 | 评价内容 |
|---------|------|---------|
| 防效 | 40% | 病害/虫害控制效果 |
| 产量影响 | 30% | 产量损失率 |
| 品质影响 | 15% | 果实品质指标 |
| 生态影响 | 15% | 天敌保护、环境影响 |

## 4. 数据记录与报告

### 4.1 记录内容

| 项目 | 内容 |
|-----|------|
| 调查时间 | 年、月、日 |
| 调查地点 | 果园位置 |
| 天气条件 | 温度、湿度、降雨 |
| 防治措施 | 药剂名称、浓度、用量、方法 |
| 调查结果 | 各项指标数据 |

### 4.2 报告格式

- 封面：标题、单位、日期
- 摘要：简要概述评估结果
- 正文：调查方法、结果分析、效果评价
- 结论与建议：防控方案优化建议
- 附表：调查数据记录表

## 5. 注意事项

- 评估应在防治前、防治后（3-7 天）分别调查。
- 设置对照区，确保评估结果的可靠性。
- 调查应在同一时间、同一条件下进行。
- 数据记录应真实、准确、完整。
