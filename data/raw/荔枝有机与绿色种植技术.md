# 荔枝有机与绿色种植技术

> 随着消费者对食品安全和品质的要求不断提高，有机荔枝和绿色荔枝的市场需求逐年增长。实施标准化生产、减少化学投入品使用，是荔枝产业转型升级的重要方向。

---

## 一、有机与绿色标准概述

### 认证体系对比

| 项目 | 绿色食品（A级） | 绿色食品（AA级） | 有机食品 |
|------|--------------|---------------|---------|
| **化学合成氮肥** | 限制使用 | **禁止** | **禁止** |
| **化学合成磷钾肥** | 限制使用 | 限制使用 | **禁止** |
| **化学农药** | 限制使用(低毒) | **禁止** | **禁止** |
| **生长调节剂** | 限制使用 | **禁止** | **禁止** |
| **转基因** | 禁止 | 禁止 | 禁止 |
| **转换期** | 1年 | 2年 | 2-3年 |
| **检查认证** | 每年 | 每年 | 每年 |

### 允许使用的投入品
| 类别 | 有机农业允许 | 绿色农业允许 |
|------|------------|------------|
| **肥料** | 有机肥、绿肥、生物菌肥、天然矿物(磷矿粉、钾矿粉、石灰等) | 有机肥+部分化肥(限量) |
| **杀虫剂** | 植物源(印楝素、除虫菊素)、微生物(Bt、白僵菌)、矿物(硫磺、波尔多液) | 有机+部分低毒化学农药(限量) |
| **杀菌剂** | 硫磺、波尔多液、石硫合剂、铜制剂、硅酸盐、小苏打 | 有机+部分化学杀菌剂(限量) |
| **除草** | 覆盖、机械、人工 | 覆盖+机械+选择性除草剂(限量) |

## 二、有机荔枝园选址要求

| 条件项 | 要求 |
|-------|------|
| **隔离带** | 距常规果园>50m（或设20m以上缓冲带） |
| **水源** | 独立水源，水质符合GB 5084标准 |
| **土壤** | 3年以上未使用禁用物质 |
| **周边环境** | 无工业污染源，远离公路>100m |
| **历史** | 前茬未种植转基因作物 |

## 三、有机果园土壤培肥

### 肥料来源

| 肥料类型 | 来源 | 制备方法 | 施用量(kg/亩/年) |
|---------|------|---------|----------------|
| **腐熟农家肥** | 猪粪、牛粪、鸡粪(需有机认证饲料) | 堆沤腐熟(>60°C, 15天) | 2000-4000 |
| **绿肥** | 紫云英、田菁、柱花草 | 果园行间种植后翻压 | 鲜草1500-3000 |
| **商品有机肥** | 需有机认证 | 直接施用 | 500-1000 |
| **饼肥** | 花生麸、菜籽麸、豆粕 | 沤制30天以上 | 200-500 |
| **生物菌肥** | 固氮菌、解磷解钾菌 | 直接施用 | 100-200 |
| **矿物肥料** | 磷矿粉、钾矿粉、石灰 | 直接施用 | 根据需要 |

### 培肥方案

| 时期 | 培肥措施 | 用量(每株) |
|------|---------|-----------|
| 冬季基肥(12-1月) | 腐熟有机肥+磷矿粉+草木灰 | 25-30kg+0.5kg+2-3kg |
| 采后肥(7月) | 饼肥+生物菌肥 | 3-5kg+0.5kg |
| 花前追肥(2月) | 腐熟有机液肥 | 15-20L |
| 壮果追肥(5月) | 腐熟有机液肥+草木灰浸出液 | 15-20L+适量 |
| 叶面追肥 | 海藻酸、氨基酸、微生物发酵液 | 按说明使用 |

## 四、有机果园病虫害防治

### 综合防治体系

| 防治层次 | 方法 | 具体措施 |
|---------|------|---------|
| **第一层（预防）** | 农业防治 | 合理修剪、清园、生草栽培、套袋、覆膜 |
| **第二层（生物）** | 天敌利用+生物农药 | 释放寄生蜂、捕食螨；使用Bt、白僵菌 |
| **第三层（物理）** | 诱杀+屏障 | 杀虫灯、粘虫板、防虫网 |
| **第四层（矿物源）** | 允许的矿物源药剂 | 石硫合剂、波尔多液、硫磺粉 |

### 许可使用的有机农药

| 农药类型 | 代表药剂 | 防治对象 | 使用要求 |
|---------|---------|---------|---------|
| **植物源杀虫剂** | 印楝素0.3%EC | 蒂蛀虫、卷叶蛾 | 800倍液，药效7天 |
| **植物源杀虫剂** | 苦参碱0.5%AS | 蚜虫、蓟马 | 500-800倍液 |
| **植物源杀虫剂** | 鱼藤酮2.5%EC | 多种害虫 | 600倍液 |
| **植物源杀菌剂** | 大黄素甲醚0.5%AS | 霜疫霉病 | 600倍液 |
| **微生物杀虫剂** | Bt 8000IU/mg | 鳞翅目幼虫 | 800倍液，避光 |
| **微生物杀虫剂** | 白僵菌100亿/g | 蒂蛀虫、天牛 | 800倍液 |
| **微生物杀菌剂** | 枯草芽孢杆菌10亿/g | 霜疫霉病、炭疽病 | 500倍液 |
| **微生物杀菌剂** | 木霉菌 | 根部病害 | 1000倍液 |
| **矿物源药剂** | 石硫合剂 | 多种病虫(清园) | 3-5波美度(冬季) |
| **矿物源药剂** | 波尔多液1:1:200 | 霜疫霉病 | 现配现用 |
| **矿物源药剂** | 硫磺粉 | 白粉病、螨类 | 喷施或熏蒸 |
| **矿物源药剂** | 矿物油99%EC | 介壳虫、螨类 | 200倍(冬季)/400倍(生长期) |

## 五、绿色食品生产规程

### 农药使用准则（绿色A级）

| 防治对象 | 推荐药剂 | 限制条件 |
|---------|---------|---------|
| 霜疫霉病 | 代森锰锌、嘧菌酯、烯酰吗啉 | 每种药剂每季不超过3次 |
| 炭疽病 | 咪鲜胺、苯醚甲环唑、吡唑醚菌酯 | 安全间隔期>7天 |
| 蒂蛀虫 | 氯氰菊酯、阿维菌素、甲维盐 | 安全间隔期>14天 |
| 荔枝蝽象 | 敌百虫、溴氰菊酯 | 花期禁用 |
| 蚜虫 | 吡虫啉、啶虫脒 | 花期慎用 |

### 肥料使用准则（绿色A级）

| 肥料类型 | 允许/限制 | 要求 |
|---------|----------|------|
| 有机肥 | 推荐 | 充分腐熟 |
| 绿肥 | 推荐 | 翻压入土 |
| 化肥(N) | **限制** | 总量不超过N 15kg/亩/年 |
| 化肥(P₂O₅) | 限制 | 不超过P₂O₅ 8kg/亩/年 |
| 化肥(K₂O) | 限制 | 不超过K₂O 20kg/亩/年 |

## 六、有机荔枝认证流程

```
第1步：信息收集（了解认证标准和要求）
第2步：选择认证机构（如中绿华夏、南京国环等）
第3步：提交申请（填写申请书+果园基本信息）
第4步：合同签订（确定费用和认证计划）
第5步：文件审核（提交生产管理记录）
第6步：现场检查（实地检查+取样检测）
第7步：认证决定（审核通过/不通过）
第8步：获得证书（有效期为1年）
第9步：年度审查（每年1次监督检查）
```

## 七、生产记录管理

### 必需记录项目

| 记录类型 | 记录内容 | 记录频率 |
|---------|---------|---------|
| **农事操作记录** | 修剪、施肥、灌溉、中耕等 | 每次操作后 |
| **肥料使用记录** | 种类、来源、用量、施用日期 | 每次施肥 |
| **农药使用记录** | 名称、用量、稀释倍数、施用日期、安全间隔期 | 每次施药 |
| **收获记录** | 采收日期、品种、产量、批次 | 每次采收 |
| **销售记录** | 销售日期、数量、客户、批次号 | 每次销售 |
| **培训记录** | 培训内容、参加人员 | 每次培训 |
| **投入品采购记录** | 购入日期、来源、数量 | 每次采购 |
