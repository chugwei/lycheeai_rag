# 荔枝品种审定登记指南

## 摘要

品种审定登记是荔枝新品种正式推广的前置法定程序，通过行政审定确认品种的特异性、一致性、稳定性（DUS）和生产应用价值。本文系统梳理我国荔枝品种审定登记的法规体系、申请流程、审定标准和技术要求，为育种单位和新品种培育者提供全流程申报指南。

## 1 法规与政策依据

| 法规文件 | 主要内容 |
| --- | --- |
| 《中华人民共和国种子法》（2021修订） | 品种审定的法定依据 |
| 《主要农作物品种审定办法》 | 审定程序与技术要求 |
| 《植物新品种保护条例》 | 品种权申请与保护 |
| 《荔枝、龙眼品种志》 | 品种特征描述参考 |

荔枝虽不属于主要农作物目录中的"主要农作物"，但作为重要果树，其品种审定主要参照林木品种审定程序，由省级林业部门或农业部门负责。

## 2 品种审定类型

| 审定类型 | 适用范围 | 主管部门 |
| --- | --- | --- |
| 国家级审定 | 拟在多个省份推广的品种 | 国家林业和草原局/农业农村部 |
| 省级审定 | 在本省区域内推广的品种 | 省级林业/农业部门 |
| 自主登记 | 非主要农作物品种 | 国家种子管理总站品种登记系统 |

## 3 申请流程

### 3.1 申请前准备

| 准备工作 | 内容 |
| --- | --- |
| DUS测试 | 至少3年DUS测试数据 |
| 区域试验 | 至少3年、4个以上地点区试 |
| 品种命名 | 确定品种名称，检索是否有重名 |
| 品种权 | 建议同步申请植物新品种权 |

### 3.2 申报材料

| 材料 | 内容要求 |
| --- | --- |
| 品种审定申请书 | 品种基本信息、来源、选育过程 |
| 品种特征特性报告 | DUS测试报告 |
| 区域试验报告 | 多年多点产量、品质数据 |
| 品种权证书 | 如已取得 |
| 品种标准照片 | 树体、叶片、果实标准照片 |
| 品种样本 | 接穗或苗木 |

### 3.3 审定时限

| 环节 | 时限 |
| --- | --- |
| 材料受理 | 30个工作日 |
| 技术审查 | 60个工作日 |
| 品种审定委员会审议 | 每年召开1-2次 |
| 公告 | 审议通过后30个工作日内 |

## 4 审定标准

### 4.1 DUS标准

| 标准项 | 要求 |
| --- | --- |
| 特异性 | 与已知品种有显著差异 |
| 一致性 | 品种内变异率≤5% |
| 稳定性 | 连续两代性状稳定 |

### 4.2 生产价值标准

| 指标 | 标准 |
| --- | --- |
| 品质 | 不低于现有推广品种平均水平 |
| 产量 | 不低于对照品种，或具有其他突出优势 |
| 适应性 | 至少在本省2个以上生态区表现良好 |

## 5 审定后的管理

| 管理事项 | 内容 |
| --- | --- |
| 审定编号 | 全国统一的品种审定编号 |
| 推广管理 | 在审定区域内推广 |
| 种子生产 | 需建立标准化种子生产基地 |
| 年度报告 | 育种单位需定期报告推广应用情况 |
| 撤销机制 | 发现严重问题可申请撤销审定 |

## 6 品种登记（非主要农作物）

对于未列入主要农作物目录的荔枝品种，可采用自主登记方式，在"国家农作物品种登记系统"进行登记，获得品种登记编号，便于品种管理和市场推广。
