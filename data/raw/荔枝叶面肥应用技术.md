# 荔枝叶面肥应用技术

## 摘要

叶面施肥是荔枝快速补充养分、矫正缺素症状、提高果实品质的重要辅助手段。本文系统介绍了荔枝叶面肥的作用原理、常用叶面肥料类（大量元素、微量元素、氨基酸类、腐殖酸类等）、配制方法、喷施技术、各生育期应用方案以及叶面施肥的效果评价，结合不同品种和土壤条件提出了差异化的叶面肥应用策略，为荔枝叶面肥的科学合理施用提供技术指导。

## 一、叶面施肥的原理与优势

### 1.1 叶面吸收机制

叶片通过角质层和气孔吸收养分。养分吸收速率受多种因素影响：
- 叶片年龄：嫩叶吸收率>老叶
- 叶背气孔多，吸收率是叶面的3-5倍
- 温度20-25℃时吸收效果最佳
- 湿度65%-80%时吸收率最高
- 表面活性剂可提高吸收率30%-50%

### 1.2 叶面施肥的优势

| 优势 | 说明 |
|------|------|
| 养分利用率高 | 叶面吸收利用率可达80%-90%，远高于土壤施肥 |
| 见效快 | 喷施后30分钟开始吸收，24-48小时见效 |
| 针对性强 | 可针对性矫正缺素症状 |
| 用量省 | 仅为土壤施肥的10%-20% |
| 不受土壤影响 | 不受土壤pH、吸附、固定等影响 |
| 可与农药混用 | 省工增效 |

### 1.3 局限性

| 局限性 | 说明 |
|------|------|
| 用量有限 | 一次喷施养分总量有限 |
| 持效期短 | 一般7-10天需再次喷施 |
| 叶面损伤风险 | 浓度过高易烧伤叶片 |
| 受天气影响 | 雨天、强光下效果差 |
| 不能替代根施 | 只能作为补充手段 |

## 二、常用叶面肥料类

### 2.1 大量元素叶面肥

| 肥料名称 | 养分含量 | 常用浓度(%) | 主要作用 |
|---------|---------|-----------|---------|
| 尿素 | N 46% | 0.2-0.5 | 补充氮素，促进生长 |
| 磷酸二氢钾 | P₂O₅ 52%, K₂O 34% | 0.2-0.4 | 促进花芽分化，壮果增糖 |
| 硝酸钾 | N 13%, K₂O 46% | 0.3-0.5 | 补充氮钾 |
| 硝酸钙 | CaO 26%, N 11% | 0.2-0.3 | 补钙防裂果 |
| 硫酸钾 | K₂O 50% | 0.3-0.5 | 补充钾素 |
| 磷酸二氢铵 | N 12%, P₂O₅ 61% | 0.2-0.3 | 补充氮磷 |

### 2.2 微量元素叶面肥

| 肥料名称 | 元素含量 | 常用浓度(%) | 适用症状 |
|---------|---------|-----------|---------|
| 硼砂 | B 11% | 0.1-0.2 | 花而不实 |
| 硫酸锌 | Zn 35% | 0.1-0.2 | 小叶簇生 |
| 硫酸亚铁 | Fe 19% | 0.1-0.3 | 缺铁黄化 |
| 硫酸镁 | Mg 16% | 0.1-0.2 | 叶脉间失绿 |
| 硫酸锰 | Mn 32% | 0.05-0.15 | 缺锰症状 |
| 钼酸铵 | Mo 54% | 0.02-0.05 | 缺钼症状 |
| 螯合铁(EDTA-Fe) | Fe 13% | 0.05-0.10 | 高效补铁 |
| 螯合锌(EDTA-Zn) | Zn 15% | 0.05-0.10 | 高效补锌 |

### 2.3 有机类叶面肥

| 类型 | 主要成分 | 常用浓度 | 主要作用 |
|------|---------|---------|---------|
| 氨基酸叶面肥 | 18种氨基酸 | 500-800倍 | 促进生长，增强抗性 |
| 腐殖酸叶面肥 | 腐殖酸 | 500-1000倍 | 改善品质，调节生长 |
| 海藻酸叶面肥 | 海藻提取物 | 800-1000倍 | 增强抗逆性 |
| 糖醇叶面肥 | 糖醇螯合元素 | 500-800倍 | 高效传输养分 |

## 三、配制方法与技术要求

### 3.1 浓度计算

| 肥料 | 配制100升药液用量 | 常用浓度 |
|------|-----------------|---------|
| 尿素 | 200-500g | 0.2%-0.5% |
| 磷酸二氢钾 | 200-400g | 0.2%-0.4% |
| 硼砂 | 100-200g | 0.1%-0.2% |
| 硫酸锌 | 100-200g | 0.1%-0.2% |
| 硫酸亚铁 | 100-300g | 0.1%-0.3% |

### 3.2 配制顺序

1. 先用少量温水溶解各组分
2. 按微量元素→大量元素→调节剂的顺序加入
3. 边加边搅拌，避免沉淀
4. 最后调节pH至6.0-7.0
5. 现配现用，不宜久置

### 3.3 喷施技术参数

| 参数 | 技术要求 |
|------|---------|
| 喷施时间 | 阴天或晴天下午4时后 |
| 喷施温度 | 15-25℃ |
| 喷施间隔 | 7-15天 |
| 喷施量 | 每株3-10升(视树冠大小) |
| 喷施部位 | 叶片正反面均匀喷施 |
| 雾化程度 | 雾滴细密均匀 |
| 湿润标准 | 叶片正反面均湿润，不滴水 |

## 四、各生育期应用方案

### 4.1 花芽分化期（12月至1月）

| 方案 | 配方 | 作用 |
|------|------|------|
| 促花方案 | 0.3%磷酸二氢钾+0.1%硼砂 | 促进花芽分化 |
| 辅助方案 | 0.1%钼酸铵+0.1%硫酸锌 | 提高花质 |

### 4.2 开花坐果期（3月至4月）

| 方案 | 配方 | 作用 |
|------|------|------|
| 盛花期 | 0.1%硼砂+0.2%磷酸二氢钾+0.1%尿素 | 促进授粉受精 |
| 谢花后 | 0.2%尿素+0.2%磷酸二氢钾 | 补充营养消耗 |
| 幼果期 | 0.1%硫酸锌+0.2%尿素+0.1%硼砂 | 促进果实发育 |

### 4.3 果实膨大期（5月至6月）

| 方案 | 配方 | 作用 |
|------|------|------|
| 壮果方案 | 0.3%磷酸二氢钾+0.1%硫酸镁 | 促进糖分积累 |
| 防裂果方案 | 0.3%氯化钙(或糖醇钙) | 减少裂果 |
| 增色方案 | 0.2%磷酸二氢钾+氨基酸500倍 | 促进着色 |

### 4.4 秋梢期（7月至9月）

| 方案 | 配方 | 作用 |
|------|------|------|
| 促梢方案 | 0.3%尿素+0.2%磷酸二氢钾 | 促进秋梢抽生 |
| 壮梢方案 | 0.3%磷酸二氢钾+0.1%硫酸锌 | 促进枝梢老熟 |

## 五、叶面肥与农药混用

| 农药类型 | 能否混用 | 注意事项 |
|---------|---------|---------|
| 杀菌剂(代森锰锌等) | 可以 | 非碱性农药均可混用 |
| 杀虫剂(菊酯类) | 可以 | 现混现用 |
| 波尔多液 | 不可 | 碱性，降低叶面肥效果 |
| 石硫合剂 | 不可 | 强碱性 |
| 矿物油 | 慎用 | 影响叶面吸收 |
| 植物生长调节剂 | 可以 | 协同增效 |

## 六、不同品种叶面肥需求特点

| 品种 | 重点需求元素 | 推荐叶面肥方案 |
|------|-----------|-------------|
| 桂味 | 钾、钙、硼 | 磷酸二氢钾+硼砂+氯化钙 |
| 糯米糍 | 钾、钙、锌 | 磷酸二氢钾+糖醇钙+硫酸锌 |
| 妃子笑 | 氮、钾、硼 | 尿素+磷酸二氢钾+硼砂 |
| 鸡嘴荔 | 钾、硼、钙 | 磷酸二氢钾+硼砂+硝酸钙 |
| 仙进奉 | 钾、钙、镁 | 磷酸二氢钾+氯化钙+硫酸镁 |

## 七、效果评价

| 评价指标 | 施用叶面肥 | 不施用 | 提高幅度 |
|---------|----------|-------|---------|
| 坐果率(%) | 3.5-5.0 | 1.5-3.0 | +50%-100% |
| 单果重(g) | 24-28 | 20-24 | +15%-20% |
| 可溶性固形物(%) | 18-21 | 16-18 | +10%-15% |
| 叶片叶绿素(SPAD) | 40-50 | 35-40 | +15%-25% |
| 缺素症状发生率(%) | 3-8 | 15-30 | -60%-80% |
| 裂果率(%) | 3-8 | 8-18 | -40%-55% |

## 八、注意事项

1. 避免高温强光下喷施，防止叶片烧伤
2. 叶面肥浓度宜控制在标示范围内，宁低勿高
3. 重点喷施叶背（气孔多，吸收好）
4. 雨后或灌溉后及时补喷
5. 不可用硬水（如井水）配制，必要时软化处理
6. 喷施后6小时内遇雨必须补喷
7. 叶面肥不能替代根际施肥，两者配合使用
