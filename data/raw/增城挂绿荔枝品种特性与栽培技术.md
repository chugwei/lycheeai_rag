# 增城挂绿荔枝品种特性与栽培技术

## 摘要

增城挂绿（Litchi chinensis Sonn. cv. 'Zengcheng Gualv'）是广东省增城区的原产优质荔枝品种，以果皮红中带绿、果肉晶莹爽脆、风味独特而闻名。本文系统阐述了增城挂绿的植物学特性、果实品质特征、物候期规律，并从园地选择、土肥水管理、整形修剪、花果调控、病虫害防治及采收等方面总结了一套配套栽培技术体系，旨在为增城挂绿的标准化生产和高品质栽培提供技术参考。

## 一、品种起源与历史渊源

增城挂绿荔枝栽培历史悠久，最早可追溯至宋代。据《增城县志》记载，挂绿荔枝因"果皮红紫，上有绿线环绕"而得名。其中以增城挂绿母树最为著名，树龄超过400年，至今仍保持结果能力。挂绿荔枝历史上曾为贡品，被誉为"荔枝之王"。20世纪80年代以来，通过无性繁殖技术培育了大量优质嫁接苗，逐步实现了规模化栽培。目前，增城挂绿已发展为增城区特色农业的支柱品种，栽培面积约3000公顷，年产量约1.8万吨。

## 二、植物学特性

### 2.1 树体特征

增城挂绿树势中等偏强，树冠呈半圆头形或圆头形，树姿开张。主干灰褐色，表皮粗糙。枝条分布均匀，中短枝居多，枝梢密度中等。叶片为偶数羽状复叶，小叶2-4对，叶片长椭圆形至披针形，叶色深绿，叶面光滑有光泽，叶缘微波浪状。叶片长度8-15厘米，宽度3-5厘米，叶脉明显。

### 2.2 花器特征

花序为聚伞花序，着生于一年生枝梢顶端或叶腋。雌雄同株异花，雄花较多，雌花较少。雄花直径约6-8毫米，花萼浅杯状，花瓣白色或淡黄色，雄蕊6-8枚。雌花较雄花稍大，子房上位，2-3室。花序长度15-30厘米，每花序有花200-800朵，雌花比例约5%-15%，自然坐果率约0.5%-3%。

### 2.3 果实特征

| 性状 | 描述 |
|------|------|
| 果形 | 近圆形或卵圆形，果顶浑圆 |
| 单果重 | 20-28克，平均24克 |
| 果皮 | 红中带绿色斑纹，果皮有1-2条明显的绿色线纹 |
| 果皮厚度 | 约1.0-1.5毫米 |
| 果肉 | 乳白色，半透明，爽脆，香气浓郁 |
| 可食率 | 75%-82% |
| 可溶性固形物 | 18%-22% |
| 总糖含量 | 15%-18% |
| 总酸含量 | 0.15%-0.25% |
| 维生素C | 30-50 mg/100g |
| 种子 | 中等大至大，部分焦核，焦核率约30% |

## 四、环境适应性

### 4.1 气候要求

增城挂绿喜温暖湿润气候，对温度较敏感。年均温21-23℃为宜，极端最低温不低于-1℃。花期适温20-25℃，低于12℃或高于30℃影响授粉受精。果实发育期需25-32℃的温度和充足的光照，以促进糖分积累和色泽发育。年降水量1500-2000毫米，花期和幼果期忌连续阴雨。

### 4.2 土壤要求

以土层深厚、排水良好、pH值5.5-6.5的微酸性沙壤土或壤土为佳。对土壤有机质含量要求较高，宜在2%以上。地下水位需在1.5米以下，忌积水。增城挂绿对钙、镁元素需求较大，缺钙易导致果实裂果和果肉褐变。

## 五、栽培技术

### 5.1 园地选择与定植

选择背风向阳、排灌方便的缓坡地或平地建园。株行距可采用5米×6米或6米×7米，每公顷栽植240-330株。定植穴规格为0.8米×0.8米×0.8米，每穴施腐熟有机肥20-30公斤、钙镁磷肥1.5公斤。定植时间以春植（3-4月）或秋植（9-10月）为宜，选择阴天或小雨天定植。

### 5.2 土壤管理

| 管理项目 | 技术要点 |
|---------|---------|
| 深翻改土 | 每年11-12月深翻15-25厘米，隔年扩穴 |
| 覆盖 | 树盘覆盖稻草或杂草，厚度10-15厘米 |
| 间作 | 幼龄园间作花生、黄豆等矮秆作物 |
| 培土 | 每年培土1-2次，厚度3-5厘米 |
| pH调节 | 每2-3年施石灰50-75公斤/亩 |

### 5.3 营养管理

增城挂绿丰产树年施肥量标准（每株/年）：

| 树龄 | 氮(N) | 磷(P₂O₅) | 钾(K₂O) | 有机肥 |
|------|-------|---------|---------|--------|
| 幼树(1-3年) | 0.3-0.6kg | 0.2-0.4kg | 0.3-0.5kg | 15-25kg |
| 初果树(4-6年) | 0.6-1.0kg | 0.4-0.6kg | 0.6-0.9kg | 25-35kg |
| 盛果树(7年以上) | 1.0-1.5kg | 0.6-0.8kg | 1.0-1.5kg | 35-50kg |

施肥时期：采果后（7月）施重肥，占全年40%；花前（2月）追肥占25%；壮果肥（4月）占25%；秋梢肥（8月）占10%。

### 5.4 水分管理

| 物候期 | 水分管理要点 |
|--------|-------------|
| 花芽分化期(11-1月) | 适当控水，保持土壤相对含水量55%-65% |
| 开花期(4月) | 保持土壤湿润，相对含水量70%-80% |
| 果实发育期(4-6月) | 充足供水，相对含水量75%-85% |
| 成熟期(6-7月) | 适当控水，利于糖分积累 |
| 秋梢生长期(7-9月) | 及时灌溉，促进秋梢健壮 |

### 5.5 整形修剪

树形以自然圆头形为主，主干高度50-70厘米，主枝3-4条，分布均匀。幼树期以整形为主，轻剪多留，培养骨干枝。结果树修剪在采果后进行，剪除过密枝、交叉枝、病虫枝和弱枝，保留健壮秋梢结果母枝。修剪量控制在总枝叶量的15%-25%。结果母枝以长度10-20厘米、粗度0.4-0.6厘米为佳。

### 5.6 花果管理

**控梢促花：** 11月至12月花芽分化期，对生长旺盛的树体进行环割或喷施控梢剂（如多效唑300-500mg/L），抑制冬梢抽生，促进花芽分化。

**保花保果：**
- 花期放蜂，每公顷放置蜜蜂10-15箱
- 花期喷施0.2%硼砂+0.3%磷酸二氢钾
- 谢花后7-10天喷施赤霉素(GA3)10-15mg/L
- 幼果期喷施0.1%硫酸锌+0.2%尿素
- 生理落果后及时疏果，每穗留果10-20个

**防裂果措施：**
- 增施钙肥，每株施硝酸钙0.3-0.5kg
- 保持水分平衡，避免干湿交替剧烈
- 果实发育期喷施0.3%氯化钙溶液2-3次

### 5.7 病虫害防治

增城挂绿主要病虫害及防治措施：

| 病虫害名称 | 危害部位 | 防治药剂 | 防治时期 |
|-----------|---------|---------|---------|
| 霜疫霉病 | 果实、花穗 | 甲霜灵·锰锌、烯酰吗啉 | 花期、幼果期 |
| 炭疽病 | 叶片、果实 | 咪鲜胺、苯醚甲环唑 | 抽梢期、果实发育期 |
| 蒂蛀虫 | 果实 | 高效氯氟氰菊酯、甲维盐 | 果实发育期 |
| 荔枝蝽象 | 嫩梢、果实 | 高效氯氟氰菊酯、啶虫脒 | 花期、幼果期 |
| 瘿螨 | 嫩叶、嫩梢 | 阿维菌素、炔螨特 | 抽梢期 |
| 红蜘蛛 | 叶片 | 哒螨灵、噻螨酮 | 春梢期 |

## 六、采收与包装

### 6.1 采收标准

增城挂绿果实在6月下旬至7月上旬成熟。采收标准：果皮红色面积达80%以上，绿色线纹明显，可溶性固形物达18%以上。采收时间宜在晴天早晨或傍晚进行，避免中午高温采果。

### 6.2 分级标准

| 等级 | 单果重(g) | 色泽 | 可溶性固形物(%) | 外观要求 |
|------|----------|------|-----------------|---------|
| 特级 | ≥25 | 鲜红带绿纹 | ≥20 | 果形端正，无病虫害 |
| 一级 | 20-25 | 红中带绿 | 18-20 | 果形端正，允许轻微瑕疵 |
| 二级 | 15-20 | 浅红带绿 | 16-18 | 果形较端正，轻微斑痕 |

### 6.3 采后处理

采收后及时预冷，2小时内将果心温度降至10℃以下。采用泡沫箱加冰袋包装，冷藏运输温度3-5℃。常温贮藏期不超过3天，冷藏条件下可保鲜7-10天。

## 七、产量与经济效益

增城挂绿盛产期株产30-60公斤，每公顷产量约9000-15000公斤。按市场均价60-120元/公斤计算，每公顷产值54-180万元，扣除生产成本约15-30万元/公顷，纯收益可达39-150万元/公顷，经济效益显著高于普通荔枝品种。

## 八、存在的主要问题及对策

| 问题 | 表现 | 对策措施 |
|------|------|---------|
| 产量不稳定 | 大小年明显 | 加强花果调控，合理负载 |
| 裂果率高 | 成熟期裂果率10%-20% | 补钙控水，套袋栽培 |
| 果实偏小 | 单果重下降 | 疏花疏果，增施钾肥 |
| 焦核率下降 | 焦核果比例降低 | 改善授粉，调节营养 |
| 品种退化 | 品质下降 | 提纯复壮，建立良种繁育体系 |
