# 荔枝煤烟病防治技术规程

> 本规程规定了荔枝煤烟病的症状识别、发病规律调查和综合防治技术，强调"治虫防病"的核心理念，适用于荔枝产区煤烟病的防治管理。

---

## 一、病害概述

荔枝煤烟病（Lychee Sooty Mold）是由多种煤炱科真菌（*Capnodium* spp.、*Meliola* spp.、*Fumago* spp.等）引起的病害。该病菌以刺吸式口器昆虫（蚜虫、介壳虫、粉虱、白蛾蜡蝉等）分泌的蜜露为营养基质进行生长繁殖，形成黑色霉层覆盖叶片、果实和枝条表面。该病在荔枝产区普遍发生，严重时影响光合作用，导致树势衰弱，果实品质下降，商品价值降低。

---

## 二、症状识别

### 2.1 症状特征
| 受害部位 | 症状描述 | 影响 |
|---------|---------|------|
| 叶片 | 叶片表面覆盖一层黑色煤烟状霉层，严重时正反面均有 | 影响光合作用，叶片早衰脱落 |
| 果实 | 果实表面覆盖黑色霉层 | 影响外观品质，商品价值大幅降低 |
| 枝条 | 严重时枝条表面也有黑色霉层 | 影响枝条正常生理功能 |
| 整体 | 远观树冠呈灰黑色 | 影响果园整体美观 |

### 2.2 诊断要点
- 霉层特征：黑色粉末状霉层，干燥时易擦落
- 下层组织：擦去霉层后，叶片组织一般正常，无坏死斑
- 蜜露痕迹：叶片表面有粘稠的昆虫排泄物（蜜露）
- 伴生昆虫：常伴有蚜虫、介壳虫、白蛾蜡蝉等刺吸式口器害虫

### 2.3 与生理性病害的区别
| 特征 | 煤烟病 | 生理性黑变 |
|------|--------|-----------|
| 霉层可擦除 | 是 | 否(已渗入组织) |
| 伴生昆虫 | 常有 | 无 |
| 蜜露 | 有 | 无 |
| 组织坏死 | 一般无 | 有 |

## 三、病原与发病规律

### 3.1 病原种类
| 病原菌 | 分类地位 | 主要特征 |
|--------|---------|---------|
| *Capnodium* spp. | 煤炱科 | 黑色菌丝体，有隔膜 |
| *Meliola* spp. | 小煤炱科 | 暗褐色菌丝，有刚毛 |
| *Fumago* spp. | 烟霉属 | 菌丝体黑色绒毛状 |
| *Alternaria* spp. | 链格孢属 | 有时伴生在霉层中 |

### 3.2 发病规律
| 因素 | 规律描述 |
|------|---------|
| 病原来源 | 多种煤炱科真菌，广泛存在于自然界 |
| 发病条件 | 必须有刺吸式口器昆虫分泌蜜露作为营养基质 |
| 温度 | 20-32°C适宜发病 |
| 湿度 | 相对湿度>80%时霉层生长迅速 |
| 高发期 | 5-9月高温高湿季节，与昆虫活动高峰期一致 |
| 果园条件 | 虫害严重、通风不良、树冠密闭的果园发病重 |
| 品种差异 | 无特异性抗性品种，发病程度取决于虫害管理 |

### 3.3 主要蜜露分泌昆虫
| 昆虫种类 | 蜜露分泌量 | 发生高峰期 | 防治关键期 |
|---------|-----------|-----------|-----------|
| 蚜虫 | 大量 | 3-5月、9-10月 | 春梢期、秋梢期 |
| 介壳虫(多种) | 中等 | 4-8月 | 若虫期 |
| 白蛾蜡蝉 | 大量 | 5-9月 | 若虫期 |
| 粉虱 | 中等 | 4-10月 | 成虫期 |

## 四、防治策略——治虫防病

### 4.1 防治原则
煤烟病防治的核心是**控制蜜露分泌的昆虫**，而非直接杀菌。只有从根本上减少昆虫蜜露，才能有效控制煤烟病的发生发展。

### 4.2 农业防治
| 防治措施 | 技术要求 | 实施时间 |
|---------|---------|---------|
| 合理修剪 | 剪除过密枝条、病虫枝，改善通风透光 | 采果后、冬季 |
| 增强树势 | 增施有机肥，合理灌溉，提高树体抗性 | 全年 |
| 控制氮肥 | 避免偏施氮肥导致嫩梢徒长吸引害虫 | 各物候期 |
| 果园生草 | 种植蜜源植物，保护天敌 | 春季 |
| 清除虫源 | 及时剪除虫害严重的枝条 | 全年 |

### 4.3 生物防治
| 天敌种类 | 防治对象 | 保护利用措施 |
|---------|---------|-------------|
| 瓢虫(龟纹瓢虫、异色瓢虫) | 蚜虫、介壳虫 | 减少广谱杀虫剂使用 |
| 寄生蜂(蚜茧蜂、跳小蜂) | 蚜虫、介壳虫 | 保护蜜源植物 |
| 草蛉 | 蚜虫、粉虱 | 保护越冬场所 |
| 食蚜蝇 | 蚜虫 | 种植开花植物 |

## 五、防治方案组合

### 5.1 常规防治方案
| 时期 | 防治重点 | 推荐方案 | 预期效果 |
|------|---------|---------|---------|
| 冬季清园(12-1月) | 越冬虫源+煤烟病 | 石硫合剂3-5波美度+矿物油150倍 | 清除越冬菌源和虫源 |
| 春梢期(3月) | 蚜虫+煤烟病 | 吡虫啉2000倍+石硫合剂0.3波美度 | 控制初期蚜虫 |
| 夏秋季(5-9月) | 介壳虫+白蛾蜡蝉+煤烟病 | 噻嗪酮1500倍+高效氯氟氰菊酯3000倍 | 控制主要蜜露昆虫 |
| 秋梢期(9月) | 蚜虫+煤烟病 | 啶虫脒1500倍+氢氧化铜800倍 | 保护秋梢 |

### 5.2 重度发生防治方案
| 措施 | 具体操作 | 注意事项 |
|------|---------|---------|
| 第1步：治虫 | 螺虫乙酯4000倍+吡蚜酮3000倍 | 同时防治多种刺吸式害虫 |
| 第2步：洗煤烟 | 碳酸氢钠0.3%溶液喷施 | 溶解霉层 |
| 第3步：防复发 | 7-10天后喷石硫合剂0.3波美度 | 预防霉层再生 |
| 第4步：农业措施 | 修剪通风，增施有机肥 | 改善果园生态 |

## 六、防治效果评价

### 6.1 效果评价指标
| 评价指标 | 计算方法 | 优秀标准 |
|---------|---------|---------|
| 霉层覆盖率降低率 | (施药前覆盖率-施药后覆盖率)/施药前覆盖率×100% | ≥80% |
| 蜜露分泌量减少率 | (防治前-防治后)/防治前×100% | ≥90% |
| 虫口减退率 | (防治前虫量-防治后虫量)/防治前虫量×100% | ≥90% |
| 果实商品率提高 | 防治后商品果率-防治前商品果率 | ≥20% |
