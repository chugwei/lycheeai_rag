# 荔枝GAP标准操作规范

## 摘要

本规范依据中国良好农业规范(GAP)标准，结合荔枝生产特点，制定了荔枝GAP标准操作规范(SOP)。规范涵盖了荔枝园环境管理、投入品管理、田间操作、病虫害防控、采后处理和记录管理等全过程，为荔枝GAP认证和规范化生产提供可操作的技术依据。

## 1. 引言

标准操作规范(Standard Operating Procedure, SOP)是GAP认证体系的核心文件，用于规范每个生产环节的操作行为，确保生产过程标准化、记录完整化和产品质量稳定化。本规范适用于中国GAP认证范围内的所有荔枝种植生产活动。

## 2. 农场环境管理SOP

### 2.1 SOP-01 产地环境监测

| 步骤 | 操作内容 | 频次 | 记录 |
|------|----------|------|------|
| 1 | 确定监测点位(土壤、水、气) | 建立时 | 点位图 |
| 2 | 采集土样(0-20cm,5点混合) | 每年1次 | 采样记录 |
| 3 | 采集水样(灌溉水源) | 每季度1次 | 采样记录 |
| 4 | 委托有资质实验室检测 | - | 委托单 |
| 5 | 检测结果评价和归档 | - | 检测报告 |

**环境指标限值**：

| 指标 | 限值 | 超出处理 |
|------|------|----------|
| pH(土壤) | 5.5-8.5 | 改良 |
| 镉 | ≤0.3mg/kg | 禁止生产 |
| 汞 | ≤0.2mg/kg | 禁止生产 |
| 砷 | ≤25mg/kg | 改良后种植 |
| 铅 | ≤80mg/kg | 改良后种植 |
| 总氮(水) | ≤100mg/L | 更换水源 |
| 总磷(水) | ≤10mg/L | 更换水源 |

### 2.2 SOP-02 农场卫生管理

| 步骤 | 操作内容 | 要求 |
|------|----------|------|
| 1 | 每日清理落叶、杂草 | 堆积至指定区 |
| 2 | 清理病枝病果 | 集中无害化处理 |
| 3 | 保持排水沟畅通 | 无堵塞 |
| 4 | 农药储存区清洁 | 无泄漏 |
| 5 | 作业后清洁工具 | 冲洗干净 |

## 3. 投入品管理SOP

### 3.1 SOP-03 农药管理

| 步骤 | 操作内容 | 要求 |
|------|----------|------|
| 1 | 建立农药台账 | 名称、来源、数量 |
| 2 | 农药专库存放 | 上锁、通风、标识 |
| 3 | 领用登记 | 日期、品种、数量、领用人 |
| 4 | 施用记录 | 日期、地点、用量、天气 |
| 5 | 空包装回收 | 集中处理 |
| 6 | 库存盘点 | 每月1次 |

**农药施用记录表**：

| 记录项 | 内容 |
|--------|------|
| 日期 | 施药日期 |
| 地点 | 果园区域 |
| 农药名称 | 商品名和有效成分 |
| 剂量 | 使用量和稀释倍数 |
| 施药方式 | 喷雾/喷粉/灌根 |
| 天气 | 温度、湿度、风速 |
| 操作人 | 签名 |
| 安全间隔期 | 下次采收起算日期 |

### 3.2 SOP-04 肥料管理

| 步骤 | 操作内容 | 要求 |
|------|----------|------|
| 1 | 建立肥料台账 | 名称、来源、数量 |
| 2 | 专用存放 | 防雨、防潮 |
| 3 | 施用记录 | 日期、地点、用量 |
| 4 | 有机肥处理 | 充分腐熟后使用 |

## 4. 田间操作SOP

### 4.1 SOP-05 施肥操作

| 步骤 | 操作内容 | 要求 |
|------|----------|------|
| 1 | 测定土壤养分 | 确定施肥方案 |
| 2 | 准备肥料 | 选择合格肥料 |
| 3 | 施用 | 按配方和深度 |
| 4 | 覆土 | 施肥后覆土 |
| 5 | 记录 | 填写施肥记录表 |

**施肥记录表**：

| 记录项 | 内容 |
|--------|------|
| 日期 | 施肥日期 |
| 地点 | 果园区域 |
| 肥料名称 | 商品名和类型 |
| 用量 | kg/亩 |
| 施肥方法 | 沟施/撒施/滴灌 |
| 操作人 | 签名 |

### 4.2 SOP-06 修剪操作

| 步骤 | 操作内容 | 要求 |
|------|----------|------|
| 1 | 修剪时机 | 采后或花前 |
| 2 | 修剪方法 | 疏除弱枝、病枝 |
| 3 | 伤口处理 | 涂抹愈合剂 |
| 4 | 废弃物处理 | 粉碎还田或堆放 |
| 5 | 工具消毒 | 修剪工具消毒 |

### 4.3 SOP-07 病虫害监测

| 步骤 | 操作内容 | 频次 | 记录 |
|------|----------|------|------|
| 1 | 设置监测点 | 每50亩1点 | - |
| 2 | 调查虫口密度 | 每周1次 | 监测记录表 |
| 3 | 调查病害发生 | 每周1次 | 病害记录表 |
| 4 | 数据分析 | 每月1次 | 分析报告 |
| 5 | 预警发布 | 达到阈值时 | 预警通知 |
