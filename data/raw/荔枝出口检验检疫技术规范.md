# 荔枝出口检验检疫技术规范

> 荔枝出口必须符合目标进口国的检验检疫要求，涵盖农药残留、病虫害、包装标识、冷链条件等各方面。本规范系统阐述中国荔枝出口的主要目标市场检疫标准和技术操作要求。

---

## 二、出口果园注册管理

### 注册条件

| 项目 | 要求标准 |
|------|---------|
| 果园面积 | ≥30亩（连片） |
| 种植年限 | ≥3年 |
| 品种纯度 | ≥90% |
| 隔离条件 | 与非注册果园有隔离带≥10m |
| 病虫害管理 | 有完整的病虫害监测记录 |
| 农事记录 | 完整的施肥、施药记录（≥2年） |
| 周边环境 | 无工业污染源 |

### 果园管理要求

| 管理项目 | 具体要求 | 检查频次 |
|---------|---------|---------|
| 病虫害监测 | 每7天一次，记录病虫种类和数量 | 出口期每周 |
| 农药管理 | 使用登记在荔枝上的农药，记录品种、时间、浓度 | 每批次 |
| 安全间隔期 | 严格遵循农药安全间隔期 | 持续监控 |
| 采前检测 | 出口前15天进行农残检测 | 每批 |
| 卫生条件 | 果园内无垃圾、无畜禽养殖 | 每月 |
| 培训 | 果园管理人员经出口检疫培训 | 年度 |

### 注册申请流程

```
果园提出申请
    ↓
县级海关初审（材料审核+现场核查）
    ↓
市级海关复审
    ↓
省级海关注册登记
    ↓
上报海关总署备案
    ↓
向进口国通报注册信息
    ↓
进口国确认或现场检查
    ↓
列入出口果园名单
```

## 三、病虫害检疫

### 检疫性有害生物

| 有害生物名称 | 拉丁名 | 分布 | 主要危害市场 | 处理方法 |
|------------|--------|------|------------|---------|
| **荔枝蒂蛀虫** | Conopomorpha sinensis | 中国、东南亚 | 美、日、韩、欧盟 | 蒸热处理 |
| **荔枝霜疫霉菌** | Peronophythora litchi | 中国特有 | 美、欧盟 | 杀菌剂+检疫 |
| **荔枝螨类** | Aceria litchii | 亚洲 | 美、欧盟 | 熏蒸处理 |
| **蚧壳虫类** | Coccoidea spp. | 亚洲 | 各国 | 熏蒸+冷处理 |
| **橘小实蝇** | Bactrocera dorsalis | 中国南方 | 美、日、韩 | 冷处理 |
| **红蜘蛛** | Panonychus citri | 全球分布 | 各国 | 药剂处理 |

### 检疫处理技术

| 处理方法 | 参数 | 适用范围 | 对品质影响 | 成本(元/吨) |
|---------|------|---------|----------|----------|
| **冷处理** | <1.5°C持续14天 | 实蝇类 | 轻微（妃子笑适宜） | 500-800 |
| **蒸热处理** | 47°C, 30min果心温度 | 蒂蛀虫、螨类 | 中等（需热驯化） | 1000-1500 |
| **溴甲烷熏蒸** | 20°C, 32g/m³, 2h | 蚧壳虫、螨类 | 较大（果皮变色） | 800-1200 |
| **磷化氢熏蒸** | 15°C以上, 2g/m³, 72h | 蒂蛀虫 | 较小 | 600-1000 |
| **辐照处理** | 400Gy | 多种害虫 | 极小 | 1500-2000 |

### 冷处理操作规程

| 步骤 | 操作 | 标准 |
|------|------|------|
| 1. 温度校准 | 校准温度传感器 | 精度±0.1°C |
| 2. 预冷 | 果心温度降至<2°C | 预冷时间4-6h |
| 3. 装柜 | 冷藏集装箱 | 堆码留通风道 |
| 4. 温度探头 | 果肉中心+环境各3个 | 分布柜前中后 |
| 5. 冷处理 | <1.5°C持续14天 | 连续168h |
| 6. 温度记录 | 每30分钟记录 | 全程记录不可间断 |
| 7. 出具报告 | 温度记录经海关确认 | 附植物检疫证书 |

## 七、出口流程管理

### 标准出口流程

```
1. 果园注册与备案
   ↓
2. 出口计划制定与目标市场确定
   ↓
3. 采前检疫（出口前15天）
   ↓
4. 采收（8-9成熟，清晨）
   ↓
5. 预冷（果心温度<5°C）
   ↓
6. 分选分级（符合目标市场标准）
   ↓
7. 检疫处理（冷处理/蒸热处理等）
   ↓
8. 包装（食品级材料+出口标识）
   ↓
9. 海关报检（提交单据）
   ↓
10. 海关查验（抽样检测）
    ↓
11. 出具植物检疫证书
    ↓
12. 冷链运输（2-4°C）
    ↓
13. 到达目的港进口清关
    ↓
14. 进口国检疫查验
    ↓
15. 上市销售
```

### 报检单证清单

| 单证名称 | 出具机构 | 说明 |
|---------|---------|------|
| 植物检疫证书 | 海关 | 证明产品经检疫合格 |
| 原产地证书 | 海关或贸促会 | 享受关税优惠 |
| 农药残留检测报告 | 第三方实验室 | 符合目标国MRL标准 |
| 冷处理报告 | 海关或认证机构 | 冷处理全程温度记录 |
| 果园注册证 | 海关 | 注册果园资质证明 |
| 包装厂注册证 | 海关 | 包装厂资质证明 |
| 装箱单 | 出口商 | 货物清单 |
| 商业发票 | 出口商 | 贸易凭证 |
| 提单/空运单 | 物流承运商 | 运输凭证 |

### 海关查验流程

| 查验环节 | 查验内容 | 取样量 |
|---------|---------|-------|
| 单证审核 | 检查所有单证是否齐全有效 | — |
| 包装标识检查 | 检查包装标识是否规范 | 抽查1-2% |
| 感官检验 | 色泽、褐变、腐烂、虫蛀 | 抽查2-5% |
| 病虫害检验 | 剖果检查蒂蛀虫、实蝇等 | 每批300-600个果 |
| 农药残留检测 | 检测目标市场关注品种 | 每批1-2kg |
| 重金属检测 | 铅、镉、砷、汞 | 每季1次 |
| 冷处理核验 | 核实温度记录 | 全批次 |
| 出证 | 合格后出具检疫证书 | — |

## 八、主要市场特别要求

### 对美出口要求

| 要求项目 | 具体规定 |
|---------|---------|
| 双边协议 | 《中国荔枝输美植物检疫要求议定书》 |
| 冷处理 | 果心温度<1.5°C连续14天 |
| 注册果园 | 必须在海关注册并在USDA备案 |
| 装运前检疫 | 出口前由海关实施检疫 |
| 到达检疫 | 美国海关在入境口岸查验 |
| 农药残留 | 遵守美国EPA规定的MRL |
| 包装要求 | 新包装材料，无土壤，无植物残体 |

### 对欧盟出口要求

| 要求项目 | 具体规定 |
|---------|---------|
| 法规依据 | EU 2019/1793强化检查 |
| 农残标准 | EU 396/2005（最严格） |
| 抽样频率 | 加强检查产品20%批次 |
| 重点关注 | 多菌灵、毒死蜱等 |
| 有机认证 | EU有机认证或等效认证 |
| 包装材料 | 符合EU食品接触材料标准 |
| 追溯要求 | 可追溯至注册果园 |

### 对日出口要求

| 要求项目 | 具体规定 |
|---------|---------|
| 检疫标准 | 日本植物防疫法 |
| 蒂蛀虫处理 | 蒸热处理（47°C果心30min） |
| 实蝇处理 | 冷处理（1°C以下14天） |
| 注册管理 | 果园和包装厂双重注册 |
| 农残标准 | 日本肯定列表制度（一律标准0.01ppm） |
| 检查频率 | 首次出口100%检查，后续逐年降低 |
