# 荔枝贮藏技术规范

> 本标准规定了荔枝鲜果贮藏的术语和定义、贮藏环境条件、贮藏技术、贮藏期管理及出库要求。适用于荔枝鲜果的商业化贮藏。荔枝采后生理代谢旺盛，正确的贮藏技术是延长保鲜期的关键。

---

## 一、范围与规范性引用文件

### 适用范围
本标准适用于各品种荔枝鲜果在冷库中的贮藏管理。

### 规范性引用文件
| 标准编号 | 标准名称 |
|---------|---------|
| NY/T 389 | 荔枝贮藏 |
| SB/T 10059 | 荔枝 |
| GB/T 9829 | 水果和蔬菜 冷库中物理条件定义和测量 |

## 二、贮藏环境条件

### 基本贮藏条件
| 环境参数 | 最适范围 | 允许范围 | 超出后果 |
|---------|---------|---------|---------|
| 温度(°C) | 2-3 | 1-5 | <1°C冷害，>5°C加速褐变 |
| 相对湿度(%) | 90-95 | 85-95 | <85%失水褐变，>95%易霉变 |
| 氧气浓度(%) | 3-5 | 2-8 | <2%无氧呼吸，>8%呼吸旺盛 |
| 二氧化碳浓度(%) | 3-5 | 2-8 | >8%果肉酒精味 |
| 乙烯浓度(μL/L) | <0.1 | <0.5 | >0.5促进衰老褐变 |
| 空气流速(m/s) | 0.1-0.3 | 0.05-0.5 | 过高加速失水 |

### 不同品种贮藏适宜条件
| 品种 | 最适温度(°C) | 相对湿度(%) | 预期贮藏期(天) | 耐贮性等级 |
|-----|-------------|------------|--------------|----------|
| 黑叶 | 2-3 | 92-95 | 25-30 | 强 |
| 妃子笑 | 2-3 | 90-93 | 20-25 | 较强 |
| 白糖罂 | 2-3 | 92-95 | 18-22 | 中等 |
| 桂味 | 2-3 | 90-93 | 15-20 | 中等 |
| 糯米糍 | 3-4 | 90-93 | 10-15 | 较弱 |
| 三月红 | 3-5 | 90-95 | 10-15 | 较弱 |
| 鸡嘴荔 | 2-3 | 90-93 | 20-28 | 强 |
| 大红袍 | 2-4 | 90-93 | 15-20 | 中等 |

## 三、贮藏前准备

### 冷库准备
| 准备工作 | 操作要求 | 完成时限 |
|---------|---------|---------|
| 库体清洁 | 彻底清扫，清水冲洗 | 入库前3天 |
| 消毒处理 | 过氧乙酸0.5%喷雾或甲醛熏蒸 | 入库前2天 |
| 设备检修 | 检查制冷、加湿、通风系统 | 入库前3天 |
| 库预冷 | 库温降至0-2°C | 入库前12小时 |
| 温度校准 | 温度传感器校准，精度±0.3°C | 入库前1天 |

### 果实准备
| 环节 | 要求 |
|-----|------|
| 采收成熟度 | 8-9成熟（依品种确定） |
| 采后时限 | 采后2小时内完成预冷 |
| 预冷终点 | 果心温度≤5°C |
| 分选 | 剔除裂果、病虫果、机械伤果 |
| 分级 | 按标准分级，不同等级分开贮藏 |
| 包装 | 采用透气的微孔保鲜袋+泡沫箱或塑料筐 |

## 四、入库管理

### 入库操作规程
| 操作步骤 | 技术要求 |
|---------|---------|
| 入库顺序 | 同一品种、同一批次、同日预冷的果实集中入库 |
| 库温要求 | 入库时库温≤2°C |
| 入库量 | 单次入库量不超过库容的15%，以防温度波动过大 |
| 堆码高度 | 泡沫箱≤5层，塑料筐≤4层 |
| 堆码间距 | 距墙20cm，距顶50cm，排间距10-15cm |
| 风道预留 | 对齐堆码，保证冷风均匀流通 |
| 标识 | 品种、等级、产地、入库日期、预计出库日期 |
| 标签位置 | 每垛至少2个标签，垛前方和侧面 |

### 堆码方式
``` 
方案一（泡沫箱）：
    箱口朝上，骑缝堆码，每层交错
    每排6箱，排间距15cm
    高5层，总高度约1.5m

方案二（塑料筐）：
    筐口朝上，对齐堆码
    每排5筐，排间距12cm
    高4层，总高度约1.2m
```

## 五、贮藏期管理

### 温湿度管理
| 管理内容 | 操作要求 |
|---------|---------|
| 温度控制 | 恒温2-3°C，波动范围±0.5°C |
| 湿度控制 | RH 90-95%，低于90%需加湿 |
| 温度监测 | 库内3个以上监测点，每30分钟记录1次 |
| 湿度监测 | 每日记录2次 |
| 除霜周期 | 蒸发器每4-6小时除霜1次 |
| 加湿方式 | 超声波加湿或微雾加湿 |

### 气体管理
| 管理项目 | 技术要求 |
|---------|---------|
| O₂浓度 | 3-5%，低于2%自动补氧 |
| CO₂浓度 | 3-5%，高于8%强制通风换气 |
| 乙烯浓度 | <0.1μL/L，使用乙烯吸收剂或高锰酸钾过滤器 |
| 换气频率 | 每24小时换气1次（10-15分钟） |

### 品质监测
| 监测项目 | 监测频率 | 检测方法 | 品质下降临界值 |
|---------|---------|---------|--------------|
| 果皮色泽 | 每日1次 | 目视/色差计 | L值下降20% |
| 褐变指数 | 每日1次 | 目视评估 | >15% |
| 失重率 | 每3天1次 | 称重法 | >5% |
| 可溶性固形物 | 每5天1次 | 手持折射仪 | 下降>2% |
| 硬度 | 每3天1次 | 硬度计 | 下降>30% |
| 腐烂率 | 每日1次 | 目视+计数 | >3% |
| 风味 | 每5天1次 | 品尝 | 出现异味 |

### 褐变指数分级标准
| 级别 | 褐变面积比例 | 商品性 |
|-----|-------------|--------|
| 0级 | 无褐变 | 完全商品果 |
| 1级 | <1/4面积 | 商品果 |
| 2级 | 1/4-1/2面积 | 次品果，降价处理 |
| 3级 | >1/2面积 | 非商品果，加工或销毁 |

## 六、气调贮藏技术

### 气调贮藏条件
| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| 温度(°C) | 2-3 | 比普通冷藏低0.5°C |
| 相对湿度(%) | 92-95 | 高湿度减少失水 |
| O₂浓度(%) | 3-5 | 低氧抑制呼吸 |
| CO₂浓度(%) | 3-5 | 高CO₂抑菌保鲜 |
| N₂ | 余量 | 填充气体 |

### 气调贮藏效果对比
| 品种 | 普通冷藏(天) | 气调贮藏(天) | 保鲜期延长(%) |
|-----|------------|------------|-------------|
| 妃子笑 | 20-25 | 30-40 | 50-60 |
| 桂味 | 15-20 | 25-30 | 50-67 |
| 糯米糍 | 10-15 | 18-22 | 47-80 |
| 黑叶 | 25-30 | 35-45 | 40-50 |

## 七、出库管理

### 出库操作规程
| 操作环节 | 技术要求 |
|---------|---------|
| 品质检验 | 出库前全面检验品质，不合格的降级或加工 |
| 出库顺序 | 先进先出原则 |
| 出库温度 | 库内完成分级、包装，保持温度≤4°C |
| 装车时限 | 出库至装车完成不超过30分钟 |
| 冷链对接 | 出库→装车无缝衔接，设温控缓冲间 |

### 出库品质标准
| 项目 | 合格标准 |
|-----|---------|
| 褐变指数 | ≤1级（褐变面积<25%） |
| 腐烂率 | ≤2% |
| 失重率 | ≤4% |
| 风味 | 品种固有风味，无异味 |
| 果肉色泽 | 乳白色或白蜡色 |
| 硬度 | 果肉饱满，弹性好 |

## 八、贮藏记录与档案

### 贮藏档案内容
| 记录项目 | 记录内容 |
|---------|---------|
| 入库记录 | 日期、品种、数量、产地、等级、预冷记录 |

| 湿度记录 | 每日2次库内湿度 |
| 气体记录 | 每日O₂和CO₂浓度 |
| 品质检测 | 抽检日期、品种、检测指标、结果 |
| 出库记录 | 日期、品种、数量、去向、运输方式 |
| 异常记录 | 设备故障、温度异常、品质问题及处理措施 |
