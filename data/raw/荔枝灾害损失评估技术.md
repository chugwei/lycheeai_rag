# 荔枝灾害损失评估技术

## 摘要

本文件规定了荔枝气象灾害损失评估的技术方法，涵盖损失评估指标体系、评估方法、数据收集、评估模型和评估报告编制等内容。灾害损失评估是灾害管理的重要环节，科学的评估可为灾后恢复、保险理赔、政策制定提供依据。本文件为荔枝产区气象灾害损失评估提供技术指导。

## 1 总则

### 1.1 适用范围

适用于荔枝产区气象灾害（低温、高温、台风、干旱、涝害、冰雹等）造成的损失评估。

### 1.2 评估目的

- 量化灾害损失，为灾后恢复提供依据
- 支撑保险理赔和灾害补偿
- 评估防御措施效果
- 为灾害预警和风险管理提供数据

### 1.3 评估原则

- 客观公正：基于实际数据，不主观臆断
- 科学规范：采用统一方法和标准
- 及时准确：灾后尽快完成评估
- 分级评估：按灾害等级确定评估深度

## 2 损失评估指标体系

### 2.1 损失类型

| 损失类型 | 具体内容 |
|---------|---------|
| 直接损失 | 产量损失、品质损失、设施损毁 |
| 间接损失 | 恢复成本、病虫害增加、次年减产 |
| 生态损失 | 土壤侵蚀、水质污染、生物多样性 |
| 社会损失 | 农民收入减少、就业影响 |

### 2.2 评估指标

| 指标类别 | 具体指标 | 单位 |
|---------|---------|------|
| 受灾面积 | 受灾果园面积 | 亩 |
| 成灾面积 | 减产30%以上面积 | 亩 |
| 绝收面积 | 完全无产量面积 | 亩 |
| 产量损失 | 减产数量 | kg |
| 经济损失 | 直接经济损失 | 元 |
| 设施损失 | 损毁设施价值 | 元 |
| 恢复成本 | 灾后恢复投入 | 元 |

## 3 评估方法

### 3.1 现场调查法

| 步骤 | 操作内容 |
|------|---------|
| 1. 划分调查区 | 按灾情等级划分 |
| 2. 设置样方 | 每50亩设1个样方 |
| 3. 数据采集 | 记录受灾程度、损失情况 |
| 4. 统计分析 | 汇总计算损失 |
| 5. 编制报告 | 形成评估报告 |

### 3.2 样方调查方法

| 参数 | 要求 |
|------|------|
| 样方大小 | 20m×20m |
| 样方数量 | 每100亩≥3个 |
| 调查内容 | 受灾率、减产率、树体损伤 |
| 调查时间 | 灾后7-15天 |
| 调查人员 | 专业技术人员 |

### 3.3 损失分级标准

| 灾害等级 | 减产率 | 受灾率 | 损失率 |
|---------|--------|--------|--------|
| 轻度 | <10% | <30% | <20% |
| 中度 | 10%-30% | 30%-60% | 20%-50% |
| 重度 | 30%-60% | 60%-80% | 50%-80% |
| 严重 | >60% | >80% | >80% |

## 5 经济损失计算

### 5.1 直接经济损失

**直接经济损失 = 产量损失 × 市场价格 + 设施损失**

| 计算项 | 公式 |
|--------|------|
| 产量损失 | (正常产量 - 实际产量) × 市场价格 |
| 品质损失 | (正常品质率 - 实际品质率) × 产量 × 价差 |
| 设施损失 | 损毁设施数量 × 单价 |
| 恢复成本 | 重建、修复所需费用 |

### 5.2 损失计算公式

| 灾害类型 | 损失估算公式 |
|---------|------------|
| 冻害 | 损失 = 受冻面积 × 单产 × 减产率 × 价格 |
| 台风 | 损失 = 受风面积 × 单产 × 落果率 × 价格 + 设施损失 |
| 高温 | 损失 = 受热面积 × 单产 × 减产率 × 价格 + 品质损失 |
| 干旱 | 损失 = 受旱面积 × 单产 × 减产率 × 价格 |
| 涝害 | 损失 = 受涝面积 × 单产 × 减产率 × 价格 |

### 5.3 评估参数

| 参数 | 取值 |
|------|------|
| 正常单产(kg/亩) | 按当地近5年平均 |
| 市场价格(元/kg) | 按灾后当时市场价 |
| 商品果率 | 按品种和等级确定 |
| 设施单价 | 按市场报价 |

## 6 遥感评估

### 6.1 遥感评估方法

| 方法 | 数据源 | 精度 |
|------|--------|------|
| NDVI变化 | 卫星遥感 | ±10% |
| 热红外 | 卫星/无人机 | ±8% |
| 高分影像 | 卫星/航空 | ±5% |

### 6.2 遥感评估流程

影像获取 → 图像处理 → 指数计算 → 变化检测 → 损失评估 → 精度验证
