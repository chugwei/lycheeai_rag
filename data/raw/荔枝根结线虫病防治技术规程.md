# 荔枝根结线虫病防治技术规程

> 本规程规定了荔枝根结线虫病的症状识别、病原鉴定、发生规律和综合防治技术，适用于荔枝产区根结线虫病的防治管理。

---

## 一、病害概述

荔枝根结线虫病（Lychee Root-Knot Nematode Disease）主要由南方根结线虫（*Meloidogyne incognita*）和爪哇根结线虫（*Meloidogyne javanica*）等引起。该病危害荔枝根系，造成营养吸收障碍，导致树势衰弱、产量下降，严重时引起全株死亡。该病在砂质土壤和连作果园中发生尤为严重。

---

## 二、症状识别

### 2.1 地上部症状
| 症状类型 | 表现特征 | 与缺素症的区别 |
|---------|---------|--------------|
| 叶片黄化 | 叶片褪绿变黄，叶脉间失绿，叶缘焦枯 | 缺铁症新叶先黄，线虫病老叶先黄 |
| 矮化 | 新梢生长缓慢，节间缩短，植株矮小 | 营养不足全株均匀矮小，线虫病不均 |
| 萎蔫 | 晴天中午前后叶片萎蔫，早晚恢复 | 水分不足全株萎蔫，线虫病局部萎蔫 |
| 叶小 | 新叶变小、变薄，光泽度降低 | 与缺锌小叶病相似，需结合根部检查 |
| 结果少 | 花量少、坐果率低、果实小 | 线虫病根系受损导致吸收障碍 |

### 2.2 根部症状
| 症状类型 | 表现特征 | 诊断要点 |
|---------|---------|---------|
| 根瘤 | 须根上形成大小不等的根瘤(虫瘿)，直径1-10mm | 根瘤是典型特征，初为白色后变褐色 |
| 根腐 | 根瘤后期腐烂，根系坏死 | 严重时根系大部分坏死 |
| 根少 | 须根数量明显减少，根系发育不良 | 健康植株须根量大，线虫病株须根少 |
| 根结 | 根瘤表面粗糙，有时可见雌虫体 | 解剖镜下可见根瘤内有白色球状雌虫 |

## 三、病原与发病规律

### 3.1 病原特征
| 病原线虫 | 分类地位 | 主要特征 | 寄主范围 |
|---------|---------|---------|---------|
| *Meloidogyne incognita* | 垫刃目根结线虫属 | 雌虫梨形，雄虫线形，会阴花纹高弓形 | 广谱，危害多种作物 |
| *Meloidogyne javanica* | 垫刃目根结线虫属 | 雌虫球形，会阴花纹近圆形 | 热带果树常见 |
| *Meloidogyne arenaria* | 垫刃目根结线虫属 | 雌虫梨形，会阴花纹圆形 | 砂质土壤常见 |

### 3.2 发病规律
| 因素 | 规律描述 |
|------|---------|
| 越冬 | 以卵和2龄幼虫在土壤中或病根残体上越冬 |
| 传播 | 主要随带病苗木、土壤、灌溉水、农具传播 |
| 温度 | 最适土温25-30°C，低于10°C或高于40°C活动受抑制 |
| 土壤 | 砂质土、疏松土壤发病重，粘土发病轻 |
| 土壤pH | pH5.0-6.5最适宜线虫生存 |
| 水分 | 土壤湿度40-70%最适宜，积水或过干不利 |
| 连作 | 连作果园发病重，轮作可减轻危害 |
| 发生代数 | 华南地区一年可发生5-7代 |

### 3.3 线虫生活史
| 阶段 | 发育过程 | 所需时间(25°C) |
|------|---------|--------------|
| 卵 | 雌虫产卵于胶质卵囊中 | 10-15天孵化 |
| 2龄幼虫(侵染期) | 从卵中孵出，侵入根尖 | 侵染期约2-3天 |
| 3龄幼虫 | 在根内发育，体形膨大 | 5-7天 |
| 4龄幼虫 | 雌虫进一步膨大，雄虫恢复线形 | 7-10天 |
| 成虫 | 雌虫产卵，完成一个世代 | 25-35天完成一代 |

## 四、防治技术

### 4.1 农业防治
| 防治措施 | 技术要求 | 实施时间 |
|---------|---------|---------|
| 选用无病苗木 | 使用无线虫苗圃培育的苗木 | 建园时 |
| 轮作倒茬 | 与水稻、玉米等禾本科作物轮作2-3年 | 重病果园 |
| 增施有机肥 | 腐熟有机肥15-20kg/株，改善土壤微生态 | 采果后 |
| 土壤改良 | 施用石灰调节pH至6.5-7.0 | 建园前或冬季 |
| 抗性砧木 | 选用抗线虫的荔枝砧木品种 | 嫁接时 |
| 休耕晒土 | 夏季深耕晒土，杀灭表层线虫 | 夏季高温期 |

### 4.2 物理防治
| 措施 | 方法 | 效果 |
|------|------|------|
| 土壤暴晒 | 夏季覆膜暴晒15-20天，地温达50°C以上 | 可杀灭土壤中80%以上线虫 |
| 热水处理 | 苗木栽植前用50°C热水浸泡10分钟 | 杀灭苗木携带的线虫 |
| 淹水处理 | 淹水2-3个月 | 厌氧环境下线虫死亡 |

### 4.3 生物防治
| 生物制剂 | 有效成分 | 使用方法 | 防治效果 |
|---------|---------|---------|---------|
| 淡紫拟青霉 | 2亿孢子/g WP | 1-2kg/亩，拌土或灌根 | 60-75% |
| 厚垣轮枝菌 | 1亿孢子/g WP | 1-2kg/亩，拌土 | 55-70% |
| 枯草芽孢杆菌 | 1000亿/g WP | 500倍液灌根 | 45-60% |
| 放线菌制剂 | 多抗霉素 | 300倍液灌根 | 40-55% |
| 几丁质 | 虾蟹壳粉 | 50-100kg/亩，翻压入土 | 促进抗线虫微生物繁殖 |

### 4.4 化学防治
| 药剂名称 | 剂型 | 使用方法 | 安全间隔期 | 备注 |
|---------|------|---------|---------|------|
| 噻唑膦 | 10%GR | 1.5-2kg/亩，沟施 | 30天 | 高效低毒，登记用于线虫防治 |
| 阿维菌素 | 1.8%EC | 2000倍液灌根，2-3L/株 | 14天 | 兼治瘿螨等 |
| 氟吡菌酰胺 | 41.7%SC | 0.01-0.02ml/株灌根 | 30天 | 新型杀线虫剂 |
| 棉隆 | 98%GR | 30-40kg/亩，土壤熏蒸 | 60天 | 种植前使用 |
| 石灰氮 | 50%GR | 40-60kg/亩，翻压 | 30天 | 兼有土壤消毒作用 |

### 4.5 化学防治注意事项
| 注意事项 | 具体要求 |
|---------|---------|
| 施药时间 | 春梢和秋梢抽生前施用 |
| 施药深度 | 15-20cm土层，根系分布层 |
| 施药后管理 | 及时浇水，利于药剂渗透 |
| 轮换用药 | 噻唑膦和阿维菌素交替使用 |
| 安全间隔 | 采收前30天停止使用化学杀线虫剂 |

## 五、防治方案

### 5.1 新植果园预防方案
| 步骤 | 措施 | 技术要求 |
|------|------|---------|
| 1 | 土壤检测 | 种植前检测土壤线虫密度 |
| 2 | 土壤处理 | 棉隆或石灰氮处理土壤 |
| 3 | 选用无病苗 | 确认苗木无根结线虫 |
| 4 | 施生物菌肥 | 定植时施淡紫拟青霉 |

### 5.2 已发病果园治疗方案
| 严重程度 | 防治方案 | 预期效果 |
|---------|---------|---------|
| 轻度(根瘤率<20%) | 噻唑膦颗粒剂沟施+枯草芽孢杆菌灌根 | 控制病情发展 |
| 中度(根瘤率20-50%) | 阿维菌素灌根+淡紫拟青霉+有机肥 | 减轻症状，恢复树势 |
| 重度(根瘤率>50%) | 挖除重病株+土壤消毒+补种抗病品种 | 阻断传播 |

---

## 六、防治效果评价

### 6.1 评价指标
| 指标 | 调查方法 | 评价标准 |
|------|---------|---------|
| 根瘤减退率 | 施药前后调查根瘤指数 | >70%为优 |
| 土壤线虫密度 | 改良贝曼漏斗法分离计数 | 密度降低>80% |
| 树势恢复 | 新梢生长量、叶片颜色 | 恢复明显的为有效 |
| 产量恢复 | 单株产量对比 | 增产>20%为有效 |

### 6.2 根瘤分级标准
| 级别 | 根瘤情况 |
|------|---------|
| 0级 | 根系无根瘤 |
| 1级 | 根瘤占根系<10% |
| 3级 | 根瘤占根系10-25% |
| 5级 | 根瘤占根系25-50% |
| 7级 | 根瘤占根系50-75% |
| 9级 | 根瘤占根系>75%或根系腐烂 |
