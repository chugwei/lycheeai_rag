# 荔枝林下经济开发模式

## 摘要

荔枝林下经济是指利用荔枝园的林下空间和生态环境资源，开展种植、养殖、采集等多种经营活动，实现"一地多用、立体增收"的农业经营模式。本指南系统阐述了荔枝林下经济的开发模式、适宜品种、技术要点和效益分析，为荔枝产区拓展林下经济提供参考。

## 1. 引言

我国荔枝种植面积超过33万公顷，其中大部分位于丘陵山地，存在大量林下空闲空间。林下空间约占果园面积的60%-70%，是未被充分利用的生产资源。发展荔枝林下经济，可以有效提高土地利用率、增加果农收入、改善果园生态环境，实现生态效益和经济效益双赢。

## 2. 林下经济开发模式

### 2.1 模式分类

| 模式类型 | 具体内容 | 适用条件 | 效益水平 |
|----------|----------|----------|----------|
| 林下种植 | 食用菌、中药材、蔬菜 | 光照适中、湿度适中 | 中等 |
| 林下养殖 | 家禽、蜜蜂、水产 | 环境适宜、管理便利 | 较高 |
| 林下采集 | 野生菌、野菜 | 生态环境好 | 较低 |
| 林下加工 | 荔枝加工、产品加工 | 交通便利 | 较高 |
| 林下服务 | 观光、体验 | 景观好 | 较高 |

### 2.2 推荐组合模式

| 模式组合 | 内容 | 投资强度 | 回报周期 |
|----------|------|----------|----------|
| 种植+养殖 | 林下种菌+养蜂 | 中等 | 1-2年 |
| 种植+加工 | 林下种菜+鲜食 | 低 | 当年 |
| 养殖+旅游 | 养鸡+农家乐 | 高 | 2-3年 |
| 种植+观光 | 林下种花+摄影 | 中等 | 1-2年 |

|------|----------|-------------|-------------|
| 荔枝菌(赤松茸) | 荔枝木屑栽培 | 500-800 | 5000-15000 |
| 香菇 | 林下段木栽培 | 200-400 | 3000-8000 |
| 木耳 | 林下袋料栽培 | 100-200 | 2000-5000 |
| 竹荪 | 林下荫蔽环境 | 50-100 | 5000-10000 |

**荔枝菌(赤松茸)栽培技术要点**：

| 参数 | 标准 |
|------|------|
| 栽培原料 | 荔枝木屑85%+玉米粉10%+石灰5% |
| 栽培季节 | 秋季(10-11月) |
| 栽培方式 | 畦式栽培 |
| 生长期 | 3-4个月 |
| 产量 | 500-800kg/亩 |
| 亩产值 | 8000-15000元 |

## 4. 林下养殖模式

### 4.1 林下养鸡

| 参数 | 标准 |
|------|------|
| 品种 | 本地土鸡或三黄鸡 |
| 饲养密度 | 10-20只/亩 |
| 饲养周期 | 5-6个月 |
| 出栏重量 | 1.5-2.0kg/只 |
| 产值 | 5000-8000元/亩 |

**管理要点**：

| 项目 | 内容 |
|------|------|
| 鸡舍 | 简易鸡舍，通风良好 |
| 饲料 | 以谷物为主，辅以虫果 |
| 防疫 | 定期接种疫苗 |
| 运动 | 林下自由活动 |

### 4.2 林下养蜂

| 参数 | 标准 |
|------|------|
| 品种 | 中华蜜蜂或意大利蜜蜂 |
| 蜂箱密度 | 3-5箱/亩 |
| 蜜种 | 荔枝蜜 |
| 产量 | 15-25kg/箱 |
| 产值 | 3000-6000元/亩 |

**养蜂与荔枝生产协同**：荔枝花期与蜜蜂取蜜期一致，养蜂不仅可生产荔枝蜜，还可促进荔枝授粉，提高荔枝坐果率5%-15%。

### 4.3 林下养鱼

| 参数 | 标准 |
|------|------|
| 品种 | 罗非鱼、鲫鱼 |
| 养殖方式 | 林下挖塘 |
| 水面比例 | 果园面积5%-10% |
| 产量 | 500-1000kg/亩 |
| 产值 | 5000-10000元/亩 |

## 5. 效益分析

### 5.1 经济效益

| 模式 | 亩产值(元) | 成本(元) | 净收益(元) |
|------|-----------|----------|-----------|
| 林下种菌 | 10000 | 4000 | 6000 |
| 林下养鸡 | 6000 | 3000 | 3000 |
| 林下养蜂 | 5000 | 1500 | 3500 |
| 组合模式 | 15000 | 6000 | 9000 |

### 5.2 生态效益

| 效益 | 说明 |
|------|------|
| 病虫害控制 | 鸡吃虫、蜂授粉 |
| 土壤改良 | 鸡粪还田 |
| 生物多样性 | 增加林下动物 |
| 水土保持 | 林下植被保持水土 |

## 6. 注意事项

1. 林下经济开发应与荔枝生产协调，不能影响荔枝正常生长
2. 选择适生品种，避免引入有害物种
3. 注意养殖污染防治，避免污染土壤和水源
4. 遵守相关法律法规，办理必要的养殖许可
5. 做好市场对接，避免产品滞销
