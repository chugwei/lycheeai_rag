# 荔枝土壤管理与改良技术

> 良好的土壤条件是荔枝健康生长和优质丰产的基础。荔枝根系对土壤通透性要求高，需要深厚、疏松、肥沃、排水良好的土壤。

---

## 二、土壤管理方式

### 清耕法
- **方法**：树盘和行间定期除草松土
- **优点**：地面干净，减少病虫害栖息
- **缺点**：土壤有机质下降快，水土流失严重
- **适用**：树盘下（清耕区）

### 生草法（推荐）
- **方法**：行间种植草类
- **优点**：保持水土，增加有机质，改善土壤结构
- **缺点**：需刈割管理，可能与树争水争肥
- **适用**：行间（生草区）

### 覆盖法（推荐）
- **方法**：树盘覆盖有机物或地膜
- **优点**：保水、调温、控草、增肥
- **缺点**：有机物需持续补充
- **适用**：树盘下（覆盖区）

### 推荐管理模式
```
树盘（清耕/覆盖）+ 行间（生草） —— 最常见模式

树盘区：半径1.5-2.0m范围的树盘，采用覆盖或清耕
生草区：行间3-5m宽，种植草类或绿肥
```

### 生草管理技术

| 管理项目 | 操作要求 |
|---------|---------|
| **草带宽度** | 行间留3-5m生草带 |
| **刈割时间** | 草高30-40cm时刈割 |
| **刈割留茬** | 10-15cm |
| **刈割物处理** | 覆盖于树盘下或就地腐烂 |
| **施肥** | 每年追施1-2次复合肥（5-10kg N/亩） |
| **更新** | 每3-4年重种（或自然更新） |
| **树盘隔离** | 生草与树盘之间留50cm清耕隔离带 |

## 四、土壤改良技术

### 1. 土壤酸化改良

**诊断标准**：
| pH范围 | 评价 | 改良需求 |
|--------|------|---------|
| 5.5-6.5 | 适宜 | 无需改良 |
| 4.5-5.5 | 轻度酸化 | 需施石灰 |
| <4.5 | 严重酸化 | 急需改良 |

**石灰施用量**（达到pH 6.0）：

| 当前pH | 砂质土(kg/亩) | 壤质土(kg/亩) | 粘质土(kg/亩) |
|--------|-------------|-------------|-------------|
| 5.5 | 50-75 | 75-100 | 100-125 |
| 5.0 | 75-100 | 100-150 | 125-175 |
| 4.5 | 100-125 | 125-175 | 150-225 |
| 4.0 | 125-150 | 150-200 | 200-275 |

**施用方法**：
- 石灰或白云石粉，与有机肥混合深翻
- 每隔2-3年施1次
- 不宜过量（过度提高pH会降低微量元素有效性）

### 2. 土壤有机质提升

| 当前有机质(%) | 评价 | 年需补充有机肥(kg/亩) | 改良措施 |
|-------------|------|--------------------|---------|
| >2.5 | 优良 | 维持：1000-1500 | 常规管理 |
| 1.5-2.5 | 良好 | 1500-2000 | 增施有机肥+生草 |
| 1.0-1.5 | 中等 | 2000-3000 | 重施有机肥+绿肥 |
| <1.0 | 缺乏 | 3000-5000 | 综合改良 |

### 3. 土壤板结改良

| 改良措施 | 操作方法 | 效果 |
|---------|---------|------|
| **深翻** | 冬季深翻30-40cm，打破犁底层 | 增加孔隙度，改善通透性 |
| **增施有机肥** | 每年施腐熟有机肥2000-4000kg/亩 | 改善团粒结构 |
| **施用生物菌肥** | 含枯草芽孢杆菌、解磷解钾菌 | 激活土壤微生物 |
| **生草栽培** | 行间生草，草根穿插疏松土壤 | 持续改善 |
| **施用土壤改良剂** | 腐殖酸、聚丙烯酰胺(PAM)等 | 促进团粒形成 |

### 4. 盐渍化改良

| 改良措施 | 方法 | 说明 |
|---------|------|------|
| **大水洗盐** | 灌水淹没田面5-10cm，排水洗盐 | 需有排水设施 |
| **增施有机肥** | 有机肥3000-4000kg/亩 | 提高缓冲能力 |
| **地膜覆盖** | 覆盖地膜减少蒸发返盐 | - |
| **深翻** | 深翻40-50cm，打破毛细管 | - |
| **耐盐植物** | 种植耐盐绿肥（田菁等） | 逐步改良 |

## 五、深翻改土

### 深翻的重要性
荔枝为深根性果树，深翻改土是果园土壤管理的基本措施，使根系向深层发展，提高抗旱抗寒能力。

### 深翻时间
| 时期 | 优点 | 缺点 |
|------|------|------|
| **冬季**(12-2月) | 树体休眠，伤根恢复快 | 冬季寒冷地区不适宜 |
| **秋季**(9-11月) | 土温适宜，有利根系恢复 | 与秋梢生长期重叠 |
| **采后**(7-8月) | 结合施肥进行 | 高温季节需注意浇水 |

### 深翻方法

#### 1. 扩穴深翻（幼树）
```
第1年：在定植穴外挖环形沟（宽30-40cm，深40-50cm）
第2年：继续向外扩挖
第3-4年：全园深翻完成
```

#### 2. 隔行深翻（成年树）
```
第1年：深翻行间的一半（每行深翻一侧）
第2年：深翻另一侧
深翻沟：宽40-50cm，深40-50cm
```

#### 3. 全园深翻
```
成年树每3-5年深翻1次
深度30-40cm
结合施有机肥进行
不宜伤及直径0.5cm以上的大根
```

### 深翻注意事项
1. **保护根系**：尽量少伤粗根（直径>0.5cm）
2. **分层施肥**：有机肥和磷肥施入中下层（20-40cm）
3. **及时灌水**：深翻后立即灌水（促进新根生长）
4. **表土回填**：将表土回填到底部，心土覆于表面
5. **配合改良**：深翻时同步施石灰和有机肥

## 六、土壤微生物与生物肥

### 土壤微生物作用
| 微生物类型 | 有益作用 | 代表种类 |
|-----------|---------|---------|
| **固氮菌** | 将大气N₂转化为树体可吸收的氮 | 根瘤菌、自生固氮菌 |
| **解磷菌** | 将土壤中固定态磷转化为有效磷 | 芽孢杆菌、假单胞菌 |
| **解钾菌** | 释放土壤矿物钾 | 硅酸盐细菌 |
| **纤维素分解菌** | 分解有机物料，释放养分 | 木霉菌、放线菌 |
| **菌根真菌** | 扩大根系吸收面积，提高磷吸收 | 丛枝菌根真菌(AMF) |

### 生物有机肥施用

| 产品类型 | 有效活菌数(cfu/g) | 有机质(%) | 施用量(kg/株) | 施用方法 |
|---------|-----------------|-----------|-------------|---------|
| 生物有机肥 | ≥0.2亿 | ≥40 | 3-5 | 沟施或穴施 |
| 复合微生物肥 | ≥0.5亿 | ≥30 | 2-4 | 基肥或追肥 |
| 微生物菌剂 | ≥2亿 | - | 0.5-1 | 沟施或灌根 |

## 七、不同产区土壤管理要点

| 产区 | 土壤类型 | 主要问题 | 管理重点 |
|------|---------|---------|---------|
| **海南** | 砖红壤 | 强酸性(pH4.0-5.0)，有机质低 | 施石灰，增施有机肥 |
| **粤西** | 赤红壤/砂壤 | 有机质中等，砂土保水差 | 覆盖保水，增施有机肥 |
| **珠三角** | 冲积土/赤红壤 | 酸化趋势，部分粘重 | 施石灰，深翻改土 |
| **粤东** | 赤红壤 | 土层浅，石砾多 | 扩穴深翻，客土改良 |
| **广西** | 赤红壤/石灰土 | 酸化，缺硼锌 | 施石灰，补微量元素 |
| **福建** | 红壤/赤红壤 | 酸性强，缺镁 | 施白云石粉补镁 |
| **云南** | 红壤/黄壤 | 土层深浅不一 | 因地制宜深翻 |
| **四川** | 紫色土/黄壤 | pH中性偏碱 | 注意微量元素缺乏 |
