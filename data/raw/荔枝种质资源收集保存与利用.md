# 荔枝种质资源收集保存与利用

## 摘要

荔枝（Litchi chinensis Sonn.）原产于中国，是世界上重要的热带亚热带果树，拥有丰富的种质资源。本文系统阐述了荔枝种质资源的收集、保存、评价与利用技术体系，包括种质资源调查方法、收集策略、活体保存技术（种质圃与田间基因库）、离体保存技术（种子保存、花粉保存、组织培养保存等）以及种质资源的鉴定评价方法和高效利用途径，旨在为荔枝种质资源的有效保护与可持续利用提供技术指导。

## 一、荔枝种质资源概况

### 1.1 中国荔枝种质资源现状

中国是世界上荔枝种质资源最丰富的国家，拥有超过350个荔枝品种和品系。国家荔枝种质资源圃（广州）保存荔枝种质资源600余份，包括栽培品种、近缘野生种和育种中间材料。主要种质来源包括广东、广西、海南、福建、云南、四川、贵州等省份。此外，在越南、泰国、印度、澳大利亚等国家也分布有丰富的荔枝种质资源。

### 1.2 种质资源的分类

| 类别 | 主要内容 | 代表品种 |
|------|---------|---------|
| 栽培品种 | 生产上主要推广的品种 | 妃子笑、桂味、糯米糍、怀枝等 |
| 地方品种 | 各地传统栽培品种 | 增城挂绿、鸡嘴荔、尚书怀等 |
| 野生资源 | 自然分布的野生荔枝 | 海南野生荔枝、云南野生荔枝 |
| 近缘种 | 荔枝属其他物种 | 广西荔枝(L. chinensis var. euspontanea) |
| 育种材料 | 杂交后代、突变体 | 各类杂交优株、辐射诱变材料 |
| 国外引种 | 从国外引进的品种 | 越南红荔、泰国金荔等 |

## 二、种质资源收集

### 2.1 收集原则

1. 代表性原则：覆盖所有栽培区域和生态类型
2. 多样性原则：包括栽培种、野生种、地方品种和近缘种
3. 完整性原则：收集完整的品种信息，包括起源、分布、农艺性状等
4. 规范性原则：遵循国际植物种质资源收集规范

### 2.2 收集方法

| 方法 | 适用对象 | 操作要点 |
|------|---------|---------|
| 实地考察 | 野生资源和地方品种 | 确定分布区、GPS定位、采集标本和繁殖材料 |
| 引种交换 | 国内外品种 | 签署协议、检疫处理、隔离观察 |
| 辐射诱变 | 新种质创制 | 剂量确定、选择变异体 |
| 杂交育种 | 新品种创制 | 亲本选择、杂交授粉、后代筛选 |

### 2.3 收集技术流程

种质调查→确定目标种质→采集繁殖材料（接穗或种子）→临时保存（保湿包装）→检疫消毒→登记编号→入选种质圃繁殖→鉴定评价→入库保存。

### 2.4 收集记录信息

每份种质需记录以下信息：种质编号、种质名称（俗名和学名）、采集地点（GPS坐标）、海拔、生境类型、树龄、树势、果实性状（果形、单果重、色泽、可溶性固形物、风味等）、物候期、抗逆性、病虫害状况以及采集人、采集日期等。

## 三、种质资源保存技术

### 3.1 田间保存（种质圃）

国家荔枝种质资源圃采用田间集中保存方式：

| 保存方式 | 技术参数 | 优缺点 |
|---------|---------|--------|
| 种质圃保存 | 每品种5-10株，株行距5m×6m | 优点：可全面评价，缺点：占地大、维护成本高 |
| 核心种质圃 | 每品种3-5株，株行距4m×5m | 优点：集约管理，缺点：样本偏少 |
| 备份保存 | 在不同生态区设置备份圃 | 优点：降低风险，缺点：多个点管理 |

田间保存管理要点：
- 正常的土肥水管理、整形修剪和病虫害防治
- 每份种质建立完整的档案记录
- 定期更新（20-25年更新一次）
- 配备防寒、防台风设施
- 建立灾害应急预案

### 3.2 离体保存

**种子保存：** 荔枝种子属顽拗型种子，不耐干燥和低温。最佳保存条件：种子含水量20%-25%，温度15-20℃，相对湿度95%以上，可保存3-6个月。长期保存效果不理想。

**花粉保存：** 荔枝花粉可低温保存。采集新鲜花粉，真空干燥至含水量5%-8%，密封于-20℃冰箱中，可保存1-2年；-80℃超低温保存可延长至5年。使用前需进行花粉活力检测。

**组织培养保存：**
- 茎尖培养慢生长保存：温度15-18℃，光照1000-2000lux，可保存12-18个月继代一次
- 超低温保存：茎尖经玻璃化法或包埋干燥法处理后投入液氮(-196℃)，可实现长期保存

| 保存方法 | 保存材料 | 保存期限 | 技术难度 |
|---------|---------|---------|---------|
| 田间保存 | 整株 | 20-30年 | 低 |
| 种子保存 | 种子 | 3-6个月 | 低 |
| 花粉保存 | 花粉 | 1-5年 | 中 |
| 茎尖慢生长 | 茎尖 | 12-18个月 | 中 |
| 超低温保存 | 茎尖/胚性愈伤 | 长期 | 高 |

### 3.3 分子标记辅助保存

利用DNA分子标记技术，对保存的种质进行遗传多样性分析，构建DNA指纹图谱，评估种质间的遗传关系，剔除重复种质，提高保存效率。

## 四、种质资源鉴定与评价

### 4.1 农艺性状评价

| 评价类别 | 主要指标 | 评价标准 |
|---------|---------|---------|
| 树体性状 | 树势、树姿、树冠大小 | 描述性记录和测量数据 |
| 叶片性状 | 叶形、叶色、叶面积 | 形态描述和测量 |
| 花器性状 | 花序长、花量、雌花比例 | 计数和测量 |
| 果实性状 | 单果重、果形、皮色、可食率 | 测量和色卡比对 |
| 品质性状 | 可溶性固形物、糖酸比、风味 | 实验室检测与感官评价 |
| 物候性状 | 萌芽期、开花期、成熟期 | 田间观察记录 |
| 丰产性 | 单株产量、单位面积产量 | 连续3年以上测产 |

### 4.2 抗性评价

| 抗性类型 | 鉴定方法 | 分级标准 |
|---------|---------|---------|
| 耐寒性 | 人工低温胁迫、田间自然鉴定 | 冻害级别0-5级 |
| 耐旱性 | 干旱胁迫处理、叶片相对含水量 | 萎蔫程度分级 |
| 耐涝性 | 淹水处理 | 受害指数 |
| 抗病性 | 人工接种、田间调查 | 发病率、病情指数 |
| 抗虫性 | 田间调查、室内接虫 | 被害率、虫口密度 |
| 耐盐性 | 盐分胁迫处理 | 生长量和受害程度 |

### 4.3 分子鉴定

利用SSR、SNP、AFLP等分子标记技术构建荔枝种质的DNA指纹图谱，进行品种鉴定和亲缘关系分析。目前开发了50余对荔枝SSR引物，可有效区分不同荔枝品种。

## 五、种质资源利用

### 5.1 品种选育中的利用

荔枝种质资源在品种选育中的利用途径：

| 利用方式 | 目标 | 成功案例 |
|---------|------|---------|
| 优系选择 | 直接利用优良品种 | 妃子笑、桂味 |
| 杂交育种 | 综合亲本优良性状 | 马贵荔、红绣球 |
| 诱变育种 | 创造新变异 | 无核荔枝 |
| 基因工程 | 定向改良性状 | 抗病、耐贮转基因研究 |
| 砧木选育 | 提高抗逆性 | 山荔砧木 |

### 5.2 砧木利用

野生荔枝和地方品种常作为砧木利用。优良砧木应具备：种子来源广、发芽率高、生长势强、根系发达、嫁接亲和性好、抗逆性强等特点。常用的砧木品种有怀枝、山荔、海南野生荔枝等。

### 5.3 优异基因挖掘

通过全基因组关联分析等方法，挖掘荔枝重要性状相关基因：

| 性状 | 相关基因 | 功能 |
|------|---------|------|
| 果实颜色 | LcMYB1, LcbHLH | 花青苷合成调控 |
| 种子败育(焦核) | LcGA20ox, LcGA2ox | 赤霉素代谢 |
| 糖积累 | LcSUS, LcINV | 糖代谢酶 |
| 抗逆性 | LcCBF, LcDREB | 低温胁迫响应 |

## 六、种质资源信息管理

### 6.1 数据库建设

建立荔枝种质资源数据库：包括基本档案数据库、形态性状数据库、农艺性状数据库、品质性状数据库、抗性数据库、分子标记数据库和图像数据库。采用统一的描述符和数据标准规范。

### 6.2 核心种质构建

核心种质构建步骤：收集全部种质的评价数据→确定聚类参数→应用聚类分析→选择代表性种质→验证核心种质的代表性→定期更新维护。

## 七、存在问题与对策

| 问题 | 表现 | 对策 |
|------|------|------|
| 种质流失 | 地方品种被淘汰，种质丢失 | 加强收集和保存工作 |
| 鉴定不充分 | 大量种质缺乏系统评价 | 提高鉴定效率，完善评价体系 |
| 利用效率低 | 种质资源利用不充分 | 加强优异基因挖掘，促进利用 |
| 资源退化 | 长期无性繁殖导致退化 | 建立提纯复壮技术体系 |
| 管理信息化不足 | 数据标准不统一 | 建立统一的信息管理平台 |
