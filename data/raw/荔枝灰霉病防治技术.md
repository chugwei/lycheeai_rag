# 荔枝灰霉病防治技术

## 摘要

荔枝灰霉病是由灰霉菌（*Botrytis cinerea*）引起的真菌性病害，主要危害荔枝果实和花穗，在低温高湿条件下暴发性强。该病可导致花穗腐烂、果实霉烂，造成严重减产。本文系统阐述灰霉病的病原特性、发病规律、诊断方法和防治技术。

## 1. 病原生物学

灰霉菌（*Botrytis cinerea*）属于半知菌亚门，葡萄孢属。菌丝无色，多隔，顶端产分生孢子梗。分生孢子梗弯曲，顶端呈串珠状排列分生孢子。分生孢子卵形或椭圆形，单胞，无色，15-20 μm × 9-15 μm。

### 1.1 灰霉菌特性

| 项目 | 特征 |
|-----|------|
| 菌丝 | 无色，多隔，生长迅速 |
| 分生孢子梗 | 弯曲，顶生，灰褐色 |
| 分生孢子 | 卵形，15-20 μm × 9-15 μm |
| 最适温度 | 15-22 ℃ |
| 最适湿度 | 相对湿度 >90% |
| 休眠结构 | 菌核，黑色，可在土壤中存活 |

## 2. 发病规律

灰霉菌以菌核和菌丝在病残体上越冬。翌年菌核萌发产生子实体或菌丝，分生孢子通过气流传播，从伤口或自然孔口侵入。低温高湿是发病的关键条件。

### 2.1 症状特征

| 部位 | 症状描述 |
|-----|---------|
| 花穗 | 花穗湿润腐烂，表面产生灰色霉层 |
| 果实 | 果皮出现褐色病斑，迅速扩大，覆盖灰色霉层 |
| 嫩梢 | 嫩梢尖端褐色枯死，有灰色霉层 |
| 叶片 | 叶尖或叶缘褐色枯死，扩展后形成不规则斑 |

### 2.2 发病与环境

| 条件 | 影响 | 阈值 |
|-----|------|------|
| 温度 15-22 ℃ | 最适发病 | 灰霉菌繁殖旺盛 |
| 相对湿度 >90% | 孢子萌发 | 饱和湿度最利 |
| 连续阴雨 | 传播侵染 | 雨后 2-3 天暴发 |
| 通风不良 | 树冠内湿度高 | 密植园严重 |
| 伤口 | 侵入门户 | 机械伤、虫伤 |

## 3. 诊断技术

### 3.1 田间诊断要点

- 病部表面覆盖灰色霉层是该病最典型的诊断特征。
- 潮湿条件下，霉层迅速扩展，呈绒毛状。
- 干燥条件下，霉层消退，但菌丝仍存活于组织中。
- 果实受害后软腐，有发酵气味。

### 3.2 实验室检测

| 方法 | 要点 | 判读 |
|-----|------|------|
| 镜检 | 取霉层制片观察 | 见串珠状分生孢子梗 |
| 分离培养 | PDA 培养基，20 ℃ | 菌落白色→灰色→灰褐色 |
| 菌核鉴定 | 观察黑色菌核 | 确认休眠结构 |

## 4. 防治技术

### 4.1 农业防治

- **清园**：清除病果、病枝和落叶，集中销毁。
- **通风**：合理修剪，降低树冠内湿度。
- **排水**：雨季及时排水，降低果园湿度。
- **控水**：避免大水漫灌，减少叶面湿度。
- **清沟**：冬季清沟晒园，减少越冬菌源。

### 4.2 化学防治

| 时期 | 药剂 | 稀释倍数 | 备注 |
|-----|------|---------|------|
| 萌芽前 | 石硫合剂 | 3-5 波美度 | 清园消毒 |
| 花期 | 嘧霉胺 50% | 1500-2000 倍 | 重点保护 |
| 幼果期 | 腐霉利 50% | 1500-2000 倍 | 保护 + 治疗 |
| 膨大期 | 异菌脲 50% | 1500-2000 倍 | 间隔 10 天 |
| 雨季 | 咯菌腈 50% | 1500-2000 倍 | 雨前喷施 |
| 采后 | 腐霉利浸果 | 500 mg/L | 杀菌防腐 |

### 4.3 关键防治时期

| 时期 | 重点 | 措施 |
|-----|------|------|
| 花期（3-4 月） | 花穗保护 | 嘧霉胺 + 嘧菌酯 |
| 幼果期（4-5 月） | 果实保护 | 腐霉利轮换使用 |
| 雨季（6-7 月） | 应急防治 | 雨后及时喷药 |
| 采后处理 | 贮藏保护 | 杀菌剂浸果 |

### 4.4 生物防治

- 木霉菌（*Trichoderma* spp.）可通过竞争性占位抑制灰霉菌生长。
- 丁香假单胞菌（*Pseudomonas* spp.）产生抗菌物质，对灰霉菌有抑制作用。
- 采后使用酵母菌生物保鲜剂，可减少灰霉病发生 50-70%。
