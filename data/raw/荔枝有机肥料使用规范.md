# 荔枝有机肥料使用规范

## 摘要

有机肥料是荔枝有机生产的核心投入品，对土壤健康、作物品质和生态安全具有决定性影响。本规范系统规定了荔枝有机生产用肥料的种类、质量标准、施用方法和注意事项，为果农科学使用有机肥料提供技术指导。

## 1. 引言

有机肥料是荔枝有机生产的唯一合法肥料来源。与化学肥料相比，有机肥料具有养分全面、改良土壤、促进微生物生长、提高产品品质等多重功效。我国有机肥资源总量约120亿吨(折干)，利用率仅30%左右，存在巨大开发潜力。规范有机肥料的使用，是保障有机荔枝品质的关键环节。

## 2. 有机肥料分类

### 2.1 有机肥料类型

| 类别 | 具体品种 | 特点 | 适用性 |
|------|----------|------|--------|
| 农家肥 | 猪粪、牛粪、鸡粪、鸭粪 | 养分全面、成本低 | 所有荔枝园 |
| 商品有机肥 | 复合有机肥、微生物有机肥 | 标准化、免处理 | 所有荔枝园 |
| 绿肥 | 紫云英、田菁、大叶相思 | 固氮、覆盖 | 行间种植 |
| 秸秆肥 | 稻草、麦秆、甘蔗渣 | 增加有机质 | 覆盖还田 |
| 生物炭 | 炭化生物质 | 改良土壤结构 | 酸性土壤 |
| 矿物肥料 | 磷矿粉、钾矿粉、石灰石 | 补充矿物养分 | 缺乏土壤 |
| 海藻肥 | 海藻提取物 | 促进生长 | 追肥 |

### 2.2 各类型肥料养分含量

| 肥料类型 | 有机质(%) | N(%) | P₂O₅(%) | K₂O(%) |
|----------|-----------|------|---------|--------|
| 猪粪 | 25-35 | 0.5-0.8 | 0.4-0.6 | 0.4-0.6 |
| 牛粪 | 20-30 | 0.4-0.6 | 0.3-0.4 | 0.3-0.5 |
| 鸡粪 | 25-35 | 1.5-2.0 | 1.2-1.8 | 0.8-1.2 |
| 商品有机肥 | 45-55 | 1.5-2.5 | 1.0-1.5 | 1.0-1.5 |
| 绿肥(干重) | 30-40 | 2.0-3.0 | 0.2-0.5 | 1.0-2.0 |
| 磷矿粉 | - | - | 25-30 | - |
| 草木灰 | - | - | 1-2 | 3-5 |

## 3. 肥料质量标准

### 3.1 商品有机肥标准(NY 525-2021)

| 指标 | 限值 |
|------|------|
| 有机质(干基) | ≥45% |
| 总养分(N+P₂O₅+K₂O) | ≥5% |
| pH | 5.5-8.5 |
| 水分 | ≤30% |
| 重金属(镉) | ≤3.0mg/kg |
| 重金属(铅) | ≤50mg/kg |
| 重金属(砷) | ≤25mg/kg |
| 重金属(汞) | ≤1.0mg/kg |
| 大肠菌群 | ≤100个/g |
| 蛔虫卵死亡率 | ≥95% |

### 3.2 农家肥处理要求

| 处理要求 | 内容 | 标准 |
|----------|------|------|
| 充分腐熟 | 发酵温度达55-65℃ | 持续3-5天 |
| 无害化处理 | 杀灭病原菌和虫卵 | 堆温达70℃以上 |
| 水分控制 | 调节含水量 | 50%-60% |
| C/N比 | 调整碳氮比 | 25-30:1 |

## 4. 施用方法与技术规范

### 4.1 基肥施用

| 施用时期 | 肥料类型 | 用量(kg/亩) | 施用方法 |
|----------|----------|-------------|----------|
| 采后(10-11月) | 腐熟农家肥 | 2000-3000 | 沟施(环状或放射状) |
| 采后 | 商品有机肥 | 500-800 | 撒施+浅耕 |
| 春季萌芽前 | 生物有机肥 | 300-500 | 沟施 |

### 4.2 追肥施用

| 时期 | 肥料类型 | 用量(kg/亩) | 施用方法 |
|------|----------|-------------|----------|
| 花芽分化期 | 海藻肥 | 20-30 | 喷施或灌根 |
| 幼果期 | 腐殖酸肥 | 50-100 | 灌根 |
| 果实膨大期 | 草木灰 | 20-50 | 撒施 |

### 4.3 叶面肥施用

| 时期 | 肥料类型 | 浓度 | 施用频次 |
|------|----------|------|----------|
| 花前 | 海藻肥 | 500-800倍 | 1-2次 |
| 幼果期 | 氨基酸肥 | 800-1000倍 | 1-2次 |
| 采后 | 氨基酸肥 | 500-800倍 | 1次 |

## 5. 养分平衡与施肥计划

### 5.1 荔枝园养分需求量

| 产量水平 | N(kg/亩) | P₂O₅(kg/亩) | K₂O(kg/亩) |
|----------|----------|-------------|------------|
| 低产(500kg/亩) | 4-6 | 2-3 | 5-8 |
| 中产(1000kg/亩) | 8-10 | 4-5 | 8-12 |
| 高产(1500kg/亩) | 10-12 | 5-6 | 10-15 |

### 5.2 有机肥+化肥配施

有机生产不允许使用化学肥料，养分完全由有机肥提供。按有机质含量计算有机肥需求：

有机肥需求量(kg/亩) = 所需养分(kg/亩) ÷ 肥料养分含量(%)

例如：需氮8kg/亩，商品有机肥含氮2%，则需有机肥400kg/亩。

| 养分 | 有机肥提供比例 | 矿物肥补充 |
|------|---------------|------------|
| 氮 | 80-100% | 绿肥固氮 |
| 磷 | 60-80% | 磷矿粉 |
| 钾 | 60-80% | 钾矿粉、草木灰 |
| 钙镁 | 50-70% | 石灰石、白云石 |
| 微量元素 | 自然提供 | 必要时补充 |

## 6. 施肥注意事项

1. 所有有机肥必须充分腐熟，避免烧根和传播病害
2. 施用前检测有机肥重金属含量，确保不超标
3. 按土壤检测确定施肥量，避免过量施用
4. 施肥结合土壤改良措施，提高肥料利用率
5. 建立有机肥投入品台账，记录来源、用量和日期
6. 禁止使用未经腐熟的畜禽粪便和含转基因成分肥料
