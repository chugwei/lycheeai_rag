# 荔枝常见病害综合防治

> 荔枝在生产过程中除霜疫霉病外，还受到多种病害的威胁。本文系统介绍荔枝的其他重要病害——炭疽病、酸腐病、煤烟病、藻斑病、叶斑病等的识别与综合防治技术。

---

## 一、荔枝炭疽病

### 病害概述
荔枝炭疽病（*Colletotrichum gloeosporioides*）是荔枝的第二大真菌病害，仅次于霜疫霉病。该病由胶孢炭疽菌（*Colletotrichum gloeosporioides* Penz.）引起，属半知菌亚门炭疽菌属。该病在高温高湿条件下易暴发，可引起落叶、落果、枝枯，严重时果实损失率可达20-30%。

### 症状识别
| 受害部位 | 症状特征 | 与其他病害的区别 |
|---------|---------|---------------|
| **果实** | 病斑初期为褐色小点，后扩大为圆形或不规则形凹陷病斑，有轮纹。潮湿时病斑上出现粉红色粘孢子团 | 霜疫霉病病斑水渍状、白色霉层；炭疽病病斑凹陷、粉红色孢子团 |
| **叶片** | 病斑多从叶尖或叶缘开始，呈灰褐色至灰白色，边缘深褐色，有不明显轮纹，后期病斑易穿孔 | - |
| **枝条** | 枝条出现褐色至灰褐色病斑，围绕枝条扩展导致枝梢枯死（回枯症状） | - |
| **花穗** | 花穗变褐枯死，严重时整个花穗坏死 | - |

### 发病规律
- **病原**：*Colletotrichum gloeosporioides*（有性态为 *Glomerella cingulata*）
- **越冬**：以菌丝体和分生孢子盘在病残体上越冬
- **传播**：分生孢子借风雨、昆虫传播
- **温度**：最适发病温度25-28°C
- **湿度**：相对湿度>90%时发病严重
- **高发期**：果实发育中后期（5-6月）和秋梢期（8-9月）

### 品种抗病性
| 抗性等级 | 品种 |
|---------|------|
| 高感 | 桂味（易感炭疽病的重要特征） |
| 中感 | 糯米糍、妃子笑、白糖罂 |
| 中抗 | 黑叶、白蜡、鸡嘴荔 |
| 抗病 | 三月红 |

### 防治措施

#### 农业防治
1. **修剪清园**：剪除病枝、病叶，清除地面落叶落果，集中烧毁
2. **合理施肥**：增施磷钾肥，控制氮肥，增强树势
3. **改善通风**：修剪过密枝条，降低果园湿度
4. **果实套袋**：谢花后30-35天套袋，减少病菌侵染

#### 化学防治
| 药剂名称 | 浓度 | 施药时期 | 间隔期 |
|---------|------|---------|-------|
| 咪鲜胺 | 45%乳油1000倍液 | 发病初期 | 7天 |
| 苯醚甲环唑 | 10%水分散粒剂1500倍液 | 发病初期 | 7-10天 |
| 吡唑醚菌酯 | 25%悬浮剂1500倍液 | 预防 | 7天 |
| 代森锰锌 | 80%可湿性粉剂600倍液 | 保护性预防 | 10-15天 |
| 多菌灵 | 50%可湿性粉剂500倍液 | 治疗 | 10天 |

**防治关键期**：
- 花穗抽生期（2-3月）：喷药保护花穗
- 幼果期（4月）：保护幼果不受侵染
- 果实膨大期（5月）：重点防治
- 采前15天停药

## 二、荔枝酸腐病

### 病害概述
荔枝酸腐病是荔枝成熟果实和采后果实的重要病害，由酵母菌（*Geotrichum candidum*）和多种细菌复合侵染引起。该病在果实成熟期和采后贮运过程中发生，可导致果实严重腐烂，造成重大经济损失。

### 症状识别
- **果实症状**：
  - 初期：果皮出现水渍状褐色斑块
  - 中期：病斑迅速扩大，整个果实变褐软化
  - 后期：果实内部浆液化，流出酸臭汁液
  - 特征：**强烈的酸臭味**是本病最典型的特征
  - 与霜疫霉病的区别：酸腐病无白色霉层，但有强烈酸臭味
- **主要危害**：成熟果和近成熟果，采后果实在高温高湿条件下24-48小时即可发病

### 发病规律
- **病原**：*Geotrichum candidum* 以及多种细菌（如 *Erwinia* spp.）
- **侵染途径**：通过果皮伤口（机械损伤、虫伤、裂果）侵入
- **温度**：25-30°C最适发病
- **高发条件**：果实采收后堆放、运输过程中高温高湿+机械损伤
- **传播方式**：接触传播，病果与健康果直接接触即可传染

### 防治措施

#### 采前预防
1. 减少裂果（稳控水分、增施钙肥）
2. 防治蒂蛀虫等果实害虫（减少虫伤）
3. 采前7-10天喷施杀菌剂（如嘧菌酯、咪鲜胺）
4. 避免雨天采收

#### 采后处理（关键）
1. **及时预冷**：采收后2小时内将果温降至2-4°C
2. **剔除病果**：剔除所有裂果、虫果、机械损伤果
3. **药剂处理**：
   - 咪鲜胺（45%乳油）1000倍液浸泡2分钟
   - 噻菌灵（50%悬浮剂）500倍液浸泡
4. **包装要求**：打孔保鲜袋包装，避免果实堆积过厚
5. **冷链运输**：全程保持2-4°C

## 三、荔枝煤烟病

### 病害概述
荔枝煤烟病（Sooty Mold）是由多种煤炱科真菌（*Capnodium* spp.、*Meliola* spp.等）引起的病害。该病不是直接侵染荔枝组织，而是在昆虫（蚜虫、介壳虫、粉虱）分泌的蜜露上生长，形成黑色霉层覆盖叶片和果实表面。

### 症状识别
- **叶片**：叶片表面覆盖一层黑色煤烟状霉层，影响光合作用
- **果实**：果实表面覆盖黑色霉层，影响外观品质和商品价值
- **枝条**：严重时枝条上也有黑色霉层
- **特征**：霉层可以擦掉，下层叶片组织一般正常

### 发病规律
- **病原**：多种煤炱科真菌（*Capnodium* spp.、*Fumago* spp.等）
- **直接原因**：昆虫蜜露（蚜虫、介壳虫、白蛾蜡蝉等分泌的含糖排泄物）
- **高发期**：5-9月高温高湿季节
- **高发条件**：果园虫害严重、通风不良、湿度大

### 防治措施

#### 核心策略——治虫防病
煤烟病的防治关键是**控制蜜露分泌的昆虫**，而不是直接杀菌。

1. **防治蚜虫**：
   - 吡虫啉10%可湿性粉剂2000倍液
   - 啶虫脒5%乳油1500倍液
2. **防治介壳虫**：
   - 噻嗪酮25%可湿性粉剂1500倍液
   - 矿物油乳剂150倍液（冬季使用）
3. **防治白蛾蜡蝉**：
   - 高效氯氟氰菊酯2.5%乳油3000倍液

#### 直接防治
1. 发病初期喷施石硫合剂0.3-0.5波美度
2. 氢氧化铜（铜制剂）800倍液
3. 雨水冲刷可自然减轻病情

#### 农业措施
1. 合理修剪，改善通风透光
2. 控制果园湿度
3. 保护天敌（瓢虫、寄生蜂等）

## 四、荔枝藻斑病

### 病害概述
荔枝藻斑病（Algal Leaf Spot）由藻类 *Cephaleuros virescens* 引起，是荔枝叶片上常见的寄生性藻类病害。老树、弱树和管理粗放的果园发病较重。

### 症状识别
- **叶片正面**：圆形或不规则形病斑，初期灰绿色，后期锈褐色
- **病斑特征**：表面有绒毛状突起（藻类孢囊梗和孢子囊）
- **叶片背面**：对应位置无明显症状
- **危害**：影响光合作用，严重时叶片早衰脱落

### 发病规律
- **病原藻**：*Cephaleuros virescens* Kunze
- **高发条件**：高温高湿、树冠密闭、通风透光不良
- **高发期**：夏秋季节（5-10月）
- **寄主范围**：危害多种热带果树（荔枝、龙眼、芒果、柑橘等）

### 防治措施
1. **改善通风透光**：修剪过密枝条，树冠透光率达20-30%
2. **增强树势**：增施有机肥和钾肥，提高树体抗性
3. **化学防治**：
   - 波尔多液0.5:1:100倍液喷施
   - 氢氧化铜77%可湿性粉剂800倍液
   - 代森锰锌80%可湿性粉剂600倍液
4. 喷药时间：发病初期（春季和夏初）

## 五、荔枝叶斑病

### 病害概述
荔枝叶斑病（Leaf Spot）由多种病原真菌引起，包括 *Pestalotia pauciseta*、*Botryodiplodia theobromae* 等。该病主要危害老叶，引起早期落叶，削弱树势。

### 症状识别
- **病斑形状**：圆形、椭圆形或不规则形
- **病斑颜色**：灰褐色至灰白色，边缘深褐色
- **病征**：病斑上散生黑色小点（病原菌的分生孢子器）
- **危害**：引起叶片早落，影响树体营养积累

### 主要病原
| 病原菌 | 病斑特征 | 发病条件 |
|-------|---------|---------|
| *Pestalotia pauciseta* | 灰褐色病斑，边缘深褐色 | 高温高湿 |
| *Botryodiplodia theobromae* | 大而规则病斑，灰白色 | 弱树、老叶易感 |
| *Phomopsis* spp. | 褐色病斑，沿叶脉扩展 | 枝梢衰弱 |

### 防治措施
1. **冬季清园**：清除病落叶，集中烧毁
2. **修剪**：剪除病枝病叶，改善通风
3. **增强树势**：合理施肥，避免偏施氮肥
4. **化学防治**：
   - 代森锰锌80%可湿性粉剂600倍液
   - 苯醚甲环唑10%水分散粒剂1500倍液
   - 多菌灵50%可湿性粉剂500倍液
   - 发病初期开始喷药，7-10天1次，连续2-3次

## 六、荔枝根腐病

### 病害概述
荔枝根腐病（Root Rot）由多种土传病原菌引起，主要包括 *Phytophthora* spp.、*Fusarium* spp. 和 *Armillaria* spp.（蜜环菌）等。该病危害根系，导致树势衰弱、叶片黄化、枝条枯死，严重时全株死亡。

### 症状识别
- **地上部症状**：
  - 叶片黄化、变小、早落
  - 新梢生长缓慢，枝条枯死
  - 结果减少，果实变小
  - 严重时全株枯萎死亡
- **根部症状**：
  - 须根腐烂、变褐色
  - 主根皮层腐烂，木质部变色
  - 根颈部有时可见白色菌丝体

### 发病条件
- 排水不良的低洼果园
- 土壤粘重、板结
- 连作重茬
- 土壤有害微生物积累
- 树体衰弱

### 防治措施

#### 预防措施
1. **选择排水良好的地块**建园
2. **起垄栽培**，垄高20-30cm
3. **施用有机肥**改良土壤结构
4. **生物防控**：施用枯草芽孢杆菌、木霉菌等生物菌肥
5. **避免积水**：雨季及时排水

#### 治疗措施
1. 挖开根颈部，刮除腐烂组织
2. 根部灌药：
   - 甲霜灵·锰锌58%可湿性粉剂500倍液灌根
   - 多菌灵50%可湿性粉剂500倍液灌根
   - 恶霉灵70%可湿性粉剂3000倍液灌根
3. 增施有机肥和生物菌肥，恢复树势
4. 严重病株挖除后土壤消毒

## 七、荔枝膏药病

### 病害概述
荔枝膏药病由 *Septobasidium* spp. 真菌引起，因菌膜似膏药贴附在枝干上而得名。该病危害枝干，影响树势。

### 症状识别
- 枝干上形成灰褐色至紫褐色菌膜（似膏药状）
- 菌膜紧贴树皮，边缘略翘起
- 严重时菌膜包围整个枝干
- 树皮组织坏死，枝梢枯死

### 防治措施
1. **刮除菌膜**：用竹片或刀刮除枝干上的菌膜
2. **涂药保护**：
   - 刮除后涂抹石硫合剂原液
   - 或涂抹波尔多浆（硫酸铜:生石灰:水=1:1:10）
3. **修剪通风**：剪除过密枝条，改善通风透光
4. **防治介壳虫**：膏药病的发生与介壳虫蜜露有关

## 八、荔枝缺素症

### 常见缺素症识别

| 缺素类型 | 症状特征 | 发生条件 | 补救措施 |
|---------|---------|---------|---------|
| **缺氮** | 老叶黄化，新叶淡绿，生长缓慢 | 土壤贫瘠，施有机肥不足 | 叶面喷0.3%尿素，土壤追施尿素 |
| **缺磷** | 叶片暗绿无光泽，老叶紫红色 | 酸性或碱性土壤磷固定 | 施过磷酸钙1-1.5kg/株 |
| **缺钾** | 叶缘焦枯，果实小，易裂果 | 砂质土钾易流失 | 施硫酸钾0.3-0.5kg/株，叶面0.3%KH₂PO₄ |
| **缺钙** | 新叶畸形、叶缘焦枯，裂果 | 酸性土壤钙不足 | 施硝酸钙或石灰，叶面0.1%硝酸钙 |
| **缺镁** | 老叶脉间失绿，呈"鱼骨状" | 酸性砂质土 | 施硫酸镁0.1-0.2kg/株 |
| **缺硼** | 花而不实，坐果率低，果肉木栓化 | 淋溶严重的酸性土 | 叶面喷0.1%硼砂，花期前后各1次 |
| **缺锌** | 新叶变小、簇生（小叶病） | 酸性砂质土 | 叶面喷0.1%硫酸锌+0.3%尿素 |
| **缺铁** | 新叶黄白化（失绿褪绿） | 石灰质土壤铁固定 | 叶面喷0.2%硫酸亚铁，土壤施螯合铁 |
