# 白糖罂荔枝品种特性与栽培技术

> 白糖罂（*Litchi chinensis* Sonn. cv. Baitangying）是荔枝早熟优质品种，因果肉甜如白糖而得名，是早熟荔枝中品质最好的品种之一。该品种主产于广东粤西地区，以高州、电白、化州等地最为集中，是早熟荔枝市场的重要品种和粤西荔枝的代表性品种。

---

## 一、品种起源与历史

### 品种来源
白糖罂原产于广东省高州市一带，栽培历史超过200年。"罂"为古代盛糖容器，因其果肉极甜、如盛满白糖之罂而得名。该品种在粤西地区素有"白糖罂、荔枝王"的美誉，是当地最受推崇的早熟荔枝品种。

### 品种地位
白糖罂是早熟荔枝中品质最优的品种之一，在5月中下旬上市，填补了早熟荔枝市场的品质空白。其极甜的风味特色使其在高端早熟荔枝市场中占据独特地位，深受消费者喜爱。

| 指标 | 数据 |
|------|------|
| 全国栽培面积占比 | 约3-5% |
| 粤西产区占比 | 10-15% |
| 单株产量（成年树） | 25-45kg |
| 亩产 | 500-1000kg |
| 市场供应期 | 5月中下旬 |
| 果实发育期 | 58-63天 |

## 二、植物学特征

### 树体特征
| 部位 | 特征描述 |
|------|---------|
| 树势 | 中等，树冠紧凑，不徒长 |
| 树冠形状 | 半圆形或圆头形，结构紧凑 |
| 枝条 | 中等粗度，分枝力较强，角度适中 |
| 叶片 | 小叶4-5对，椭圆形，叶缘平展 |
| 叶色 | 深绿色，叶片厚实有光泽 |
| 生长习性 | 一年抽梢3次，生长速度中等，易管理 |
| 树干 | 灰褐色，较光滑 |

### 花穗特征
| 特征 | 描述 |
|------|------|
| 花穗类型 | 纯花穗为主，部分带叶花穗 |
| 花穗长度 | 12-18cm |
| 花量 | 中等偏多，每穗含花800-1500朵 |
| 雌雄花比例 | 1:3-1:6 |
| 开花习性 | 雌雄异熟，花期较为集中（约15-20天） |
| 自花结实率 | 较低（<15%），需配置授粉树 |

### 果实特征
| 指标 | 数值 |
|------|------|
| 单果重 | 18-22g |
| 果形 | 圆形或近圆形，端正 |
| 果皮颜色 | 鲜红色（全红时成熟，色泽鲜艳） |
| 龟裂片 | 中等突起，排列较整齐 |
| 果肉颜色 | 白蜡色，半透明 |
| 果肉质地 | 爽脆，清甜，化渣性好 |
| 风味 | 极甜，如白糖般甜腻，无酸味 |
| 可食率 | 72-76% |
| 可溶性固形物 | 18-20% |
| 种子大小 | 大多数为大核（焦核率20-30%） |
| 香气 | 清淡雅致 |

## 四、栽培技术要点

### 1. 园地选择与定植
| 项目 | 要求 |
|------|------|
| 土壤要求 | 砂壤土或壤土最佳，pH 5.5-6.5，排水良好 |
| 温度要求 | 年均温>22℃，冬季最低温>0℃，冬季需有适量低温 |
| 降雨量 | 年降雨量1500-2000mm |
| 定植密度 | 4m×5m（33株/亩）或5m×5m（26株/亩） |
| 定植穴 | 80cm×80cm×70cm，每穴施有机肥15-20kg |
| 授粉树配置 | 推荐配置妃子笑或黑叶，比例5:1 |
| 定植时间 | 春植（2-3月）或秋植（9-10月） |

### 2. 肥水管理

| 施肥时期 | 肥料种类 | 用量（每株） | 作用 |
|---------|---------|------------|------|
| 采后肥（5-6月） | 腐熟有机肥+复合肥 | 15-20kg+0.5kg | 恢复树势，促发秋梢 |
| 秋梢肥（7-8月） | 复合肥（15-15-15） | 0.3-0.5kg | 促进秋梢健壮充实 |
| 促花肥（12-1月） | 复合肥+硼砂+硫酸锌 | 0.3-0.5kg+15g+10g | 促进花芽分化，提高花质 |
| 保果肥（3-4月） | 高钾复合肥+硝酸钙 | 0.3-0.5kg+0.2kg | 减少落果，增加糖度 |

### 3. 水分管理
| 时期 | 管理要求 | 注意事项 |
|------|---------|---------|
| 秋梢生长期（7-8月） | 保持充足水分 | 促进新梢生长，注意排水防涝 |
| 花芽分化期（12-1月） | 适当控水 | 保持土壤相对干燥促进花芽分化 |
| 开花期（2-3月） | 保持土壤湿润 | 田间持水量70-80%，提高坐果率 |
| 果实发育期（3-5月） | 水分均衡供给 | 避免忽干忽湿导致裂果 |

### 4. 整形修剪
| 树龄 | 修剪目标 | 具体方法 |
|------|---------|---------|
| 幼树期（1-3年） | 培养树冠骨架 | 定干50-60cm，培养3-4个主枝，开张角度45-50° |
| 初果期（4-6年） | 扩大树冠 | 疏除直立枝、交叉枝，培养结果枝组 |
| 盛果期（7-20年） | 保持丰产树形 | 采后及时回缩修剪，更新结果母枝 |
| 衰老期（>20年） | 更新复壮 | 回缩骨干枝，利用徒长枝更新 |

### 5. 控梢促花
白糖罂花芽分化对温度敏感，冬季需有适量低温：
1. **末次秋梢**：控制在10月下旬至11月初老熟，长度15-20cm
2. **冬季控水**：11月至12月保持土壤适当干旱
3. **环割**：12月上旬对主干环割1圈
4. **多效唑**：秋梢老熟后喷施15%多效唑300-400倍液
5. **断根**：12月在树冠滴水线内侧挖沟断根，减少营养吸收

### 6. 保花保果
| 措施 | 时期 | 操作方法 |
|------|------|---------|
| 放蜂授粉 | 盛花期 | 每10亩放置蜜蜂5-8箱 |
| 叶面追肥 | 谢花后 | 0.3%磷酸二氢钾+0.1%硼砂+0.1%硫酸锌 |
| 激素保果 | 谢花后7-10天 | 赤霉素20mg/L+细胞分裂素5mg/L |
| 环割保果 | 谢花后15天 | 对营养枝环割1圈，促进坐果 |

### 7. 病虫害防治
| 病虫害 | 为害特点 | 防治时期 | 药剂选择 |
|--------|---------|---------|---------|
| 霜疫霉病 | 花穗、果实腐烂 | 花穗期-幼果期 | 甲霜灵锰锌、烯酰吗啉 |
| 炭疽病 | 叶片、果实病斑 | 春梢期、果实发育期 | 咪鲜胺、苯醚甲环唑 |
| 蒂蛀虫 | 幼虫蛀食果实 | 果实发育期（重点防治） | 氯虫苯甲酰胺、菊酯类 |
| 荔枝蝽象 | 成虫若虫吸食 | 花穗期 | 敌百虫、吡虫啉 |
| 介壳虫 | 枝干吸食 | 枝梢期 | 矿物油、噻嗪酮 |

## 五、采收与采后处理

### 采收标准
| 指标 | 标准 |
|------|------|
| 果皮颜色 | 鲜红色（全红） |
| 可溶性固形物 | 18%以上 |
| 风味 | 充分甜，无酸味 |
| 采收时间 | 晴天早晨露水干后或傍晚 |

### 采后处理流程
1. **预冷**：采后2小时内预冷至4-6℃
2. **分选**：剔除病虫果、裂果、畸形果
3. **分级**：按单果重分级（大>22g、中18-22g、小<18g）
4. **包装**：透气包装+冰袋，每箱5-10kg
5. **冷链运输**：2-4℃运输，保鲜期5-7天

## 六、优缺点分析

### 优点
| 项目 | 说明 |
|------|------|
| 早熟优质 | 5月中下旬上市，品质优于同期其他品种 |
| 风味极甜 | 果肉甜度高，适口性极好 |
| 果色鲜艳 | 全红果，外观吸引力强 |
| 市场售价较好 | 早熟优质品种，经济效益较高 |
| 树冠紧凑 | 适合适度密植，土地利用效率高 |
| 大小年不明显 | 产量相对稳定 |

### 缺点
| 项目 | 说明 |
|------|------|
| 可食率偏低 | 大核品种，可食率仅72-76% |
| 焦核率低 | 仅20-30%，大部分为大核果 |
| 对低温敏感 | 冬季低温不足严重影响花芽分化 |
| 产量中等 | 丰产性不及妃子笑、黑叶等品种 |
| 适应性一般 | 适宜产区范围较窄 |

## 七、适种区域与种植建议

### 主产区
广东省茂名市（高州、电白、化州）为最适产区，该地区气候温暖、冬季有适量低温，最适合白糖罂种植。

### 适宜发展区域
| 区域 | 评价 |
|------|------|
| 广东粤西（湛江、阳江部分地区） | 适宜，品质优良 |
| 海南 | 早熟优势明显，但冬季低温可能不足 |
| 广西南部（玉林、钦州） | 较适宜，需注意冬季低温条件 |
| 云南干热河谷 | 可试种，需评估品质表现 |

### 种植建议
1. 选择冬季有适量低温的地区发展
2. 注意配置授粉树，提高坐果率
3. 作为早熟搭配品种，与妃子笑错峰上市
4. 适度发展，不宜大规模单一种植
5. 结合避雨栽培可提高商品果率
