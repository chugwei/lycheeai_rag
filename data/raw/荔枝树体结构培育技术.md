# 荔枝树体结构培育技术

## 摘要

荔枝树体结构培育是建园后至盛产期逐步构建合理树冠骨架的基础性工作，决定成年树的产量潜力和管理便利性。本文系统阐述荔枝树体结构培育的树形选择、骨架培养、枝层配置、通风透光管理和结构评价标准，为荔枝高效栽培提供树体结构培育技术指南。

## 1. 树体结构培育概述

荔枝树体结构培育是一个长期过程，从定植开始至盛产期（约6-10年），通过整形修剪逐步构建合理的树冠骨架。良好的树体结构应具备：主干直立、主枝分布均匀、侧枝层次分明、通风透光良好、树冠紧凑。

## 2. 树形选择

### 2.1 主要树形比较

| 树形名称 | 特点 | 适用条件 | 推荐指数 |
|---------|------|---------|---------|
| 自然圆头形 | 自然生长，主干明显 | 常规栽培 | ★★★★☆ |
| 开心形 | 无中央主干，主枝开张 | 矮化密植 | ★★★★★ |
| 多层形 | 分层次培养主枝 | 高干栽培 | ★★★☆☆ |
| 丛枝形 | 多主干丛状生长 | 老树改造 | ★★★☆☆ |
| 棚架形 | 枝条上架形成棚面 | 特殊栽培 | ★★☆☆☆ |

### 2.2 推荐树形

开心形树形是荔枝矮化密植栽培的最佳选择，具有树冠低矮、通风透光好、管理方便、产量高等优点。

## 3. 骨架培养

### 3.1 主干培养

| 培养阶段 | 目标 | 操作要点 |
|---------|------|---------|
| 定植期 | 定干高度100-120cm | 剪除定干以上枝梢 |
| 第1年 | 主干高120-150cm | 抹除下部萌芽 |
| 第2年 | 选留3-5个主枝 | 在主干上选留 |
| 第3-4年 | 主干定型 | 不再增高，重点培养侧枝 |

### 3.2 主枝培养

| 培养要素 | 标准 |
|---------|------|
| 主枝数量 | 3-5个 |
| 主枝分布 | 螺旋状均匀分布，互不重叠 |
| 主枝间距 | 15-25cm |
| 主枝角度 | 开张至45°-60° |
| 主枝粗细 | 较主干细1/2-2/3 |
| 主枝长度 | 2-3年时达1.5-2.5m |

### 3.3 侧枝培养

| 培养要素 | 标准 |
|---------|------|
| 侧枝数量 | 每主枝2-4个 |
| 侧枝分布 | 在主枝上螺旋状均匀分布 |
| 侧枝角度 | 开张至60°-80° |
| 侧枝长度 | 0.8-1.5m |
| 侧枝层次 | 形成2-3个层次 |

## 4. 枝层配置

### 4.1 枝层配置标准

| 配置要素 | 标准 |
|---------|------|
| 层数 | 2-3层 |
| 层间距 | 40-60cm |
| 层内枝距 | 15-25cm |
| 层内枝量 | 每层3-5枝 |
| 层间通风 | 层间有足够空间 |

### 4.2 枝层培养方法

| 方法 | 操作要点 | 时期 |
|------|---------|------|
| 拉枝分层 | 将枝条拉至目标层次 | 夏季 |
| 短截分层 | 短截培养不同层次枝 | 冬季 |
| 摘心分层 | 摘心控制枝高形成层次 | 夏季 |

## 5. 通风透光管理

### 5.1 通风透光标准

| 评价指标 | 优良标准 |
|---------|---------|
| 冠内光照 | 树冠下部能照到阳光 |
| 枝梢分布 | 均匀分布，不重叠 |
| 内膛枝条 | 有少量健壮枝，不郁闭 |
| 冠内温度 | 与外界温差<5°C |

### 5.2 改善通风透光措施

| 措施 | 操作内容 | 时期 |
|------|---------|------|
| 疏枝 | 疏除过密交叉枝 | 冬季和夏季 |
| 拉枝 | 拉枝开角改善光照 | 夏季 |
| 回缩 | 回缩过长枝条 | 冬季 |
| 短截 | 短截徒长枝 | 全年 |

## 6. 树体结构评价

### 6.1 结构评价标准

| 评价等级 | 评价标准 |
|---------|---------|
| 优良 | 主干直立，主枝均匀，层次分明，通风透光好 |
| 良好 | 主干较直立，主枝较均匀，基本分层，通风尚可 |
| 一般 | 主干不直立，主枝不均匀，分层不明显 |
| 较差 | 主干弯曲，主枝混乱，无层次，郁闭 |

### 6.2 结构改造

| 结构问题 | 改造措施 |
|---------|---------|
| 主枝过密 | 疏除多余主枝 |
| 主枝下垂 | 拉枝开角或支撑 |
| 树冠郁闭 | 疏枝+回缩 |
| 单主枝 | 培养补充主枝 |

## 7. 不同栽培模式树体结构

| 栽培模式 | 树形 | 树高 | 主枝数 | 特点 |
|---------|------|------|--------|------|
| 常规栽培 | 自然圆头形 | 4-6m | 4-6 | 自然生长 |
| 矮化密植 | 开心形 | 2.5-3.5m | 3-5 | 低矮紧凑 |
| 超高密度 | 开心形 | 1.5-2.5m | 2-3 | 极矮化 |
| 老树改造 | 丛枝形 | 3-5m | 3-5 | 保留主干 |

## 8. 注意事项

树体结构培育是长期过程，需从定植开始就按标准操作。主枝培养应及时，错过培养窗口期补救困难。结构调整应在冬季进行，避免夏季大修剪。
