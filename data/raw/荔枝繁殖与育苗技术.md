# 荔枝繁殖与育苗技术

> 荔枝繁殖方式包括有性繁殖（实生播种）和无性繁殖（空中压条、嫁接、扦插、组织培养）。生产上以嫁接繁殖为主，空中压条（高压）为辅。

---

## 一、繁殖方式概述

| 繁殖方式 | 优点 | 缺点 | 适用场景 |
|---------|------|------|---------|
| **嫁接繁殖** | 保持优良品种特性，根系发达，抗逆性强 | 技术要求较高，需砧木培育 | **生产上最常用** |
| **空中压条（高压）** | 技术简单，成苗快，结果早（2-3年） | 根系弱，寿命短，不耐移植 | 小规模繁殖、庭院种植 |
| **实生播种** | 操作简单，根系健壮 | 后代变异大，结果迟（5-12年） | 砧木培育、育种 |
| **扦插繁殖** | 可大量繁殖 | 生根困难，成活率低（<20%） | 研究用 |
| **组织培养** | 繁殖系数高，脱毒 | 成本高，技术复杂 | 脱毒苗生产、优良品种扩繁 |

## 二、砧木培育（实生播种法）

### 种子采集与处理
| 步骤 | 操作要求 | 注意事项 |
|------|---------|---------|
| **采种母树** | 生长健壮、无病虫害的成年树 | 选择抗病性强的品种（如黑叶） |
| **采种时间** | 果实充分成熟时 | 种子饱满、发芽率高 |
| **取种** | 去果肉，清水洗净 | 勿损伤种皮 |
| **种子筛选** | 选大粒饱满种子 | 淘汰瘪小、病虫种子 |
| **消毒** | 50%多菌灵500倍液浸泡10分钟 | 杀灭种皮病菌 |

### 种子活力保存
荔枝种子**寿命极短**，自然条件下4-5天即丧失活力80%以上：

| 保存方法 | 保存时间 | 发芽率(%) |
|---------|---------|----------|
| 采后立即播种 | 当天 | 85-95 |
| 湿沙贮藏（室温） | 5天 | 50-60 |
| 湿沙贮藏（室温） | 7天 | 20-30 |
| 湿沙贮藏（室温） | 10天 | <10 |
| 4°C湿沙贮藏 | 15天 | 50-60 |
| 4°C保湿密封 | 20天 | 30-40 |

**结论**：种子宜**随采随播**，最多不超过5天。

### 播种技术

| 项目 | 要求 |
|------|------|
| **播种时间** | 5-6月（早熟品种种子）或6-7月（中晚熟品种） |
| **播种方式** | 条播或撒播 |
| **播种深度** | 2-3cm |
| **行距** | 20-25cm |
| **株距** | 5-8cm |
| **覆土** | 细土+草木灰混合覆盖 |
| **浇水** | 播后立即浇透水 |
| **遮荫** | 搭遮光率50%的遮阳网 |

### 苗期管理

| 管理项目 | 时间 | 操作要求 |
|---------|------|---------|
| **发芽期** | 播种后10-15天 | 保持土壤湿润，防积水 |
| **第一次施肥** | 幼苗展开2-3片真叶（约30天） | 0.3%尿素+0.2%复合肥液 |
| **间苗** | 苗高10-15cm | 去弱留强，株距15cm |
| **第二次施肥** | 间苗后 | 0.5%复合肥液 |
| **除草** | 每月1次 | 人工拔除，勿伤苗根 |
| **病虫害防治** | 根据发生情况 | 防治炭疽病、蚜虫 |
| **苗木分级** | 苗高30-40cm | 一级苗（粗度>0.6cm）和二级苗 |

### 砧木标准
| 砧木品系 | 嫁接适宜粗度(cm) | 嫁接适宜苗龄 | 主要特点 |
|---------|----------------|------------|---------|
| 黑叶 | 0.7-1.0 | 12-18个月 | 生长旺，亲和性好 |
| 山枝（野生荔枝） | 0.6-0.8 | 18-24个月 | 耐旱耐瘠，生长慢 |
| 龙荔 | 0.8-1.2 | 12-24个月 | 抗涝性强 |
| 大花荔枝 | 0.6-0.9 | 12-18个月 | 耐寒性强 |

## 三、嫁接繁殖

### 嫁接原理
荔枝嫁接成功的关键在于**砧木和接穗的维管束形成层紧密结合**。荔枝是嫁接较难成活的果树之一，需要精细操作。

### 砧木选择

| 砧木类型 | 来源 | 优点 | 缺点 |
|---------|------|------|------|
| **黑叶种子苗** | 常见品种 | 生长快，根系发达，亲和性好 | 种子来源有限 |
| **山枝（野生荔枝）** | 山地野生 | 耐旱耐瘠，亲和性好 | 生长较慢 |
| **龙荔种子苗** | 龙荔 | 抗涝性强 | 面积不宜过大 |
| **红皮荔枝** | 品种群 | 生长一致性好 | 种子较小 |

### 接穗采集与处理

| 接穗要求 | 标准 |
|---------|------|
| **采穗母树** | 品种纯正、丰产稳产、无病虫害的成年树 |
| **采穗时间** | 嫁接前1-3天（随采随接最好） |
| **枝梢选择** | 生长充实、芽饱满的秋梢或春梢 |
| **枝梢粗度** | 直径0.5-0.8cm |
| **枝梢长度** | 20-30cm |
| **贮藏方法** | 湿布包裹+保鲜袋，4-8°C可保存3-5天 |
| **接穗消毒** | 70%酒精擦拭表面 |

### 嫁接时期

| 地区 | 最佳嫁接期 | 说明 |
|------|----------|------|
| 广东 | 3-4月（春接） | 气温回升，形成层开始活跃 |
| 广东 | 9-10月（秋接） | 秋梢老熟后，温度适宜 |
| 海南 | 1-3月 | 避开高温和雨季 |
| 福建 | 3-4月、10-11月 | 避开低温期 |
| 云南 | 3-4月 | 春季气温回升后 |

**最适嫁接条件**：
- 气温：20-28°C
- 湿度：85-90%
- 天气：无风阴天
- 砧木：处于生长活跃期（树液流动期）

### 嫁接方法

#### 1. 切接法（最常用）
```
步骤1：砧木处理——在离地15-20cm处剪砧，从断面一侧纵切2-3cm
步骤2：接穗处理——选择有2-3个饱满芽的接穗段，下端削成2-3cm长的楔形切面
步骤3：插入接穗——将接穗楔形插入砧木切口，对齐形成层（至少一侧对齐）
步骤4：绑扎——用嫁接膜从下往上绑扎，密封切口
步骤5：保湿——接穗顶端涂接蜡或包膜保湿
```

#### 2. 腹接法（补接用）
```
步骤1：砧木处理——在砧木光滑处向下斜切一刀（深达木质部）
步骤2：接穗处理——削成舌形（一面长切面2-3cm，一面短切面0.5-1cm）
步骤3：插入接穗——将接穗长切面朝砧木木质部插入
步骤4：绑扎——用嫁接膜密封切口
```

#### 3. 芽接法（T字形芽接）
```
步骤1：砧木处理——在砧木光滑处开T形切口
步骤2：取芽片——从接穗上削取盾形芽片（含一个芽和少量木质部）
步骤3：插入芽片——将芽片插入T形切口，对齐形成层
步骤4：绑扎——露出芽眼，其余部分密封
```

### 嫁接后管理

| 管理项目 | 时间 | 操作内容 |
|---------|------|---------|
| **检查成活** | 嫁接后15-20天 | 接穗芽膨大、叶柄脱落为成活标志 |
| **补接** | 嫁接后25-30天 | 未成活株及时补接 |
| **解绑** | 嫁接后40-50天 | 用刀片划断嫁接膜（勿伤苗） |
| **除萌** | 随时 | 抹除砧木上抽生的萌蘖，每7-10天1次 |
| **立支柱** | 新梢长20-30cm | 竹竿支撑，防止风折 |
| **肥水管理** | 新梢萌发后 | 每15天施0.5%复合肥液1次 |
| **整形** | 苗高50-60cm | 摘心促分枝，培养3-4个主枝 |
| **病虫害防治** | 新梢期 | 喷药防治蚜虫、卷叶蛾 |

### 嫁接成活率影响因素

| 因素 | 最佳条件 | 失败原因 |
|------|---------|---------|
| **砧木质量** | 粗度0.7-1.0cm，生长旺盛 | 砧木过细/过弱 |
| **接穗质量** | 芽饱满，木质化程度中等 | 接穗过老/过嫩 |
| **嫁接技术** | 削面平滑，形成层对齐 | 削面不平/错位 |
| **绑扎密封** | 严密不透气不进水 | 密封不严/进水 |
| **嫁接时期** | 20-28°C，高湿度 | 温度过低/过高/大风干燥 |
| **接口湿度** | 保持90%以上 | 接穗失水干枯 |
| **砧穗亲和力** | 同种嫁接（荔枝接荔枝） | 种间嫁接常不亲和 |

## 四、空中压条（高压繁殖）

### 适应范围
空中压条适用于：
1. 优良母树的少量繁殖
2. 庭院园艺
3. 难以嫁接成活的品种
4. 快速获得结果树（2-3年结果）

### 操作流程

| 步骤 | 时间 | 操作方法 |
|------|------|---------|
| **选择枝条** | 3-4月或7-8月 | 选择直径1.5-2.5cm、生长健壮的2-3年生枝条 |
| **环状剥皮** | 压条当天 | 在枝条光滑处上下环割2圈（间距2-3cm），剥去皮层 |
| **刮除形成层** | 剥皮后 | 用小刀刮去露出的形成层（防止愈伤连接） |
| **涂抹生根剂** | 刮除形成层后 | 涂50-100ppm NAA或IBA溶液 |
| **包裹基质** | 涂生根剂后立即 | 用湿苔藓或湿椰糠包裹环剥处（直径8-10cm球状） |
| **包裹塑料膜** | 包裹基质后 | 用透明塑料膜包裹保湿，上下扎紧 |
| **检查发根** | 60-90天后 | 透过塑料膜观察根系生长情况 |
| **剪离母树** | 根系发育良好时 | 从包裹体下方剪断枝条 |
| **假植** | 剪离后立即 | 栽入营养袋（保持湿润和遮荫） |

### 不同时期高压的发根效果

| 压条时期 | 发根率(%) | 发根天数 | 根系质量 |
|---------|----------|---------|---------|
| 3-4月（春） | 85-95 | 80-100天 | 根系发达 |
| 7-8月（夏-秋） | 75-85 | 60-80天 | 根系中等 |
| 10-11月（秋-冬） | 50-65 | 100-120天 | 根系较弱 |

### 高压苗的优缺点
| 项目 | 优点 | 缺点 |
|------|------|------|
| **结果年龄** | 定植后2-3年开始结果 | - |
| **根系** | - | 无主根，须根多但浅 |
| **寿命** | - | 较嫁接苗短（20-30年） |
| **移植成活率** | - | 较低，需精细管理 |
| **抗风力** | - | 较差，易倒伏 |

## 五、组织培养繁殖

### 适用领域
1. **优良品种的快速扩繁**（年繁殖系数可达10⁴-10⁶）
2. **脱毒苗生产**（茎尖培养去除病毒）
3. **种质资源保存**（超低温保存）
4. **遗传转化研究**

### 基本流程

| 阶段 | 内容 | 培养基 | 培养条件 |
|------|------|-------|---------|
| **外植体消毒** | 茎尖(0.3-0.5mm)或腋芽 | 75%酒精30s+0.1%升汞5min | 超净工作台 |
| **初代培养** | 诱导芽萌发 | MS+BA 0.5-2.0mg/L+NAA 0.1mg/L | 25±2°C，光16h/d |
| **继代培养** | 增殖扩繁 | MS+BA1.0mg/L+KT0.5mg/L | 每4-6周继代1次 |
| **生根培养** | 诱导生根 | 1/2MS+IBA 1.0mg/L+NAA0.5mg/L | 黑暗培养1周后见光 |
| **炼苗** | 适应自然条件 | - | 逐步降低湿度，7-10天 |
| **移栽** | 移入营养袋 | 泥炭:珍珠岩=3:1 | 保湿遮荫 |

### 组培苗管理要点
- 移栽基质需消毒（高温或药剂消毒）
- 移栽后前2周保持相对湿度>90%
- 逐步降低湿度，适应期10-15天
- 移栽成活率一般60-80%

## 六、苗木出圃标准

### 嫁接苗质量标准（参照行业标准）

| 级别 | 苗高(cm) | 茎粗(cm) | 枝条数量 | 根系状况 | 嫁接口愈合 |
|------|---------|---------|---------|---------|----------|
| **一级苗** | >60 | >0.8 | 3-4条健壮分枝 | 3条以上侧根发达 | 愈合良好 |
| **二级苗** | 40-60 | 0.6-0.8 | 2-3条分枝 | 2-3条侧根 | 愈合良好 |
| **三级苗** | 30-40 | 0.4-0.6 | 1-2条分枝 | 1-2条侧根 | 基本愈合 |

### 出圃要求
1. **苗龄**：嫁接苗12-24个月，高压苗9-12个月
2. **检疫**：无检疫性病虫害
3. **品种纯度**：≥95%
4. **包装**：带土球（直径15-20cm）或营养袋苗
5. **运输**：保湿、防晒、防挤压

### 苗木假植
- 不能及时定植的苗木需假植
- 假植方法：开沟斜埋（与地面成45°角），覆土至苗高2/3
- 假植时间不超过30天
- 假植期间保持土壤湿润
