# 荔枝秋梢肥施用技术

## 摘要

秋梢是荔枝翌年的结果母枝，秋梢的健壮程度直接影响花芽分化和来年产量。秋梢肥的合理施用是培养优质结果母枝的关键。本文系统阐述了荔枝秋梢的生长发育规律和营养需求特点，详细介绍了秋梢肥的施用时期、肥料种类选择、施肥量确定、施肥方法和配套管理技术，分析了不同树龄、树势和品种的差异化施肥策略，并提供了秋梢肥施用效果的评价方法。

## 一、秋梢的生长发育与营养需求

### 1.1 秋梢的重要性

秋梢是荔枝翌年最主要的结果母枝，其质量直接影响花芽分化和开花结果。

| 秋梢质量指标 | 优质秋梢 | 劣质秋梢 |
|------------|---------|---------|
| 长度(cm) | 15-25 | <10或>30 |
| 粗度(cm) | 0.4-0.6 | <0.3 |
| 节间长度(cm) | 2-4 | >5 |
| 叶片数(片) | 8-12 | <6 |
| 老熟程度 | 充分老熟 | 未老熟或过嫩 |
| 病虫害状况 | 无 | 有 |

### 1.2 秋梢的营养需求

| 养分元素 | 秋梢吸收比例(%) | 功能 |
|---------|--------------|------|
| 氮(N) | 40-45 | 促进新梢伸长和叶片生长 |
| 磷(P₂O₅) | 20-25 | 促进根系生长和枝梢充实 |
| 钾(K₂O) | 20-30 | 促进枝条老熟和养分积累 |
| 钙(Ca) | 5-8 | 增强枝条韧性 |
| 镁(Mg) | 3-5 | 促进光合作用 |

## 二、秋梢肥的施用时期

### 2.1 最佳施用时期

| 秋梢类型 | 放梢时间 | 施肥时间 | 品种适用 |
|---------|---------|---------|---------|
| 第一次秋梢 | 7月中旬-8月上旬 | 采果后立即施用 | 早熟品种 |
| 第二次秋梢 | 8月下旬-9月中旬 | 第一次梢老熟后 | 中晚熟品种 |
| 秋梢(一次放梢) | 8月 | 采果后(7月) | 结果量大的树 |

### 2.2 时间安排原则

1. **采后及时：** 采果后7天内施完，越早越好
2. **梢前施用：** 放梢前10-15天施肥，为抽梢储备养分
3. **梢后追补：** 新梢抽出后根据生长情况追肥
4. **老熟前控肥：** 枝梢老熟前15-20天停止追氮

## 三、肥料选择与配比

### 3.1 肥料种类

| 肥料类型 | 推荐肥料 | 作用特点 |
|---------|---------|---------|
| 速效氮肥 | 尿素、碳酸氢铵 | 快速供氮，促进抽梢 |
| 磷肥 | 过磷酸钙、钙镁磷肥 | 促进根系和枝梢充实 |
| 钾肥 | 硫酸钾、氯化钾 | 促进枝条老熟 |
| 有机肥 | 腐熟猪粪、牛粪、鸡粪 | 长效改良土壤 |
| 复合肥 | 荔枝专用复合肥 | 养分全面均衡 |

### 3.2 推荐配比

| 树龄 | N:P₂O₅:K₂O配比 | 推荐肥料组合 |
|------|--------------|-------------|
| 幼树(1-3年) | 1:0.5:0.5 | 尿素+过磷酸钙+硫酸钾 |
| 初果树(4-6年) | 1:0.4:0.8 | 复合肥(15-8-18)+有机肥 |
| 盛果树(7年以上) | 1:0.4:1.0 | 复合肥(12-6-20)+有机肥 |
| 高产树 | 1:0.3:1.2 | 复合肥(10-5-25)+有机肥 |

## 五、施肥方法

### 5.1 施肥位置

| 树龄 | 施肥位置 | 施肥深度(cm) |
|------|---------|------------|
| 幼树 | 树冠投影外围 | 15-25 |
| 成年树 | 树冠滴水线附近 | 20-30 |
| 大树 | 树冠投影内1/2-2/3处 | 25-35 |

### 5.2 施肥方式

| 方式 | 操作 | 适用条件 |
|------|------|---------|
| 条状沟施 | 沿树冠两侧开沟 | 平地果园 |
| 环状沟施 | 树冠滴水线开环形沟 | 幼树、缓坡地 |
| 放射状沟施 | 自树干向外辐射开沟 | 大树、粘重土壤 |
| 穴施 | 挖4-6个穴 | 树冠投影范围内 |
| 撒施覆土 | 均匀撒施后翻耕 | 密植园、根系浅 |

### 5.3 施肥步骤

1. 开沟（沟深20-30cm，宽15-20cm）
2. 底层施有机肥（与土混合）
3. 中层施磷肥
4. 上层施氮钾肥
5. 覆土填平
6. 灌水促进肥料溶解

## 六、配套管理措施

### 6.1 水分管理

| 阶段 | 管理措施 |
|------|---------|
| 施肥后 | 充分灌水，促进肥料溶解吸收 |
| 抽梢期 | 保持土壤湿润，每5-7天灌水1次 |
| 梢生长中期 | 保持湿润，防干旱 |
| 梢老熟期 | 减少灌水，促进枝条充实 |

### 6.2 修剪配合

| 修剪措施 | 作用 |
|---------|------|
| 采果后立即回缩修剪 | 刺激新梢抽生 |
| 疏除过密枝 | 集中营养供给保留枝梢 |
| 短截病虫枝 | 减少养分消耗 |
| 抹除多余芽 | 选留健壮新梢 |

### 6.3 病虫害防治

| 防治对象 | 防治措施 | 防治时期 |
|---------|---------|---------|
| 尺蠖 | 高效氯氟氰菊酯 | 新梢抽出3-5cm |
| 卷叶蛾 | 甲维盐 | 新梢生长期 |
| 炭疽病 | 咪鲜胺 | 新梢抽生期 |
| 红蜘蛛 | 阿维菌素 | 秋梢生长期 |

## 七、不同品种的秋梢肥方案

| 品种 | 放梢时间 | N:P₂O₅:K₂O | 特殊要求 |
|------|---------|----------|---------|
| 妃子笑 | 7月中旬 | 1:0.4:0.7 | 氮肥稍多，促发新梢 |
| 桂味 | 7月下旬-8月上旬 | 1:0.5:1.0 | 重视钾肥，提高枝条充实度 |
| 糯米糍 | 7月下旬 | 1:0.4:1.0 | 控氮增钾，防枝条徒长 |
| 鸡嘴荔 | 7月下旬-8月上旬 | 1:0.4:0.8 | 平衡施肥 |
| 怀枝 | 7月下旬 | 1:0.3:0.6 | 氮肥适当增加 |

## 八、秋梢肥施用效果评价

| 评价指标 | 合理施肥 | 施肥不足 | 施肥过量 |

| 新梢长度(cm) | 15-25 | <12 | >30 |
