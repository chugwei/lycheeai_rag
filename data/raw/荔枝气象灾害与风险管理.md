# 荔枝气象灾害与风险管理

> 荔枝生长期长，在年生长周期中面临多种气象灾害威胁。系统了解各类灾害的成因、影响和应对措施，是保障荔枝生产安全的重要前提。

---

## 一、荔枝主要气象灾害总览

| 灾害类型 | 发生频率 | 危害程度 | 影响面积 | 主要发生期 | 关键敏感物候期 |
|---------|---------|---------|---------|-----------|-------------|
| **低温冻害** | 中（3-5年1次） | 高 | 大面积 | 12-2月 | 花芽分化期 |
| **倒春寒** | 中（2-3年1次） | 高 | 中面积 | 2-4月 | 花穗期、开花期 |
| **高温热害** | 中高（1-2年1次） | 中 | 中面积 | 5-7月 | 果实发育期 |
| **台风** | 高（1-2年1次） | 高 | 局部 | 6-10月 | 成熟期、秋梢期 |
| **暴雨洪涝** | 高（1-2年1次） | 中高 | 局部 | 5-9月 | 果实期 |
| **干旱** | 中（2-3年1次） | 中 | 中面积 | 7-12月 | 秋梢期、花芽分化期 |
| **冰雹** | 低（5-10年1次） | 极高 | 局部 | 3-5月 | 花穗期、幼果期 |
| **龙舟水** | 年际（每年） | 中 | 大面积 | 5-6月 | 果实膨大-成熟期 |

## 二、低温冻害

### 冻害分级标准

| 等级 | 日最低温(°C) | 持续时间 | 危害症状 |
|------|------------|---------|---------|
| **轻冻害** | 0至-2 | 2-4小时 | 叶片边缘冻伤，嫩梢萎蔫 |
| **中冻害** | -2至-3 | 4-8小时 | 叶片全部冻伤变褐，1年生枝冻伤 |
| **重冻害** | -3至-4 | >8小时 | 2-3年生枝冻伤，主干皮层开裂 |
| **极重冻害** | < -4 | >12小时 | 全株死亡或地上部全部冻死 |

### 不同品种耐寒性

| 耐寒等级 | 品种 | 临界致死温度(°C) |
|---------|------|----------------|
| **强** | 黑叶、妃子笑 | -4至-3 |
| **中** | 桂味、白糖罂 | -3至-2 |
| **弱** | 糯米糍、增城挂绿 | -2至-1 |
| **极弱** | 三月红 | -1至0 |

### 防冻措施

| 措施 | 操作方法 | 效果 | 成本 |
|------|---------|------|------|
| **树干涂白** | 生石灰+硫磺+食盐涂干1.0-1.5m | 减少昼夜温差 | 低 |
| **培土护根** | 根颈培土20-30cm高 | 保护根颈和嫁接口 | 低 |
| **覆盖防寒布** | 树冠覆盖防寒布或编织袋 | 提高树冠温度1-3°C | 中 |
| **熏烟** | 果园堆放湿草+锯末熏烟 | 提高果园温度1-2°C | 低 |
| **灌水防冻** | 冻前灌透水 | 利用水热容量缓冲 | 低 |
| **喷施防冻剂** | 植物防冻剂按说明喷施 | 提高细胞抗寒性 | 低 |
| **搭建防寒棚** | 小树搭建简易防寒棚 | 有效保护幼树 | 高 |

### 冻后恢复措施
1. **冻后修剪**：冻害稳定后（2-3周），剪除冻死枝条
2. **伤口处理**：大剪口涂抹愈合剂
3. **追肥**：冻后追施速效肥（0.3%尿素叶面喷施）
4. **防日灼**：冻后树皮开裂处涂抹石灰浆（防止日灼）
5. **补植**：严重冻死树清理补植

## 三、倒春寒

### 定义与危害
倒春寒是指春季气温回暖后（3-4月）突然出现持续低温（<10°C）的天气现象。

| 物候期 | 危害温度 | 危害机制 | 后果 |
|-------|---------|---------|------|
| 花穗期(2-3月) | <10°C | 花穗生长停止 | 花穗短小，花量减少 |
| 开花期(3-4月) | <15°C | 花粉萌发受阻，昆虫活动减少 | 授粉不良，坐果率低 |
| 幼果期(4-5月) | <12°C | 幼果发育停滞 | 落果增加 |

### 防范措施
1. **花期预报**：关注天气预报，提前准备防寒物资
2. **喷施防冻剂**：低温来临前1-2天喷施植物防冻剂
3. **覆盖遮阳网**：抵御低温+防冷雨
4. **花期增温**：果园熏烟
5. **叶面补肥**：低温后喷0.3%磷酸二氢钾+0.2%硼砂

## 四、台风灾害

### 风害分级

| 风级 | 风速(m/s) | 危害程度 | 主要危害 |
|------|----------|---------|---------|
| 6-7级 | 10.8-17.1 | 轻度 | 落果5-10%，枝叶损伤 |
| 8-9级 | 17.2-24.4 | 中度 | 落果10-30%，断枝 |
| 10-11级 | 24.5-32.6 | 重度 | 落果30-60%，断干，倒伏 |
| 12级以上 | >32.6 | 极重度 | 落果60%以上，全园破坏 |

### 台风防御措施

#### 台风前预防
| 措施 | 操作 | 时间 |
|------|------|------|
| 立支柱 | 老年树、浅根树用支架加固 | 台风季前 |
| 修剪 | 疏除过密枝，降低风阻 | 台风季前 |
| 排水沟清理 | 清理排水沟，确保排水畅通 | 台风雨前 |
| 果实抢收 | 成熟度8成以上的果实抢收 | 台风来临前 |
| 加固设施 | 加固防虫网、避雨棚等设施 | 台风来临前 |

#### 台风后恢复
| 措施 | 操作 | 时间 |
|------|------|------|
| 排水 | 及时排除果园积水 | 台风过后立即 |
| 扶正倒树 | 倒伏树尽快扶正并支撑 | 24小时内 |
| 修剪 | 剪除断枝、撕裂枝、病枝 | 3天内 |
| 伤口处理 | 大伤口涂抹愈合剂或波尔多浆 | 修剪后立即 |
| 叶面追肥 | 0.3%尿素+0.2%磷酸二氢钾 | 台风后3-5天 |
| 病虫害防治 | 台风后易发霜疫霉病和炭疽病 | 台风后立即喷药 |

## 五、暴雨洪涝

### 危害机理
| 积水时间 | 危害 | 恢复能力 |
|---------|------|---------|
| <12小时 | 基本无影响 | 完全恢复 |
| 12-24小时 | 部分须根受损 | 3-5天恢复 |
| 24-48小时 | 大量须根坏死 | 1-2周恢复 |
| 48-72小时 | 粗根受损，叶片黄化 | 2-4周恢复 |
| >72小时 | 根系严重坏死，可能导致死亡 | 难以恢复 |

### 涝害预防与救治
| 阶段 | 措施 |
|------|------|
| **预防** | 起垄栽培(高20-30cm)；排水沟系统完善；雨季前清沟 |
| **抢排** | 积水后立即启动排水设备，24小时内排净 |
| **雨后管理** | 松土增氧（浅松5-10cm） |
| **追肥** | 排涝后喷0.2%磷酸二氢钾+0.1%尿素促进恢复 |
| **防病** | 涝后喷70%代森锰锌600倍液或50%多菌灵500倍液防病 |
| **促根** | 灌施生根剂（如萘乙酸20ppm或商品生根剂） |

## 六、干旱灾害

### 干旱分级与影响

| 干旱等级 | 持续无雨天数 | 土壤含水量(%) | 影响 |
|---------|-----------|-------------|------|
| 轻度干旱 | 10-15天 | 15-18 | 新梢生长减缓 |
| 中度干旱 | 15-25天 | 10-15 | 叶片卷曲，果实膨大受阻 |
| 重度干旱 | 25-40天 | 8-10 | 叶片脱落，枝梢枯死 |
| 极重干旱 | >40天 | <8 | 树体严重受损 |

### 抗旱措施
1. **灌溉**：滴灌/沟灌/穴灌（见《荔枝水分与灌溉管理.md》）
2. **覆盖**：树盘覆盖稻草/地膜（减少蒸发40-70%）
3. **松土**：雨后立即松土，切断毛细管
4. **抗旱剂**：喷施黄腐酸、旱地龙等抗旱剂
5. **灌施保水剂**：土壤施用聚丙烯酰胺(PAM)等保水剂

## 七、龙舟水与连续阴雨

### 灾害特征
| 项目 | 描述 |
|------|------|
| **时间** | 5月下旬-6月中旬（端午节前后）|
| **特点** | 连续10-20天阴雨，降雨量大 |
| **危害1** | **霜疫霉病暴发**（最严重危害） |
| **危害2** | 授粉受阻（花期遇雨）|
| **危害3** | 裂果增多 |
| **危害4** | 光照不足→光合减弱→品质下降 |

### 防御措施
1. **抢晴喷药**：雨停间隙立即喷施杀菌剂（保护性+内吸性）
2. **排水防渍**：清理排水系统，确保不积水
3. **果实套袋**：保护果实免受雨水直接接触
4. **覆地膜**：树盘覆盖地膜，减少土壤水分和初侵染源
5. **补充光照**：有条件的使用植物补光灯

## 八、高温热害

### 热害分级

| 等级 | 日最高温(°C) | 持续天数 | 危害 |
|------|------------|---------|------|
| 轻度 | 33-35 | 3-5天 | 叶片萎蔫，光合受抑 |
| 中度 | 35-37 | 5-7天 | 日灼果，落果增加 |
| 重度 | 37-40 | >7天 | 大量落果，叶片焦枯 |

### 高温防御
1. **叶面喷水**：高温时段叶面喷水降温（2-5°C）
2. **树盘覆盖**：覆盖稻草/地膜降低地温
3. **遮阳网**：果园覆盖遮光率30-50%的遮阳网
4. **增施钾肥**：钾肥提高细胞渗透调节能力
5. **套袋防日灼**：用浅色袋套果，反射强光
6. **生草栽培**：行间生草降低地表温度

## 九、冰雹灾害

### 危害特点
| 项目 | 描述 |
|------|------|
| **发生季节** | 3-5月（花穗至幼果期） |
| **危害部位** | 叶片破损、花穗折断、幼果脱落、枝干损伤 |
| **危害程度** | 轻度（雹粒<1cm）：局部损伤；重度（雹粒>2cm）：毁灭性 |

### 防雹与补救
| 阶段 | 措施 |
|------|------|
| **预警** | 关注气象预报，雹灾预警期做好防护 |
| **防雹网** | 重点果园搭建防雹网（成本较高） |
| **雹后修剪** | 剪除破损枝、断枝、脱皮枝 |
| **伤口处理** | 大伤口涂抹愈合剂 |
| **喷药防病** | 冰雹造成大量伤口→立即喷杀菌剂 |
| **追肥恢复** | 叶面喷0.3%尿素+0.2%磷酸二氢钾 |

## 十、农业保险

### 保险类型
| 险种 | 保障范围 | 保费补贴比例(%) | 赔付标准 |
|------|---------|--------------|---------|
| **荔枝种植保险** | 气象灾害、病虫害 | 中央+省+市县80% | 按产量损失比例赔付 |
| **荔枝价格保险** | 价格下跌风险 | 省+市县70% | 低于目标价时补差 |
| **荔枝收入保险** | 产量+价格双重风险 | 试点地区 | 综合保障 |
| **气象指数保险** | 特定气象指标触发 | 试点地区 | 指数达标自动赔付 |

### 投保建议
1. **主栽品种全部投保**（保费低，保障高）
2. **山地果园重点投保**（灾损风险高）
3. **防重于赔**（保险与防灾措施结合）

## 附录：气象灾害应急预案

### 灾害预警响应流程
```
气象预警发布 → 启动应急预案 → 物资准备到位 
→ 采取预防措施 → 灾后评估 → 恢复管理
```

### 各灾害应急响应一览

| 灾害 | 预警-24h | 预警-12h | 预警-6h | 灾后24h | 灾后1周 |
|------|---------|---------|---------|---------|---------|
| **台风** | 检查加固、抢收 | 清沟排水 | 人员和设备撤离 | 排水+扶正 | 修剪+防病 |
| **低温** | 灌水+覆盖 | 熏烟堆准备 | 开始熏烟 | 检查冻害 | 修剪+追肥 |
| **暴雨** | 清沟排水 | - | - | 排水+松土 | 防病+追肥 |
| **冰雹** | - | - | 覆盖保护 | 修剪+伤口处理 | 防病+追肥 |
| **高温** | 准备喷水设备 | - | 开启灌溉 | 持续降温 | - |
